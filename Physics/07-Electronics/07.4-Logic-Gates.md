# Logic Gates

## Definition

Digital building blocks operating on binary signals (0/1):

| Gate | Boolean | Output is 1 when… |
|------|---------|-------------------|
| AND | $A\cdot B$ | both inputs 1 |
| OR | $A + B$ | either input 1 |
| NOT | $\overline{A}$ | input is 0 |
| NAND | $\overline{A\cdot B}$ | not both 1 |
| NOR | $\overline{A+B}$ | neither 1 |
| XOR | $A \oplus B$ | inputs differ |

**NAND is universal** — every other gate can be built from NAND gates alone.

## The Intuition

Logic gates are switches with rules. NAND's universality is why NAND flash dominates storage: one physical structure encodes all logic.

## The Physics

| Quantity | Notes |
|----------|-------|
| Boolean algebra | laws: De Morgan, distributivity |
| Truth tables | exhaustive 0/1 listing |
| Universal gates | NAND and NOR each suffice |
| Voltage levels | 0 = low (≈0 V), 1 = high (≈$V_{CC}$) |

## Derivation

De Morgan's laws $\overline{A\cdot B} = \overline{A}+\overline{B}$ and $\overline{A+B} = \overline{A}\cdot\overline{B}$ let you push NOTs through expressions — verified by truth tables. Universality of NAND: $\overline{A} = A\text{ NAND }A$, $A\cdot B = \overline{A\text{ NAND }B}$, $A+B = \overline{A}\cdot\overline{B}$. [Full derivations: [[07.5-Digital-Systems]]]

## Method

1. Write the Boolean expression from the gate diagram.
2. Simplify with Boolean laws / De Morgan.
3. Build the truth table by enumerating all input combinations.

## Worked Examples

**Setup:** Truth table for $Y = \overline{A\cdot B}$ (NAND).

**Solution:** $Y = 1$ except when $A = B = 1$ (then $Y = 0$).

**Key insight:** NAND is AND followed by NOT — three 1s and one 0.

---

**Setup:** Express OR using only NAND gates.

**Solution:** $A + B = \overline{\overline{A}\cdot\overline{B}}$ = NAND(NAND($A$,$A$), NAND($B$,$B$)).

**Key insight:** Universality — one gate type builds all logic.

## Common Traps

- NAND/NOR inversion — forgetting the NOT
- De Morgan: the bar "breaks" and the operator flips (AND ↔ OR)
- XOR vs OR — XOR requires inputs to *differ*
- Mixing positive-logic and negative-logic conventions
