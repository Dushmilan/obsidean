# Operational Amplifiers

## Definition

A high-gain differential amplifier used with negative feedback. **Ideal op-amp rules:**
- Input current = 0 (infinite input impedance).
- $V_+ = V_-$ (virtual short, when feedback is present).

| Configuration | Gain |
|---------------|------|
| Inverting | $-\dfrac{R_f}{R_1}$ |
| Non-inverting | $1 + \dfrac{R_f}{R_1}$ |
| Voltage follower | 1 |

## The Intuition

The op-amp is a machine that drives its output to make the two inputs equal — with feedback it "forces" $V_+ = V_-$. Gain is set entirely by resistor ratios, not by the chip: stable, predictable, and immune to component tolerances.

## The Physics

| Quantity | Equation | Notes |
|----------|----------|-------|
| Inverting gain | $G = -\frac{R_f}{R_1}$ | inverts + amplifies |
| Non-inverting gain | $G = 1 + \frac{R_f}{R_1}$ | never inverts |
| Follower | $G = 1$ | buffer |
| Slew/bandwidth | — | real-op-amp limits |

## Derivation

Virtual short: with huge open-loop gain, any input difference is driven to zero. Inverting gain: current through $R_1$ equals current through $R_f$ (input current zero), giving $V_{out} = -V_{in}R_f/R_1$. [Full derivations: [[05.3-Current-Electricity]]]

## Method

1. Apply the two ideal rules ($I_- = 0$, $V_+ = V_-$).
2. Write node currents (Kirchhoff) at the inverting input.
3. Solve for $V_{out}$ in terms of $V_{in}$.

## Worked Examples

**Setup:** Non-inverting amp with $R_f = 90$ kΩ, $R_1 = 10$ kΩ. Gain?

**Solution:** $G = 1 + \frac{90}{10} = 10$. A 0.1 V input → 1 V output. Inverting would give $-9$.

**Key insight:** Gain depends only on resistor ratios — the power of negative feedback.

---

**Setup:** Design a follower to buffer a sensor.

**Solution:** $R_f = 0$ (or no feedback resistor): $G = 1$, infinite input impedance, low output impedance.

**Key insight:** A follower isolates the sensor from the load — it copies the voltage without loading it.

## Common Traps

- The virtual short only holds *with* negative feedback (no feedback → comparator)
- Input current is zero — don't put a resistor in series with an input and expect a drop
- Op-amp outputs can't exceed the supply rails
- Slew rate and bandwidth limit real (non-ideal) op-amps
