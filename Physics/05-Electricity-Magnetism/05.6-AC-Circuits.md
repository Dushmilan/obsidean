# AC Circuits

## Definition

Alternating current with reactance and impedance:

$$Z = \sqrt{R^2 + (X_L - X_C)^2}, \qquad X_L = 2\pi fL, \qquad X_C = \frac{1}{2\pi fC}$$

RMS values: $I_{rms} = \frac{I_0}{\sqrt2}$, $V_{rms} = \frac{V_0}{\sqrt2}$. **Resonance:** $f_0 = \frac{1}{2\pi\sqrt{LC}}$ where $X_L = X_C$ and $Z$ is minimum.

## The Intuition

Inductors and capacitors "fight" AC — inductors oppose current changes, capacitors oppose voltage changes. At resonance their effects cancel, and the circuit behaves as if only the resistor remains: large currents, perfect tuning.

## The Physics

| Quantity | Equation | Units |
|----------|----------|-------|
| Capacitive reactance | $X_C = \frac{1}{2\pi fC}$ | Ω |
| Inductive reactance | $X_L = 2\pi fL$ | Ω |
| Impedance | $Z = \sqrt{R^2 + (X_L - X_C)^2}$ | Ω |
| Resonance | $f_0 = \frac{1}{2\pi\sqrt{LC}}$ | Hz |
| RMS | $V_{rms} = \frac{V_0}{\sqrt2}$ | V |

## Derivation

$X_L = \omega L$ and $X_C = 1/\omega C$ come from the voltage-current relations of ideal inductor/capacitor under sinusoidal drive. Impedance is the vector sum (reactances subtract — they're opposite). Resonance: set $X_L = X_C$. [Full derivations: [[Maths/Pure/01-Algebra/04-Polynomials/04-Polynomials]]]

## Method

1. Compute $X_L$, $X_C$ at the operating frequency.
2. $Z = \sqrt{R^2 + (X_L-X_C)^2}$.
3. Resonance: $X_L = X_C \Rightarrow f_0 = 1/(2\pi\sqrt{LC})$.

## Worked Examples

**Setup:** Series RLC: $R = 100\ \Omega$, $L = 0.1$ H, $C = 100\ \mu$F at 50 Hz. $Z$?

**Solution:** $X_L = 31.4\ \Omega$, $X_C = 31.8\ \Omega$. $Z = \sqrt{100^2 + (31.4-31.8)^2} \approx 100\ \Omega$.

**Key insight:** Near resonance the reactances cancel and $Z \to R$ — useful for tuning, dangerous for power.

---

**Setup:** Find the resonant frequency for $L = 10$ mH, $C = 100$ nF.

**Solution:** $f_0 = \frac{1}{2\pi\sqrt{10^{-2}\times10^{-7}}} = \frac{1}{2\pi\times3.16\times10^{-5}} \approx 5$ kHz.

**Key insight:** Resonance is how radios select one station among thousands.

## Common Traps

- $X_L - X_C$ — they subtract (opposite phase)
- RMS vs peak — power uses RMS; instantaneous uses peak
- Resonance minimizes $Z$ (maximises current), not maximises it
- $X_C$ drops as $f$ rises; $X_L$ rises — easy to invert
