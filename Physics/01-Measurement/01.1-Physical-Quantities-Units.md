# Physical Quantities & Units

## Definition

Physics is built on measurement: every quantity is a **number and a unit**. The SI system defines **seven base quantities**; everything else is derived from them.

| Quantity | Symbol | Unit | Symbol | Defined by |
|----------|--------|------|--------|-----------|
| Length | $l$ | metre | m | $c = 299\,792\,458$ m/s |
| Mass | $m$ | kilogram | kg | $h = 6.62607015\times10^{-34}$ J·s |
| Time | $t$ | second | s | Cs-133 transition (9 192 631 770 periods) |
| Current | $I$ | ampere | A | $e = 1.602176634\times10^{-19}$ C |
| Temperature | $T$ | kelvin | K | $k = 1.380649\times10^{-23}$ J/K |
| Amount | $n$ | mole | mol | $N_A = 6.02214076\times10^{23}$ mol⁻¹ |
| Luminous intensity | $I_v$ | candela | cd | $K_{cd} = 683$ lm/W |

## The Intuition

SI units are a universal language — a kilogram in Colombo is the same kilogram in London. Since 2019 the base units are locked to **exact values of fundamental constants** (speed of light, Planck's constant, elementary charge), so they'll never drift. Derived units decompose into base units: $F = ma$ gives $[MLT^{-2}]$, which is why the newton is kg·m·s⁻².

## The Physics

| Quantity | Equation | Units |
|----------|----------|-------|
| Force | $F = ma$ | N = kg·m·s⁻² |
| Energy | $E = \frac12 mv^2$ | J = kg·m²·s⁻² |
| Power | $P = \frac{E}{t}$ | W = kg·m²·s⁻³ |
| Pressure | $p = \frac{F}{A}$ | Pa = kg·m⁻¹·s⁻² |

**Prefixes** attach directly ($km$, $MHz$, $\mu m$) but **never stack** ($\mu km$ is illegal). Capitalisation changes the prefix: M (mega, $10^6$) vs m (milli, $10^{-3}$).

## Derivation

The newton's dimensions follow from $F = ma$: $[F] = [M][LT^{-2}] = MLT^{-2}$. Every derived unit decomposes this way. [Full derivations: [[01.1-SI-Base-Units-Proofs]]]

## Method

1. **Dimensional homogeneity:** every term in a valid equation must share dimensions — check before algebra.
2. **Converting units:** multiply by conversion factors equal to 1, cancelling units ($72$ km/h $\times \frac{1000\text{ m}}{3600\text{ s}} = 20$ m/s).
3. **Finding dimensions:** isolate the unknown, substitute known dimensions, simplify.

## Worked Examples

**Setup:** Find the dimensions of $G$ from $F = G\frac{m_1m_2}{r^2}$.

**Solution:** $[G] = \frac{[F][r]^2}{[m]^2} = \frac{MLT^{-2}\cdot L^2}{M^2} = M^{-1}L^3T^{-2}$.

**Key insight:** Isolate the unknown, substitute known dimensions, simplify.

---

**Setup:** Verify $T = 2\pi\sqrt{l/g}$ dimensionally.

**Solution:** $[T] = T$; $\sqrt{[l]/[g]} = \sqrt{L/LT^{-2}} = \sqrt{T^2} = T$. Dimensions match.

**Key insight:** Dimensional analysis can't find the $2\pi$ — it only confirms the form.

---

**Setup:** Convert $72$ km/h to m/s.

**Solution:** $72 \times \frac{1000\text{ m}}{3600\text{ s}} = 20$ m/s.

**Key insight:** Multiply by conversion factors that equal 1 — the units cancel where they should.

## Common Traps

- Confusing M (mega, $10^6$) with m (milli, $10^{-3}$) — capitalisation changes the prefix by $10^9$
- Stacking prefixes ($\mu km$) — one prefix per unit
- Forgetting angle is dimensionless (radians/degrees have no base dimensions)
- Writing m/s⁻¹ instead of m·s⁻¹ — the negative exponent belongs to the unit, not the fraction
