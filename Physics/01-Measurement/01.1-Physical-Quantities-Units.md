# 1.1 Physical Quantities & Units

**Syllabus:** GCE A/L Physics (022) — Unit 1, Topic 1.1

---

## 1. Physical Quantities

A **physical quantity** is a property that can be measured and expressed numerically with a unit.

### Classification
| Type | Examples | Characteristics |
|------|----------|-----------------|
| **Base quantities** | Length, Mass, Time, Current, Temperature, Amount, Luminous intensity | 7 fundamental quantities, cannot be expressed in terms of others |
| **Derived quantities** | Velocity, Force, Energy, Power, Pressure, Charge, etc. | Defined from base quantities via physical laws |
| **Supplementary** | Plane angle (rad), Solid angle (sr) | Dimensionless but have special names |

---

## 2. SI Base Units (7)

| Quantity | Symbol | Unit | Symbol | Definition (Current SI, 2019) |
|----------|--------|------|--------|------------------------------|
| Length | $l$ | Metre | m | Distance light travels in vacuum in $1/299\,792\,458$ s |
| Mass | $m$ | Kilogram | kg | Fixed by Planck constant $h = 6.626\,070\,15 \times 10^{-34}$ J·s |
| Time | $t$ | Second | s | $9\,192\,631\,770$ periods of Cs-133 hyperfine transition |
| Electric current | $I$ | Ampere | A | Fixed by elementary charge $e = 1.602\,176\,634 \times 10^{-19}$ C |
| Temperature | $T$ | Kelvin | K | Fixed by Boltzmann constant $k = 1.380\,649 \times 10^{-23}$ J/K |
| Amount of substance | $n$ | Mole | mol | Fixed by Avogadro constant $N_A = 6.022\,140\,76 \times 10^{23}$ mol$^{-1}$ |
| Luminous intensity | $I_v$ | Candela | cd | Luminous efficacy of 540 THz radiation $K_{cd} = 683$ lm/W |

> **Note:** Since 2019, all SI base units are defined by fixing exact values of fundamental constants.

## 5. Homogeneity of Physical Equations

**Principle:** All terms in a physical equation must have the same dimensions.

**Example:** $v = u + at$
- $[v] = [u] =$ LT$^{-1}$
- $[at] =$ LT$^{-2}$·T = LT$^{-1}$ ✓

**Use:** Check correctness of equations, find dimensions of unknown constants.

## 8. Unit Conversion

**Method:** Multiply by conversion factor = 1 (e.g., $1\ \text{km} = 1000\ \text{m}$)

**Example:** $72\ \text{km/h} = 72 \times \frac{1000\ \text{m}}{3600\ \text{s}} = 20\ \text{m/s}$

## 9. Problem Patterns (A/L)

| Pattern | Strategy |
|---------|----------|
| Identify base/derived quantity | Check if defined from base quantities via physical law |
| Convert between units | Use prefix factors, conversion factors = 1 |
| Check equation homogeneity | Compare dimensions of each term |
| Find dimensions of constant | Rearrange equation, substitute known dimensions |
| Express in base units | Substitute derived unit definitions |

## 10. Worked Examples

### Example 1: Dimensions of $G$ (Newton's law)
$F = G\frac{m_1 m_2}{r^2} \Rightarrow [G] = \frac{[F][r]^2}{[m]^2} = \frac{\text{MLT}^{-2}\text{L}^2}{\text{M}^2} = \text{M}^{-1}\text{L}^3\text{T}^{-2}$

### Example 2: Check $T = 2\pi\sqrt{\frac{l}{g}}$
$[T] = \text{T}$, $[2\pi] = 1$, $[\sqrt{l/g}] = \sqrt{\text{L}/\text{LT}^{-2}} = \sqrt{\text{T}^2} = \text{T}$ ✓

### Example 3: Convert $1\ \text{eV}$ to joules
$1\ \text{eV} = 1.602 \times 10^{-19}\ \text{J}$ (by definition)

### Example 4: Dimensions of $\epsilon_0$ (Coulomb's law)
$F = \frac{1}{4\pi\epsilon_0}\frac{q_1 q_2}{r^2} \Rightarrow [\epsilon_0] = \frac{[q]^2}{[F][r]^2} = \frac{\text{A}^2\text{T}^2}{\text{MLT}^{-2}\text{L}^2} = \text{M}^{-1}\text{L}^{-3}\text{T}^4\text{A}^2$

## 11. Common Traps

- ❌ Using compound prefixes (e.g., "μkm", "mmicro")
- ❌ Forgetting to convert all quantities to same unit system before calculating
- ❌ Treating angle as having dimension (it's dimensionless)
- ❌ Confusing prefix symbol case (M = mega, m = milli)
- ❌ Writing "m/s$^{-1}$" instead of "m/s" or "m·s$^{-1}$"
- ❌ Using "sec" instead of "s" for second
