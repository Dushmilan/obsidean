# Dimensional Analysis

## Definition

Every physical quantity has dimensions built from the base set $[M], [L], [T], [I], [\Theta], [N], [J]$. **Dimensional analysis** checks that every term in an equation has the same dimensions — or it's physically wrong.

**Buckingham π theorem:** if quantity $Q$ depends on $n$ variables with $k$ base dimensions, there are $n-k$ independent dimensionless groups. For a power law $Q \propto M^aL^bT^c$, equate exponents to find $a,b,c$.

## The Intuition

Translating a physics equation into another language: if one side talks about "metres" and the other about "kilograms per second", the translation is broken. Dimensions are the **grammar** of physics — they tell you whether an equation is a valid sentence.

## The Physics

| Quantity | Dimensions |
|----------|------------|
| Velocity | $LT^{-1}$ |
| Force | $MLT^{-2}$ |
| Energy | $ML^2T^{-2}$ |
| Pressure | $ML^{-1}T^{-2}$ |
| Charge | $IT$ |
| Resistance | $ML^2T^{-3}I^{-2}$ |

**Dimensionless numbers:** Reynolds $Re = \rho vL/\eta$ (turbulence), Mach $M = v/c$ (compressibility), Froude $Fr = v/\sqrt{gL}$ (open-channel flow).

## Derivation

The dimension exponents come from the defining equations ($F = ma \Rightarrow MLT^{-2}$). Buckingham's theorem follows from the requirement that physical laws be invariant under changes of unit scale. [Full derivations: [[01.4-Buckingham-Pi-Proofs]]]

## Method

1. **Verify an equation:** check every term has the same dimensions.
2. **Derive the form:** list variables and base dimensions, count groups ($n-k$), form dimensionless products, solve.
3. **Convert units:** use the exponents — $1\ \text{N} = 1\ \text{kg·m/s}^2 = 1000\text{ g}\times100\text{ cm/s}^2 = 10^5$ dyn.

## Worked Examples

**Setup:** Check $T = 2\pi\sqrt{L/g}$ dimensionally.

**Solution:** $[T] = T$; $\sqrt{L/LT^{-2}} = \sqrt{T^2} = T$. Consistent.

**Key insight:** Consistency is necessary but not sufficient — a dimensionless factor could still be wrong.

---

**Setup:** The pendulum period depends on $L, g, m, \theta_0$. Find its form.

**Solution:** 5 variables, 3 base dimensions → 2 groups: $\pi_1 = T\sqrt{g/L}$, $\pi_2 = \theta_0$. So $T = \sqrt{L/g}\,f(\theta_0)$; small angles give $f \approx 2\pi$.

**Key insight:** Dimensional analysis narrows the form to one unknown function — theory/experiment fixes it.

## Common Traps

- Trying to find dimensionless constants ($2\pi$, $\frac12$) — dimensional analysis finds the form, not pure numbers
- Confusing same-dimension quantities (work vs torque — both $ML^2T^{-2}$)
- Forgetting angle is dimensionless
- Using the wrong base-dimension set
