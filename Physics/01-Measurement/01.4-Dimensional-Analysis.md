# Dimensional Analysis

**Syllabus:** GCE A/L Physics (022) — Unit 1, Topic 1.4

---

## 1. Dimensions

**Dimension** of a physical quantity: powers to which base quantities must be raised to represent it.

**Base Dimensions:**
| Base Quantity | Symbol | Dimension |
|---------------|--------|-----------|
| Length | $L$ | $[L]$ |
| Mass | $M$ | $[M]$ |
| Time | $T$ | $[T]$ |
| Electric current | $I$ | $[I]$ |
| Temperature | $\Theta$ | $[\Theta]$ |
| Amount of substance | $N$ | $[N]$ |
| Luminous intensity | $J$ | $[J]$ |

**Notation:** $[Q]$ = dimensions of quantity $Q$

## 3. Dimensional Homogeneity

**Principle:** In any physically correct equation, **all terms must have the same dimensions**.

**Examples of homogeneous equations:**
- $s = ut + \frac{1}{2}at^2$ → $[L] = [L T^{-1}][T] + [L T^{-2}][T^2]$ ✓
- $v^2 = u^2 + 2as$ → $[L^2 T^{-2}] = [L^2 T^{-2}] + [L T^{-2}][L]$ ✓
- $F = ma$ → $[M L T^{-2}] = [M][L T^{-2}]$ ✓
- $E = mc^2$ → $[M L^2 T^{-2}] = [M][L T^{-1}]^2$ ✓

**Non-homogeneous (incorrect):**
- $s = ut + a$ → $[L] \neq [L] + [L T^{-2}]$ ✗
- $v = u + at^2$ → $[L T^{-1}] \neq [L T^{-1}] + [L]$ ✗

## 4. Applications

### 4.1 Checking Equations
**Step-by-step:**
1. Write dimensions of each term
2. Verify all terms have identical dimensions
3. If not, equation is dimensionally incorrect

**Example:** Check $T = 2\pi\sqrt{\frac{L}{g}}$ for pendulum period
$$[T] \stackrel{?}{=} \sqrt{\frac{[L]}{[L T^{-2}]}} = \sqrt{[T^2]} = [T] \quad \text{✓}$$

### 4.2 Finding Relationships (Buckingham π Theorem)
If a quantity $Q$ depends on $n$ variables, and $k$ base dimensions involved, there are $n-k$ independent dimensionless groups.

**Procedure:**
1. List all relevant variables with dimensions
2. Form dimensionless products $\pi_i$
3. Express relationship: $\pi_1 = f(\pi_2, \pi_3, \dots)$

**Example:** Period $T$ of pendulum depends on $L, g, m, \theta_0$
Variables: $T([T]), L([L]), g([L T^{-2}]), m([M]), \theta_0([1])$
Base dimensions: $M, L, T$ ($k=3$)
$n=5$ → $n-k=2$ dimensionless groups
$$\pi_1 = T\sqrt{\frac{g}{L}}, \quad \pi_2 = \theta_0, \quad \pi_3 = \frac{m}{m} = 1$$
$$\pi_1 = f(\pi_2) \Rightarrow T = \sqrt{\frac{L}{g}} f(\theta_0)$$
For small $\theta_0$: $f(\theta_0) \approx 2\pi$

### 4.3 Deriving Formulas (Limited)
Can determine **form** but not dimensionless constants.

**Example:** Drag force $F$ on sphere depends on $v, r, \rho, \eta$
$F([M L T^{-2}]), v([L T^{-1}]), r([L]), \rho([M L^{-3}]), \eta([M L^{-1} T^{-1}])$
Assume $F \propto v^a r^b \rho^c \eta^d$
Equate dimensions:
$M: 1 = c + d$
$L: 1 = a + b - 3c - d$
$T: -2 = -a - d$

Solve: $F = \rho v^2 r^2 f\left(\frac{\eta}{\rho v r}\right) = \rho v^2 r^2 f(Re)$
Where $Re = \frac{\rho v r}{\eta}$ is Reynolds number.

### 4.4 Converting Units Between Systems
If $[Q] = [M^a L^b T^c \dots]$, then numerical value $n$ scales as:
$$\frac{n_1}{n_2} = \left(\frac{M_1}{M_2}\right)^a \left(\frac{L_1}{L_2}\right)^b \left(\frac{T_1}{T_2}\right)^c \dots$$

**Example:** Convert 1 N to dyn (CGS)
$[F] = [M L T^{-2}]$
$1 \text{ N} = 1 \text{ kg·m/s}^2 = 1000 \text{ g} \cdot 100 \text{ cm} / 1^2 \text{ s}^2 = 10^5 \text{ dyn}$

## 5. Dimensionless Quantities

| Type | Examples |
|------|----------|
| **Ratios of same dimension** | Strain ($\Delta L/L$), Poisson's ratio, refractive index |
| **Angles** | Radian, steradian, degree |
| **Trigonometric functions** | $\sin\theta, \cos\theta, \tan\theta$ |
| **Exponents/Arguments of log** | $e^x$, $\ln x$, $10^x$ (argument must be dimensionless) |
| **Reynolds number** | $Re = \frac{\rho v L}{\eta}$ |
| **Mach number** | $M = \frac{v}{c}$ |
| **Froude number** | $Fr = \frac{v}{\sqrt{gL}}$ |
| **Prandtl number** | $Pr = \frac{\eta c_p}{k}$ |

---

## 6. Limitations of Dimensional Analysis

| Limitation | Explanation |
|------------|-------------|
| **Cannot find dimensionless constants** | $2\pi$, $\frac{1}{2}$, etc. |
| **Cannot distinguish between quantities with same dimensions** | Work vs torque (both $[M L^2 T^{-2}]$) |
| **Cannot handle dimensionless functions** | $\sin$, $\cos$, $\exp$, $\ln$ require dimensionless args |
| **Cannot derive formulas with sums** | Only power-law relations |
| **Assumes correct variables chosen** | Missing variable → wrong result |

## 7. Problem Patterns (A/L)

| Pattern | Strategy |
|---------|----------|
| Check homogeneity of equation | Write dims of each term, compare |
| Find dimensions of unknown constant | Equate dimensions on both sides |
| Derive relationship between variables | Assume power law, equate exponents |
| Convert between unit systems | Use dimension scaling factors |
| Identify dimensionless groups | Buckingham π method |
| Verify formula by dimensions | Quick check before using |

## 8. Worked Examples

### Example 1: Dimensions of $G$ in $F = G\frac{m_1 m_2}{r^2}$
$$[G] = \frac{[F][r^2]}{[m_1][m_2]} = \frac{[M L T^{-2}][L^2]}{[M][M]} = [M^{-1} L^3 T^{-2}]$$

### Example 2: Check $v = \sqrt{\frac{E}{\rho}}$ for sound speed in fluid
$[v] = [L T^{-1}]$
$\left[\sqrt{\frac{E}{\rho}}\right] = \sqrt{\frac{[M L^{-1} T^{-2}]}{[M L^{-3}]}} = \sqrt{[L^2 T^{-2}]} = [L T^{-1}]$ ✓

### Example 3: Find form of $T$ for mass-spring system
$T$ depends on $m([M])$ and $k([M T^{-2}])$
Assume $T \propto m^a k^b$
$[T] = [M]^a [M T^{-2}]^b = [M^{a+b} T^{-2b}]$
Equate: $a+b=0, -2b=1 \Rightarrow b=-1/2, a=1/2$
$$T \propto \sqrt{\frac{m}{k}}$$

### Example 4: Convert 1 J to erg
$[E] = [M L^2 T^{-2}]$
$1 \text{ J} = 1 \text{ kg·m}^2/\text{s}^2 = 1000 \text{ g} \cdot (100 \text{ cm})^2 / 1^2 = 10^7 \text{ erg}$

### Example 5: Buckingham π for flow in pipe
Variables: $\Delta p, L, D, \rho, v, \eta$ ($n=6$)
Base dims: $M, L, T$ ($k=3$) → 3 π groups
$$\pi_1 = \frac{\Delta p}{\rho v^2}, \quad \pi_2 = \frac{L}{D}, \quad \pi_3 = \frac{\rho v D}{\eta} = Re$$
$$\frac{\Delta p}{\rho v^2} = f\left(\frac{L}{D}, Re\right)$$

---

## 9. Quick Reference

**Base dims:** $M, L, T, I, \Theta, N, J$
**Homogeneity:** All terms in equation must have same dimensions
**Power law:** $[Q] = [M]^a[L]^b[T]^c\dots \Rightarrow Q \propto M^a L^b T^c\dots$
**Buckingham π:** $n$ vars, $k$ dims → $n-k$ dimensionless groups
**Dimensionless:** Ratios, angles, trig args, exponents, $Re$, $M$, $Fr$
**Limitations:** No constants, no sums, can't distinguish same dims
