# 1.4 Dimensional Analysis

Before you solve any equation, you can check whether it even makes sense. Dimensional analysis is that check — every term must have the same dimensions, or the equation is physically wrong.

**The Intuition:** Imagine translating a physics equation into another language. If one side talks about "metres" and the other about "kilograms per second," the translation is broken. Dimensions are the grammar of physics — they tell you whether an equation is a valid sentence.

**The Math:** Each quantity has dimensions built from base dimensions $[M]$, $[L]$, $[T]$, $[I]$, $[\Theta]$, $[N]$, $[J]$. The Buckingham $\pi$ theorem says if $Q$ depends on $n$ variables with $k$ base dimensions, there are $n-k$ independent dimensionless groups. For a power law $Q \propto M^a L^b T^c$, equate exponents on both sides to find $a$, $b$, $c$.

**What does this mean for Physics?** You can verify equations, derive the form of unknown relationships, and convert between unit systems — all without knowing the physics in detail. The limitation: you can't find dimensionless constants like $2\pi$ or $\frac{1}{2}$, and you can't distinguish quantities with the same dimensions (work vs torque).

| Quantity | Dimensions |
|----------|------------|
| Velocity | $LT^{-1}$ |
| Force | $MLT^{-2}$ |
| Energy | $ML^2T^{-2}$ |
| Pressure | $ML^{-1}T^{-2}$ |
| Charge | $IT$ |
| Resistance | $ML^2T^{-3}I^{-2}$ |

---

**Setup:** Check whether $T = 2\pi\sqrt{L/g}$ is dimensionally consistent.

**Solution:** $[T] = T$. $\sqrt{[L]/[g]} = \sqrt{L / LT^{-2}} = \sqrt{T^2} = T$. Both sides match.

**Key insight:** Dimensional consistency is necessary but not sufficient — the equation could still be wrong by a dimensionless factor.

---

**Setup:** The period $T$ of a pendulum depends on length $L$, gravity $g$, mass $m$, and angle $\theta_0$. Find the form of $T$.

**Solution:** 5 variables, 3 base dimensions ($M$, $L$, $T$) → $5 - 3 = 2$ dimensionless groups. $\pi_1 = T\sqrt{g/L}$, $\pi_2 = \theta_0$. So $T = \sqrt{L/g}\,f(\theta_0)$. For small angles, $f(\theta_0) \approx 2\pi$.

**Key insight:** Dimensional analysis narrows the form to a single unknown function — experiment or deeper theory determines that function.

---

**Setup:** Convert 1 newton to CGS units (dynes).

**Solution:** $[F] = [MLT^{-2}]$. $1\ \text{N} = 1\ \text{kg·m/s}^2 = 1000\ \text{g} \times 100\ \text{cm/s}^2 = 10^5\ \text{dyn}$.

**Key insight:** Use the dimension exponents as a guide: multiply by $(M_1/M_2)^a (L_1/L_2)^b (T_1/T_2)^c$.

---

**Dimensionless numbers to know:** Reynolds number $Re = \rho v L / \eta$ (turbulence), Mach number $M = v/c$ (compressibility), Froude number $Fr = v/\sqrt{gL}$ (open-channel flow). These arise naturally from dimensional analysis and tell you which physical regime you're in.

## Common Mistakes

- ❌ Trying to find dimensionless constants (2π, ½) — dimensional analysis only finds the form, not pure numbers
- ❌ Confusing quantities with same dimensions (work vs torque) — both are ML²T⁻² but physically different
- ❌ Forgetting angle is dimensionless — radians, degrees, and solid angles have no base dimensions
- ❌ Using wrong base dimensions — make sure you know which of [M], [L], [T], [I] etc. are needed
