# 1.2 Errors & Uncertainties

**Syllabus:** GCE A/L Physics (022) — Unit 1, Topic 1.2

---

## 1. Types of Errors

| Type | Characteristic | Detection | Correction |
|------|----------------|-----------|------------|
| **Systematic** | Consistent bias, same direction | Calibration, comparison with standard | Apply correction, recalibrate |
| **Random** | Scatter, unpredictable | Repeated measurements, statistics | Average multiple readings, improve precision |

### Examples
- **Systematic:** Zero error, calibration drift, parallax (if consistent), thermal expansion
- **Random:** Human reaction time, electrical noise, environmental fluctuations

---

## 2. Precision vs Accuracy

| Term | Meaning | Related to |
|------|---------|------------|
| **Accuracy** | Closeness to true value | Systematic error |
| **Precision** | Closeness of repeated measurements | Random error |

```
High accuracy, high precision  → Bullseye cluster
High accuracy, low precision   → Scattered around bullseye
Low accuracy, high precision   → Tight cluster away from bullseye
Low accuracy, low precision    → Scattered away from bullseye
```

---

## 3. Uncertainty

**Uncertainty** quantifies the doubt about a measurement result.

### Types
| Type | Source | Evaluation |
|------|--------|------------|
| **Type A** | Statistical analysis of repeated readings | Standard deviation, standard error |
| **Type B** | Other info (calibration cert, spec sheets, experience) | Rectangular, triangular, U-distribution |

### Expressing Uncertainty
- **Absolute:** $\Delta x$ (same units as $x$)
- **Relative:** $\frac{\Delta x}{x}$ (dimensionless)
- **Percentage:** $\frac{\Delta x}{x} \times 100\%$

---

## 4. Estimating Uncertainty

### Single Reading (Analogue)
$$\Delta x = \frac{\text{least count}}{2}$$
or $\Delta x = \text{least count}$ (conservative)

### Single Reading (Digital)
$$\Delta x = \pm 1 \text{ in last digit displayed}$$

### Repeated Readings (Type A)
$$\bar{x} = \frac{1}{n}\sum_{i=1}^n x_i$$
$$\Delta x_{\text{random}} = \frac{\sigma}{\sqrt{n}} \quad \text{(standard error)}$$
$$\sigma = \sqrt{\frac{\sum(x_i - \bar{x})^2}{n-1}} \quad \text{(sample standard deviation)}$$

**Report:** $x = \bar{x} \pm \Delta x$

### Instrument Specification (Type B)
- Rectangular distribution: $\Delta x = \frac{a}{\sqrt{3}}$ where $a$ = half-width
- Example: Voltmeter $\pm 2\%$ reading $\pm 1$ digit → combine both

---

## 5. Propagation of Uncertainties

### General Formula (Differentials)
For $z = f(x, y, \dots)$:
$$\Delta z = \sqrt{\left(\frac{\partial f}{\partial x}\Delta x\right)^2 + \left(\frac{\partial f}{\partial y}\Delta y\right)^2 + \dots}$$

### Common Cases (Maximum Uncertainty Method)

| Operation | Formula | Relative Uncertainty |
|-----------|---------|---------------------|
| $z = x + y$ | $\Delta z = \Delta x + \Delta y$ | — |
| $z = x - y$ | $\Delta z = \Delta x + \Delta y$ | — |
| $z = xy$ | $\Delta z = y\Delta x + x\Delta y$ | $\frac{\Delta z}{z} = \frac{\Delta x}{x} + \frac{\Delta y}{y}$ |
| $z = x/y$ | $\Delta z = \frac{y\Delta x + x\Delta y}{y^2}$ | $\frac{\Delta z}{z} = \frac{\Delta x}{x} + \frac{\Delta y}{y}$ |
| $z = x^n$ | $\Delta z = |n| x^{n-1}\Delta x$ | $\frac{\Delta z}{z} = |n|\frac{\Delta x}{x}$ |
| $z = \sin x$ | $\Delta z = \cos x \cdot \Delta x$ (rad) | — |
| $z = \ln x$ | $\Delta z = \frac{\Delta x}{x}$ | — |
| $z = e^x$ | $\Delta z = e^x \Delta x$ | — |

> **Note:** A/L typically uses maximum uncertainty (sum of absolutes). RSS (root-sum-square) gives probable uncertainty.

### Example: $\rho = \frac{m}{\frac{4}{3}\pi r^3}$
$$\frac{\Delta \rho}{\rho} = \frac{\Delta m}{m} + 3\frac{\Delta r}{r}$$

## 6. Significant Figures

### Rules
1. Non-zero digits significant
2. Zeros between non-zero significant
3. Leading zeros NOT significant
4. Trailing zeros WITH decimal significant
5. Trailing zeros WITHOUT decimal ambiguous → use scientific notation

### In Calculations
- **Add/Subtract:** Result has same **decimal places** as term with fewest
- **Multiply/Divide:** Result has same **significant figures** as factor with fewest
- **Logs:** Mantissa has same sig figs as argument
- **Exact numbers** (counting, definitions): Infinite sig figs

### Rounding
- Round **only final answer**
- If digit to drop $\ge 5$, round up
- If digit to drop $= 5$ exactly, round to even (banker's rounding)

---

## 7. Graphical Treatment of Uncertainties

### Error Bars
- Vertical/horizontal bars showing $\pm \Delta y$, $\pm \Delta x$
- Length = $2\Delta$ (total span)

### Gradient Uncertainty
$$\Delta m = \frac{m_{\text{max}} - m_{\text{min}}}{2}$$
Draw steepest and shallowest lines through error bars.

### Intercept Uncertainty
$$\Delta c = \frac{c_{\text{max}} - c_{\text{min}}}{2}$$

### Linearisation
| Original | Plot | Gradient | Intercept |
|----------|------|----------|-----------|
| $y = mx + c$ | $y$ vs $x$ | $m$ | $c$ |
| $y = ax^n$ | $\log y$ vs $\log x$ | $n$ | $\log a$ |
| $y = ae^{bx}$ | $\ln y$ vs $x$ | $b$ | $\ln a$ |
| $y = a + b/x$ | $y$ vs $1/x$ | $b$ | $a$ |

---

## 8. Reporting Results

**Format:** $x = x_{\text{best}} \pm \Delta x$ (units)

**Rules:**
1. Uncertainty to **1 significant figure** (2 if first digit is 1)
2. Best value rounded to **same decimal place** as uncertainty
3. Units **always** included
4. Use scientific notation for large/small numbers

**Examples:**
- $v = 12.34 \pm 0.06\ \text{m/s}$ ✓
- $v = 12.3 \pm 0.06\ \text{m/s}$ ✗ (decimal mismatch)
- $v = (1.234 \pm 0.006) \times 10^1\ \text{m/s}$ ✓
- $v = 12.34 \pm 0.1\ \text{m/s}$ → round to $12.3 \pm 0.1$ ✓

## 9. Practical Applications

### Vernier Calipers
- Least count = $\frac{\text{1 MSD} - \text{1 VSD}}{n}$ or $\frac{\text{MSD}}{n}$
- Zero error: Check when jaws closed, apply correction

### Micrometer Screw Gauge
- Least count = $\frac{\text{pitch}}{n}$
- Zero error correction
- Anvil/ratchet for consistent pressure

### Voltmeter/Ammeter
- Analogue: $\pm$ half-scale division or $\pm 1$ division
- Digital: $\pm 1$ LSD $\pm$ (% reading + digits)
- Loading effect (voltmeter resistance, ammeter resistance)

### Stopwatch
- Human reaction $\approx 0.2\ \text{s}$ (systematic + random)
- Multiple oscillations: measure $nT$, divide by $n$

## 10. Problem Patterns (A/L)

| Pattern | Strategy |
|---------|----------|
| Find absolute/relative/percentage uncertainty | Convert using definitions |
| Propagate through formula | Apply rules (add for $\pm$, add relative for $\times\div$, multiply by power) |
| Graph: find gradient/intercept uncertainty | Max/min gradient method through error bars |
| Significant figures in result | Track through calculation, round only at end |
| Identify systematic vs random | Look for consistent bias vs scatter |
| Design experiment to minimise uncertainty | Choose instruments, increase readings, reduce dominant error |

## 11. Worked Examples

### Example 1: Period of pendulum
$n=20$ oscillations, $t = 40.0 \pm 0.5\ \text{s}$ (reaction time)
$$T = \frac{t}{n} = \frac{40.0}{20} = 2.00\ \text{s}$$
$$\Delta T = \frac{\Delta t}{n} = \frac{0.5}{20} = 0.025\ \text{s}$$
$$T = 2.00 \pm 0.03\ \text{s}$$

### Example 2: Resistivity
$\rho = \frac{RA}{l}$, $R = 4.5 \pm 0.2\ \Omega$, $d = 0.50 \pm 0.01\ \text{mm}$, $l = 1.000 \pm 0.001\ \text{m}$
$$A = \frac{\pi d^2}{4} \Rightarrow \frac{\Delta A}{A} = 2\frac{\Delta d}{d} = 2 \times \frac{0.01}{0.50} = 0.04$$
$$\frac{\Delta \rho}{\rho} = \frac{\Delta R}{R} + \frac{\Delta A}{A} + \frac{\Delta l}{l} = \frac{0.2}{4.5} + 0.04 + \frac{0.001}{1.000} = 0.044 + 0.04 + 0.001 = 0.085$$

### Example 3: $g$ from $T = 2\pi\sqrt{l/g}$
$l = 1.00 \pm 0.01\ \text{m}$, $T = 2.01 \pm 0.02\ \text{s}$
$$g = \frac{4\pi^2 l}{T^2} \Rightarrow \frac{\Delta g}{g} = \frac{\Delta l}{l} + 2\frac{\Delta T}{T} = 0.01 + 2(0.01) = 0.03$$
$g = 9.77\ \text{m/s}^2$, $\Delta g = 0.29\ \text{m/s}^2$
$$g = 9.8 \pm 0.3\ \text{m/s}^2$$

## 12. Quick Reference

| Symbol | Meaning |
|--------|---------|
| $\Delta x$ | Absolute uncertainty |
| $\frac{\Delta x}{x}$ | Relative uncertainty |
| $\bar{x}$ | Mean |
| $\sigma$ | Standard deviation |
| $u(x)$ | Standard uncertainty (Type A: $\sigma/\sqrt{n}$) |
| $U$ | Expanded uncertainty ($k \cdot u$, typically $k=2$) |

**Rules:**
- Add absolute for $\pm$
- Add relative for $\times\div$
- Multiply relative by power
- 1 sig fig in uncertainty, match decimals
