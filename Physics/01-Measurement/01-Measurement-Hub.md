## 📐 Key Formulas Quick Reference

### Physical Quantities
- **Base quantities:** $m, kg, s, A, K, mol, cd$
- **Derived:** All from base via physical equations
- **SI prefixes:** $T=10^{12}, G=10^9, M=10^6, k=10^3, c=10^{-2}, m=10^{-3}, \mu=10^{-6}, n=10^{-9}, p=10^{-12}$

### Errors & Uncertainties
- **Absolute uncertainty:** $\Delta x$
- **Relative uncertainty:** $\frac{\Delta x}{x}$
- **Percentage uncertainty:** $\frac{\Delta x}{x} \times 100\%$
- **Addition/Subtraction:** $\Delta z = \Delta x + \Delta y$
- **Multiplication/Division:** $\frac{\Delta z}{z} = \frac{\Delta x}{x} + \frac{\Delta y}{y}$
- **Powers:** $\frac{\Delta z}{z} = n\frac{\Delta x}{x}$

### Vectors
- **Addition:** $\vec{R} = \vec{A} + \vec{B}$ (triangle/parallelogram/components)
- **Components:** $A_x = A\cos\theta, \quad A_y = A\sin\theta$
- **Magnitude:** $A = \sqrt{A_x^2 + A_y^2}$
- **Direction:** $\theta = \tan^{-1}(A_y/A_x)$
- **Dot product:** $\vec{A}\cdot\vec{B} = AB\cos\theta = A_xB_x + A_yB_y$
- **Cross product:** $\vec{A}\times\vec{B} = AB\sin\theta\,\hat{n}$ (RHR)

### Dimensional Analysis
- **Homogeneity:** All terms in equation must have same dimensions
- **Buckingham π:** $n$ variables, $k$ base dimensions → $n-k$ dimensionless groups
- **Common dimensionless:** $Re, M, Fr, Pr$
