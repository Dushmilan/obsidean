# 1.4 Dimensional Analysis Derivations

**Syllabus:** GCE A/L Physics (022) — Unit 1, Topic 1.4

---

## 1. Buckingham π Theorem

### Statement
If a physical relationship involves $n$ variables and $k$ fundamental dimensions, then the relationship can be expressed in terms of $n-k$ independent dimensionless products ($\pi$ groups).

### Proof Outline

Let the relationship be:
$$f(q_1, q_2, \dots, q_n) = 0$$

Each variable $q_i$ has dimensions $[q_i] = M^{a_i} L^{b_i} T^{c_i} \dots$

**Step 1:** Choose $k$ repeating variables that span the $k$ dimensions (typically $M, L, T$).

**Step 2:** Form dimensionless products $\pi_i$ by combining each non-repeating variable with the repeating variables.

**Step 3:** There are exactly $n-k$ independent $\pi$ groups.

**Step 4:** The relationship becomes:
$$\Phi(\pi_1, \pi_2, \dots, \pi_{n-k}) = 0$$
or equivalently:
$$\pi_1 = f(\pi_2, \dots, \pi_{n-k})$$

### Why $n-k$?
- The dimensional matrix has rank $k$ (by choice of repeating variables)
- Nullity = $n - k$ (number of independent solutions to homogeneous system)
- Each null vector gives a dimensionless product

---

## 2. Procedure to Find π Groups

### Algorithm
1. **List variables** and their dimensions
2. **Identify** $k$ (number of fundamental dimensions involved)
3. **Select $k$ repeating variables** that:
   - Span all $k$ dimensions
   - Are dimensionally independent
   - Do not form a dimensionless group themselves
4. **Form $\pi$ groups:** For each remaining variable $q_j$:
   $$\pi_j = q_j \cdot (q_1)^{a_1} \cdot (q_2)^{a_2} \cdots (q_k)^{a_k}$$
   Solve for $a_i$ to make $\pi_j$ dimensionless
5. **Express** relationship as $\pi_1 = f(\pi_2, \dots, \pi_{n-k})$

## 3. Worked Examples

### Example 1: Pendulum Period
**Variables:** $T$ (period), $L$ (length), $g$ (gravity), $m$ (mass), $\theta_0$ (amplitude)
**Dimensions:**
- $[T] = T$
- $[L] = L$
- $[g] = LT^{-2}$
- $[m] = M$
- $[\theta_0] = 1$

$n=5$, $k=3$ ($M, L, T$) → $n-k=2$ groups

**Repeating variables:** $L, g, m$ (span $L, T, M$)

**$\pi_1$ for $T$:**
$$\pi_1 = T L^a g^b m^c$$
$$[T] \cdot [L]^a \cdot [LT^{-2}]^b \cdot [M]^c = T^{1-2b} L^{a+b} M^c = 1$$
$1-2b=0 \Rightarrow b=1/2$
$a+b=0 \Rightarrow a=-1/2$
$c=0$
$$\pi_1 = T \sqrt{\frac{g}{L}}$$

**$\pi_2$ for $\theta_0$:**
$$\pi_2 = \theta_0 \quad \text{(already dimensionless)}$$

**Result:**
$$\pi_1 = f(\pi_2) \Rightarrow T \sqrt{\frac{g}{L}} = f(\theta_0) \Rightarrow T = \sqrt{\frac{L}{g}} f(\theta_0)$$
For small angles: $f(\theta_0) \approx 2\pi$

---

### Example 2: Drag Force on Sphere
**Variables:** $F$ (drag), $\rho$ (density), $v$ (velocity), $D$ (diameter), $\mu$ (viscosity)
**Dimensions:**
- $[F] = MLT^{-2}$
- $[\rho] = ML^{-3}$
- $[v] = LT^{-1}$
- $[D] = L$
- $[\mu] = ML^{-1}T^{-1}$

$n=5$, $k=3$ → 2 groups

**Repeating:** $\rho, v, D$

**$\pi_1$ for $F$:**
$$\pi_1 = F \rho^a v^b D^c$$
$$MLT^{-2} \cdot (ML^{-3})^a \cdot (LT^{-1})^b \cdot L^c = M^{1+a} L^{1-3a+b+c} T^{-2-b}$$
$1+a=0 \Rightarrow a=-1$
$-2-b=0 \Rightarrow b=-2$
$1-3(-1)+(-2)+c=0 \Rightarrow 1+3-2+c=0 \Rightarrow c=-2$
$$\pi_1 = \frac{F}{\rho v^2 D^2} \quad \text{(pressure coefficient)}$$

**$\pi_2$ for $\mu$:**
$$\pi_2 = \mu \rho^a v^b D^c$$
$$ML^{-1}T^{-1} \cdot (ML^{-3})^a \cdot (LT^{-1})^b \cdot L^c = M^{1+a} L^{-1-3a+b+c} T^{-1-b}$$
$a=-1, b=-1, c=-1$
$$\pi_2 = \frac{\mu}{\rho v D} = \frac{1}{Re} \quad \text{(inverse Reynolds number)}$$

**Result:**
$$\frac{F}{\rho v^2 D^2} = f(Re)$$

---

### Example 3: Flow Through Pipe
**Variables:** $\Delta p$ (pressure drop), $L$ (length), $D$ (diameter), $\rho$ (density), $v$ (velocity), $\mu$ (viscosity)
**Dimensions:** Same as above + $[L] = L$

$n=6$, $k=3$ → 3 groups

**Repeating:** $\rho, v, D$

**$\pi_1$ for $\Delta p$:** $\pi_1 = \frac{\Delta p}{\rho v^2}$ (Euler number)

**$\pi_2$ for $L$:** $\pi_2 = \frac{L}{D}$ (geometric ratio)

**$\pi_3$ for $\mu$:** $\pi_3 = \frac{\mu}{\rho v D} = \frac{1}{Re}$

**Result:**
$$\frac{\Delta p}{\rho v^2} = f\left(\frac{L}{D}, Re\right)$$

---

### Example 4: Heat Transfer (Nusselt Number)
**Variables:** $h$ (heat transfer coefficient), $k$ (thermal conductivity), $L$ (length), $\rho, v, \mu, c_p$ (specific heat)

$n=7$, $k=4$ ($M, L, T, \Theta$) → 3 groups

**Repeating:** $\rho, v, L, \mu$

**$\pi_1 = \frac{h L}{k} = Nu$** (Nusselt number)

**$\pi_2 = \frac{\rho v L}{\mu} = Re$** (Reynolds number)

**$\pi_3 = \frac{\mu c_p}{k} = Pr$** (Prandtl number)

**Result:**
$$Nu = f(Re, Pr)$$

## 4. Common Dimensionless Groups in Physics

| Name | Symbol | Formula | Significance |
|------|--------|---------|--------------|
| Reynolds number | $Re$ | $\frac{\rho v L}{\mu}$ | Inertial/viscous forces |
| Froude number | $Fr$ | $\frac{v}{\sqrt{gL}}$ | Inertial/gravity forces |
| Mach number | $M$ | $\frac{v}{c}$ | Velocity/sound speed |
| Prandtl number | $Pr$ | $\frac{\mu c_p}{k}$ | Momentum/thermal diffusivity |
| Nusselt number | $Nu$ | $\frac{h L}{k}$ | Convective/conductive heat transfer |
| Grashof number | $Gr$ | $\frac{g\beta\Delta T L^3}{\nu^2}$ | Natural convection |
| Strouhal number | $St$ | $\frac{f L}{v}$ | Oscillating flow |
| Weber number | $We$ | $\frac{\rho v^2 L}{\sigma}$ | Inertial/surface tension |
| Euler number | $Eu$ | $\frac{\Delta p}{\rho v^2}$ | Pressure/inertial forces |
| Biot number | $Bi$ | $\frac{h L}{k}$ | Conduction/convection in solid |

## 5. Limitations of Dimensional Analysis

| Limitation | Reason |
|------------|--------|
| Cannot determine dimensionless constants | $2\pi$, $1/2$, etc. come from detailed theory |
| Cannot distinguish same-dimension quantities | Work vs torque both $ML^2T^{-2}$ |
| Cannot handle sums of terms | Only power-law relations |
| Requires correct variable selection | Missing variable → wrong π groups |
| Cannot derive functional form $f(\pi)$ | Only relates variables dimensionally |

## 6. Dimensional Checking of Equations

### Principle
In any valid physical equation, **all terms must have identical dimensions**.

### Method
1. Write dimensions of each term
2. Compare — must match exactly
3. If not, equation is dimensionally incorrect

### Examples

**Correct:** $v = u + at$
$[v] = [u] = LT^{-1}$, $[at] = LT^{-2} \cdot T = LT^{-1}$ ✓

**Correct:** $s = ut + \frac{1}{2}at^2$
$[s] = L$, $[ut] = LT^{-1} \cdot T = L$, $[at^2] = LT^{-2} \cdot T^2 = L$ ✓

**Incorrect:** $v = u + a$
$[v] = LT^{-1}$, $[u] = LT^{-1}$, $[a] = LT^{-2}$ ✗

**Incorrect:** $F = ma + v$
$[F] = MLT^{-2}$, $[ma] = MLT^{-2}$, $[v] = LT^{-1}$ ✗

## 7. Converting Between Unit Systems

### General Formula
If $[Q] = M^a L^b T^c \dots$, then:
$$\frac{n_1}{n_2} = \left(\frac{M_1}{M_2}\right)^a \left(\frac{L_1}{L_2}\right)^b \left(\frac{T_1}{T_2}\right)^c \dots$$

### Example: Newton to Dyne
$[F] = MLT^{-2}$
$1\ \text{N} = 1\ \text{kg·m/s}^2 = 1000\ \text{g} \cdot 100\ \text{cm} / 1^2 = 10^5\ \text{dyn}$

### Example: Joule to Erg
$[E] = ML^2T^{-2}$
$1\ \text{J} = 1\ \text{kg·m}^2/\text{s}^2 = 1000 \cdot 100^2 = 10^7\ \text{erg}$

---

## 8. Finding Dimensions of Unknown Constants

### Example: $F = \frac{G m_1 m_2}{r^2}$
$$[G] = \frac{[F][r]^2}{[m]^2} = \frac{MLT^{-2} \cdot L^2}{M^2} = M^{-1}L^3T^{-2}$$

### Example: $T = 2\pi\sqrt{\frac{m}{k}}$
$$[k] = \frac{[m]}{[T]^2} = \frac{M}{T^2} = MT^{-2}$$

### Example: $v = \sqrt{\frac{E}{\rho}}$ (sound in fluid)
$$[E] = [v]^2[\rho] = (LT^{-1})^2 (ML^{-3}) = ML^{-1}T^{-2}$$

|------|--------|
