# 1.2 Error Propagation Derivations

**Syllabus:** GCE A/L Physics (022) — Unit 1, Topic 1.2

---

## 1. General Formula (Differentials)

For a function $z = f(x, y, \dots)$ with independent uncertainties $\Delta x, \Delta y, \dots$:

$$\Delta z = \sqrt{\left(\frac{\partial f}{\partial x}\Delta x\right)^2 + \left(\frac{\partial f}{\partial y}\Delta y\right)^2 + \dots}$$

This is the **root-sum-square (RSS)** or **standard uncertainty** method.

**Maximum uncertainty method** (often used in A/L):

$$\Delta z = \left|\frac{\partial f}{\partial x}\right|\Delta x + \left|\frac{\partial f}{\partial y}\right|\Delta y + \dots$$

---

## 2. Addition/Subtraction

### $z = x + y$ or $z = x - y$

**Differential:** $dz = dx \pm dy$

**Maximum uncertainty:**
$$\Delta z = \Delta x + \Delta y$$

**RSS uncertainty:**
$$\Delta z = \sqrt{(\Delta x)^2 + (\Delta y)^2}$$

**Proof:**
$$z = x \pm y \Rightarrow \frac{\partial z}{\partial x} = 1, \quad \frac{\partial z}{\partial y} = \pm 1$$
$$\Delta z = \sqrt{(1\cdot\Delta x)^2 + (\pm 1\cdot\Delta y)^2} = \sqrt{\Delta x^2 + \Delta y^2}$$
For maximum: $|\Delta x| + |\Delta y| = \Delta x + \Delta y$

---

## 3. Multiplication/Division

### $z = xy$ or $z = x/y$

**Differential:** $dz = y\,dx + x\,dy$ (product) or $dz = \frac{1}{y}dx - \frac{x}{y^2}dy$ (quotient)

**Relative uncertainty:**
$$\frac{\Delta z}{z} = \frac{\Delta x}{x} + \frac{\Delta y}{y} \quad \text{(maximum)}$$

**RSS relative uncertainty:**
$$\frac{\Delta z}{z} = \sqrt{\left(\frac{\Delta x}{x}\right)^2 + \left(\frac{\Delta y}{y}\right)^2}$$

**Proof for $z = xy$:**
$$\ln z = \ln x + \ln y \Rightarrow \frac{dz}{z} = \frac{dx}{x} + \frac{dy}{y}$$
$$\Rightarrow \Delta z = z\left(\frac{\Delta x}{x} + \frac{\Delta y}{y}\right) = y\Delta x + x\Delta y$$

**Proof for $z = x/y$:**
$$\ln z = \ln x - \ln y \Rightarrow \frac{dz}{z} = \frac{dx}{x} - \frac{dy}{y}$$
$$\Rightarrow \frac{\Delta z}{z} = \frac{\Delta x}{x} + \frac{\Delta y}{y} \quad \text{(max)}$$

---

## 4. Powers

### $z = x^n$

**Differential:** $dz = n x^{n-1} dx$

**Relative uncertainty:**
$$\frac{\Delta z}{z} = |n| \frac{\Delta x}{x} \quad \text{(max)}$$
$$\frac{\Delta z}{z} = |n| \frac{\Delta x}{x} \quad \text{(RSS)}$$

**Proof:**
$$\ln z = n \ln x \Rightarrow \frac{dz}{z} = n \frac{dx}{x}$$
$$\Rightarrow \Delta z = |n| z \frac{\Delta x}{x}$$

---

## 5. Functions of One Variable

| Function | Derivative | $\Delta z$ (max) | $\Delta z$ (RSS) |
|----------|------------|------------------|------------------|
| $z = \sin x$ | $\cos x$ | $|\cos x|\Delta x$ | $|\cos x|\Delta x$ |
| $z = \cos x$ | $-\sin x$ | $|\sin x|\Delta x$ | $|\sin x|\Delta x$ |
| $z = \tan x$ | $\sec^2 x$ | $\sec^2 x \Delta x$ | $\sec^2 x \Delta x$ |
| $z = \ln x$ | $1/x$ | $\Delta x/x$ | $\Delta x/x$ |
| $z = e^x$ | $e^x$ | $e^x \Delta x$ | $e^x \Delta x$ |
| $z = x^n$ | $n x^{n-1}$ | $|n| x^{n-1}\Delta x$ | same |
| $z = \sqrt{x}$ | $1/(2\sqrt{x})$ | $\frac{\Delta x}{2\sqrt{x}}$ | same |

---

## 6. Combined Functions

### Example: $z = \frac{x^2 y}{w}$

$$\ln z = 2\ln x + \ln y - \ln w$$
$$\frac{dz}{z} = 2\frac{dx}{x} + \frac{dy}{y} - \frac{dw}{w}$$

**Maximum:**
$$\frac{\Delta z}{z} = 2\frac{\Delta x}{x} + \frac{\Delta y}{y} + \frac{\Delta w}{w}$$

**RSS:**
$$\frac{\Delta z}{z} = \sqrt{\left(2\frac{\Delta x}{x}\right)^2 + \left(\frac{\Delta y}{y}\right)^2 + \left(\frac{\Delta w}{w}\right)^2}$$

---

## 7. Uncertainty of Mean (Type A)

For $n$ readings $x_1, x_2, \dots, x_n$:

$$\bar{x} = \frac{1}{n}\sum x_i$$
$$\sigma = \sqrt{\frac{\sum(x_i - \bar{x})^2}{n-1}} \quad \text{(sample standard deviation)}$$
$$u(\bar{x}) = \frac{\sigma}{\sqrt{n}} \quad \text{(standard error of mean)}$$

**Expanded uncertainty (95% confidence, $k \approx 2$):**
$$U = 2 \cdot u(\bar{x})$$

---

## 8. Combined Uncertainty (Type A + Type B)

$$u_c = \sqrt{u_A^2 + u_B^2}$$

Where $u_A = \frac{\sigma}{\sqrt{n}}$ (Type A) and $u_B$ from specifications (Type B).

---

## 9. Practical Examples

### Example 1: Resistivity $\rho = \frac{RA}{l} = \frac{R\pi d^2}{4l}$

$$\frac{\Delta \rho}{\rho} = \frac{\Delta R}{R} + 2\frac{\Delta d}{d} + \frac{\Delta l}{l}$$

### Example 2: $g = \frac{4\pi^2 l}{T^2}$

$$\frac{\Delta g}{g} = \frac{\Delta l}{l} + 2\frac{\Delta T}{T}$$

### Example 3: Young's modulus $E = \frac{Fl}{Ae}$

$$\frac{\Delta E}{E} = \frac{\Delta F}{F} + \frac{\Delta l}{l} + \frac{\Delta A}{A} + \frac{\Delta e}{e}$$

### Example 4: $v = \sqrt{\frac{T}{\mu}}$

$$\frac{\Delta v}{v} = \frac{1}{2}\frac{\Delta T}{T} + \frac{1}{2}\frac{\Delta \mu}{\mu}$$

## 10. Common Traps in A/L

- ❌ Using RSS when question asks for maximum uncertainty
- ❌ Forgetting absolute values in $\frac{\Delta z}{z} = |n|\frac{\Delta x}{x}$
- ❌ Not converting to relative uncertainties before adding for $\times/\div$
- ❌ Adding absolute uncertainties for $\times/\div$ instead of relative
- ❌ Forgetting factor of 2 for $x^2$ term
- ❌ Not rounding uncertainty to 1 significant figure (2 if first digit is 1)
- ❌ Mismatched decimal places between value and uncertainty
