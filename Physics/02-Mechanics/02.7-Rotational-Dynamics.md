# Rotational Dynamics

## Definition

The rotational analogues of Newton's laws:

$$\tau = I\alpha, \qquad L = I\omega, \qquad KE_{rot} = \tfrac12 I\omega^2$$

- **Torque:** $\tau = rF\sin\theta$ (N·m) — the twisting effect.
- **Moment of inertia:** $I = \sum m_ir_i^2$ (kg·m²) — how mass is distributed.
- **Parallel axis theorem:** $I = I_{cm} + md^2$.

## The Intuition

A door: push near the hinge (small $r$) — it barely moves; push near the handle (large $r$) — it swings easily. That's torque. A figure skater pulls arms in to spin faster: same angular momentum, smaller $I$, bigger $\omega$.

## The Physics

| Quantity | Equation | Analogue |
|----------|----------|----------|
| Torque | $\tau = rF\sin\theta$ | force |
| Newton's 2nd (rot.) | $\tau = I\alpha$ | $F = ma$ |
| Moment of inertia | $I = \sum m_ir_i^2$ | mass |
| Angular momentum | $L = I\omega$ | $p = mv$ |
| Rotational KE | $KE = \frac12 I\omega^2$ | $\frac12 mv^2$ |
| Parallel axis | $I = I_{cm} + md^2$ | — |

## Derivation

$\tau = I\alpha$ follows from $\tau = rF$ and $F = ma$ with $a = r\alpha$. Angular momentum conservation: with $\tau_{ext} = 0$, $L = I\omega$ stays constant. [Full derivations: [[Maths/Applied/06-Moment-of-Inertia/06.3-Rotational-KE-Angular-Momentum]]]

## Method

1. Compute $I$ about the rotation axis (standard bodies + parallel axis).
2. Apply $\tau = I\alpha$ or conservation of $L = I\omega$.
3. Rolling: total KE $= \frac12 Mv^2 + \frac12 I_{cm}\omega^2$.

## Worked Examples

**Setup:** A disc ($I = \frac12 MR^2$, $M = 2$ kg, $R = 0.5$ m) with 10 N·m torque. Find $\alpha$.

**Solution:** $I = \frac12(2)(0.5)^2 = 0.25$ kg·m². $\alpha = \tau/I = 10/0.25 = 40$ rad/s².

**Key insight:** A ring ($I = MR^2$) resists rotation more than a disc of the same mass — mass farther from the axis.

---

**Setup:** A solid sphere ($I = \frac25 MR^2$, 4 kg, 0.1 m) rolls down a 30° incline from rest.

**Solution:** $mg\sin\theta - f = ma$ and $fR = I\alpha = \frac25 MRa/R$: combine → $a = \frac{g\sin\theta}{1 + 2/5} = \frac{5}{7}(5) = 3.57$ m/s².

**Key insight:** Rolling shares energy between translation and rotation — acceleration is less than $g\sin\theta$.

## Common Traps

- Torque needs the perpendicular distance ($r\sin\theta$), not the full length
- $I$ is axis-dependent — use the parallel-axis theorem for off-centre axes
- Angular momentum is a vector (direction via the right-hand rule)
- $\tau = I\alpha$ needs $I$ about the *same* axis as $\tau$
