# Tech Stack

## Languages
- JavaScript/TypeScript, Python, C

## Frontend
- **Framework:** React 18/19, Next.js 14 App Router, Vite
- **Styling:** Tailwind CSS v3 exclusively (no CSS modules, no styled-components)
- **State:** Zustand (no Redux, no React Query)
- **Animations:** GSAP (imperative, timelines, ScrollTrigger) — NOT Framer Motion
- **Icons:** Lucide React
- **UI Primitives:** Radix UI
- **Testing:** Vitest (unit), Playwright (E2E), MSW (mocks)

## Backend
- **Python:** FastAPI, SQLAlchemy async, Alembic, Pydantic v2
- **JS/TS:** Cloudflare Workers + Hono, Prisma + D1
- **Auth:** JWT (RS256), OAuth (Supabase, GitHub)
- **Cache:** Redis with content-hash keys and graceful degradation

## AI/ML
- **Primary:** Claude API, Claude.ai
- **Planning:** Kimi K2.6
- **Explored:** Google AI Studio, Groq, GitHub Models, NVIDIA NIM, DeepSeek
- **Fine-tuning:** Gemma 2B (planned)
- **Audio ML interest:** SpeechBrain, PyAnnote, wav2vec2, ECAPA-TDNN, VQ-VAE
- **Approach:** Multi-agent pipeline, tiered model strategy

## DevOps & Tools
- **Package managers:** npm/pnpm
- **Monorepos:** Workspace packages
- **Pre-commit:** Husky + lint-staged (ESLint + Prettier)
- **Formatters:** Prettier (100 char, single quotes, trailing commas), Ruff
- **MCP servers:** Context7, Playwright, Firecrawl, GitHub MCP
- **Knowledge management:** Notion

## Math
- Linear Algebra (SVD, Eigen), Vector Calculus, Diff Eqs, Error Analysis
