# 5.6 AC Circuits

**Syllabus:** GCE A/L Physics (022) — Unit 5, Topic 5.6

## Definition

In AC circuits, voltage and current vary sinusoidally. Capacitors and inductors introduce phase differences. Impedance replaces resistance.

## Key Formulas

| Formula | Variables |
|---------|-----------|
| $X_C = \frac{1}{2\pi fC}$ | Capacitive reactance |
| $X_L = 2\pi fL$ | Inductive reactance |
| $Z = \sqrt{R^2 + (X_L - X_C)^2}$ | Impedance |
| $I_{rms} = \frac{I_0}{\sqrt{2}}$ | RMS current |
| $f_0 = \frac{1}{2\pi\sqrt{LC}}$ | Resonant frequency |

## Worked Example

Series RLC: $R = 100\ \Omega$, $L = 0.1$ H, $C = 100\ \mu$F at 50 Hz. Find impedance.

$$X_L = 2\pi \times 50 \times 0.1 = 31.4\ \Omega$$
$$X_C = \frac{1}{2\pi \times 50 \times 100 \times 10^{-6}} = 31.8\ \Omega$$
$$Z = \sqrt{100^2 + (31.4 - 31.8)^2} \approx 100\ \Omega$$

## Common Mistakes

- ❌ Adding reactances algebraically (must use phasor diagram)
- ❌ Forgetting RMS values for power calculations
- ❌ Confusing resonance ($X_L = X_C$) with unity power factor
