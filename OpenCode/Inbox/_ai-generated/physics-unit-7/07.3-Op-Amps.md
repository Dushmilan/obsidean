# 7.3 Operational Amplifiers

**Syllabus:** GCE A/L Physics (022) — Unit 7, Topic 7.3

## Definition

An op-amp is a high-gain differential amplifier. Ideal op-amps have infinite input impedance, zero output impedance, and infinite gain.

## Key Formulas

| Formula | Variables |
|---------|-----------|
| $V_{out} = A(V_+ - V_-)$ | Open-loop gain |
| $A \to \infty$ (ideal) | Virtual short: $V_+ = V_-$ |
| $G = 1 + \frac{R_f}{R_1}$ | Non-inverting gain |
| $G = -\frac{R_f}{R_1}$ | Inverting gain |

**Configuration summary:**
| Config | Gain | Input impedance |
|--------|------|-----------------|
| Inverting | $-R_f/R_1$ | $R_1$ |
| Non-inverting | $1 + R_f/R_1$ | $\infty$ |
| Voltage follower | 1 | $\infty$ |

## Worked Example

Non-inverting amplifier: $R_f = 90$ kΩ, $R_1 = 10$ kΩ. Find gain.

$$G = 1 + \frac{90}{10} = 10$$

## Common Mistakes

- ❌ Forgetting the virtual short concept ($V_+ = V_-$)
- ❌ Confusing inverting and non-inverting gain signs
- ❌ Assuming ideal op-amp in real circuits (saturation, offset)
