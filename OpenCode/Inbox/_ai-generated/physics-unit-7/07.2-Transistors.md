# 7.2 Transistors

**Syllabus:** GCE A/L Physics (022) — Unit 7, Topic 7.2

## Definition

Transistors amplify or switch signals. BJTs use current control; FETs use voltage control. Both have three terminals.

## Key Formulas

| Formula | Variables |
|---------|-----------|
| $I_C = \beta I_B$ | BJT current gain |
| $\beta = \frac{I_C}{I_B} \approx 100$ | Typical $\beta$ |
| $I_E = I_C + I_B$ | Current relationship |
| $I_D = I_{DSS}(1 - \frac{V_{GS}}{V_P})^2$ | FET transfer (Shockley) |

**Transistor terminals:**
| Type | Terminals | Key parameter |
|------|-----------|---------------|
| NPN/PNP (BJT) | Base, Collector, Emitter | $\beta$ (current gain) |
| JFET/MOSFET | Gate, Drain, Source | $g_m$ (transconductance) |

## Worked Example

BJT with $\beta = 100$ and $I_B = 20\ \mu$A. Find $I_C$.

$$I_C = \beta I_B = 100 \times 20 \times 10^{-6} = 2\ \text{mA}$$

## Common Mistakes

- ❌ Confusing NPN and PNP biasing
- ❌ Forgetting base-emitter junction must be forward biased
- ❌ Using BJT formulas for FETs (different physics)
