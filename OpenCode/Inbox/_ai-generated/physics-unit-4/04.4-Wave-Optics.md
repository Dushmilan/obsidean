# 4.4 Wave Optics

**Syllabus:** GCE A/L Physics (022) — Unit 4, Topic 4.4

## Definition

Wave optics explains interference, diffraction, and polarization — phenomena that particle theory cannot.

## Key Formulas

| Formula | Variables |
|---------|-----------|
| $d\sin\theta = n\lambda$ | Double-slit maxima |
| $d\sin\theta = (n+\frac{1}{2})\lambda$ | Double-slit minima |
| $a\sin\theta = n\lambda$ | Single-slit minima |
| $I = I_0\cos^2\phi$ | Intensity after polarizer |

## Worked Example

Double slit ($d = 0.2$ mm), light ($\lambda = 500$ nm). Find angle to 1st maximum.

$$\sin\theta = \frac{n\lambda}{d} = \frac{1 \times 500 \times 10^{-9}}{0.2 \times 10^{-3}} = 0.0025 \implies \theta = 0.14°$$

## Common Mistakes

- ❌ Confusing maxima and minima conditions
- ❌ Forgetting diffraction grating has sharper maxima than double slit
- ❌ Mixing up polarization (transverse only) with diffraction
