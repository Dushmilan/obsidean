# Vectors

A scalar is a single number — temperature, mass, speed. A vector is a quantity with both magnitude and direction, represented as an ordered triple $\langle a_1, a_2, a_3 \rangle$. Physical quantities like force naturally have "how much" and "which way," so treating them as algebraic objects lets us add forces, scale them, and compute angles.

**The Intuition:** A vector is like a flight itinerary: it tells you how far to move east-west ($x$), north-south ($y$), and up-down ($z$). The magnitude is the total straight-line distance; the direction is where you end up relative to where you started. Two arrows with the same length and pointing the same way represent the same vector, regardless of where they sit.

**The Math:** A vector $\mathbf{v} = \langle v_1, v_2, v_3 \rangle$ can also be written $v_1\mathbf{i} + v_2\mathbf{j} + v_3\mathbf{k}$. The key operations are:

- **Addition:** $\mathbf{u} + \mathbf{v} = \langle u_1 + v_1,\; u_2 + v_2,\; u_3 + v_3 \rangle$
- **Scalar multiplication:** $c\mathbf{v} = \langle cv_1,\; cv_2,\; cv_3 \rangle$
- **Magnitude:** $\|\mathbf{v}\| = \sqrt{v_1^2 + v_2^2 + v_3^2}$
- **Unit vector:** $\hat{\mathbf{v}} = \dfrac{\mathbf{v}}{\|\mathbf{v}\|}$
- **Vector from two points:** $\overrightarrow{AB} = \langle x_2 - x_1,\; y_2 - y_1,\; z_2 - z_1 \rangle$

These follow from the distance formula in $\mathbb{R}^3$. Vectors here are position-free (free vectors); for vectors tied to specific points, additional context is needed.

**Setup:** Let $A(1, 2, -3)$ and $B(4, 0, 5)$. Find $\overrightarrow{AB}$ and its magnitude.

**Solution:** $\overrightarrow{AB} = \langle 4-1,\; 0-2,\; 5+3 \rangle = \langle 3, -2, 8 \rangle$. Then $\|\overrightarrow{AB}\| = \sqrt{9 + 4 + 64} = \sqrt{77} \approx 8.77$.

**Key insight:** Subtract coordinates terminal minus initial. The magnitude follows the 3D distance formula.

**Setup:** Find the unit vector in the direction of $\mathbf{v} = \langle 2, -3, 6 \rangle$.

**Solution:** $\|\mathbf{v}\| = \sqrt{4 + 9 + 36} = 7$, so $\hat{\mathbf{v}} = \langle 2/7,\; -3/7,\; 6/7 \rangle$.

**Key insight:** Divide each component by the magnitude. The result always has magnitude 1, preserving direction.

**Setup:** Three forces act on a point: $\mathbf{F}_1 = \langle 3, -1, 2 \rangle$, $\mathbf{F}_2 = \langle -2, 4, -1 \rangle$, $\mathbf{F}_3 = \langle -1, -3, x \rangle$. For what value of $x$ is the system in equilibrium?

**Solution:** Equilibrium means $\mathbf{F}_1 + \mathbf{F}_2 + \mathbf{F}_3 = \mathbf{0}$. The sum is $\langle 0,\; 0,\; 1+x \rangle$, so $x = -1$.

**Key insight:** Equilibrium means the vector sum is zero. Solve component-wise — each component must independently equal zero.

### A/L Additional Notes

**What does this mean for Pure Mathematics?** Vector algebra is the grammar of 3D mathematics. Linear independence tells you whether a set of vectors spans space or lies flat in a plane. The section formula lets you pinpoint exact locations between two known points. These tools let you describe any point, line, or plane in 3D.

Linear dependence in 3D means coplanar. Three vectors are linearly dependent iff they lie in the same plane. Four or more vectors in 3D are always dependent.

### A/L Worked Examples

**Setup:** $\mathbf{a} = 3\mathbf{i} - 2\mathbf{j} + \mathbf{k}$, $\mathbf{b} = -\mathbf{i} + 4\mathbf{j} - 2\mathbf{k}$. Find $2\mathbf{a} - 3\mathbf{b}$, $\|\mathbf{a}\|$, and the unit vector along $\mathbf{a}$. **Solution:** $2\mathbf{a} - 3\mathbf{b} = 9\mathbf{i} - 16\mathbf{j} + 8\mathbf{k}$. $\|\mathbf{a}\| = \sqrt{14}$. Unit vector: $\frac{1}{\sqrt{14}}(3\mathbf{i} - 2\mathbf{j} + \mathbf{k})$. **Key insight:** Component-wise arithmetic. The unit vector divides each component by the magnitude.

**Setup:** $A(1,2,3)$, $B(4,6,9)$, $P$ divides $AB$ in ratio $2:3$ (internal). Find the position vector of $P$. **Solution:** $\mathbf{p} = \frac{3\mathbf{a} + 2\mathbf{b}}{5} = \frac{11}{5}\mathbf{i} + \frac{18}{5}\mathbf{j} + \frac{27}{5}\mathbf{k}$. **Key insight:** The ratio $2:3$ means $AP:PB = 2:3$, so $n = 3$ goes with $\mathbf{a}$ and $m = 2$ goes with $\mathbf{b}$. The coefficients swap.
