
## Definition

**Principle of Virtual Work:** a system is in equilibrium iff the total work done by all forces under an infinitesimal, constraint-consistent **virtual displacement** is zero:

$$\delta W = \sum \vec{F}_i \cdot \delta\vec{r}_i = 0$$

**D'Alembert's principle** (dynamics): $\delta W = \sum (\vec{F}_i - m_i\vec{a}_i)\cdot\delta\vec{r}_i = 0$.

A virtual displacement $\delta\vec{r}$ is an infinitesimal change consistent with the constraints, imposed with time frozen. Constraint forces (normals, string tensions, pin reactions) do **no work** in consistent displacements — they vanish from the equation.

## The Intuition

A lever in equilibrium: nudge it slightly and the work you do equals the work against the load — net work zero. A balanced seesaw: the child going down gains work while the other loses it; in equilibrium these balance exactly. If a system is in equilibrium, any imagined displacement can't change the energy — total work is zero for all possible displacements.

## The Toolkit

| Simple machine | Equilibrium relation |
|----------------|---------------------|
| Lever | $Ea = Lb$ |
| Inclined plane | $P = W\sin\theta$ |
| Wedge | $P = W\tan\alpha$ |
| Screw jack | $E = \dfrac{Wp}{2\pi R}$ |
| Pulley (mechanical advantage $n$) | $E = \dfrac{W}{n}$ |

## Derivation

Work is force × displacement along the force. Under a virtual displacement, equilibrium requires the sum over all *working* forces to vanish; constraint forces are excluded because their displacement component is zero (or perpendicular). For machines, write the virtual displacements geometrically (e.g. the lever's ends move in ratio $a:b$) and set $\delta W = 0$. [Full derivations: 03.5-Proofs-Virtual-Work]

## Method

1. **Identify the one degree of freedom** — the single variable describing the motion.
2. Express every force's displacement in terms of it (geometry: similar triangles, pulley ratios).
3. Write $\sum F_i \cdot \delta r_i = 0$ (work sign: force and displacement same direction = positive).
4. Constraint forces are automatically excluded — no need to find them.

## Worked Examples

**Setup:** A lever with effort at distance $a$, load at distance $b$. Find the effort $E$ balancing load $L$.

**Solution:** Virtual displacements: effort moves $a\theta$, load moves $b\theta$. $\delta W = E(a\theta) - L(b\theta) = 0 \Rightarrow Ea = Lb$.

**Key insight:** The ratio of displacements is the ratio of distances — geometry replaces force resolution.

---

**Setup:** A block on an inclined plane with force $P$ up the plane balancing $W$. Use virtual work.

**Solution:** Move the block a virtual distance $ds$ up the plane: $P\,ds - W\sin\theta\,ds = 0 \Rightarrow P = W\sin\theta$.

**Key insight:** The weight does work only through its component along the displacement — $W\sin\theta$ appears naturally.

## Common Traps

- Forgetting the sign convention (work positive when force and displacement agree)
- Including constraint forces that do zero work
- Choosing a displacement that violates the constraints
- Using virtual work for multi-degree-of-freedom systems without enough equations
- Mixing up real work (with time) and virtual work (time frozen)
