
## Definition

Two competing failure modes when a force pushes a body:
- **Sliding** — overcomes friction: $P_{\text{slide}} = \mu W$.
- **Toppling** — rotation about an edge: $P_{\text{topple}} = \dfrac{Wb}{2y}$ (force at height $y$).

The winner is decided by comparing $\mu$ with the aspect ratio $\frac{b}{2h}$:

| Comparison | Failure mode |
|---|---|
| $\mu < \dfrac{b}{2h}$ | slides first |
| $\mu > \dfrac{b}{2h}$ | topples first |
| $\mu = \dfrac{b}{2h}$ | simultaneous |

## The Intuition

Pushing a tall wardrobe: slippery floor (low $\mu$) → it slides; grippy floor + tall narrow wardrobe → it topples about the bottom edge. Toppling happens when the weight's line of action falls **outside the base** — at the critical moment it passes exactly through the edge. Pushing high up makes toppling easier ($P \propto 1/y$); pushing low makes sliding more likely.

## The Toolkit

| Quantity | Formula |
|----------|---------|
| Sliding angle (incline) | $\theta_{\text{slide}} = \tan^{-1}\mu$ |
| Toppling angle (incline) | $\theta_{\text{topple}} = \tan^{-1}\dfrac{b}{2h}$ |
| Horizontal sliding force | $P_{\text{slide}} = \mu W$ |
| Toppling force at height $y$ | $P_{\text{topple}} = \dfrac{Wb}{2y}$ |
| At top edge $y = h$ | $P_{\text{topple}} = \dfrac{Wb}{2h}$ |
| At mid-height $y = h/2$ | $P_{\text{topple}} = \dfrac{Wb}{h}$ |

## Derivation

Toppling: take moments about the bottom edge — the applied force $P$ at height $y$ must overcome the weight's restoring moment about the edge: $Py = W\cdot\frac b2$. Sliding: $P = \mu R = \mu W$. On an incline, resolve weight into components and compare the two critical angles. [Full derivations: 03.4-Proofs-Toppling-Sliding]

## Method

1. Compute both failure thresholds.
2. Compare: the *smaller* threshold is what happens first.
3. For a push at height $y$: $P_{\text{topple}} = \frac{Wb}{2y}$ — lower push → harder to topple.
4. An **upward** component of force reduces $R$ → easier to slide, harder to topple.

## Worked Examples

**Setup:** A block $2$ m wide, $1$ m tall, weight $W$, $\mu = 0.6$. A horizontal force acts at the top. Which fails first?

**Solution:** $P_{\text{slide}} = 0.6W$. $P_{\text{topple}} = \frac{W(2)}{2(1)} = W$. Since $0.6W < W$, **sliding** happens first.

**Key insight:** Compare the two thresholds directly — the smaller one wins.

---

**Setup:** A uniform cuboid $b$ wide, $h$ tall on an incline. Find the angle at which it topples.

**Solution:** Topples when the weight line passes through the lower edge: $\theta_{\text{topple}} = \tan^{-1}\frac{b}{2h}$.

**Key insight:** Tall and narrow ($h$ large) → small toppling angle; wide and squat → topples late.

## Common Traps

- Checking only one failure mode
- Using the wrong dimension in $b/2h$ (base half-width, not full width)
- Ignoring how the push height $y$ changes $P_{\text{topple}}$
- Forgetting that upward-pulling forces reduce the normal reaction (and hence friction)
- Applying the slide threshold when the body is also on the verge of rotating
