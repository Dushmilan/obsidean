
## Definition

Simple Harmonic Motion is defined by the differential equation

$$\ddot{x} + \omega^2 x = 0$$

with general solution $x(t) = A\cos(\omega t + \phi)$. The defining property: **acceleration is proportional to displacement and opposite in direction**:

$$a = -\omega^2 x$$

Equivalent forms: restoring force $F = -kx$ (Hooke), potential $U = \frac12 kx^2$, or the ODE above. $A$ = amplitude, $\phi$ = phase (set by initial conditions), $\omega$ = angular frequency (a system constant).

## The Intuition

A mass on a spring: pull it aside and release — the spring pulls back, the mass overshoots, the spring pulls the other way, and the cycle repeats. The further you pull, the harder it pulls back (linear restoring force). Only sinusoidal functions have derivatives proportional to themselves (with a sign flip), which is why the solution must be $A\cos(\omega t + \phi)$.

## The Toolkit

| Quantity | Formula |
|----------|---------|
| ODE | $\ddot{x} + \omega^2 x = 0$ |
| Solution | $x = A\cos(\omega t + \phi)$ |
| Velocity | $\dot{x} = -A\omega\sin(\omega t + \phi)$ |
| Acceleration | $\ddot{x} = -A\omega^2\cos(\omega t + \phi) = -\omega^2 x$ |
| Angular frequency | $\omega = \sqrt{k/m}$ (spring) |
| Period | $T = \dfrac{2\pi}{\omega}$ |
| Frequency | $f = \dfrac{1}{T} = \dfrac{\omega}{2\pi}$ |
| Max speed | $v_{\max} = A\omega$ (at equilibrium) |
| Max acceleration | $a_{\max} = A\omega^2$ (at extremes) |

## Derivation

$F = -kx$ with $F = ma$ gives $m\ddot{x} = -kx \Rightarrow \ddot{x} + \frac{k}{m}x = 0$, so $\omega = \sqrt{k/m}$. The solution is sinusoidal because it must satisfy $\ddot{x} = -\omega^2 x$ — the second derivative returning a negative multiple of the function. [Full derivations: 05.1-Proofs-SHM-Definition-Characteristics]

## Method

1. **Identify the restoring force** and confirm it's linear ($F = -kx$).
2. Write the ODE, read off $\omega$.
3. Fit $x = A\cos(\omega t + \phi)$ to the initial conditions ($x(0)$, $\dot{x}(0)$).
4. Convert to period/frequency as requested.

## Worked Examples

**Setup:** A mass oscillates with $A = 0.2$ m, $T = 2$ s. Find $\omega$, $v_{\max}$, $a_{\max}$.

**Solution:** $\omega = \frac{2\pi}{T} = \pi$ rad/s. $v_{\max} = A\omega = 0.2\pi$ m/s. $a_{\max} = A\omega^2 = 0.2\pi^2$ m/s².

**Key insight:** $v_{\max}$ occurs at equilibrium, $a_{\max}$ at the extremes — one formula each.

---

**Setup:** Given $x(0) = A_0$ and $\dot{x}(0) = 0$, write the solution.

**Solution:** $\phi = 0$: $x(t) = A_0\cos\omega t$ — released from rest at the extreme.

**Key insight:** "Released from rest" means $\dot{x}(0) = 0$, forcing the sine term to vanish ($\phi = 0$).

## Common Traps

- $a = -\omega^2 x$ — the minus sign is the *definition* (restoring)
- Confusing $\omega$ with $f$: $\omega = 2\pi f$
- Using degrees in $\omega t$ — radians only
- Forgetting the phase constant from initial conditions
- Assuming SHM where the restoring force isn't linear
