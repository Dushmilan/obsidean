
## Definition

Motion where acceleration **isn't constant** — calculus replaces SUVAT. The method depends on what $a$ is a function of:

| Case | What $a$ depends on | Approach |
|------|--------------------|----------|
| 1 | $a = a(t)$ | direct integration |
| 2 | $a = a(v)$ | separate variables: $dt = \dfrac{dv}{a(v)}$ |
| 3 | $a = a(s)$ | chain rule: $a = v\dfrac{dv}{ds}$ |

## The Intuition

A car with a spring-loaded accelerator: the harder you press, the more the spring resists, so acceleration depends on current speed. At low speed you accelerate quickly; at high speed, less so; eventually you hit **terminal velocity** where drag balances the driving force. Integration adds up all the tiny changes ($a\,dt$, $v\,dt$) to recover totals.

## The Toolkit

| Case | Result |
|------|--------|
| $a = a(t)$ | $v(t) = u + \int_0^t a\,d\tau$, $s(t) = \int_0^t v\,d\tau$ |
| $a = a(v)$ | $t = \int_u^v \dfrac{dv'}{a(v')}$, $s = \int_u^v \dfrac{v'\,dv'}{a(v')}$ |
| $a = a(s)$ | $v^2 = u^2 + 2\int_0^s a(s')\,ds'$ |
| Linear drag | $a = -kv \Rightarrow v = ue^{-kt}$ (terminal velocity problems) |
| SHM | $a = -\omega^2 s \Rightarrow s = A\cos(\omega t + \phi)$, $T = 2\pi/\omega$ |

## Derivation

The chain-rule form isn't a new formula — $a = \frac{dv}{dt} = \frac{dv}{ds}\cdot\frac{ds}{dt} = v\frac{dv}{ds}$. Case 2 rearranges $\frac{dv}{dt} = a(v)$ into $dt = \frac{dv}{a(v)}$ and integrates. Case 3 integrates $v\,dv = a(s)\,ds$. SUVAT is the special case $a$ constant. [Full derivations: 01.5-Proofs-Variable-Acceleration]

## Method

1. **Identify the case** — what is $a$ a function of ($t$, $v$, or $s$)?
2. Set up the correct integral form.
3. Integrate, then **apply the initial condition** immediately to fix the constant.
4. Check dimensions after every integration (catches most errors).

## Worked Examples

**Setup:** $a = kt$ (linear), with $u = 0$, $s = 0$ at $t = 0$. Find $v$ and $s$.

**Solution:** $v = \int kt\,dt = \frac12 kt^2$; $s = \int \frac12 kt^2\,dt = \frac16 kt^3$.

**Key insight:** Each integration adds a power of $t$; the constants vanish with the initial conditions.

---

**Setup:** $a = -kv$ (linear drag). Find $v(t)$.

**Solution:** $t = \int_u^v \frac{dv'}{-kv'} = -\frac1k\ln\frac{v}{u}$, so $v = ue^{-kt}$ — exponential decay toward rest.

**Key insight:** Case 2 (depends on $v$) always produces exponentials — the hallmark of drag problems.

## Common Traps

- Applying SUVAT where $a$ varies — the classic error
- Using case 2 formulas when $a$ depends on $t$ (and vice versa)
- Forgetting the integration constant and initial condition
- No dimension check after integration
- $a = v\frac{dv}{ds}$ written as $\frac{dv}{ds}$ missing the $v$ factor
