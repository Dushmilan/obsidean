
## Definition

Two-dimensional motion under **gravity alone**: horizontal velocity is constant, vertical motion is uniformly accelerated. Decompose into two independent 1D problems:

$$u_x = u\cos\theta \ (\text{constant}), \qquad u_y = u\sin\theta \ (\text{subject to } g)$$
$$x = (u\cos\theta)t, \qquad y = (u\sin\theta)t - \tfrac12 gt^2$$

## The Intuition

A ball rolls off a table at the same instant an identical ball is dropped: **both hit the ground at the same time**. The horizontally-launched ball moves sideways but its vertical motion matches the dropped ball exactly — gravity acts only vertically, so the components are independent.

## The Toolkit

| Result | Formula | Valid when |
|--------|---------|-----------|
| Time of flight | $T = \dfrac{2u\sin\theta}{g}$ | level ground |
| Max height | $H = \dfrac{u^2\sin^2\theta}{2g}$ | — |
| Range (level) | $R = \dfrac{u^2\sin 2\theta}{g}$ | level ground |
| Max range angle | $\theta = 45^\circ$ | level ground |
| Trajectory | $y = x\tan\theta - \dfrac{gx^2}{2u^2\cos^2\theta}$ | eliminate $t$ |
| Speed at height $y$ | $v = \sqrt{u^2 - 2gy}$ | energy — independent of angle |
| Range up incline $\alpha$ | $R = \dfrac{u^2\sin 2(\theta-\alpha)}{g\cos\alpha}$ | inclined plane |
| Range down incline | $R = \dfrac{u^2\sin 2(\theta+\alpha)}{g\cos\alpha}$ | inclined plane |
| Optimum up incline | $\theta = 45^\circ + \alpha/2$ | — |

## Derivation

Time of flight: set $y = 0$ in $y = u\sin\theta\, t - \frac12 gt^2$. Max height: $v_y = 0$ at the peak. Range: $R = u\cos\theta \cdot T$. Trajectory: eliminate $t$ between $x$ and $y$. Speed at height: from $v^2 = u^2 + 2as$ applied vertically — hence angle-independent. [Full derivations: 01.3-Proofs-Projectile-Motion]

## Method

1. **Resolve the launch velocity** into horizontal (constant) and vertical (SUVAT) components.
2. **Vertical equations** answer height/time questions; **horizontal** answers range questions ($x = u\cos\theta \cdot t$ — shared time $t$).
3. At the peak: $v_y = 0$.
4. **Inclined planes:** measure angles relative to the plane; the formulas change.

## Worked Examples

**Setup:** A projectile is launched at $30^\circ$ with $u = 20$ m/s ($g = 10$). Find range and max height.

**Solution:** $R = \frac{u^2\sin 2\theta}{g} = \frac{400\sin 60^\circ}{10} = 20\sqrt3 \approx 34.6$ m. $H = \frac{u^2\sin^2\theta}{2g} = \frac{400 \cdot \frac14}{20} = 5$ m.

**Key insight:** $R$ uses $\sin 2\theta$; $H$ uses $\sin^2\theta$ — different trig factors, easy to confuse.

---

**Setup:** Two projectiles launched at complementary angles ($\theta$ and $90^\circ-\theta$) with the same speed — compare ranges.

**Solution:** $\sin 2\theta = \sin(180^\circ - 2\theta) = \sin 2(90^\circ-\theta)$ — **equal ranges**.

**Key insight:** Complementary angles give the same range (one high-and-short, one low-and-long).

## Common Traps

- Using SUVAT horizontally (acceleration there is zero, not $g$)
- Forgetting the vertical component has $a = -g$
- Applying level-ground range formulas on inclined planes
- $v^2 = u^2 - 2gy$ sign — speed depends only on height dropped
- Assuming max range is at $45^\circ$ on an incline (it's $45^\circ + \alpha/2$)
