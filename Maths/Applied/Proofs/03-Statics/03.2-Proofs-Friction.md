# Proofs: Friction

**Syllabus:** GCE A/L Combined Mathematics (021) — Paper II, Topic 3.2

---

## Proof 1: Angle of Friction

**Statement:** At limiting equilibrium, the angle $\lambda$ between the resultant contact force and the normal reaction satisfies $\tan\lambda = \mu$.

**Proof:**
At limiting equilibrium: friction $F = \mu R$.
Resultant $S = \sqrt{R^2 + F^2}$.
Angle $\lambda$ between $S$ and $R$:
$\tan\lambda = \frac{F}{R} = \frac{\mu R}{R} = \mu$.
Thus $\lambda = \tan^{-1}\mu$.
∎

---

## Proof 2: Cone of Friction

**Statement:** For a given normal reaction $R$, the resultant contact force $\vec{S} = \vec{R} + \vec{F}$ must lie within a cone of half-angle $\lambda = \tan^{-1}\mu$ about the normal.

**Proof:**
Static friction satisfies $F \leq \mu R$.
Resultant magnitude $S = \sqrt{R^2 + F^2}$.
Angle $\theta$ from normal: $\tan\theta = \frac{F}{R} \leq \mu = \tan\lambda$.
Thus $\theta \leq \lambda$.
All possible $\vec{S}$ form a cone of semi-angle $\lambda$ about the normal.
∎

## Proof 3: Minimum Force to Move Block on Rough Horizontal Plane

**Statement:** Minimum horizontal force $P$ to move a block of weight $W$ on a rough plane ($\mu$) is $P_{\text{min}} = \mu W$, applied horizontally. If force can be applied at angle $\alpha$, minimum is $P_{\text{min}} = W\sin\lambda = \frac{\mu W}{\sqrt{1+\mu^2}}$ at $\alpha = \lambda$.

**Proof:**
Force $P$ at angle $\alpha$ to horizontal.
$R = W - P\sin\alpha$, $F = P\cos\alpha$.
At limiting equilibrium: $P\cos\alpha = \mu(W - P\sin\alpha)$.
$P = \frac{\mu W}{\cos\alpha + \mu\sin\alpha}$.
Minimize $P$ wrt $\alpha$: denominator max when $\frac{d}{d\alpha}(\cos\alpha + \mu\sin\alpha) = -\sin\alpha + \mu\cos\alpha = 0$.
$\Rightarrow \tan\alpha = \mu = \tan\lambda \Rightarrow \alpha = \lambda$.
Substitute: $\cos\lambda + \mu\sin\lambda = \cos\lambda + \tan\lambda\sin\lambda = \frac{\cos^2\lambda + \sin^2\lambda}{\cos\lambda} = \frac{1}{\cos\lambda} = \sqrt{1+\mu^2}$.
$P_{\text{min}} = \frac{\mu W}{\sqrt{1+\mu^2}} = W\sin\lambda$.
∎

## Proof 4: Equilibrium on Rough Inclined Plane

**Statement:** A block on a rough plane of angle $\theta$ remains in equilibrium without external force iff $\theta \leq \lambda$, where $\lambda = \tan^{-1}\mu$ is the angle of friction (also called angle of repose).

**Proof:**
Forces: Weight $W$, Normal $R$, Friction $F$.
$R = W\cos\theta$, component down plane $W\sin\theta$.
Equilibrium: $F = W\sin\theta$ with $F \leq \mu R = \mu W\cos\theta$.
$W\sin\theta \leq \mu W\cos\theta \Rightarrow \tan\theta \leq \mu \Rightarrow \theta \leq \tan^{-1}\mu = \lambda$.
At $\theta = \lambda$: limiting equilibrium (angle of repose).
∎

## Proof 5: Ladder Against Rough Wall and Floor

**Statement:** Uniform ladder length $2l$, weight $W$, angle $\alpha$, rough wall ($\mu_w$) and floor ($\mu_f$). For limiting equilibrium at both contacts:
$$
\tan\alpha = \frac{1 - \mu_f\mu_w}{2\mu_f}
$$

**Proof:**
Forces: $W$ at centre, $R_f, F_f = \mu_f R_f$ at floor, $R_w, F_w = \mu_w R_w$ at wall.
Equilibrium:
$\sum F_x = 0: R_w = F_f = \mu_f R_f$
$\sum F_y = 0: R_f + F_w = W \Rightarrow R_f + \mu_w R_w = W$
Substitute $R_w$: $R_f + \mu_w\mu_f R_f = W \Rightarrow R_f = \frac{W}{1 + \mu_f\mu_w}$, $R_w = \frac{\mu_f W}{1 + \mu_f\mu_w}$

$\sum M_{\text{floor}} = 0$:
$W(l\cos\alpha) = R_w(2l\sin\alpha) + F_w(2l\cos\alpha) = R_w(2l\sin\alpha) + \mu_w R_w(2l\cos\alpha)$
$W\cos\alpha = 2\mu_f R_f(\sin\alpha + \mu_w\cos\alpha) = \frac{2\mu_f W}{1 + \mu_f\mu_w}(\sin\alpha + \mu_w\cos\alpha)$

Simplify:
$(1 + \mu_f\mu_w)\cos\alpha = 2\mu_f(\sin\alpha + \mu_w\cos\alpha)$
$\cos\alpha + \mu_f\mu_w\cos\alpha = 2\mu_f\sin\alpha + 2\mu_f\mu_w\cos\alpha$
$\cos\alpha = 2\mu_f\sin\alpha + \mu_f\mu_w\cos\alpha$
Divide by $\cos\alpha$:
$1 = 2\mu_f\tan\alpha + \mu_f\mu_w$
$\tan\alpha = \frac{1 - \mu_f\mu_w}{2\mu_f}$.
∎

## Proof 6: Capstan Equation (Rope on Rough Cylinder)

**Statement:** For a rope wrapped around a rough cylinder with angle of contact $\theta$ (radians), coefficient $\mu$, the tension ratio is $\frac{T_2}{T_1} = e^{\mu\theta}$ where $T_2 > T_1$.

**Proof:**
Consider element $d\theta$. Tension $T$ on one side, $T+dT$ on other.
Normal reaction $dN$ from cylinder.
Friction $dF = \mu dN$ (impending slip towards $T_2$).
Radial equilibrium: $dN = (T + \frac{dT}{2})d\theta \approx T\,d\theta$ (for small $d\theta$).
Tangential equilibrium: $T + dT = T + dF = T + \mu dN = T + \mu T\,d\theta$.
$\Rightarrow dT = \mu T\,d\theta$.
$\frac{dT}{T} = \mu\,d\theta$.
Integrate from $T_1$ to $T_2$ and $0$ to $\theta$:
$\ln\frac{T_2}{T_1} = \mu\theta \Rightarrow \frac{T_2}{T_1} = e^{\mu\theta}$.
∎

## Proof 7: Wedge Problem (Self-Locking Condition)

**Statement:** For a wedge of angle $\alpha$ and coefficient $\mu$ on all faces, the wedge is self-locking (cannot be pushed out) if $\mu \geq \cot\alpha$.

**Proof:**
Force $P$ to push wedge under load $W$.
Resolve forces on load: $R_1$ normal to slope, $F_1 = \mu R_1$.
Vertical: $W = R_1\cos\alpha - F_1\sin\alpha = R_1(\cos\alpha - \mu\sin\alpha)$.
Resolve forces on wedge: $P$ horizontal, reactions from load and ground.
Ground: $R_2, F_2 = \mu R_2$.
Horizontal: $P = R_1\sin\alpha + F_1\cos\alpha + F_2 = R_1\sin\alpha + \mu R_1\cos\alpha + \mu R_2$.
Vertical (wedge): $R_2 = R_1\cos\alpha + F_1\sin\alpha = R_1(\cos\alpha + \mu\sin\alpha)$.

Substitute: $P = R_1\sin\alpha + \mu R_1\cos\alpha + \mu R_1(\cos\alpha + \mu\sin\alpha)$
$= R_1[\sin\alpha + \mu\cos\alpha + \mu\cos\alpha + \mu^2\sin\alpha]$
$= R_1[(1+\mu^2)\sin\alpha + 2\mu\cos\alpha]$

From $W = R_1(\cos\alpha - \mu\sin\alpha)$:
$P = W \frac{(1+\mu^2)\sin\alpha + 2\mu\cos\alpha}{\cos\alpha - \mu\sin\alpha}$

If $\cos\alpha - \mu\sin\alpha \leq 0 \Rightarrow \mu \geq \cot\alpha$, then $W$ cannot be supported for any finite $P$ (or $P \to \infty$ to push in, and wedge locks).
∎

## Proof 8: Equilibrium Range on Inclined Plane with Applied Force

**Statement:** For a block on a rough inclined plane ($\theta$, $\mu$) with force $P$ parallel to plane (up positive), equilibrium range is:
$$
W(\sin\theta - \mu\cos\theta) \leq P \leq W(\sin\theta + \mu\cos\theta)
$$

**Proof:**
Case 1: $P$ up plane (preventing sliding down).
Friction $F$ acts up plane.
$P + F = W\sin\theta$, $R = W\cos\theta$.
$F \leq \mu R \Rightarrow P \geq W\sin\theta - \mu W\cos\theta$.

Case 2: $P$ up plane (preventing sliding up).
Friction $F$ acts down plane.
$P = W\sin\theta + F \leq W\sin\theta + \mu W\cos\theta$.

Combining: $W(\sin\theta - \mu\cos\theta) \leq P \leq W(\sin\theta + \mu\cos\theta)$.
∎

## Proof 9: Friction on a Particle Inside a Rough Hemisphere

**Statement:** A particle inside a rough hemispherical bowl of radius $r$ is in equilibrium at angle $\theta$ from vertical iff $\tan\theta \leq \mu$.

**Proof:**
Forces: Weight $W$ down, Normal $R$ radial, Friction $F$ tangential.
Tangential equilibrium: $W\sin\theta = F$.
Radial equilibrium: $R = W\cos\theta$.
Limiting: $F \leq \mu R \Rightarrow W\sin\theta \leq \mu W\cos\theta \Rightarrow \tan\theta \leq \mu$.
∎

## Proof 10: Range of Angles for Ladder on Rough Floor, Smooth Wall

**Statement:** Uniform ladder length $2l$, weight $W$, angle $\theta$, rough floor ($\mu$), smooth wall. Equilibrium requires $\theta \geq \tan^{-1}\frac{1}{2\mu}$.

**Proof:**
Forces: $W$ at centre, $R_w$ at wall (horizontal), $R_f, F_f = \mu R_f$ at floor.
$\sum F_x = 0: R_w = F_f = \mu R_f$
$\sum F_y = 0: R_f = W$
$\sum M_{\text{floor}} = 0: W(l\cos\theta) = R_w(2l\sin\theta) = \mu W(2l\sin\theta)$
$\cos\theta = 2\mu\sin\theta \Rightarrow \cot\theta = 2\mu \Rightarrow \tan\theta = \frac{1}{2\mu}$.
For equilibrium with $F_f \leq \mu R_f$: $\tan\theta \geq \frac{1}{2\mu}$.
∎
