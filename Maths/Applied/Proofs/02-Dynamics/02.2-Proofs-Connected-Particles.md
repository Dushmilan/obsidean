# Proofs: Connected Particles

**Syllabus:** GCE A/L Combined Mathematics (021) — Paper II, Topic 2.2

---

## Proof 1: Atwood Machine — Acceleration and Tension

**Statement:** For masses $m_1$, $m_2$ ($m_2 > m_1$) hanging over smooth pulley:
$$
a = \frac{m_2 - m_1}{m_1 + m_2}g, \quad T = \frac{2m_1m_2}{m_1 + m_2}g
$$

**Proof:**
FBD equations:
- $m_1$: $T - m_1g = m_1a$  (up positive)
- $m_2$: $m_2g - T = m_2a$  (down positive)

Add equations:
$$
m_2g - m_1g = (m_1 + m_2)a \implies a = \frac{m_2 - m_1}{m_1 + m_2}g
$$

Substitute $a$ into $T = m_1g + m_1a$:
$$
T = m_1g + m_1\left(\frac{m_2 - m_1}{m_1 + m_2}g\right) = m_1g\left(1 + \frac{m_2 - m_1}{m_1 + m_2}\right) = \frac{2m_1m_2}{m_1 + m_2}g
$$
∎

## Proof 2: Atwood Machine — Pulley Reaction

**Statement:** Reaction force on pulley support is $R = 2T = \frac{4m_1m_2}{m_1 + m_2}g$.

**Proof:**
Pulley experiences two downward tensions $T$. For equilibrium of massless pulley:
$$
R = T + T = 2T = \frac{4m_1m_2}{m_1 + m_2}g
$$
∎

## Proof 3: Horizontal Surface + Hanging Mass

**Statement:** For $m_1$ on smooth horizontal table connected to hanging $m_2$:
$$
a = \frac{m_2}{m_1 + m_2}g, \quad T = \frac{m_1m_2}{m_1 + m_2}g
$$

**Proof:**
- $m_1$: $T = m_1a$
- $m_2$: $m_2g - T = m_2a$

Add: $m_2g = (m_1 + m_2)a \implies a = \frac{m_2}{m_1 + m_2}g$

Then $T = m_1a = \frac{m_1m_2}{m_1 + m_2}g$. ∎

## Proof 4: Rough Horizontal Surface + Hanging Mass

**Statement:** With friction coefficient $\mu$ on table:
$$
a = \frac{m_2 - \mu m_1}{m_1 + m_2}g, \quad T = \frac{m_1m_2(1+\mu)}{m_1 + m_2}g
$$

**Proof:**
- $m_1$: $T - \mu m_1g = m_1a$
- $m_2$: $m_2g - T = m_2a$

Add: $m_2g - \mu m_1g = (m_1 + m_2)a \implies a = \frac{m_2 - \mu m_1}{m_1 + m_2}g$

Tension: $T = m_1a + \mu m_1g = m_1\left(\frac{m_2 - \mu m_1}{m_1 + m_2}g\right) + \mu m_1g$
$$
= \frac{m_1m_2 - \mu m_1^2 + \mu m_1^2 + \mu m_1m_2}{m_1 + m_2}g = \frac{m_1m_2(1+\mu)}{m_1 + m_2}g
$$
∎

## Proof 5: Double Inclined Planes (Smooth)

**Statement:** For $m_1$ on $\theta_1$, $m_2$ on $\theta_2$, string over pulley:
$$
a = \frac{m_2\sin\theta_2 - m_1\sin\theta_1}{m_1 + m_2}g, \quad T = \frac{m_1m_2(\sin\theta_1 + \sin\theta_2)}{m_1 + m_2}g
$$

**Proof:**
- $m_1$ (up plane): $T - m_1g\sin\theta_1 = m_1a$
- $m_2$ (down plane): $m_2g\sin\theta_2 - T = m_2a$

Add:
$$
g(m_2\sin\theta_2 - m_1\sin\theta_1) = (m_1 + m_2)a \implies a = \frac{m_2\sin\theta_2 - m_1\sin\theta_1}{m_1 + m_2}g
$$

Substitute into $T = m_1g\sin\theta_1 + m_1a$:
$$
T = m_1g\sin\theta_1 + m_1\frac{m_2\sin\theta_2 - m_1\sin\theta_1}{m_1 + m_2}g
= \frac{m_1(m_1+m_2)\sin\theta_1 + m_1m_2\sin\theta_2 - m_1^2\sin\theta_1}{m_1 + m_2}g
= \frac{m_1m_2(\sin\theta_1 + \sin\theta_2)}{m_1 + m_2}g
$$
∎

## Proof 6: Inclined Plane + Hanging Mass (Smooth)

**Statement:** $m_1$ on incline $\theta$, $m_2$ hanging:
$$
a = \frac{m_2 - m_1\sin\theta}{m_1 + m_2}g, \quad T = \frac{m_1m_2(1+\sin\theta)}{m_1 + m_2}g
$$

**Proof:**
- $m_1$: $T - m_1g\sin\theta = m_1a$
- $m_2$: $m_2g - T = m_2a$

Add: $g(m_2 - m_1\sin\theta) = (m_1 + m_2)a$. Result follows. ∎

---

## Proof 7: Rough Inclined Plane + Hanging Mass

**Statement:** With friction $\mu$ on incline (assume $m_1$ moves up):
$$
a = \frac{m_2 - m_1(\sin\theta + \mu\cos\theta)}{m_1 + m_2}g
$$

**Proof:**
- $m_1$: $T - m_1g\sin\theta - \mu m_1g\cos\theta = m_1a$
- $m_2$: $m_2g - T = m_2a$

Add:
$$
m_2g - m_1g(\sin\theta + \mu\cos\theta) = (m_1 + m_2)a
$$
$$
a = \frac{m_2 - m_1(\sin\theta + \mu\cos\theta)}{m_1 + m_2}g
$$
∎

---

## Proof 8: Condition for Motion on Rough Incline

**Statement:** $m_1$ moves up the plane iff $m_2 > m_1(\sin\theta + \mu\cos\theta)$.

**Proof:**
From Proof 7, $a > 0$ (up plane) requires:
$$
m_2 - m_1(\sin\theta + \mu\cos\theta) > 0 \implies m_2 > m_1(\sin\theta + \mu\cos\theta)
$$
If equality, $a=0$ (limiting equilibrium). If less, $m_1$ moves down (friction reverses). ∎

## Proof 9: Three Particles in Line on Horizontal Surface

**Statement:** For $m_1 \xrightarrow{T_1} m_2 \xrightarrow{T_2} m_3$ pulled by force $F$ on $m_1$:
$$
a = \frac{F}{M}, \quad T_2 = \frac{m_3}{M}F, \quad T_1 = \frac{m_2+m_3}{M}F
$$
where $M = m_1+m_2+m_3$.

**Proof:**
- $m_1$: $F - T_1 = m_1a$
- $m_2$: $T_1 - T_2 = m_2a$
- $m_3$: $T_2 = m_3a$

Add all: $F = (m_1+m_2+m_3)a = Ma \implies a = F/M$.

From $m_3$: $T_2 = m_3a = m_3F/M$.

From $m_2$: $T_1 = T_2 + m_2a = (m_3+m_2)F/M$. ∎

## Proof 10: Movable Pulley (Mass $M$) with Hanging Mass $m$

**Statement:** For movable pulley with mass $M$, string fixed at ceiling, mass $m$ hanging from string:
$$
a_m = \frac{2mg}{M+4m}g \quad (\text{Wait, let's derive properly})
$$

**Proof:**
Let $a_p$ = acceleration of pulley (up positive), $a_m$ = acceleration of mass (down positive).
Constraint: $a_m = 2a_p$ (pulley rises $x$, string shortens by $2x$ on both sides).

FBDs:
- Pulley ($M$): $2T - Mg = Ma_p$
- Mass $m$: $mg - T = ma_m = m(2a_p)$

From second: $T = mg - 2ma_p$.

Substitute into first:
$$
2(mg - 2ma_p) - Mg = Ma_p \implies 2mg - 4ma_p - Mg = Ma_p
$$
$$
2mg - Mg = (M + 4m)a_p \implies a_p = \frac{2m - M}{M + 4m}g
$$

Then $a_m = 2a_p = \frac{4m - 2M}{M + 4m}g = \frac{2(2m - M)}{M + 4m}g$.

Tension: $T = mg - 2ma_p = mg - 2m\frac{2m - M}{M + 4m}g = \frac{mg(M + 4m - 4m + 2M)}{M + 4m} = \frac{3Mm}{M + 4m}g$.

∎

## Proof 11: String Length Constraint — Wedge and Block

**Statement:** For block on wedge ($\theta$) connected to fixed point:
$$
a_{\text{wedge}} + a_{\text{block}}\cos\theta = 0
$$

**Proof:**
Let $x$ = horizontal displacement of wedge, $y$ = displacement of block along wedge.
String length: $L = x + y + \text{constants}$ (horizontal segment + along plane segment).
Differentiate twice:
$$
0 = \ddot{x} + \ddot{y} \implies a_w + a_b = 0
$$
Wait — careful: $y$ is along the plane. The string segment along the plane has horizontal projection $y\cos\theta$. So:
$$
L = x + y\cos\theta + \text{const} \implies 0 = a_w + a_b\cos\theta
$$
∎

## Proof 12: Massive Pulley (Moment of Inertia $I$, Radius $R$)

**Statement:** For Atwood machine with massive pulley:
$$
a = \frac{m_2 - m_1}{m_1 + m_2 + I/R^2}g
$$

**Proof:**
- $m_1$: $T_1 - m_1g = m_1a$
- $m_2$: $m_2g - T_2 = m_2a$
- Pulley: $(T_2 - T_1)R = I\alpha = I(a/R)$

From pulley: $T_2 - T_1 = \frac{I}{R^2}a$.

Add all three:
$$
m_2g - m_1g = (m_1 + m_2)a + \frac{I}{R^2}a = \left(m_1 + m_2 + \frac{I}{R^2}\right)a
$$
$$
a = \frac{m_2 - m_1}{m_1 + m_2 + I/R^2}g
$$
∎
