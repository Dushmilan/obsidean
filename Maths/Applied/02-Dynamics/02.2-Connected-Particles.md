# Connected Particles

**Syllabus:** GCE A/L Combined Mathematics (021) — Paper II, Topic 2.2

---

## 1. General Principles

**System:** Two or more particles connected by light, inextensible strings passing over smooth (or rough) pulleys.

**Key Assumptions:**
- String: massless, inextensible, doesn't stretch
- Pulley: smooth (frictionless), massless, changes direction only
- Tension: same throughout a continuous string over smooth pulley
- Acceleration: all connected particles have same magnitude (if string taut)

---

## 2. Standard Configurations

### 2.1 Two Particles — One Horizontal, One Hanging

```
    m₁ (horizontal surface) ───┬─── string ─── m₂ (hanging)
                               │
                          pulley (smooth)
```

**Equations:**
- $m_1$ (horizontal): $T = m_1 a$
- $m_2$ (vertical): $m_2 g - T = m_2 a$

**Solution:**
$$
a = \frac{m_2 g}{m_1 + m_2}, \quad T = \frac{m_1 m_2 g}{m_1 + m_2}
$$

---

### 2.2 Two Particles on Inclined Planes

```
    m₁ on incline θ₁ ───┬─── string ─── m₂ on incline θ₂
                        │
                   pulley (smooth)
```

**Equations** (assuming $m_1$ moves up plane):
- $m_1$: $T - m_1 g \sin\theta_1 = m_1 a$
- $m_2$: $m_2 g \sin\theta_2 - T = m_2 a$

**Solution:**
$$
a = \frac{m_2 \sin\theta_2 - m_1 \sin\theta_1}{m_1 + m_2} g, \quad T = \frac{m_1 m_2 (\sin\theta_1 + \sin\theta_2)}{m_1 + m_2} g
$$

---

### 2.3 Particle on Rough Incline + Hanging Particle

```
    m₁ on rough incline θ (μ) ───┬─── string ─── m₂ (hanging)
                                 │
                            pulley (smooth)
```

**Equations** (assuming $m_1$ moves up):
- $m_1$: $T - m_1 g \sin\theta - \mu m_1 g \cos\theta = m_1 a$
- $m_2$: $m_2 g - T = m_2 a$

**Solution:**
$$
a = \frac{m_2 - m_1(\sin\theta + \mu\cos\theta)}{m_1 + m_2} g
$$

---

## 3. Multiple Pulleys (Block and Tackle)

### Movable Pulley
- Mechanical advantage = 2
- If load $W$ hangs from movable pulley, $2T = W$ (static)
- For acceleration: $2T - W = \frac{W}{g}a$

### General Rule
For $n$ strings supporting a load:
- Total upward force = $nT$
- Constraint: displacement of load = $\frac{1}{n}$ × displacement of effort point

---

## 4. Massive Strings / Ropes

If string has mass $\lambda$ per unit length:
- Tension varies along string: $T(x) = T_0 + \lambda g x$ (vertical)
- For horizontal massive string pulled by force $F$: $T(x) = F(1 - \frac{x}{L})$

---

## 5. Constraint Relations (Inextensible String)

### String Length Constant
$$
\text{Total string length} = \text{constant}
$$
Differentiate w.r.t time for velocity constraints, again for acceleration.

### Example: Wedge and Block
```
    Block on wedge (θ) ── string ── pulley ── fixed point
```

If wedge moves horizontally by $x$, block moves along wedge by $y$:
$$
x + y\cos\theta = \text{constant} \implies a_{\text{wedge}} + a_{\text{block}}\cos\theta = 0
$$

---

## 6. Smooth vs Rough Pulleys

| Pulley Type | Tension | Moment of Inertia |
|-------------|---------|-------------------|
| Smooth, massless | Same both sides | $I = 0$ |
| Rough, massless | Same both sides | $I = 0$ (no slip) |
| Rough, massive | $T_1 \neq T_2$ | $I \neq 0$ |

**Massive rough pulley:**
$$
(T_1 - T_2)R = I\alpha, \quad a = \alpha R
$$

---

## 7. Solution Strategy

1. **Draw FBD for each particle**
2. **Identify constraints** (string length, geometry)
3. **Choose coordinate axes** (along motion direction for each)
4. **Write $\sum F = ma$ for each particle**
5. **Apply constraint equations** to relate accelerations
6. **Solve system** for $a$, $T$, etc.
7. **Check consistency** (tensions positive, accelerations in assumed directions)

---

## 8. Common Pitfalls

- Assuming same acceleration direction for all particles
- Forgetting normal reaction on inclined planes
- Wrong friction direction (opposes *relative* motion/tendency)
- Using $g$ instead of $g\sin\theta$ on inclines
- Ignoring pulley mass when given
- Sign errors in constraint equations
