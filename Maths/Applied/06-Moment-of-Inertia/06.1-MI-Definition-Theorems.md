
## Definition

Moment of inertia (MI) measures how mass is distributed relative to a rotation axis:

$$I = \sum m_i r_i^2 \quad (\text{discrete}), \qquad I = \int r^2\,dm \quad (\text{continuous})$$

**Radius of gyration:** $k = \sqrt{I/M}$ — the distance at which all the mass could be concentrated to give the same MI ($I = Mk^2$).

**Parallel axes theorem:** $I = I_{CM} + Md^2$ — MI about a parallel axis = MI about the CM axis + $Md^2$.
**Perpendicular axes theorem:** $I_z = I_x + I_y$ — planar lamina only (in the $xy$-plane).

## The Intuition

Pushing a door: MI depends only on mass distribution. Mass far from the axis contributes a lot ($mr^2$); mass near the axis contributes little — the $r^2$ weighting means outer layers dominate. A hollow cylinder has *more* MI than a solid one of the same mass (mass farther out). MI is **minimum about the CM axis**; any parallel axis adds $Md^2$.

## The Toolkit

| Result | Formula | Valid when |
|--------|---------|-----------|
| Discrete | $I = \sum m_i r_i^2$ | point masses |
| Continuous | $I = \int r^2\,dm$ | any body |
| Radius of gyration | $k = \sqrt{I/M}$ | — |
| Parallel axes | $I = I_{CM} + Md^2$ | parallel axes |
| Perpendicular axes | $I_z = I_x + I_y$ | planar lamina in $xy$-plane |
| Torque | $\tau = I\alpha$ | fixed axis |

## Derivation

Parallel axes: for mass element $dm$ at $\vec{r}$ from the CM, distance to a parallel axis at $\vec{d}$ is $|\vec{r}+\vec{d}|$. Then $I = \int (r^2 + d^2 + 2\vec{r}\cdot\vec{d})\,dm = I_{CM} + Md^2$, since $\int\vec{r}\,dm = 0$ by the CM definition. Perpendicular axes: $r^2 = x^2 + y^2$ for a lamina, so $\int r^2\,dm = \int x^2\,dm + \int y^2\,dm$. [Full derivations: 06.1-MI-Definition-Theorems-Proof]

## Method

1. **Choose the axis** — the problem's axis of rotation.
2. Find the CM-axis MI (standard table or integration), then shift with the parallel-axes theorem.
3. **Planar lamina:** use perpendicular-axes to relate $I_x, I_y, I_z$.
4. Composite bodies: combine standard MIs with the theorems.

## Worked Examples

**Setup:** A rod of mass $M$, length $L$ about its centre is $I_{CM} = \frac{1}{12}ML^2$. Find the MI about one end.

**Solution:** Parallel axes with $d = L/2$: $I = \frac{1}{12}ML^2 + M(L/2)^2 = \frac13 ML^2$.

**Key insight:** Shifting from the centre to the end multiplies by 4 — always $I_{CM} + Md^2$.

---

**Setup:** A uniform square lamina has $I_z$ about its centre. Relate $I_x, I_y$.

**Solution:** By symmetry $I_x = I_y$; perpendicular axes: $I_z = I_x + I_y = 2I_x$.

**Key insight:** The perpendicular-axes theorem turns a 3D question into a 2D symmetry argument.

## Common Traps

- Using the perpendicular-axes theorem on 3D bodies (lamina only)
- Applying parallel axes from the wrong axis (must be through the CM)
- Radius of gyration: $I = Mk^2$, not $I = Mk$
- Forgetting $r$ is the perpendicular distance to the axis, not the radial distance to a point
- Adding MIs about different axes
