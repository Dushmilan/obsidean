# Vector Subtraction

> **Stewart Calculus, Chapter 12, Section 12.2**

## Definition
**Vector subtraction** is defined as addition with the [[Negative-Vector|negative]]:

$$\mathbf{u} - \mathbf{v} = \mathbf{u} + (-\mathbf{v}) = \langle u_1 - v_1, \, u_2 - v_2, \, u_3 - v_3 \rangle$$

## Key Properties
- Component-wise subtraction
- Geometrically: when $\mathbf{u}$ and $\mathbf{v}$ share the same tail, $\mathbf{u} - \mathbf{v}$ points from the tip of $\mathbf{v}$ to the tip of $\mathbf{u}$
- Used to find the vector between two points: $\overrightarrow{AB} = \mathbf{b} - \mathbf{a}$

## Worked Example
If $A(1, 2, 3)$ and $B(4, 5, 6)$:
$$\overrightarrow{AB} = \langle 4-1, \, 5-2, \, 6-3 \rangle = \langle 3, 3, 3 \rangle$$

Algebraic check: $\mathbf{b} - \mathbf{a} = \langle 4,5,6 \rangle - \langle 1,2,3 \rangle = \langle 3,3,3 \rangle$
