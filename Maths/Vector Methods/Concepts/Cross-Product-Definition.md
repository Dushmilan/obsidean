# Cross Product Definition

The cross product $\mathbf{a}\times\mathbf{b}$ is a vector orthogonal to both $\mathbf{a}$ and $\mathbf{b}$. It is only defined in $\mathbb{R}^3$.

## Magnitude

$$\|\mathbf{a}\times\mathbf{b}\| = \|\mathbf{a}\|\|\mathbf{b}\|\sin\theta$$
