# Vector Definition

> **Stewart Calculus, Chapter 12, Section 12.2**

## Definition
A **vector** is a mathematical object possessing both **magnitude** (length) and **direction**. Vectors are used to represent quantities such as force, velocity, and displacement.

- **Notation:** $\mathbf{v}$, $\vec{v}$, or $\langle v_1, v_2, v_3 \rangle$ (component form)
- **Contrast with scalars:** Scalars have magnitude only (e.g., temperature, mass)

## Key Properties
- A vector is determined solely by its magnitude and direction, not by its position in space
- Component form $\langle v_1, v_2, v_3 \rangle$ encodes the vector in a coordinate system
- The **standard position** vector starts at the origin $(0,0,0)$

## Worked Example
The vector from point $A(1, 2, 3)$ to $B(4, 6, 3)$ has components:
$$\overrightarrow{AB} = \langle 4-1, 6-2, 3-3 \rangle = \langle 3, 4, 0 \rangle$$

Its magnitude is $\|\overrightarrow{AB}\| = \sqrt{3^2 + 4^2 + 0^2} = 5$.
