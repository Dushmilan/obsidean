# Zero Vector

> **Stewart Calculus, Chapter 12, Section 12.2**

## Definition
The **zero vector** is the unique vector with magnitude zero:

$$\mathbf{0} = \langle 0, 0, 0 \rangle$$

## Key Properties
- **Magnitude:** $\|\mathbf{0}\| = 0$
- **Direction:** Undefined (arbitrary or no direction)
- **Additive identity:** $\mathbf{v} + \mathbf{0} = \mathbf{v}$ for any vector $\mathbf{v}$
- All zero vectors are equivalent regardless of their "position"

## Worked Example
For any vector $\mathbf{v} = \langle 3, -1, 4 \rangle$:
$$\mathbf{v} + \mathbf{0} = \langle 3, -1, 4 \rangle + \langle 0, 0, 0 \rangle = \langle 3, -1, 4 \rangle = \mathbf{v}$$
