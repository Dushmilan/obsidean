# Vector Projection

The vector projection (shadow) of $\mathbf{b}$ onto $\mathbf{a}$ is:

$$\text{proj}_{\mathbf{a}}\mathbf{b} = \frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|^2}\mathbf{a} = (\text{comp}_{\mathbf{a}}\mathbf{b})\hat{\mathbf{a}}$$

## Example

Project $\langle 3,4 \rangle$ onto $\langle 1,0 \rangle$:

$$\text{proj} = \frac{3}{1}\langle 1,0 \rangle = \langle 3,0 \rangle$$
