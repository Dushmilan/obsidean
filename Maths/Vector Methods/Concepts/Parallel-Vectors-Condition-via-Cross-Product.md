# Parallel Vectors Condition via Cross Product

Two nonzero vectors are parallel if and only if:

$$\mathbf{a}\times\mathbf{b} = \mathbf{0}$$

This is equivalent to one vector being a scalar multiple of the other.

## Example

$$\langle 1,2,3 \rangle \times \langle 2,4,6 \rangle = \langle 0,0,0 \rangle$$

since $\langle 2,4,6 \rangle = 2\langle 1,2,3 \rangle$.
