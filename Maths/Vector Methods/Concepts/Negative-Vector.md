# Negative Vector

> **Stewart Calculus, Chapter 12, Section 12.2**

## Definition
The **negative** of a vector $\mathbf{v}$ is the vector with the same magnitude but opposite direction:

$$-\mathbf{v} = (-1)\mathbf{v} = \langle -v_1, \, -v_2, \, -v_3 \rangle$$

## Key Properties
- $\|-\mathbf{v}\| = \|\mathbf{v}\|$ (same magnitude)
- Direction is exactly reversed ($180°$ rotation)
- **Additive inverse:** $\mathbf{v} + (-\mathbf{v}) = \mathbf{0}$
- $-(-\mathbf{v}) = \mathbf{v}$ (double negation returns original)
- Relates to directed segments: $\overrightarrow{BA} = -\overrightarrow{AB}$

## Worked Example
$$\mathbf{v} = \langle 3, -1, 4 \rangle$$
$$-\mathbf{v} = \langle -3, 1, -4 \rangle$$
$$\mathbf{v} + (-\mathbf{v}) = \langle 3+(-3), \, -1+1, \, 4+(-4) \rangle = \langle 0, 0, 0 \rangle = \mathbf{0}$$
