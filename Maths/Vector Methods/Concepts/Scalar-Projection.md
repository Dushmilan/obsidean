# Scalar Projection

The scalar projection (component) of $\mathbf{b}$ along $\mathbf{a}$ is:

$$\text{comp}_{\mathbf{a}}\mathbf{b} = \frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|} = \|\mathbf{b}\|\cos\theta$$

This is a **signed scalar**: positive when the angle is acute, negative when obtuse.
