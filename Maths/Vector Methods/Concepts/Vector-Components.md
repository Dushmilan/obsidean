# Vector Components

> **Stewart Calculus, Chapter 12, Section 12.2**

## Definition

A vector in two dimensions is represented as an ordered pair $\langle a_1, a_2 \rangle$, and in three dimensions as an ordered triple $\langle a_1, a_2, a_3 \rangle$. The values $a_1, a_2, a_3$ are called the **scalar components** of the vector and can be any real number, including negative values.

The expression $a_1\mathbf{i} + a_2\mathbf{j} + a_3\mathbf{k}$ is the **component form** of the vector, where $\mathbf{i}, \mathbf{j}, \mathbf{k}$ are the standard basis vectors.

## Key Properties

- Scalar components can be negative, zero, or positive
- Two vectors are equal if and only if their corresponding components are equal
- The zero vector is $\langle 0, 0, 0 \rangle$ with all components equal to zero
- Component form and bracket notation are interchangeable: $\langle a_1, a_2 \rangle = (a_1, a_2)$

## Worked Example

Express the vector from the origin to the point $P(3, -2, 5)$ in component form and component notation.

**Solution:** The vector is $\mathbf{v} = \langle 3, -2, 5 \rangle = 3\mathbf{i} - 2\mathbf{j} + 5\mathbf{k}$.

The scalar components are $a_1 = 3$, $a_2 = -2$, $a_3 = 5$.
