# Position Vector

> **Stewart Calculus, Chapter 12, Section 12.2**

## Definition

The **position vector** of a point $P(a_1, a_2, a_3)$ is the vector $\overrightarrow{OP}$ from the origin $O(0,0,0)$ to $P$. It is denoted $\mathbf{r} = \langle a_1, a_2, a_3 \rangle$.

Every point in space has a unique position vector, and every vector determines a unique point when placed in standard position (tail at the origin).

## Key Properties

- The position vector of the origin is the zero vector: $\mathbf{r}_O = \langle 0, 0, 0 \rangle$
- There is a one-to-one correspondence between points and position vectors
- The components of the position vector equal the coordinates of the point
- Position vectors allow geometric problems to be translated into algebraic ones

## Worked Example

Find the position vector of the point $Q(-1, 4, 2)$.

**Solution:** The position vector is $\mathbf{r}_Q = \overrightarrow{OQ} = \langle -1, 4, 2 \rangle$.

Check: the tail is at $O(0,0,0)$ and the head is at $Q(-1,4,2)$, so $\overrightarrow{OQ} = \langle -1-0,\; 4-0,\; 2-0 \rangle = \langle -1, 4, 2 \rangle$.
