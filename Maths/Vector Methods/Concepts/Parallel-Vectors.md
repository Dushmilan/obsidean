# Parallel Vectors

> **Stewart Calculus, Chapter 12, Section 12.2**

## Definition
Two nonzero vectors $\mathbf{u}$ and $\mathbf{v}$ are **parallel** if and only if one is a scalar multiple of the other:

$$\mathbf{u} = k\mathbf{v} \quad \text{for some scalar } k \neq 0$$

## Key Properties
- Parallel vectors point in the **same direction** ($k > 0$) or **opposite direction** ($k < 0$)
- The zero vector is considered parallel to every vector
- Parallel vectors have proportional components: $\frac{u_1}{v_1} = \frac{u_2}{v_2} = \frac{u_3}{v_3}$
- Parallel vectors are used to test if points are collinear

## Worked Example
$\mathbf{u} = \langle 2, -4, 6 \rangle$ and $\mathbf{v} = \langle 1, -2, 3 \rangle$

Since $\mathbf{u} = 2\mathbf{v}$, the vectors are parallel (same direction, $\mathbf{u}$ is twice as long).

Check: $\frac{2}{1} = \frac{-4}{-2} = \frac{6}{3} = 2$ ✓
