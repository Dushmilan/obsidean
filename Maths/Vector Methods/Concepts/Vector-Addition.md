# Vector Addition

> **Stewart Calculus, Chapter 12, Section 12.2**

## Definition
**Vector addition** combines two vectors by adding their corresponding components:

$$\mathbf{u} + \mathbf{v} = \langle u_1 + v_1, \, u_2 + v_2, \, u_3 + v_3 \rangle$$

## Key Properties
- **Commutative:** $\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}$
- **Associative:** $(\mathbf{u} + \mathbf{v}) + \mathbf{w} = \mathbf{u} + (\mathbf{v} + \mathbf{w})$
- **Identity:** $\mathbf{v} + \mathbf{0} = \mathbf{v}$
- **Inverse:** $\mathbf{v} + (-\mathbf{v}) = \mathbf{0}$
- Geometrically: [[Triangle-Law]] or [[Parallelogram-Law]]

## Worked Example
$$\langle 1, 2, 3 \rangle + \langle 4, -1, 0 \rangle = \langle 1+4, \, 2+(-1), \, 3+0 \rangle = \langle 5, 1, 3 \rangle$$
