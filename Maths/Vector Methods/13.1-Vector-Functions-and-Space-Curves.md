# Vector Functions and Space Curves

Before this section, calculus dealt with curves defined by $y = f(x)$. But many real paths — a helix, a comet's orbit, a roller coaster — cannot be written as a function of one coordinate. A vector function takes a scalar parameter and outputs a vector, tracing a curve through 3D space.

**The Intuition:** Think of a vector function as an instruction set for a robot arm. At each time $t$, you give three numbers — how far left/right, forward/back, up/down — and the arm moves to that point. A trail of breadcrumbs in 3D space: each breadcrumb is placed at time $t$, and the full trail is the curve.

**The Math:** A vector function $\mathbf{r}(t) = \langle f(t), g(t), h(t) \rangle$ can also be written $f(t)\,\mathbf{i} + g(t)\,\mathbf{j} + h(t)\,\mathbf{k}$. The domain is the intersection of all three component domains: $\text{dom}(\mathbf{r}) = \text{dom}(f) \cap \text{dom}(g) \cap \text{dom}(h)$.

Limits and continuity are handled component-wise: $\lim_{t \to a} \mathbf{r}(t) = \langle \lim_{t \to a} f(t),\; \lim_{t \to a} g(t),\; \lim_{t \to a} h(t) \rangle$, and $\mathbf{r}$ is continuous at $a$ iff each component is.

**Setup:** Let $\mathbf{r}(t) = \langle \cos t, \sin t, t \rangle$. What curve does this trace?

**Solution:** $x^2 + y^2 = 1$, so the projection onto the $xy$-plane is a unit circle. Meanwhile $z = t$ increases linearly. The result is a circular helix winding up the $z$-axis with radius 1, rising at 1 unit per radian.

**Key insight:** Identifying the curve means looking at projections onto coordinate planes first.

**Setup:** Find the domain of $\mathbf{r}(t) = \langle \sqrt{t},\; \ln(4-t),\; e^t \rangle$.

**Solution:** $\sqrt{t}$ requires $t \geq 0$. $\ln(4-t)$ requires $t < 4$. $e^t$ is defined everywhere. Intersection: $[0, 4)$.

**Key insight:** Always check each component independently, then intersect.

**Setup:** Evaluate $\lim_{t \to 0} \langle \frac{\sin t}{t},\; t^2,\; \frac{e^t - 1}{t} \rangle$.

**Solution:** Component 1: $\lim_{t \to 0} \frac{\sin t}{t} = 1$. Component 2: $0$. Component 3: $1$. Result: $\langle 1, 0, 1 \rangle$.

**Key insight:** Each component is a standard scalar limit. Don't try to evaluate the vector limit all at once.

### A/L Additional Notes

**What does this mean for Pure Mathematics?** Every vector calculus operation works component-wise. Differentiate each scalar function separately. The vector structure is preserved throughout. Kinematics is the most important application — position, velocity, speed, and acceleration are all vector functions of time.

**Acceleration decomposition:** $\mathbf{a} = v'\mathbf{T} + v^2\kappa\mathbf{N}$. The tangential component $v'$ changes speed. The normal component $v^2\kappa$ changes direction. Even at constant speed, acceleration is non-zero if the path curves.

**Setup:** $\mathbf{r}(t) = 3\cos t\,\mathbf{i} + 3\sin t\,\mathbf{j} + 4t\,\mathbf{k}$. Find velocity, acceleration, and speed. **Solution:** $\mathbf{v} = -3\sin t\,\mathbf{i} + 3\cos t\,\mathbf{j} + 4\mathbf{k}$. $\mathbf{a} = -3\cos t\,\mathbf{i} - 3\sin t\,\mathbf{j}$. $v = \sqrt{9 + 16} = 5$ (constant). **Key insight:** Constant speed does not mean zero acceleration — the direction is changing.

**Setup:** Find the curvature of $\mathbf{r}(t) = \cos t\,\mathbf{i} + \sin t\,\mathbf{j} + t\,\mathbf{k}$. **Solution:** $\mathbf{r}' = -\sin t\,\mathbf{i} + \cos t\,\mathbf{j} + \mathbf{k}$, $\|\mathbf{r}'\| = \sqrt{2}$. $\mathbf{r}'' = -\cos t\,\mathbf{i} - \sin t\,\mathbf{j}$. $\mathbf{r}' \times \mathbf{r}'' = \sin t\,\mathbf{i} - \cos t\,\mathbf{j} + \mathbf{k}$, $\|\mathbf{r}' \times \mathbf{r}''\| = \sqrt{2}$. $\kappa = \frac{\sqrt{2}}{(\sqrt{2})^3} = \frac{1}{2}$. **Key insight:** A helix has constant curvature, meaning it curves at a uniform rate.
