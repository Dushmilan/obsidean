# 05.5 Vector Equations of Lines and Planes

## Definition
Vector equations describe geometric objects (lines, planes) using vectors. A line is determined by a point and direction; a plane by a point and normal (or two directions).

## Formulae

| Formula | Expression |
|---------|------------|
| **Line (vector)** | $\mathbf{r} = \mathbf{a} + \lambda \mathbf{b}$ |
| **Line (cartesian)** | $\frac{x - a_1}{l} = \frac{y - a_2}{m} = \frac{z - a_3}{n}$ |
| **Line (two-point)** | $\mathbf{r} = \mathbf{a} + \lambda (\mathbf{b} - \mathbf{a})$ |
| **Plane (vector)** | $\mathbf{r} = \mathbf{a} + \lambda \mathbf{b} + \mu \mathbf{c}$ |
| **Plane (normal)** | $\mathbf{r} \cdot \mathbf{n} = \mathbf{a} \cdot \mathbf{n}$ or $(\mathbf{r} - \mathbf{a}) \cdot \mathbf{n} = 0$ |
| **Plane (cartesian)** | $ax + by + cz = d$ |
| **Plane (three-point)** | $(\mathbf{r} - \mathbf{a}) \cdot ((\mathbf{b} - \mathbf{a}) \times (\mathbf{c} - \mathbf{a})) = 0$ |
| **Point to plane** | $\frac{|\mathbf{p} \cdot \mathbf{n} - d|}{\|\mathbf{n}\|}$ |
| **Point to line** | $\frac{\|(\mathbf{p}-\mathbf{a}) \times \mathbf{d}\|}{\|\mathbf{d}\|}$ |
| **Skew lines** | $\frac{|(\mathbf{b}-\mathbf{a}) \cdot (\mathbf{d} \times \mathbf{e})|}{\|\mathbf{d} \times \mathbf{e}\|}$ |
| **Parallel planes** | $\frac{|d_2 - d_1|}{\|\mathbf{n}\|}$ |
| **Line & plane angle** | $\sin\theta = \frac{|\mathbf{d} \cdot \mathbf{n}|}{\|\mathbf{d}\|\|\mathbf{n}\|}$ |
| **Two planes angle** | $\cos\theta = \frac{|\mathbf{n}_1 \cdot \mathbf{n}_2|}{\|\mathbf{n}_1\|\|\mathbf{n}_2\|}$ |

## Properties / Key Concepts

### Lines
- Vector form: $\mathbf{r} = \mathbf{a} + \lambda \mathbf{b}$
- Cartesian form: if any direction component is 0, that coordinate is constant
- Two-point form: $\mathbf{r} = \mathbf{a} + \lambda (\mathbf{b} - \mathbf{a})$

### Planes
- Normal form: $(\mathbf{r} - \mathbf{a}) \cdot \mathbf{n} = 0$
- Three-point form: normal $\mathbf{n} = (\mathbf{b} - \mathbf{a}) \times (\mathbf{c} - \mathbf{a})$

### Intersections

**Line and Plane:** substitute line into plane: $(\mathbf{p} + \lambda \mathbf{d}) \cdot \mathbf{n} = k \Rightarrow \lambda = \frac{k - \mathbf{p} \cdot \mathbf{n}}{\mathbf{d} \cdot \mathbf{n}}$
- $\mathbf{d} \cdot \mathbf{n} \neq 0$: unique intersection
- $\mathbf{d} \cdot \mathbf{n} = 0$ and $\mathbf{p} \cdot \mathbf{n} = k$: line lies in plane
- $\mathbf{d} \cdot \mathbf{n} = 0$ and $\mathbf{p} \cdot \mathbf{n} \neq k$: line parallel, no intersection

**Two Planes:** intersect in line with direction $\mathbf{d} = \mathbf{n}_1 \times \mathbf{n}_2$

**Three Planes:** matrix form $N\mathbf{r} = \mathbf{d}$
- Rank 3: unique point
- Rank 2, augmented rank 2: line intersection
- Rank 2, augmented rank 3: no common intersection (prism)
- Rank 1: all parallel or coincident

### Distances
- Point to plane: $\frac{|\mathbf{p} \cdot \mathbf{n} - d|}{\|\mathbf{n}\|}$
- Point to line: $\frac{\|(\mathbf{p}-\mathbf{a}) \times \mathbf{d}\|}{\|\mathbf{d}\|}$
- Skew lines: $\frac{|(\mathbf{b}-\mathbf{a}) \cdot (\mathbf{d} \times \mathbf{e})|}{\|\mathbf{d} \times \mathbf{e}\|}$
- Parallel planes: $\frac{|d_2 - d_1|}{\|\mathbf{n}\|}$

### Angles
- Line and plane: $\sin\theta = \frac{|\mathbf{d} \cdot \mathbf{n}|}{\|\mathbf{d}\|\|\mathbf{n}\|}$ (note: uses sine, not cosine)
- Two planes: $\cos\theta = \frac{|\mathbf{n}_1 \cdot \mathbf{n}_2|}{\|\mathbf{n}_1\|\|\mathbf{n}_2\|}$

## Worked Examples

### Example 1: Line Equations
Through $A(1,2,3)$ parallel to $2\mathbf{i} - \mathbf{j} + \mathbf{k}$

Vector: $\mathbf{r} = \mathbf{i} + 2\mathbf{j} + 3\mathbf{k} + \lambda(2\mathbf{i} - \mathbf{j} + \mathbf{k})$
Cartesian: $\frac{x-1}{2} = \frac{y-2}{-1} = \frac{z-3}{1}$

### Example 2: Plane Equation
Through $A(1,2,3)$ with normal $\mathbf{n} = \mathbf{i} + 2\mathbf{j} - 3\mathbf{k}$

$\mathbf{r} \cdot (\mathbf{i} + 2\mathbf{j} - 3\mathbf{k}) = (1,2,3) \cdot (1,2,-3) = 1 + 4 - 9 = -4$
Cartesian: $x + 2y - 3z = -4$

### Example 3: Line-Plane Intersection
Line: $\mathbf{r} = \mathbf{i} + 2\mathbf{j} + 3\mathbf{k} + \lambda(2\mathbf{i} - \mathbf{j} + \mathbf{k})$
Plane: $x - 2y + z = 5$

Substitute: $(1+2\lambda) - 2(2-\lambda) + (3+\lambda) = 5$
$1+2\lambda - 4+2\lambda + 3+\lambda = 5$
$5\lambda = 5 \Rightarrow \lambda = 1$

Point: $(1+2, 2-1, 3+1) = (3, 1, 4)$

### Example 4: Distance Point to Plane
$P(1,2,3)$, Plane $2x - y + 2z = 10$

$\mathbf{n} = (2,-1,2)$, $\|\mathbf{n}\| = 3$
Distance $= \frac{|2(1) - 1(2) + 2(3) - 10|}{3} = \frac{|2 - 2 + 6 - 10|}{3} = \frac{4}{3}$

### Example 5: Skew Lines Distance
Line 1: $\mathbf{r} = \mathbf{i} + \lambda(\mathbf{i} + \mathbf{j})$
Line 2: $\mathbf{r} = \mathbf{j} + \mu(\mathbf{j} + \mathbf{k})$

$\mathbf{a} = \mathbf{i}$, $\mathbf{d} = \mathbf{i} + \mathbf{j}$
$\mathbf{b} = \mathbf{j}$, $\mathbf{e} = \mathbf{j} + \mathbf{k}$

$\mathbf{b} - \mathbf{a} = -\mathbf{i} + \mathbf{j}$
$\mathbf{d} \times \mathbf{e} = (\mathbf{i}+\mathbf{j}) \times (\mathbf{j}+\mathbf{k}) = \mathbf{i} \times \mathbf{j} + \mathbf{i} \times \mathbf{k} + \mathbf{j} \times \mathbf{j} + \mathbf{j} \times \mathbf{k} = \mathbf{k} - \mathbf{j} + \mathbf{i} = \mathbf{i} - \mathbf{j} + \mathbf{k}$

$|(\mathbf{b}-\mathbf{a}) \cdot (\mathbf{d} \times \mathbf{e})| = |(-\mathbf{i}+\mathbf{j}) \cdot (\mathbf{i}-\mathbf{j}+\mathbf{k})| = |-1-1+0| = 2$
$\|\mathbf{d} \times \mathbf{e}\| = \sqrt{1+1+1} = \sqrt{3}$

Distance $= \frac{2}{\sqrt{3}}$

### Pattern 1: Line Equations
**Given:** Point $A(1,2,3)$, direction $\mathbf{d} = 2\mathbf{i} - \mathbf{j} + \mathbf{k}$
**Find:** Vector and cartesian equations

### Pattern 2: Plane Equations
**Given:** Point $A(1,2,3)$, normal $\mathbf{n} = \mathbf{i} + 2\mathbf{j} - 3\mathbf{k}$
**Find:** Vector and cartesian equations

### Pattern 3: Line-Plane Intersection
**Given:** Line $\mathbf{r} = \mathbf{i} + 2\mathbf{j} + 3\mathbf{k} + \lambda(2\mathbf{i} - \mathbf{j} + \mathbf{k})$, Plane $x - 2y + z = 5$
**Find:** Intersection point

### Pattern 4: Distance Point to Plane
**Given:** Point $P(1,2,3)$, Plane $2x - y + 2z = 10$
**Find:** Distance

### Pattern 5: Skew Lines Distance
**Given:** Line 1: $\mathbf{r} = \mathbf{i} + \lambda(\mathbf{i} + \mathbf{j})$, Line 2: $\mathbf{r} = \mathbf{j} + \mu(\mathbf{j} + \mathbf{k})$
**Find:** Shortest distance

## Common Traps

| Trap | Wrong | Correct |
|------|-------|---------|
| Plane normal | Use direction vector as normal | Normal is perpendicular to plane |
| Line-plane intersection | Solve without checking parallel | Check $\mathbf{d} \cdot \mathbf{n} = 0$ first |
| Distance point-line | Use $\|\mathbf{p} - \mathbf{a}\|$ | Use $\|(\mathbf{p}-\mathbf{a}) \times \mathbf{d}\|/\|\mathbf{d}\|$ |
| Skew lines distance | Use $\|\mathbf{b} - \mathbf{a}\|$ | Use formula with scalar triple product |
| Angle line-plane | Use $\cos\theta = \frac{|\mathbf{d} \cdot \mathbf{n}|}{\|\mathbf{d}\|\|\mathbf{n}\|}$ | Use $\sin\theta$ |
| Cartesian form | Forget direction component zero | If $l=0$, then $x=a_1$ |
