# 05.7 Applications of Vectors

## Definition
Vectors have wide applications across geometry, mechanics, electromagnetism, crystallography, navigation, and computer graphics.

## Formulae

| Formula | Expression |
|---------|------------|
| **Triangle centroid** | $\mathbf{g} = \frac{\mathbf{a}+\mathbf{b}+\mathbf{c}}{3}$ |
| **Tetrahedron volume** | $V = \frac{1}{6}\|(\mathbf{b}-\mathbf{a}) \cdot ((\mathbf{c}-\mathbf{a}) \times (\mathbf{d}-\mathbf{a}))\|$ |
| **Tetrahedron centroid** | $\mathbf{g} = \frac{\mathbf{a} + \mathbf{b} + \mathbf{c} + \mathbf{d}}{4}$ |
| **Parallelogram law** | $\|\mathbf{a} + \mathbf{b}\|^2 + \|\mathbf{a} - \mathbf{b}\|^2 = 2\|\mathbf{a}\|^2 + 2\|\mathbf{b}\|^2$ |
| **Moment** | $\boldsymbol{\tau} = \mathbf{r} \times \mathbf{F}$ |
| **Angular momentum** | $\mathbf{L} = \mathbf{r} \times m\mathbf{v}$ |
| **Velocity (rotation)** | $\mathbf{v} = \boldsymbol{\omega} \times \mathbf{r}$ |
| **Acceleration (rotation)** | $\mathbf{a} = \boldsymbol{\alpha} \times \mathbf{r} + \boldsymbol{\omega} \times (\boldsymbol{\omega} \times \mathbf{r})$ |
| **Lorentz force** | $\mathbf{F} = q(\mathbf{E} + \mathbf{v} \times \mathbf{B})$ |
| **Current force** | $d\mathbf{F} = I d\mathbf{l} \times \mathbf{B}$ |
| **Magnetic moment** | $\boldsymbol{\mu} = I\mathbf{A}$ |
| **Torque on dipole** | $\boldsymbol{\tau} = \boldsymbol{\mu} \times \mathbf{B}$ |
| **Poynting vector** | $\mathbf{S} = \frac{1}{\mu_0}\mathbf{E} \times \mathbf{B}$ |
| **Reciprocal vectors** | $\mathbf{a}' = \frac{\mathbf{b} \times \mathbf{c}}{[\mathbf{a} \; \mathbf{b} \; \mathbf{c}]}$ |
| **Relative velocity** | $\mathbf{v}_{A/B} = \mathbf{v}_A - \mathbf{v}_B$ |

## Properties / Key Concepts

### Triangle Geometry
- Centroid: $\mathbf{g} = \frac{\mathbf{a} + \mathbf{b} + \mathbf{c}}{3}$
- Orthocentre (if circumcentre is origin): $\mathbf{h} = \mathbf{a} + \mathbf{b} + \mathbf{c}$
- Circumcentre: solve $\|\mathbf{r} - \mathbf{a}\| = \|\mathbf{r} - \mathbf{b}\| = \|\mathbf{r} - \mathbf{c}\|$
- Incentre: $\mathbf{i} = \frac{a\mathbf{a} + b\mathbf{b} + c\mathbf{c}}{a+b+c}$ where $a = \|\mathbf{b}-\mathbf{c}\|$

### Tetrahedron
- Volume: $V = \frac{1}{6}\|(\mathbf{b}-\mathbf{a}) \cdot ((\mathbf{c}-\mathbf{a}) \times (\mathbf{d}-\mathbf{a}))\|$
- Centroid: $\mathbf{g} = \frac{\mathbf{a} + \mathbf{b} + \mathbf{c} + \mathbf{d}}{4}$
- Altitude from $\mathbf{a}$: direction $(\mathbf{b}-\mathbf{a}) \times (\mathbf{c}-\mathbf{a})$

### Mechanics
- Resultant force: $\mathbf{R} = \sum \mathbf{F}_i$
- Equilibrium: $\sum \mathbf{F}_i = \mathbf{0}$ and $\sum \boldsymbol{\tau}_i = \mathbf{0}$
- Moment (torque): $\boldsymbol{\tau} = \mathbf{r} \times \mathbf{F}$
- Couple: $\boldsymbol{\tau} = (\mathbf{r}_1 - \mathbf{r}_2) \times \mathbf{F}$
- Angular momentum: $\mathbf{L} = \mathbf{r} \times m\mathbf{v}$

### Electromagnetism
- Lorentz force: $\mathbf{F} = q(\mathbf{E} + \mathbf{v} \times \mathbf{B})$
- Force on current: $d\mathbf{F} = I d\mathbf{l} \times \mathbf{B}$
- Magnetic moment: $\boldsymbol{\mu} = I \mathbf{A}$
- Poynting vector: $\mathbf{S} = \frac{1}{\mu_0} \mathbf{E} \times \mathbf{B}$

### Crystallography
- Reciprocal vectors: $\mathbf{a}' = \frac{\mathbf{b} \times \mathbf{c}}{[\mathbf{a} \; \mathbf{b} \; \mathbf{c}]}$
- Properties: $\mathbf{a} \cdot \mathbf{a}' = 1$, $\mathbf{a} \cdot \mathbf{b}' = 0$
- Miller indices: plane with intercepts $\frac{a}{h}, \frac{b}{k}, \frac{c}{l}$ has normal parallel to $h\mathbf{a}' + k\mathbf{b}' + l\mathbf{c}'$

### Navigation
- Relative velocity: $\mathbf{v}_{A/B} = \mathbf{v}_A - \mathbf{v}_B$
- Closest approach: $t = -\frac{(\mathbf{a}-\mathbf{b})\cdot(\mathbf{u}-\mathbf{v})}{\|\mathbf{u}-\mathbf{v}\|^2}$
- Wind/current: true velocity = velocity in still medium + velocity of medium

### Computer Graphics
- Orthographic projection: $\mathbf{r}_{\text{proj}} = \mathbf{r} - (\mathbf{r} \cdot \hat{\mathbf{n}})\hat{\mathbf{n}}$
- Perspective: $\mathbf{r}_{\text{proj}} = \mathbf{e} + \frac{d}{(\mathbf{r} - \mathbf{e}) \cdot \hat{\mathbf{n}}}(\mathbf{r} - \mathbf{e})$
- Barycentric: $\mathbf{p} = \alpha\mathbf{a} + \beta\mathbf{b} + \gamma\mathbf{c}$, $\alpha+\beta+\gamma=1$

## Worked Examples

### Example 1: Moment of Force
$\mathbf{F} = 3\mathbf{i} - 4\mathbf{j} + 2\mathbf{k}$ N at point $(1, 2, 3)$ m.
Moment about origin:
$$\boldsymbol{\tau} = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ 1 & 2 & 3 \\ 3 & -4 & 2 \end{vmatrix} = \mathbf{i}(4+12) - \mathbf{j}(2-9) + \mathbf{k}(-4-6) = 16\mathbf{i} + 7\mathbf{j} - 10\mathbf{k} \text{ N·m}$$

### Example 2: Relative Motion
Ship A at $(0,0)$ velocity $10\mathbf{i} + 5\mathbf{j}$ km/h.
Ship B at $(20, 10)$ velocity $5\mathbf{i} - 10\mathbf{j}$ km/h.
Relative position: $(20, 10) - (0,0) = 20\mathbf{i} + 10\mathbf{j}$
Relative velocity: $(5-10)\mathbf{i} + (-10-5)\mathbf{j} = -5\mathbf{i} - 15\mathbf{j}$
Closest approach when $(\mathbf{r} \cdot \mathbf{v}) = 0$:
$$(20\mathbf{i}+10\mathbf{j}) \cdot (-5\mathbf{i}-15\mathbf{j}) = -100 - 150 = -250 \neq 0$$
Time: $t = -\frac{(\mathbf{r} \cdot \mathbf{v})}{\|\mathbf{v}\|^2} = \frac{250}{250} = 1$ hour
Distance: $\|\mathbf{r} + \mathbf{v}t\| = \|15\mathbf{i} - 5\mathbf{j}\| = 5\sqrt{10}$ km

### Example 3: Reciprocal Vectors
$\mathbf{a} = \mathbf{i} + \mathbf{j}$, $\mathbf{b} = \mathbf{j} + \mathbf{k}$, $\mathbf{c} = \mathbf{k} + \mathbf{i}$
$[\mathbf{a} \; \mathbf{b} \; \mathbf{c}] = \det \begin{pmatrix} 1 & 1 & 0 \\ 0 & 1 & 1 \\ 1 & 0 & 1 \end{pmatrix} = 2$
$\mathbf{a}' = \frac{\mathbf{b} \times \mathbf{c}}{2} = \frac{1}{2} \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ 0 & 1 & 1 \\ 1 & 0 & 1 \end{vmatrix} = \frac{1}{2}(\mathbf{i} + \mathbf{j} - \mathbf{k})$

### Pattern 1: Geometry Proofs
**Given:** Points $A, B, C, D$ with position vectors...
**Prove:** $ABCD$ is a parallelogram / $G$ is centroid / lines concurrent
**Strategy:** Express in vector form, use $\mathbf{a} - \mathbf{b} = \overrightarrow{BA}$

### Pattern 2: Mechanics
**Given:** Forces $\mathbf{F}_1, \mathbf{F}_2, \mathbf{F}_3$ at points...
**Find:** Resultant, moment about $O$, conditions for equilibrium

### Pattern 3: Navigation
**Given:** Ship positions and velocities...
**Find:** Closest distance, time of closest approach, interception course

### Pattern 4: Electromagnetism
**Given:** Current $I$, magnetic field $\mathbf{B}$, wire segment...
**Find:** Force $d\mathbf{F} = I d\mathbf{l} \times \mathbf{B}$

## Common Traps

| Trap | Wrong | Correct |
|------|-------|---------|
| Moment about point | Use $\mathbf{r} \times \mathbf{F}$ for any point | Use $(\mathbf{r} - \mathbf{a}) \times \mathbf{F}$ about point $\mathbf{a}$ |
| Reciprocal vectors | Mix up order in cross product | $\mathbf{a}' = \frac{\mathbf{b} \times \mathbf{c}}{[\mathbf{a} \; \mathbf{b} \; \mathbf{c}]}$ |
| Lorentz force | $q(\mathbf{v} \times \mathbf{E})$ | $q(\mathbf{E} + \mathbf{v} \times \mathbf{B})$ |
| Poynting vector | $\mathbf{E} \times \mathbf{B}$ | $\frac{1}{\mu_0}\mathbf{E} \times \mathbf{B}$ |
| Centripetal acceleration | $\omega^2 r$ outward | $\omega^2 r$ toward centre ($-\omega^2\mathbf{r}$) |
| Triangle centroid | $\frac{\mathbf{a}+\mathbf{b}+\mathbf{c}}{2}$ | $\frac{\mathbf{a}+\mathbf{b}+\mathbf{c}}{3}$ |
