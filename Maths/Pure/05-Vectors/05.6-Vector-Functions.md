# 05.6 Vector Functions

## Definition
A **vector function** maps a scalar parameter $t$ to a vector:
$$\mathbf{r}(t) = x(t)\mathbf{i} + y(t)\mathbf{j} + z(t)\mathbf{k}$$
where $x(t), y(t), z(t)$ are scalar functions of $t$.
- Domain: subset of $\mathbb{R}$ (parameter $t$)
- Range: subset of $\mathbb{R}^3$ (vectors)

## Formulae

| Formula | Expression |
|---------|------------|
| **Derivative** | $\mathbf{r}'(t) = x'(t)\mathbf{i} + y'(t)\mathbf{j} + z'(t)\mathbf{k}$ |
| **Unit tangent** | $\mathbf{T}(t) = \frac{\mathbf{r}'(t)}{\|\mathbf{r}'(t)\|}$ |
| **Speed** | $v = \|\mathbf{r}'\|$ |
| **Arc length** | $L = \int_a^b \|\mathbf{r}'(t)\| \, dt$ |
| **Curvature** | $\kappa = \frac{\|\mathbf{r}'(t) \times \mathbf{r}''(t)\|}{\|\mathbf{r}'(t)\|^3}$ |
| **Radius of curvature** | $\rho = \frac{1}{\kappa}$ |
| **Plane curvature** | $\kappa = \frac{|y''|}{(1 + y'^2)^{3/2}}$ |
| **Acceleration** | $\mathbf{a} = v'\mathbf{T} + v^2\kappa\mathbf{N}$ |
| **Velocity** | $\mathbf{v}(t) = \mathbf{r}'(t)$ |
| **Acceleration (2nd)** | $\mathbf{a}(t) = \mathbf{r}''(t)$ |

## Properties / Key Concepts

### Limits and Continuity
$$\lim_{t \to t_0} \mathbf{r}(t) = \lim_{t \to t_0} x(t)\mathbf{i} + \lim_{t \to t_0} y(t)\mathbf{j} + \lim_{t \to t_0} z(t)\mathbf{k}$$
$\mathbf{r}(t)$ continuous at $t_0$ iff each component is continuous.

### Differentiation Rules

| Rule | Formula |
|------|---------|
| Sum | $\frac{d}{dt}(\mathbf{u}+\mathbf{v}) = \mathbf{u}' + \mathbf{v}'$ |
| Scalar multiple | $\frac{d}{dt}(f\mathbf{u}) = f'\mathbf{u} + f\mathbf{u}'$ |
| Dot product | $\frac{d}{dt}(\mathbf{u} \cdot \mathbf{v}) = \mathbf{u}' \cdot \mathbf{v} + \mathbf{u} \cdot \mathbf{v}'$ |
| Cross product | $\frac{d}{dt}(\mathbf{u} \times \mathbf{v}) = \mathbf{u}' \times \mathbf{v} + \mathbf{u} \times \mathbf{v}'$ |
| Chain rule | $\frac{d}{dt}\mathbf{r}(g(t)) = g'(t)\mathbf{r}'(g(t))$ |

### Arc Length
- $s(t) = \int_{t_0}^t \|\mathbf{r}'(u)\| \, du$
- $L = \int_a^b \|\mathbf{r}'(t)\| \, dt = \int_a^b \sqrt{x'(t)^2 + y'(t)^2 + z'(t)^2} \, dt$
- If $s$ is arc length from fixed point, then $\left\|\frac{d\mathbf{r}}{ds}\right\| = 1$

### Kinematics
- **Position:** $\mathbf{r}(t)$
- **Velocity:** $\mathbf{v}(t) = \mathbf{r}'(t)$
- **Speed:** $v(t) = \|\mathbf{v}(t)\|$
- **Acceleration:** $\mathbf{a}(t) = \mathbf{v}'(t) = \mathbf{r}''(t)$
- Decomposition: $\mathbf{a} = \frac{dv}{dt}\mathbf{T} + v^2\kappa \mathbf{N}$

### Circular Motion
$\mathbf{r}(t) = R\cos(\omega t)\mathbf{i} + R\sin(\omega t)\mathbf{j}$
- $\mathbf{v} = -R\omega\sin(\omega t)\mathbf{i} + R\omega\cos(\omega t)\mathbf{j}$, $\|\mathbf{v}\| = R\omega$
- $\mathbf{a} = -\omega^2\mathbf{r}$ (centripetal, magnitude $R\omega^2$, toward centre)

### Integration
$$\int \mathbf{r}(t) \, dt = \left(\int x(t) \, dt\right)\mathbf{i} + \left(\int y(t) \, dt\right)\mathbf{j} + \left(\int z(t) \, dt\right)\mathbf{k} + \mathbf{c}$$
From acceleration: $\mathbf{v}(t) = \int \mathbf{a}(t) \, dt + \mathbf{v}_0$, $\mathbf{r}(t) = \int \mathbf{v}(t) \, dt + \mathbf{r}_0$

## Worked Examples

### Example 1: Velocity and Acceleration
$\mathbf{r}(t) = 3\cos t \mathbf{i} + 3\sin t \mathbf{j} + 4t \mathbf{k}$

$\mathbf{v}(t) = -3\sin t \mathbf{i} + 3\cos t \mathbf{j} + 4 \mathbf{k}$
$\mathbf{a}(t) = -3\cos t \mathbf{i} - 3\sin t \mathbf{j}$

Speed: $\|\mathbf{v}\| = \sqrt{9\sin^2 t + 9\cos^2 t + 16} = 5$

### Example 2: Arc Length
$\mathbf{r}(t) = \cos t \mathbf{i} + \sin t \mathbf{j} + t \mathbf{k}$, $0 \le t \le 2\pi$

$\mathbf{r}'(t) = -\sin t \mathbf{i} + \cos t \mathbf{j} + \mathbf{k}$
$\|\mathbf{r}'(t)\| = \sqrt{\sin^2 t + \cos^2 t + 1} = \sqrt{2}$

$L = \int_0^{2\pi} \sqrt{2} \, dt = 2\pi\sqrt{2}$

### Example 3: Curvature of Helix
$\mathbf{r}(t) = \cos t \mathbf{i} + \sin t \mathbf{j} + t \mathbf{k}$

$\mathbf{r}' = -\sin t \mathbf{i} + \cos t \mathbf{j} + \mathbf{k}$, $\|\mathbf{r}'\| = \sqrt{2}$
$\mathbf{r}'' = -\cos t \mathbf{i} - \sin t \mathbf{j}$
$\mathbf{r}' \times \mathbf{r}'' = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ -\sin t & \cos t & 1 \\ -\cos t & -\sin t & 0 \end{vmatrix} = \sin t \mathbf{i} - \cos t \mathbf{j} + \mathbf{k}$
$\|\mathbf{r}' \times \mathbf{r}''\| = \sqrt{2}$
$\kappa = \frac{\sqrt{2}}{(\sqrt{2})^3} = \frac{1}{2}$

### Pattern 1: Differentiate Vector Function
**Given:** $\mathbf{r}(t) = (t^2)\mathbf{i} + (2t-1)\mathbf{j} + (\sin t)\mathbf{k}$
**Find:** $\mathbf{v}(t)$, $\mathbf{a}(t)$, speed at $t=1$

### Pattern 2: Tangent Vector
**Given:** $\mathbf{r}(t) = \cos t \mathbf{i} + \sin t \mathbf{j} + t \mathbf{k}$
**Find:** Unit tangent at $t = \pi/2$

### Pattern 3: Arc Length
**Given:** $\mathbf{r}(t) = t\mathbf{i} + t^2\mathbf{j} + t^3\mathbf{k}$, $0 \le t \le 1$
**Find:** Length of curve

### Pattern 4: Kinematics from Acceleration
**Given:** $\mathbf{a}(t) = 2\mathbf{i} + 4t\mathbf{j}$, $\mathbf{v}(0) = \mathbf{i} + 2\mathbf{j}$, $\mathbf{r}(0) = 3\mathbf{k}$
**Find:** $\mathbf{r}(t)$

## Common Traps

| Trap | Wrong | Correct |
|------|-------|---------|
| Derivative | Differentiate magnitude | Differentiate components separately |
| Unit tangent | $\frac{\mathbf{r}'}{\|\mathbf{r}\|}$ | $\frac{\mathbf{r}'}{\|\mathbf{r}'\|}$ |
| Arc length | $\int \|\mathbf{r}\| dt$ | $\int \|\mathbf{r}'\| dt$ |
| Cross product derivative | $\mathbf{u}' \times \mathbf{v}'$ | $\mathbf{u}' \times \mathbf{v} + \mathbf{u} \times \mathbf{v}'$ |
| Curvature | $\|\mathbf{r}''\|$ | $\frac{\|\mathbf{r}' \times \mathbf{r}''\|}{\|\mathbf{r}'\|^3}$ |
| Acceleration | Only tangential | Has normal component too |
