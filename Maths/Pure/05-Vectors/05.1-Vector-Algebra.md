# 05.1 Vector Algebra

## Definition
A **vector** is a quantity with both magnitude and direction.
- Notation: $\mathbf{a}, \vec{a}, \underline{a}$
- Bold for printed: $\mathbf{a}$
- Magnitude: $\|\mathbf{a}\| = |\mathbf{a}|$

## Formulae

| Formula | Expression |
|---------|------------|
| **Components** | $\mathbf{a} = a_1\mathbf{i} + a_2\mathbf{j} + a_3\mathbf{k} = \begin{pmatrix} a_1 \\ a_2 \\ a_3 \end{pmatrix}$ |
| **Addition** | $\mathbf{a} + \mathbf{b} = (a_1+b_1)\mathbf{i} + (a_2+b_2)\mathbf{j} + (a_3+b_3)\mathbf{k}$ |
| **Scalar mult** | $k\mathbf{a} = (ka_1)\mathbf{i} + (ka_2)\mathbf{j} + (ka_3)\mathbf{k}$ |
| **Magnitude** | $\|\mathbf{a}\| = \sqrt{a_1^2+a_2^2+a_3^2}$ |
| **Unit vector** | $\frac{\mathbf{a}}{\|\mathbf{a}\|}$ |
| **Position vector** | $\mathbf{r} = x\mathbf{i} + y\mathbf{j} + z\mathbf{k}$ |
| **AB vector** | $\overrightarrow{AB} = \mathbf{b} - \mathbf{a}$ |
| **Midpoint** | $\frac{\mathbf{a}+\mathbf{b}}{2}$ |
| **Section (internal)** | $\frac{n\mathbf{a}+m\mathbf{b}}{m+n}$ |
| **Direction cosines** | $\frac{a_i}{\|\mathbf{a}\|}$, sum of squares = 1 |

## Properties / Key Concepts

### Vector Operations
- Addition is commutative: $\mathbf{a} + \mathbf{b} = \mathbf{b} + \mathbf{a}$
- Addition is associative: $(\mathbf{a} + \mathbf{b}) + \mathbf{c} = \mathbf{a} + (\mathbf{b} + \mathbf{c})$
- Triangle law: $\mathbf{a} + \mathbf{b}$ represented by diagonal of parallelogram
- Scalar mult: $\|k\mathbf{a}\| = |k|\|\mathbf{a}\|$, same direction if $k>0$, opposite if $k<0$

### Position Vectors
For point $P(x,y,z)$, position vector $\overrightarrow{OP} = \mathbf{r} = x\mathbf{i} + y\mathbf{j} + z\mathbf{k}$
If $A$ and $B$ have position vectors $\mathbf{a}$ and $\mathbf{b}$: $\overrightarrow{AB} = \mathbf{b} - \mathbf{a}$
Position vector of midpoint $M$ of $AB$: $\mathbf{m} = \frac{\mathbf{a} + \mathbf{b}}{2}$

### Section Formula
If $P$ divides $AB$ in ratio $m:n$:
$$\mathbf{p} = \frac{n\mathbf{a} + m\mathbf{b}}{m+n}$$
- Internal division: $m,n > 0$
- External division: one negative

### Linear Dependence and Independence
Vectors $\mathbf{a}_1, \mathbf{a}_2, \dots, \mathbf{a}_n$ are:
- **Linearly dependent** if $\exists \alpha_i$ not all zero: $\sum \alpha_i \mathbf{a}_i = \mathbf{0}$
- **Linearly independent** if $\sum \alpha_i \mathbf{a}_i = \mathbf{0} \implies \alpha_i = 0$ for all $i$
- **2 vectors in 2D:** dependent iff one is scalar multiple of other
- **3 vectors in 3D:** dependent iff they lie in same plane (coplanar)
- **4 or more vectors in 3D:** always dependent
- Test: $\det(\mathbf{a}_1, \mathbf{a}_2, \mathbf{a}_3) \neq 0 \implies \text{independent}$

### Basis and Dimension
- Standard basis: $\{\mathbf{i}, \mathbf{j}, \mathbf{k}\}$
- Any 3 linearly independent vectors $\{\mathbf{e}_1, \mathbf{e}_2, \mathbf{e}_3\}$ form a basis for $\mathbb{R}^3$
- Change of basis: if $\mathbf{e}_i' = \sum P_{ji} \mathbf{e}_j$, coordinates transform by $P^{-1}$

### Direction Cosines
For $\mathbf{a} = a_1\mathbf{i} + a_2\mathbf{j} + a_3\mathbf{k}$:
$$\cos\alpha = \frac{a_1}{\|\mathbf{a}\|}, \quad \cos\beta = \frac{a_2}{\|\mathbf{a}\|}, \quad \cos\gamma = \frac{a_3}{\|\mathbf{a}\|}$$
$$\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1$$

### Vector Equations of Lines
- Through $A(\mathbf{a})$ parallel to $\mathbf{b}$: $\mathbf{r} = \mathbf{a} + \lambda \mathbf{b}$
- Through $A(\mathbf{a})$ and $B(\mathbf{b})$: $\mathbf{r} = \mathbf{a} + \lambda (\mathbf{b} - \mathbf{a})$

## Worked Examples

### Example 1: Operations
$\mathbf{a} = 3\mathbf{i} - 2\mathbf{j} + \mathbf{k}$, $\mathbf{b} = -\mathbf{i} + 4\mathbf{j} - 2\mathbf{k}$

$$2\mathbf{a} - 3\mathbf{b} = (6+3)\mathbf{i} + (-4-12)\mathbf{j} + (2+6)\mathbf{k} = 9\mathbf{i} - 16\mathbf{j} + 8\mathbf{k}$$
$$\|\mathbf{a}\| = \sqrt{9+4+1} = \sqrt{14}$$
Unit vector along $\mathbf{a}$: $\frac{1}{\sqrt{14}}(3\mathbf{i} - 2\mathbf{j} + \mathbf{k})$

### Example 2: Section Formula
$A(1,2,3)$, $B(4,6,9)$, $P$ divides $AB$ in ratio $2:3$ (internal)

$$\mathbf{p} = \frac{3\mathbf{a} + 2\mathbf{b}}{5} = \frac{3(\mathbf{i}+2\mathbf{j}+3\mathbf{k}) + 2(4\mathbf{i}+6\mathbf{j}+9\mathbf{k})}{5} = \frac{11\mathbf{i} + 18\mathbf{j} + 27\mathbf{k}}{5}$$

### Example 3: Linear Independence
$\mathbf{a} = \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix}, \mathbf{b} = \begin{pmatrix} 2 \\ -1 \\ 1 \end{pmatrix}, \mathbf{c} = \begin{pmatrix} 3 \\ 1 \\ 4 \end{pmatrix}$

$$\det = \begin{vmatrix} 1 & 2 & 3 \\ 2 & -1 & 1 \\ 3 & 1 & 4 \end{vmatrix} = 1(-4-1) - 2(8-3) + 3(2+3) = -5 - 10 + 15 = 0$$
Dependent. Indeed $\mathbf{c} = \mathbf{a} + \mathbf{b}$.

### Pattern 1: Vector Operations
**Given:** $\mathbf{a} = 2\mathbf{i} - \mathbf{j} + 3\mathbf{k}$, $\mathbf{b} = \mathbf{i} + 2\mathbf{j} - \mathbf{k}$
**Find:** $2\mathbf{a} - 3\mathbf{b}$, $\|\mathbf{a} + \mathbf{b}\|$, unit vector in direction of $\mathbf{a}$

### Pattern 2: Position Vectors
**Given:** $A(1,2,3)$, $B(4,5,6)$, $C$ divides $AB$ in ratio $2:3$
**Find:** $\overrightarrow{AB}$, $\overrightarrow{BA}$, position vector of $C$

### Pattern 3: Linear Dependence
**Given:** $\mathbf{a} = \mathbf{i} + 2\mathbf{j} + 3\mathbf{k}$, $\mathbf{b} = 2\mathbf{i} - \mathbf{j} + \mathbf{k}$, $\mathbf{c} = 3\mathbf{i} + \mathbf{j} + 4\mathbf{k}$
**Test:** Are they linearly independent? (Compute determinant)

### Pattern 4: Section Formula
**Given:** $A(-2, 1, 4)$, $B(4, -3, 2)$, $P$ divides $AB$ externally in ratio $3:1$
**Find:** Position vector of $P$

## Common Traps

| Trap | Wrong | Correct |
|------|-------|---------|
| Vector addition | Add magnitudes | Add components |
| Unit vector | $\frac{\mathbf{a}}{\|\mathbf{a}\|^2}$ | $\frac{\mathbf{a}}{\|\mathbf{a}\|}$ |
| Direction | Same vector = same direction | Can be opposite direction (negative scalar) |
| Section formula | $\frac{m\mathbf{a} + n\mathbf{b}}{m+n}$ for internal | Check internal/external: $\frac{n\mathbf{a} + m\mathbf{b}}{m+n}$ |
| Linear dependence | 3 vectors in 3D always independent | Check determinant = 0 |
