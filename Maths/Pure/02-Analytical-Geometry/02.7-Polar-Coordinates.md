# 2.7 Polar Coordinates

## Definition

**Polar coordinates** represent a point $P$ by $(r, \theta)$ where:
- $r = OP$ (distance from origin, $r \ge 0$)
- $\theta = \angle XOP$ (angle from positive x-axis, measured anticlockwise, $0 \le \theta < 2\pi$)

---

## Formulae

| Formula | Expression |
|---------|------------|
| **Polar → Cartesian** | $x = r\cos\theta,\; y = r\sin\theta$ |
| **Cartesian → Polar** | $r = \sqrt{x^2+y^2},\; \theta = \tan^{-1}(y/x)$ |
| **Distance** | $\sqrt{r_1^2+r_2^2-2r_1r_2\cos(\theta_1-\theta_2)}$ |
| **Circle (pole)** | $r = a$ |
| **Circle (diameter)** | $r = 2a\cos\theta$ or $r = 2a\sin\theta$ |
| **Line (general)** | $r = \frac{p}{\cos(\theta-\alpha)}$ |
| **Conic (focus)** | $r = \frac{l}{1+e\cos\theta}$ |
| **Tangent gradient** | $\frac{dy}{dx} = \frac{r\cos\theta+r'\sin\theta}{-r\sin\theta+r'\cos\theta}$ where $r' = \frac{dr}{d\theta}$ |
| **Angle $\psi$ (tangent-radius)** | $\tan\psi = \frac{r}{r'} = \frac{r}{dr/d\theta}$ |
| **Area** | $\frac{1}{2}\int_{\alpha}^{\beta} r^2 d\theta$ |
| **Arc length** | $\int_{\alpha}^{\beta} \sqrt{r^2+(dr/d\theta)^2} d\theta$ |

### Conversion Between Systems

**Polar → Cartesian:**
$$x = r\cos\theta,\quad y = r\sin\theta$$

**Cartesian → Polar:**
$$r = \sqrt{x^2 + y^2},\quad \theta = \tan^{-1}\left(\frac{y}{x}\right)$$

**Quadrant adjustment for $\theta$:**
| x | y | Quadrant | $\theta$ |
|---|---|----------|----------|
| + | + | I | $\tan^{-1}(y/x)$ |
| - | + | II | $\pi + \tan^{-1}(y/x)$ or $\pi - \tan^{-1}(|y/x|)$ |
| - | - | III | $\pi + \tan^{-1}(y/x)$ or $-\pi + \tan^{-1}(|y/x|)$ |
| + | - | IV | $2\pi + \tan^{-1}(y/x)$ or $-\tan^{-1}(|y/x|)$ |

### Distance Formula in Polar Coordinates

For $P_1(r_1, \theta_1)$ and $P_2(r_2, \theta_2)$:
$$P_1P_2 = \sqrt{r_1^2 + r_2^2 - 2r_1r_2\cos(\theta_1 - \theta_2)}$$

### Common Polar Equations

| Curve | Equation | Description |
|-------|----------|-------------|
| Circle (centre pole) | $r = a$ | Radius $a$ |
| Circle (diameter on x-axis) | $r = 2a\cos\theta$ | Centre $(a, 0)$, radius $a$ |
| Circle (diameter on y-axis) | $r = 2a\sin\theta$ | Centre $(0, a)$, radius $a$ |
| Line through pole | $\theta = \alpha$ | |
| Line (perpendicular distance $p$) | $r = \frac{p}{\cos(\theta-\alpha)}$ | $\alpha$ = angle of perpendicular |
| Conic (focus at pole) | $r = \frac{l}{1+e\cos\theta}$ | $l$ = semi-latus rectum, $e$ = eccentricity |
| Parabola | $r = \frac{2a}{1+\cos\theta}$ | $e=1, l=2a$ |
| Ellipse | $r = \frac{a(1-e^2)}{1+e\cos\theta}$ | $0<e<1$ |
| Hyperbola | $r = \frac{a(e^2-1)}{1+e\cos\theta}$ | $e>1$ |
| Cardioid | $r = a(1+\cos\theta)$ | Heart-shaped |
| Spiral | $r = a\theta$ | Archimedean |

### Tangent in Polar Coordinates

For curve $r = f(\theta)$ at point $P(r, \theta)$:

**Gradient of tangent:**
$$\frac{dy}{dx} = \frac{r\cos\theta + r'\sin\theta}{-r\sin\theta + r'\cos\theta} \quad \text{where } r' = \frac{dr}{d\theta}$$

**Angle $\psi$ between tangent and radius vector:**
$$\tan\psi = \frac{r}{r'} = \frac{r}{dr/d\theta}$$

### Area in Polar Coordinates

**Area bounded by curve $r = f(\theta)$ and rays $\theta = \alpha, \beta$:**
$$\text{Area} = \frac{1}{2}\int_{\alpha}^{\beta} r^2 d\theta = \frac{1}{2}\int_{\alpha}^{\beta} [f(\theta)]^2 d\theta$$

**Area between two curves $r = f(\theta)$ and $r = g(\theta)$:**
$$\text{Area} = \frac{1}{2}\int_{\alpha}^{\beta} \left[f(\theta)^2 - g(\theta)^2\right] d\theta$$

### Arc Length in Polar Coordinates

Arc length of $r = f(\theta)$ from $\theta = \alpha$ to $\beta$:
$$L = \int_{\alpha}^{\beta} \sqrt{r^2 + \left(\frac{dr}{d\theta}\right)^2} d\theta$$

## Properties / Key Concepts

### Quadrant Adjustment

When converting from Cartesian to polar, always check the quadrant:
- Quadrant I: $\theta = \tan^{-1}(y/x)$
- Quadrant II: $\theta = \pi + \tan^{-1}(y/x)$
- Quadrant III: $\theta = \pi + \tan^{-1}(y/x)$
- Quadrant IV: $\theta = 2\pi + \tan^{-1}(y/x)$

### Negative Radius Convention

$r \ge 0$ by convention; $(-r, \theta) \equiv (r, \theta+\pi)$

### Polar Forms of Conics

All conics with focus at pole can be written as $r = \frac{l}{1+e\cos\theta}$ where:
- $l$ = semi-latus rectum
- $e$ = eccentricity ($e=1$ parabola, $0<e<1$ ellipse, $e>1$ hyperbola)

## Worked Examples

### Example 1: Convert $(3, \pi/4)$ to Cartesian
$x = 3\cos(\pi/4) = 3/\sqrt{2}$, $y = 3\sin(\pi/4) = 3/\sqrt{2}$

### Example 2: Convert $(-2, 2)$ to Polar
$r = \sqrt{8} = 2\sqrt{2}$, $\theta = \tan^{-1}(-1) = 3\pi/4$ (Quadrant II)

### Example 3: Area of circle $r = 2a\cos\theta$
$\text{Area} = \frac{1}{2}\int_{-\pi/2}^{\pi/2} 4a^2\cos^2\theta d\theta = a^2\pi$

### Example 4: Distance between $(2, \pi/3)$ and $(3, \pi/6)$
$d = \sqrt{4 + 9 - 12\cos(\pi/6)} = \sqrt{13 - 6\sqrt{3}}$

### Example 5: Tangent to $r = a(1+\cos\theta)$ (cardioid) at $\theta = \pi/3$
$r = a(1+1/2) = 3a/2$, $r' = -a\sin(\pi/3) = -a\sqrt{3}/2$
Gradient $= \frac{\frac{3a}{2}\cdot\frac{1}{2} + (-\frac{a\sqrt{3}}{2})\cdot\frac{\sqrt{3}}{2}}{-\frac{3a}{2}\cdot\frac{\sqrt{3}}{2} + (-\frac{a\sqrt{3}}{2})\cdot\frac{1}{2}} = \frac{\frac{3a}{4} - \frac{3a}{4}}{-\frac{3a\sqrt{3}}{4} - \frac{a\sqrt{3}}{4}} = 0$

## Common Traps

| Mistake | Correction |
|---------|------------|
| ❌ Wrong quadrant for $\theta$ | Always check signs of $x, y$ |
| ❌ Negative $r$ | $r \ge 0$ by convention; $(-r, \theta) \equiv (r, \theta+\pi)$ |
| ❌ Forgetting $r^2$ in area | Area element is $\frac{1}{2}r^2 d\theta$, not $r d\theta$ |
| ❌ Wrong limits for area | Find intersection angles correctly |
