# 2.1 Cartesian Coordinates & Distance Formula

## Definition

The **Cartesian coordinate system** (rectangular coordinate system) represents points in a plane using an ordered pair $(x, y)$ relative to two perpendicular number lines (axes).

### Components
| Component | Description |
|-----------|-------------|
| **x-axis** | Horizontal axis; positive right, negative left |
| **y-axis** | Vertical axis; positive up, negative down |
| **Origin O** | Intersection $(0,0)$ |
| **Coordinates of P** | $(x, y)$ where $x$ = abscissa (distance from y-axis), $y$ = ordinate (distance from x-axis) |

### Quadrants
| Quadrant | x | y | Region |
|----------|---|---|--------|
| I | + | + | $x>0, y>0$ |
| II | - | + | $x<0, y>0$ |
| III | - | - | $x<0, y<0$ |
| IV | + | - | $x>0, y<0$ |

Points on axes: $x=0$ (y-axis), $y=0$ (x-axis)

---

## Formulae

| Formula | Expression |
|---------|------------|
| **Distance** | $AB = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ |
| **Midpoint** | $\left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\right)$ |
| **Internal division** $m:n$ | $\left(\frac{mx_2+nx_1}{m+n}, \frac{my_2+ny_1}{m+n}\right)$ |
| **External division** $m:n$ | $\left(\frac{mx_2-nx_1}{m-n}, \frac{my_2-ny_1}{m-n}\right)$ |
| **Triangle area** | $\frac{1}{2}|x_1(y_2-y_3)+x_2(y_3-y_1)+x_3(y_1-y_2)|$ |
| **Centroid** | $\left(\frac{x_1+x_2+x_3}{3}, \frac{y_1+y_2+y_3}{3}\right)$ |
| **Polar → Cartesian** | $x=r\cos\theta,\; y=r\sin\theta$ |
| **Cartesian → Polar** | $r=\sqrt{x^2+y^2},\; \theta=\tan^{-1}(y/x)$ |
| **Polar distance** | $\sqrt{r_1^2+r_2^2-2r_1r_2\cos(\theta_1-\theta_2)}$ |

### Distance Formula Derivation

For points $A(x_1, y_1)$ and $B(x_2, y_2)$:
- Horizontal distance: $|x_2 - x_1|$
- Vertical distance: $|y_2 - y_1|$
- By Pythagoras in $\triangle ABN$ (right-angled at N):

$$AB^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2$$

### Section Formula

**Internal Division:** Point $P$ divides $AB$ internally in ratio $m:n$ ($m,n > 0$):

$$P\left(\frac{mx_2 + nx_1}{m+n},\; \frac{my_2 + ny_1}{m+n}\right)$$

**External Division:** Point $P$ divides $AB$ externally in ratio $m:n$ ($m \neq n$):

$$P\left(\frac{mx_2 - nx_1}{m-n},\; \frac{my_2 - ny_1}{m-n}\right)$$

### Special Cases
| Ratio | Name | Formula |
|-------|------|---------|
| $1:1$ | **Midpoint** | $\left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\right)$ |
| $m:n$ | Internal | $\left(\frac{mx_2+nx_1}{m+n}, \frac{my_2+ny_1}{m+n}\right)$ |
| $m:n$ | External | $\left(\frac{mx_2-nx_1}{m-n}, \frac{my_2-ny_1}{m-n}\right)$ |

## Properties / Key Concepts

### Centres of Triangle

For $\triangle ABC$ with vertices $A(x_1,y_1), B(x_2,y_2), C(x_3,y_3)$:

| Centre | Coordinates |
|--------|-------------|
| **Centroid (G)** | $\left(\frac{x_1+x_2+x_3}{3}, \frac{y_1+y_2+y_3}{3}\right)$ |
| **Incentre (I)** | $\left(\frac{ax_1+bx_2+cx_3}{a+b+c}, \frac{ay_1+by_2+cy_3}{a+b+c}\right)$ where $a=BC, b=CA, c=AB$ |
| **Circumcentre (O)** | Intersection of perpendicular bisectors of sides |
| **Orthocentre (H)** | Intersection of altitudes |

**Euler Line:** $G$ divides $OH$ in ratio $1:2$ ($OG:GH = 1:2$)

### Collinearity Condition

Three points are collinear $\iff$ Area $= 0$

### Transformation of Axes

**Translation of Axes:** New origin $O'(h,k)$, axes parallel to original:
$$x = x' + h,\quad y = y' + k$$

**Rotation of Axes:** Axes rotated by $\theta$ (anticlockwise):
$$x = x'\cos\theta - y'\sin\theta$$
$$y = x'\sin\theta + y'\cos\theta$$

**Combined (Translation + Rotation):**
$$x = x'\cos\theta - y'\sin\theta + h$$
$$y = x'\sin\theta + y'\cos\theta + k$$

### Polar Coordinates

Point $P$ represented by $(r, \theta)$ where:
- $r = OP$ (distance from origin, $r \ge 0$)
- $\theta = \angle XOP$ (angle from positive x-axis, $0 \le \theta < 2\pi$)

### Distance Properties
- $AB = BA$ (symmetric)
- $AB \ge 0$; $AB = 0 \iff A = B$
- Invariant under translation/rotation of axes

## Worked Examples

### Example 1: Distance & Midpoint
Points $A(3, -2), B(-1, 4)$
- Distance: $AB = \sqrt{(-1-3)^2 + (4+2)^2} = \sqrt{16+36} = \sqrt{52} = 2\sqrt{13}$
- Midpoint: $\left(\frac{3-1}{2}, \frac{-2+4}{2}\right) = (1, 1)$

### Example 2: Section Formula
$A(2, 3), B(8, -1)$. Point dividing $AB$ in ratio $2:3$ internally:
$$x = \frac{2(8)+3(2)}{5} = \frac{22}{5},\quad y = \frac{2(-1)+3(3)}{5} = \frac{7}{5}$$
Point: $\left(\frac{22}{5}, \frac{7}{5}\right)$

### Example 3: Triangle Area
$A(1,2), B(4,6), C(5,2)$
$$\text{Area} = \frac{1}{2}|1(6-2) + 4(2-2) + 5(2-6)| = \frac{1}{2}|4 + 0 - 20| = 8$$

### Example 4: Polar Conversion
Cartesian $(3, 4)$ → Polar:
$$r = \sqrt{9+16} = 5,\quad \theta = \tan^{-1}(4/3) \approx 53.13^\circ$$

## Common Traps

| Mistake | Correction |
|---------|------------|
| ❌ Forgetting absolute value in distance | Distance is always positive; squaring handles signs |
| ❌ Confusing internal/external division | Internal: $m+n$ denominator; External: $m-n$ |
| ❌ Sign errors in area formula | Use absolute value; vertex order affects sign only |
| ❌ Mixing up centroid/circumcentre | Centroid = average of vertices; Circumcentre = equidistant from vertices |
| ❌ Quadrant errors in polar $\theta$ | Use $\tan^{-1}(y/x)$ and adjust quadrant based on $(x,y)$ signs |
