# 2.6 Hyperbola

## Definition

A **hyperbola** is the locus of a point which moves in a plane such that its distance from a fixed point (focus) bears a constant ratio $e$ (eccentricity, $e > 1$) to its distance from a fixed line (directrix). Alternatively: Difference of distances from two fixed points (foci) is constant $= 2a$.

### Standard Equation (Centre at Origin, Transverse Axis on x-axis)

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \quad (a, b > 0)$$

**Key Parameters:**
- Centre: $(0, 0)$
- Vertices: $(\pm a, 0)$
- Foci: $(\pm ae, 0)$ where $e = \sqrt{1 + \frac{b^2}{a^2}} > 1$
- Directrices: $x = \pm \frac{a}{e}$
- Transverse axis: x-axis, length $2a$
- Conjugate axis: y-axis, length $2b$
- Latus rectum: $\frac{2b^2}{a}$
- Asymptotes: $y = \pm \frac{b}{a}x$

### Standard Equation (Transverse Axis on y-axis)

$$\frac{y^2}{a^2} - \frac{x^2}{b^2} = 1$$

- Foci: $(0, \pm ae)$
- Directrices: $y = \pm \frac{a}{e}$
- Asymptotes: $y = \pm \frac{a}{b}x$

### General Hyperbola (Centre at $(h, k)$)

$$\frac{(x-h)^2}{a^2} - \frac{(y-k)^2}{b^2} = 1$$

Centre: $(h, k)$, axes parallel to coordinate axes.

| Formula | Expression |
|---------|------------|

| **Foci** | $(\pm ae, 0)$ |
| **Directrices** | $x = \pm a/e$ |
| **Asymptotes** | $y = \pm \frac{b}{a}x$ |
| **Latus rectum** | $2b^2/a$ |
| **Parametric** | $(a\sec\theta, b\tan\theta)$ |
| **Tangent at $\theta$** | $\frac{x\sec\theta}{a} - \frac{y\tan\theta}{b} = 1$ |
| **Tangent at $(x_1,y_1)$** | $\frac{xx_1}{a^2} - \frac{yy_1}{b^2} = 1$ |
| **Tangent slope $m$** | $y = mx \pm \sqrt{a^2m^2 - b^2}$ |
| **Condition of tangency** | $c^2 = a^2m^2 - b^2$ |
| **Normal at $\theta$** | $\frac{ax}{\sec\theta} + \frac{by}{\tan\theta} = a^2 + b^2$ |
| **Normal at $(x_1,y_1)$** | $\frac{a^2x}{x_1} + \frac{b^2y}{y_1} = a^2 + b^2$ |
| **Normal slope $m$** | $y = mx - \frac{m(a^2 + b^2)}{\sqrt{a^2m^2 - b^2}}$ |
| **Chord $\theta_1,\theta_2$** | $\frac{x}{a}\cos\frac{\theta_1-\theta_2}{2} - \frac{y}{b}\sin\frac{\theta_1+\theta_2}{2} = \cos\frac{\theta_1+\theta_2}{2}$ |
| **Focal chord** | $\tan\frac{\theta_1}{2}\tan\frac{\theta_2}{2} = \frac{e-1}{e+1}$ or $\frac{e+1}{e-1}$ |
| **Chord midpoint (T = S₁)** | $\frac{xx_1}{a^2} - \frac{yy_1}{b^2} = \frac{x_1^2}{a^2} - \frac{y_1^2}{b^2}$ |
| **Polar / Chord of contact** | $\frac{xx_1}{a^2} - \frac{yy_1}{b^2} = 1$ |
| **Director circle** | $x^2 + y^2 = a^2 - b^2$ (exists only if $a > b$) |
| **Rectangular hyperbola** | $xy = c^2$ |
| **Rect. hyp. parametric** | $(ct, c/t)$ |
| **Rect. hyp. tangent** | $x + t^2y = 2ct$ |
| **Rect. hyp. normal** | $t^3x - ty = c(t^4 - 1)$ |
| **Rect. hyp. chord** | $x + t_1t_2y = c(t_1 + t_2)$ |
| **Rect. hyp. focal chord** | $t_1t_2 = -1$ |
| **Pair of tangents** | $\left(\frac{xx_1}{a^2} - \frac{yy_1}{b^2} - 1\right)^2 = \left(\frac{x^2}{a^2} - \frac{y^2}{b^2} - 1\right)\left(\frac{x_1^2}{a^2} - \frac{y_1^2}{b^2} - 1\right)$ |

### Tangent Equations

**At Point $(x_1, y_1)$:**
$$\frac{xx_1}{a^2} - \frac{yy_1}{b^2} = 1$$

**At Parameter $\theta$:**
$$\frac{x\sec\theta}{a} - \frac{y\tan\theta}{b} = 1$$

**With Given Slope $m$:**
$$y = mx \pm \sqrt{a^2m^2 - b^2}$$

**Condition of tangency:** $c^2 = a^2m^2 - b^2$ for line $y = mx + c$.

### Normal Equations

**At Point $(x_1, y_1)$:**
$$\frac{a^2x}{x_1} + \frac{b^2y}{y_1} = a^2 + b^2$$

**At Parameter $\theta$:**
$$\frac{ax}{\sec\theta} + \frac{by}{\tan\theta} = a^2 + b^2$$

**With Given Slope $m$:**
$$y = mx - \frac{m(a^2 + b^2)}{\sqrt{a^2m^2 - b^2}}$$

### Chord Equations

**Chord Joining $\theta_1$ and $\theta_2$:**
$$\frac{x}{a}\cos\frac{\theta_1-\theta_2}{2} - \frac{y}{b}\sin\frac{\theta_1+\theta_2}{2} = \cos\frac{\theta_1+\theta_2}{2}$$

**Focal Chord:**
Chord through focus $(\pm ae, 0)$. If ends are $\theta_1, \theta_2$:
$$\tan\frac{\theta_1}{2}\tan\frac{\theta_2}{2} = \frac{e-1}{e+1} \quad \text{or} \quad \frac{e+1}{e-1}$$
(Same condition as ellipse!)

## Properties / Key Concepts

### Asymptotes

Lines that the hyperbola approaches but never touches:
$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 0 \Rightarrow y = \pm \frac{b}{a}x$$

**Properties:**
- Pass through centre
- Diagonals of central rectangle with vertices $(\pm a, \pm b)$
- Angle between asymptotes: $2\tan^{-1}(b/a)$

### Pole and Polar

**Polar of $(x_1, y_1)$:**
$$\frac{xx_1}{a^2} - \frac{yy_1}{b^2} = 1$$

(Same as tangent if point lies on hyperbola)

**Chord of Contact from $P(x_1, y_1)$:**
Same equation: $\frac{xx_1}{a^2} - \frac{yy_1}{b^2} = 1$

### Director Circle

Locus of points from which perpendicular tangents are drawn:
$$x^2 + y^2 = a^2 - b^2$$

**Exists only if** $a > b$ (i.e., $e < \sqrt{2}$).

### Rectangular Hyperbola

Standard form (referred to asymptotes as axes): $xy = c^2$

**Properties:**
- Asymptotes: coordinate axes
- Centre: $(0, 0)$
- Vertices: $(c, c), (-c, -c)$
- Foci: $(\sqrt{2}c, \sqrt{2}c), (-\sqrt{2}c, -\sqrt{2}c)$
- Eccentricity: $e = \sqrt{2}$
- Latus rectum: $2c$
- Parametric: $x = ct, y = \frac{c}{t}$

### Conjugate Hyperbola

For $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$, conjugate is:
$$\frac{y^2}{b^2} - \frac{x^2}{a^2} = 1 \quad \text{or} \quad \frac{x^2}{a^2} - \frac{y^2}{b^2} = -1$$

**Properties:**
- Same asymptotes
- Transverse/conjugate axes swapped
- $e_1^2 = 1 + \frac{b^2}{a^2}$, $e_2^2 = 1 + \frac{a^2}{b^2}$
- $e_1^{-2} + e_2^{-2} = 1$

### Intersection of Line and Hyperbola

Line: $y = mx + c$ | Hyperbola: $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$

Substitute:
$$\left(\frac{1}{a^2} - \frac{m^2}{b^2}\right)x^2 - \frac{2mc}{b^2}x - \left(\frac{c^2}{b^2} + 1\right) = 0$$

| Discriminant | Intersection |
|--------------|--------------|
| $> 0$ | Two points |
| $= 0$ | Tangent ($c^2 = a^2m^2 - b^2$) |
| $< 0$ | No intersection |

### Pair of Tangents from $P(x_1, y_1)$

$$\left(\frac{xx_1}{a^2} - \frac{yy_1}{b^2} - 1\right)^2 = \left(\frac{x^2}{a^2} - \frac{y^2}{b^2} - 1\right)\left(\frac{x_1^2}{a^2} - \frac{y_1^2}{b^2} - 1\right)$$

## Worked Examples

### Example 1: Find elements
Hyperbola: $\frac{x^2}{9} - \frac{y^2}{16} = 1$
$a=3, b=4$. $e = \sqrt{1 + 16/9} = 5/3$.
Foci: $(\pm 5, 0)$. Directrices: $x = \pm 9/5 = \pm 1.8$.
Asymptotes: $y = \pm \frac{4}{3}x$. Latus rectum: $2 \times 16/3 = 32/3$.

### Example 2: Tangent with slope
Tangent to $\frac{x^2}{25} - \frac{y^2}{9} = 1$ with $m = 2$:
$c^2 = 25(4) - 9 = 91 \Rightarrow c = \pm \sqrt{91}$.
Tangents: $y = 2x \pm \sqrt{91}$.

### Example 3: Rectangular hyperbola
$xy = 4$. Tangent at $(2, 2)$: $2y + 2x = 8 \Rightarrow x + y = 4$.

## Common Traps

| Mistake | Correction |
|---------|------------|
| ❌ Sign in tangent formula | $\frac{xx_1}{a^2} - \frac{yy_1}{b^2} = 1$ (minus!) |
| ❌ Asymptote equation | $y = \pm \frac{b}{a}x$ (from $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 0$) |
| ❌ Director circle existence | Only if $a > b$ ($e < \sqrt{2}$) |
| ❌ Tangent condition | $c^2 = a^2m^2 - b^2$ (minus!) |
| ❌ Rectangular hyperbola $e$ | $e = \sqrt{2}$ always |
