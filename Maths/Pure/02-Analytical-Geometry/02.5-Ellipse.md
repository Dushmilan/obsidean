# 2.5 Ellipse

## Definition

An **ellipse** is the locus of a point which moves in a plane such that its distance from a fixed point (focus) bears a constant ratio $e$ (eccentricity, $0 < e < 1$) to its distance from a fixed line (directrix). Alternatively: Sum of distances from two fixed points (foci) is constant $= 2a$.

### Standard Equation (Centre at Origin, Major Axis on x-axis)

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad (a > b > 0)$$

**Key Parameters:**
- Centre: $(0, 0)$
- Vertices: $(\pm a, 0)$
- Foci: $(\pm ae, 0)$ where $e = \sqrt{1 - \frac{b^2}{a^2}}$
- Directrices: $x = \pm \frac{a}{e}$
- Major axis: x-axis, length $2a$
- Minor axis: y-axis, length $2b$
- Latus rectum: $\frac{2b^2}{a}$

### Standard Equation (Major Axis on y-axis)

$$\frac{x^2}{b^2} + \frac{y^2}{a^2} = 1 \quad (a > b > 0)$$

- Foci: $(0, \pm ae)$
- Directrices: $y = \pm \frac{a}{e}$
- Major axis: y-axis

### General Ellipse (Centre at $(h, k)$)

$$\frac{(x-h)^2}{a^2} + \frac{(y-k)^2}{b^2} = 1$$

Centre: $(h, k)$, axes parallel to coordinate axes.

## Formulae

| Formula | Expression |
|---------|------------|
| **Eccentricity** | $e = \sqrt{1 - b^2/a^2}$ |
| **$b^2$ relation** | $b^2 = a^2(1-e^2)$ |
| **Latus rectum** | $\frac{2b^2}{a} = 2a(1-e^2)$ |
| **Foci** | $(\pm ae, 0)$ |
| **Directrices** | $x = \pm a/e$ |
| **Parametric** | $(a\cos\theta, b\sin\theta)$ |
| **Tangent at $\theta$** | $\frac{x\cos\theta}{a} + \frac{y\sin\theta}{b} = 1$ |
| **Tangent at $(x_1,y_1)$** | $\frac{xx_1}{a^2} + \frac{yy_1}{b^2} = 1$ |
| **Tangent slope $m$** | $y = mx \pm \sqrt{a^2m^2 + b^2}$ |
| **Condition of tangency** | $c^2 = a^2m^2 + b^2$ |
| **Normal at $\theta$** | $\frac{ax}{\cos\theta} - \frac{by}{\sin\theta} = a^2 - b^2$ |
| **Normal at $(x_1,y_1)$** | $\frac{a^2x}{x_1} - \frac{b^2y}{y_1} = a^2 - b^2$ |
| **Normal slope $m$** | $y = mx - \frac{m(a^2 - b^2)}{\sqrt{a^2m^2 + b^2}}$ |
| **Chord $\theta_1, \theta_2$** | $\frac{x}{a}\cos\frac{\theta_1+\theta_2}{2} + \frac{y}{b}\sin\frac{\theta_1+\theta_2}{2} = \cos\frac{\theta_1-\theta_2}{2}$ |
| **Focal chord condition** | $\tan\frac{\theta_1}{2}\tan\frac{\theta_2}{2} = \frac{e-1}{e+1}$ or $\frac{e+1}{e-1}$ |
| **Chord midpoint (T = S₁)** | $\frac{xx_1}{a^2} + \frac{yy_1}{b^2} = \frac{x_1^2}{a^2} + \frac{y_1^2}{b^2}$ |
| **Polar / Chord of contact** | $\frac{xx_1}{a^2} + \frac{yy_1}{b^2} = 1$ |
| **Director circle** | $x^2 + y^2 = a^2 + b^2$ |
| **Auxiliary circle** | $x^2 + y^2 = a^2$ |
| **Pair of tangents** | $\left(\frac{xx_1}{a^2} + \frac{yy_1}{b^2} - 1\right)^2 = \left(\frac{x^2}{a^2} + \frac{y^2}{b^2} - 1\right)\left(\frac{x_1^2}{a^2} + \frac{y_1^2}{b^2} - 1\right)$ |

### Tangent Equations

**At Point $(x_1, y_1)$:**
$$\frac{xx_1}{a^2} + \frac{yy_1}{b^2} = 1$$

**At Parameter $\theta$:**
$$\frac{x\cos\theta}{a} + \frac{y\sin\theta}{b} = 1$$

**With Given Slope $m$:**
$$y = mx \pm \sqrt{a^2m^2 + b^2}$$

**Condition of tangency:** $c^2 = a^2m^2 + b^2$ for line $y = mx + c$.

### Normal Equations

**At Point $(x_1, y_1)$:**
$$\frac{a^2x}{x_1} - \frac{b^2y}{y_1} = a^2 - b^2$$

**At Parameter $\theta$:**
$$\frac{ax}{\cos\theta} - \frac{by}{\sin\theta} = a^2 - b^2$$

**With Given Slope $m$:**
$$y = mx - \frac{m(a^2 - b^2)}{\sqrt{a^2m^2 + b^2}}$$

### Chord Equations

**Chord Joining $\theta_1$ and $\theta_2$:**
$$\frac{x}{a}\cos\frac{\theta_1+\theta_2}{2} + \frac{y}{b}\sin\frac{\theta_1+\theta_2}{2} = \cos\frac{\theta_1-\theta_2}{2}$$

**Focal Chord:**
Chord through focus $(\pm ae, 0)$. If ends are $\theta_1, \theta_2$:
$$\tan\frac{\theta_1}{2}\tan\frac{\theta_2}{2} = \frac{e-1}{e+1} \quad \text{or} \quad \frac{e+1}{e-1}$$

## Properties / Key Concepts

### Important Properties

| Property | Description |
|----------|-------------|
| Sum of focal distances | $PS_1 + PS_2 = 2a$ |
| Product of perpendiculars from foci on tangent | $b^2$ (constant) |

### Eccentric Angle and Eccentricity

| Quantity | Formula |
|----------|---------|
| Eccentricity | $e = \sqrt{1 - \frac{b^2}{a^2}}$ |
| $b^2$ | $a^2(1-e^2)$ |
| Latus rectum | $\frac{2b^2}{a} = 2a(1-e^2)$ |
| Focus | $(\pm ae, 0)$ |
| Directrix | $x = \pm \frac{a}{e}$ |

### Auxiliary Circle

Circle on major axis as diameter: $x^2 + y^2 = a^2$.

**Relation:** If $P(a\cos\theta, b\sin\theta)$ on ellipse, corresponding point on auxiliary circle is $Q(a\cos\theta, a\sin\theta)$.

### Intersection of Line and Ellipse

Line: $y = mx + c$ | Ellipse: $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$

Substitute:
$$\left(\frac{1}{a^2} + \frac{m^2}{b^2}\right)x^2 + \frac{2mc}{b^2}x + \left(\frac{c^2}{b^2} - 1\right) = 0$$

| Discriminant | Intersection |
|--------------|--------------|
| $> 0$ | Two points |
| $= 0$ | Tangent ($c^2 = a^2m^2 + b^2$) |
| $< 0$ | No intersection |

### Pair of Tangents from $P(x_1, y_1)$

$$\left(\frac{xx_1}{a^2} + \frac{yy_1}{b^2} - 1\right)^2 = \left(\frac{x^2}{a^2} + \frac{y^2}{b^2} - 1\right)\left(\frac{x_1^2}{a^2} + \frac{y_1^2}{b^2} - 1\right)$$

## Worked Examples

### Example 1: Find elements
Ellipse: $\frac{x^2}{25} + \frac{y^2}{9} = 1$
$a=5, b=3$. $e = \sqrt{1 - 9/25} = 4/5 = 0.8$.
Foci: $(\pm 4, 0)$. Directrices: $x = \pm 25/4 = \pm 6.25$.
Latus rectum: $2 \times 9/5 = 18/5 = 3.6$.

### Example 2: Tangent with slope
Tangent to $\frac{x^2}{16} + \frac{y^2}{4} = 1$ with $m = 1/2$:
$c^2 = 16(1/4) + 4 = 8 \Rightarrow c = \pm 2\sqrt{2}$.
Tangents: $y = \frac{1}{2}x \pm 2\sqrt{2}$.

### Example 3: Focal chord
Ellipse: $\frac{x^2}{25} + \frac{y^2}{9} = 1$ ($e = 0.8$).
Focal chord condition: $\tan\frac{\theta_1}{2}\tan\frac{\theta_2}{2} = \frac{0.8-1}{0.8+1} = -\frac{1}{9}$.

## Common Traps

| Mistake | Correction |
|---------|------------|
| ❌ Confusing $a$ and $b$ | $a$ is ALWAYS semi-major axis ($a > b$) |
| ❌ Wrong tangent formula | $\frac{xx_1}{a^2} + \frac{yy_1}{b^2} = 1$ (not $= 0$) |
| ❌ Forgetting $e < 1$ | Ellipse has $0 < e < 1$ |
| ❌ Mixing up major/minor axis | Major axis = longer axis = $2a$ |
