# 2.4 Parabola

## Definition

A **parabola** is the locus of a point which moves in a plane such that its distance from a fixed point (focus) equals its distance from a fixed line (directrix). Eccentricity $e = 1$.

### Standard Equations (Vertex at Origin)

| Orientation | Equation | Focus | Directrix | Axis | Latus Rectum |
|-------------|----------|-------|-----------|------|--------------|
| Right-opening | $y^2 = 4ax$ ($a>0$) | $(a, 0)$ | $x = -a$ | x-axis | $4a$ |
| Left-opening | $y^2 = -4ax$ ($a>0$) | $(-a, 0)$ | $x = a$ | x-axis | $4a$ |
| Upward-opening | $x^2 = 4ay$ ($a>0$) | $(0, a)$ | $y = -a$ | y-axis | $4a$ |
| Downward-opening | $x^2 = -4ay$ ($a>0$) | $(0, -a)$ | $y = a$ | y-axis | $4a$ |

**Vertex:** $(0,0)$ for all standard forms.
**Latus Rectum endpoints:** $(\pm a, \pm 2a)$ for $y^2 = 4ax$.

### Shifted Parabola (Vertex at $(h, k)$)

$$(y - k)^2 = 4a(x - h) \quad \text{or} \quad (x - h)^2 = 4a(y - k)$$

Focus: $(h+a, k)$ or $(h, k+a)$ | Directrix: $x = h-a$ or $y = k-a$ | Vertex: $(h, k)$

## Formulae

| Formula | Expression |
|---------|------------|
| **Parametric** | $(at^2, 2at)$ for $y^2 = 4ax$ |
| **Tangent at $t$** | $ty = x + at^2$ |
| **Tangent at $(x_1,y_1)$** | $yy_1 = 2a(x+x_1)$ |
| **Tangent slope $m$** | $y = mx + a/m$ |
| **Condition of tangency** | $c = a/m$ |
| **Normal at $t$** | $y = -tx + 2at + at^3$ |
| **Normal slope $m$** | $y = mx - 2am - am^3$ |
| **Normal cubic** | $at^3 + (2a-x_1)t - y_1 = 0$ |
| **Chord $t_1,t_2$** | $(t_1+t_2)y = 2x + 2at_1t_2$ |
| **Focal chord** | $t_1t_2 = -1$ |
| **Focal chord length** | $a(t_1 - t_2)^2 = a\left(t_1 + \frac{1}{t_1}\right)^2$ |
| **Chord midpoint (T = S₁)** | $yy_1 - 2a(x+x_1) = y_1^2 - 4ax_1$ |
| **Polar / Chord of contact** | $yy_1 = 2a(x+x_1)$ |
| **Subnormal** | $2a$ (constant) |
| **Diameter** | $y = 2a/m$ |
| **Pair of tangents** | $(yy_1 - 2a(x+x_1))^2 = (y^2 - 4ax)(y_1^2 - 4ax_1)$ |

### Parametric Equations

For $y^2 = 4ax$:
$$x = at^2,\quad y = 2at \quad (t \in \mathbb{R})$$

Point: $P(at^2, 2at)$. Parameter $t = \frac{y}{2a} = \frac{1}{m}$ (where $m$ = tangent gradient).

| Equation | Parametric |
|----------|------------|
| $y^2 = -4ax$ | $x = -at^2,\; y = 2at$ |
| $x^2 = 4ay$ | $x = 2at,\; y = at^2$ |
| $x^2 = -4ay$ | $x = 2at,\; y = -at^2$ |

### Tangent Equations

**At Point $(x_1, y_1)$ on $y^2 = 4ax$:**
$$yy_1 = 2a(x + x_1)$$

**At Parameter $t$ on $y^2 = 4ax$:**
$$ty = x + at^2$$

**With Given Slope $m$ on $y^2 = 4ax$:**
$$y = mx + \frac{a}{m} \quad (m \neq 0)$$

| Equation | Tangent at $t$ |
|----------|----------------|
| $y^2 = 4ax$ | $ty = x + at^2$ |
| $y^2 = -4ax$ | $ty = -x - at^2$ |
| $x^2 = 4ay$ | $tx = y + at^2$ |

### Normal Equations

**At Point $(x_1, y_1)$ on $y^2 = 4ax$:**
$$y - y_1 = -\frac{y_1}{2a}(x - x_1)$$

**At Parameter $t$ on $y^2 = 4ax$:**
$$y = -tx + 2at + at^3$$

**With Given Slope $m$ on $y^2 = 4ax$:**
$$y = mx - 2am - am^3$$

### Chord Equations

**Chord Joining $t_1$ and $t_2$ on $y^2 = 4ax$:**
$$(t_1 + t_2)y = 2x + 2at_1t_2$$

**Focal Chord:**
Chord passing through focus $(a, 0)$. If ends are $t_1, t_2$, then $t_1t_2 = -1$.

**Length of focal chord:** $a(t_1 - t_2)^2 = a\left(t_1 + \frac{1}{t_1}\right)^2$

## Properties / Key Concepts

### Normal Properties (Important!)

**Number of Normals from $P(x_1, y_1)$:**
Cubic in $t$: $at^3 + (2a - x_1)t - y_1 = 0$

- 3 real normals if discriminant $> 0$
- 1 real normal if discriminant $< 0$

**Feet of Normals:**
If $t_1, t_2, t_3$ are parameters of feet:
$$t_1 + t_2 + t_3 = 0$$
$$\frac{1}{t_1} + \frac{1}{t_2} + \frac{1}{t_3} = 0$$

**Centroid of feet:** Lies on axis of parabola.

**Conormal Points:** Points where normals from a single point meet the parabola.

### Pole and Polar

**Polar of $P(x_1, y_1)$ w.r.t $y^2 = 4ax$:**
$$yy_1 = 2a(x + x_1)$$

(Same as tangent at $(x_1, y_1)$ if $P$ is on parabola)

**Chord of Contact from $P(x_1, y_1)$:**
Same equation: $yy_1 = 2a(x + x_1)$

### Subtangent and Subnormal

At $P(at^2, 2at)$ on $y^2 = 4ax$:

| Quantity | Value |
|----------|-------|
| **Subtangent** | $2at^2 = 2x_1$ |
| **Subnormal** | $2a$ (constant!) |

### Diameter

Locus of midpoints of parallel chords with slope $m$:
$$y = \frac{2a}{m}$$

### Director Circle

Not defined for parabola (unlike ellipse/hyperbola).

### Reflection Property

Ray from focus parallel to axis reflects along axis. More generally:
- Ray from focus reflects parallel to axis
- Ray parallel to axis reflects through focus

Used in satellite dishes, headlights, solar cookers.

### Intersection of Line and Parabola

Line: $y = mx + c$ | Parabola: $y^2 = 4ax$

Substitute: $(mx + c)^2 = 4ax$
$$m^2x^2 + (2mc - 4a)x + c^2 = 0$$

Discriminant $\Delta = (2mc - 4a)^2 - 4m^2c^2 = 16a(a - mc)$

| $\Delta$ | Intersection |
|----------|--------------|
| $> 0$ | Two points (secant) |
| $= 0$ | Tangent ($mc = a$) |
| $< 0$ | No intersection |

## Worked Examples

### Example 1: Tangent with slope
Parabola: $y^2 = 12x$ ($4a = 12 \Rightarrow a = 3$).
Tangent with $m = 2$: $y = 2x + \frac{3}{2}$ or $4x - 2y + 3 = 0$.

### Example 2: Normal at parameter
Parabola: $y^2 = 8x$ ($a = 2$).
Normal at $t = 2$: $y = -2x + 8 + 16 = -2x + 24$.

### Example 3: Focal chord
Ends at $t = 2$ and $t = -\frac{1}{2}$.
Length: $a(t_1 - t_2)^2 = a(2.5)^2 = 6.25a$.

### Example 4: Three normals
From $P(10, 4)$ to $y^2 = 4x$ ($a=1$).
Equation: $t^3 + (2-10)t - 4 = t^3 - 8t - 4 = 0$.
Roots: $t = -2, 1+\sqrt{2}, 1-\sqrt{2}$ (3 normals).

## Common Traps

| Mistake | Correction |
|---------|------------|
| ❌ Forgetting $t$ is parameter, not tangent slope | $t = \frac{y}{2a} = \frac{1}{\text{tangent slope}}$ |
| ❌ Using tangent formula for point outside parabola | Tangent formula only works if point is ON parabola |
| ❌ Sign error in normal cubic | $at^3 + (2a-x_1)t - y_1 = 0$ |
| ❌ Confusing focal chord condition | $t_1t_2 = -1$ (not 1) |
| ❌ Missing $\pm$ in tangent with slope | Always two tangents for given $m$ |
