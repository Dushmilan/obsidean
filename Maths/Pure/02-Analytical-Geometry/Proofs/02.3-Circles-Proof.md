# Proofs: Circles

## 1. Standard Equation of a Circle

**Theorem:** Equation of circle with centre $C(a, b)$ and radius $r$:
$$(x - a)^2 + (y - b)^2 = r^2$$

**Proof:**
Let $P(x, y)$ be any point on the circle. Distance $PC = r$.
$$PC = \sqrt{(x - a)^2 + (y - b)^2} = r$$
Square both sides:
$$(x - a)^2 + (y - b)^2 = r^2 \quad \square$$

---

## 2. General Equation of a Circle

**Theorem:** General equation $x^2 + y^2 + 2gx + 2fy + c = 0$ represents a circle with centre $(-g, -f)$ and radius $\sqrt{g^2 + f^2 - c}$ (provided $g^2 + f^2 - c > 0$).

**Proof:**
Complete the square:
$$x^2 + 2gx + y^2 + 2fy + c = 0$$
$$(x^2 + 2gx + g^2) + (y^2 + 2fy + f^2) = g^2 + f^2 - c$$
$$(x + g)^2 + (y + f)^2 = g^2 + f^2 - c$$
$$(x - (-g))^2 + (y - (-f))^2 = (\sqrt{g^2 + f^2 - c})^2$$
Centre: $(-g, -f)$, Radius: $\sqrt{g^2 + f^2 - c} \quad \square$

**Note:** If $g^2 + f^2 - c = 0$, it's a point circle (radius 0).
If $g^2 + f^2 - c < 0$, no real locus.

## 3. Tangent at a Point on the Circle

### Circle $x^2 + y^2 = r^2$

**Theorem:** Tangent at $(x_1, y_1)$ on $x^2 + y^2 = r^2$:
$$xx_1 + yy_1 = r^2$$

**Proof (Method 1: Using perpendicular radius):**
Radius $OP$ has gradient $\frac{y_1}{x_1}$.
Tangent gradient $m = -\frac{x_1}{y_1}$ (perpendicular).
Equation: $y - y_1 = -\frac{x_1}{y_1}(x - x_1)$
$$y y_1 - y_1^2 = -x x_1 + x_1^2$$
$$x x_1 + y y_1 = x_1^2 + y_1^2 = r^2 \quad \square$$

**Proof (Method 2: Using limit of chord):**
Chord through $(x_1, y_1)$ and nearby point $(x_2, y_2)$:
$$\frac{y - y_1}{x - x_1} = \frac{y_2 - y_1}{x_2 - x_1}$$
Since both points satisfy $x^2 + y^2 = r^2$:
$$x_2^2 - x_1^2 + y_2^2 - y_1^2 = 0$$
$$(x_2 - x_1)(x_2 + x_1) + (y_2 - y_1)(y_2 + y_1) = 0$$
$$\frac{y_2 - y_1}{x_2 - x_1} = -\frac{x_2 + x_1}{y_2 + y_1}$$
As $(x_2, y_2) \to (x_1, y_1)$:
$$\text{Gradient} = -\frac{2x_1}{2y_1} = -\frac{x_1}{y_1}$$
Tangent: $y - y_1 = -\frac{x_1}{y_1}(x - x_1) \Rightarrow xx_1 + yy_1 = r^2 \quad \square$

### Circle $x^2 + y^2 + 2gx + 2fy + c = 0$

**Theorem:** Tangent at $(x_1, y_1)$:
$$xx_1 + yy_1 + g(x + x_1) + f(y + y_1) + c = 0$$

**Proof:**
Rewrite circle as $(x+g)^2 + (y+f)^2 = r^2$ where $r^2 = g^2+f^2-c$.
Shift origin to $(-g, -f)$: $X = x+g, Y = y+f$.
Point becomes $(X_1, Y_1) = (x_1+g, y_1+f)$.
Tangent in new coords: $XX_1 + YY_1 = r^2$.
Substitute back:
$$(x+g)(x_1+g) + (y+f)(y_1+f) = g^2 + f^2 - c$$
$$xx_1 + gx + gx_1 + g^2 + yy_1 + fy + fy_1 + f^2 = g^2 + f^2 - c$$
$$xx_1 + yy_1 + g(x+x_1) + f(y+y_1) + c = 0 \quad \square$$

## 4. Tangent with Given Slope $m$

### Circle $x^2 + y^2 = r^2$

**Theorem:** Tangents with slope $m$: $y = mx \pm r\sqrt{1+m^2}$

**Proof:**
Line: $y = mx + c$.
Substitute in $x^2 + y^2 = r^2$:
$$x^2 + (mx + c)^2 = r^2$$
$$(1+m^2)x^2 + 2mcx + (c^2 - r^2) = 0$$
For tangency, discriminant $= 0$:
$$(2mc)^2 - 4(1+m^2)(c^2 - r^2) = 0$$
$$4m^2c^2 - 4(c^2 - r^2 + m^2c^2 - m^2r^2) = 0$$
$$4m^2c^2 - 4c^2 + 4r^2 - 4m^2c^2 + 4m^2r^2 = 0$$
$$-4c^2 + 4r^2(1+m^2) = 0$$
$$c^2 = r^2(1+m^2) \Rightarrow c = \pm r\sqrt{1+m^2} \quad \square$$

### Circle $x^2 + y^2 + 2gx + 2fy + c = 0$

**Theorem:** Tangents with slope $m$:
$$y + f = m(x + g) \pm r\sqrt{1+m^2} \quad (r = \sqrt{g^2+f^2-c})$$

**Proof:**
Shift origin to $(-g, -f)$: $X = x+g, Y = y+f$.
Circle: $X^2 + Y^2 = r^2$.
Tangent: $Y = mX \pm r\sqrt{1+m^2}$.
Substitute back: $y+f = m(x+g) \pm r\sqrt{1+m^2} \quad \square$

## 5. Normal to a Circle

**Theorem:** Normal at $(x_1, y_1)$ on circle $(x-a)^2 + (y-b)^2 = r^2$ passes through centre $(a, b)$:
$$\frac{x - x_1}{x_1 - a} = \frac{y - y_1}{y_1 - b}$$

**Proof:**
Normal is perpendicular to tangent.
Tangent: $(x_1-a)(x-x_1) + (y_1-b)(y-y_1) = 0$ (from dot product)
Gradient of tangent: $-\frac{x_1-a}{y_1-b}$
Gradient of normal: $\frac{y_1-b}{x_1-a}$
Equation through $(x_1, y_1)$: $y - y_1 = \frac{y_1-b}{x_1-a}(x - x_1)$
$$\frac{x - x_1}{x_1 - a} = \frac{y - y_1}{y_1 - b} \quad \square$$

**Alternative form (point-normal):**
$$(x_1-a)(y - y_1) - (y_1-b)(x - x_1) = 0$$

## 6. Chord of Contact

**Theorem:** Chord of contact from $P(x_1, y_1)$ to $x^2 + y^2 + 2gx + 2fy + c = 0$:
$$xx_1 + yy_1 + g(x+x_1) + f(y+y_1) + c = 0$$

**Proof:**
Let tangents from $P$ touch circle at $Q(x_2, y_2)$ and $R(x_3, y_3)$.
Tangent at $Q$: $xx_2 + yy_2 + g(x+x_2) + f(y+y_2) + c = 0$
Tangent at $R$: $xx_3 + yy_3 + g(x+x_3) + f(y+y_3) + c = 0$
Both pass through $P(x_1, y_1)$:
$$x_1x_2 + y_1y_2 + g(x_1+x_2) + f(y_1+y_2) + c = 0$$
$$x_1x_3 + y_1y_3 + g(x_1+x_3) + f(y_1+y_3) + c = 0$$
Thus $Q$ and $R$ satisfy:
$$xx_1 + yy_1 + g(x+x_1) + f(y+y_1) + c = 0$$
This is line $QR$, the chord of contact $\quad \square$

## 7. Pole and Polar

**Definition:** Polar of point $P(x_1, y_1)$ w.r.t circle $S=0$: $S_1 = 0$ where
$$S \equiv x^2 + y^2 + 2gx + 2fy + c$$
$$S_1 \equiv xx_1 + yy_1 + g(x+x_1) + f(y+y_1) + c$$

**Proof:** Same as chord of contact. If $P$ is outside, polar = chord of contact.
If $P$ is on circle, polar = tangent.
If $P$ is inside, polar is line with geometric interpretation (harmonic conjugates).

## 8. Orthogonal Circles

**Theorem:** Circles $S_1=0$ and $S_2=0$ cut orthogonally iff:
$$2g_1g_2 + 2f_1f_2 = c_1 + c_2$$

**Proof:**
Let centres be $C_1(-g_1, -f_1)$, $C_2(-g_2, -f_2)$.
Radii: $r_1^2 = g_1^2 + f_1^2 - c_1$, $r_2^2 = g_2^2 + f_2^2 - c_2$.
Distance between centres: $C_1C_2^2 = (g_1-g_2)^2 + (f_1-f_2)^2$.
For orthogonal intersection: $C_1C_2^2 = r_1^2 + r_2^2$ (Pythagoras at intersection).
$$(g_1-g_2)^2 + (f_1-f_2)^2 = (g_1^2+f_1^2-c_1) + (g_2^2+f_2^2-c_2)$$
$$g_1^2 - 2g_1g_2 + g_2^2 + f_1^2 - 2f_1f_2 + f_2^2 = g_1^2+f_1^2+g_2^2+f_2^2 - c_1 - c_2$$
$$-2g_1g_2 - 2f_1f_2 = -c_1 - c_2$$
$$2g_1g_2 + 2f_1f_2 = c_1 + c_2 \quad \square$$

## 9. Director Circle

**Theorem:** Director circle of $x^2 + y^2 = r^2$ is $x^2 + y^2 = 2r^2$.

**Proof:**
Point $P(h, k)$ such that tangents from $P$ are perpendicular.
Tangents: $y - k = m(x - h)$ with condition $c^2 = r^2(1+m^2)$.
Line: $y = mx + (k - mh)$.
Condition: $(k - mh)^2 = r^2(1+m^2)$.
$$k^2 - 2hkm + h^2m^2 = r^2 + r^2m^2$$
$$(h^2 - r^2)m^2 - 2hkm + (k^2 - r^2) = 0$$
This quadratic in $m$ gives two slopes $m_1, m_2$.
Perpendicular tangents: $m_1m_2 = -1$.
$$\frac{k^2 - r^2}{h^2 - r^2} = -1$$
$$k^2 - r^2 = -h^2 + r^2$$
$$h^2 + k^2 = 2r^2$$
Locus of $P$: $x^2 + y^2 = 2r^2 \quad \square$

## 10. Intersection of Line and Circle

**Theorem:** Line $y = mx + c$ and circle $x^2 + y^2 = r^2$ intersect in:
- Two points if $c^2 < r^2(1+m^2)$
- One point (tangent) if $c^2 = r^2(1+m^2)$
- No points if $c^2 > r^2(1+m^2)$

**Proof:**
Substitute: $(1+m^2)x^2 + 2mcx + (c^2 - r^2) = 0$.
Discriminant $\Delta = 4m^2c^2 - 4(1+m^2)(c^2 - r^2) = 4[r^2(1+m^2) - c^2]$.
- $\Delta > 0 \iff c^2 < r^2(1+m^2)$
- $\Delta = 0 \iff c^2 = r^2(1+m^2)$
- $\Delta < 0 \iff c^2 > r^2(1+m^2) \quad \square$

## 11. Family of Circles

### Through Intersection of Circle $S=0$ and Line $L=0$

**Theorem:** $S + \lambda L = 0$ represents family of circles through intersection of $S=0$ and $L=0$.

**Proof:**
Any point on both $S=0$ and $L=0$ satisfies $S + \lambda L = 0$ for all $\lambda$.
Equation is of form $x^2 + y^2 + 2g'x + 2f'y + c' = 0$ (circle).
For $\lambda = 0$, gives $S=0$. As $\lambda \to \infty$, gives $L=0$ (degenerate circle, line). $\quad \square$

### Through Intersection of Two Circles $S_1=0$ and $S_2=0$

**Theorem:** $S_1 + \lambda S_2 = 0$ represents family of circles through their intersections.

**Proof:**
Intersections satisfy both $S_1=0$ and $S_2=0$, so satisfy $S_1 + \lambda S_2 = 0$.
Equation is $x^2(1+\lambda) + y^2(1+\lambda) + \dots = 0$.
If $\lambda \neq -1$, divide by $(1+\lambda)$: $x^2 + y^2 + \dots = 0$ (circle).
If $\lambda = -1$, gives $S_1 - S_2 = 0$ (radical axis, a line). $\quad \square$
