# Proofs: Straight Lines

## 1. General Form to Slope-Intercept Form

**Theorem:** Line $Ax + By + C = 0$ ($B \neq 0$) can be written as $y = mx + c$ where $m = -\frac{A}{B}, c = -\frac{C}{B}$.

**Proof:**
$$Ax + By + C = 0$$
$$By = -Ax - C$$
$$y = -\frac{A}{B}x - \frac{C}{B}$$
Let $m = -\frac{A}{B}$ (gradient) and $c = -\frac{C}{B}$ (y-intercept).
Then $y = mx + c \quad \square$

**Special case:** $B = 0 \Rightarrow Ax + C = 0 \Rightarrow x = -\frac{C}{A}$ (vertical line, undefined gradient)

---

## 2. Point-Slope Form Derivation

**Theorem:** Line through $(x_1, y_1)$ with gradient $m$:
$$y - y_1 = m(x - x_1)$$

**Proof:**
Let $P(x, y)$ be any point on the line. Gradient of $P(x_1,y_1)$ to $P(x,y)$ is $m$:
$$\frac{y - y_1}{x - x_1} = m$$
$$y - y_1 = m(x - x_1) \quad \square$$

---

## 3. Two-Point Form Derivation

**Theorem:** Line through $(x_1, y_1)$ and $(x_2, y_2)$:
$$\frac{y - y_1}{y_2 - y_1} = \frac{x - x_1}{x_2 - x_1}$$

**Proof:**
Gradient using two known points: $m = \frac{y_2 - y_1}{x_2 - x_1}$.
Using point-slope form with $(x_1, y_1)$:
$$y - y_1 = \frac{y_2 - y_1}{x_2 - x_1}(x - x_1)$$
$$\frac{y - y_1}{y_2 - y_1} = \frac{x - x_1}{x_2 - x_1} \quad \square$$

**Alternative symmetric form:**
$$\frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1} = t \quad (\text{parameter } t)$$

---

## 4. Intercept Form Derivation

**Theorem:** Line with x-intercept $a$, y-intercept $b$ ($a,b \neq 0$):
$$\frac{x}{a} + \frac{y}{b} = 1$$

**Proof:**
Points: $(a, 0)$ and $(0, b)$.
Two-point form:
$$\frac{y - 0}{b - 0} = \frac{x - a}{0 - a}$$
$$\frac{y}{b} = -\frac{x - a}{a} = -\frac{x}{a} + 1$$
$$\frac{x}{a} + \frac{y}{b} = 1 \quad \square$$

**From general form $Ax+By+C=0$:**
- x-intercept: set $y=0 \Rightarrow x = -\frac{C}{A} = a$
- y-intercept: set $x=0 \Rightarrow y = -\frac{C}{B} = b$
$$\frac{x}{-C/A} + \frac{y}{-C/B} = 1 \Rightarrow \frac{Ax}{-C} + \frac{By}{-C} = 1 \Rightarrow Ax + By = -C$$

---

## 5. Normal Form (Perpendicular Form) Derivation

**Theorem:** Line at perpendicular distance $p$ from origin, with perpendicular making angle $\alpha$ with x-axis:
$$x\cos\alpha + y\sin\alpha = p \quad (p \ge 0)$$

**Proof:**
Let $ON = p$ be perpendicular from origin to line. $\angle XON = \alpha$.
$N(p\cos\alpha, p\sin\alpha)$ is foot of perpendicular.

Line is perpendicular to $ON$, so gradient of line $= -\frac{1}{\tan\alpha} = -\cot\alpha$ (if $\alpha \neq 0$).

Using point-slope with $N(p\cos\alpha, p\sin\alpha)$:
$$y - p\sin\alpha = -\cot\alpha(x - p\cos\alpha)$$
$$y - p\sin\alpha = -\frac{\cos\alpha}{\sin\alpha}(x - p\cos\alpha)$$
Multiply by $\sin\alpha$:
$$y\sin\alpha - p\sin^2\alpha = -x\cos\alpha + p\cos^2\alpha$$
$$x\cos\alpha + y\sin\alpha = p(\sin^2\alpha + \cos^2\alpha)$$
$$x\cos\alpha + y\sin\alpha = p \quad \square$$

**Conversion from General Form $Ax+By+C=0$:**

Distance from origin: $p = \frac{|C|}{\sqrt{A^2+B^2}}$.
$$\cos\alpha = \frac{A}{\pm\sqrt{A^2+B^2}}, \quad \sin\alpha = \frac{B}{\pm\sqrt{A^2+B^2}}$$

Choose sign so that $p > 0$:
$$Ax+By+C=0 \Rightarrow \frac{Ax+By+C}{\pm\sqrt{A^2+B^2}} = 0$$
$$\frac{A}{\pm\sqrt{A^2+B^2}}x + \frac{B}{\pm\sqrt{A^2+B^2}}y = \frac{-C}{\pm\sqrt{A^2+B^2}}$$
Normal form: $x\cos\alpha + y\sin\alpha = p$

## 6. Angle Between Two Lines

**Theorem:** Angle $\theta$ between lines with gradients $m_1, m_2$:
$$\tan\theta = \left|\frac{m_1 - m_2}{1 + m_1m_2}\right|$$

**Proof:**
Let lines make angles $\theta_1, \theta_2$ with x-axis.
$m_1 = \tan\theta_1$, $m_2 = \tan\theta_2$.
Angle between lines: $\theta = |\theta_1 - \theta_2|$ (acute angle).
$$\tan\theta = \tan|\theta_1 - \theta_2| = \left|\frac{\tan\theta_1 - \tan\theta_2}{1 + \tan\theta_1\tan\theta_2}\right| = \left|\frac{m_1 - m_2}{1 + m_1m_2}\right| \quad \square$$

**Special Cases:**
- **Parallel:** $\theta = 0 \Rightarrow \tan\theta = 0 \Rightarrow m_1 = m_2$
- **Perpendicular:** $\theta = 90^\circ \Rightarrow \tan\theta \to \infty \Rightarrow 1 + m_1m_2 = 0 \Rightarrow m_1m_2 = -1$

**From General Form $A_1x+B_1y+C_1=0$ and $A_2x+B_2y+C_2=0$:**
$$m_1 = -\frac{A_1}{B_1}, \quad m_2 = -\frac{A_2}{B_2}$$
$$\tan\theta = \left|\frac{-\frac{A_1}{B_1} + \frac{A_2}{B_2}}{1 + \frac{A_1A_2}{B_1B_2}}\right| = \left|\frac{A_2B_1 - A_1B_2}{A_1A_2 + B_1B_2}\right|$$
- **Parallel:** $A_1B_2 = A_2B_1$ or $\frac{A_1}{A_2} = \frac{B_1}{B_2}$
- **Perpendicular:** $A_1A_2 + B_1B_2 = 0$

## 7. Distance from Point to Line

**Theorem:** Perpendicular distance from $P(x_1, y_1)$ to line $Ax + By + C = 0$:
$$d = \frac{|Ax_1 + By_1 + C|}{\sqrt{A^2 + B^2}}$$

**Proof:**

Let line $L: Ax + By + C = 0$.
Foot of perpendicular from $P$ to $L$ is $M(x_0, y_0)$.

Line through $P$ perpendicular to $L$ has gradient $\frac{B}{A}$ (negative reciprocal of $-\frac{A}{B}$).
Equation: $y - y_1 = \frac{B}{A}(x - x_1)$ $\Rightarrow$ $Bx - Ay = Bx_1 - Ay_1$.

Intersect with $L$:
$$\begin{cases}
Ax + By = -C \\
Bx - Ay = Bx_1 - Ay_1
\end{cases}$$

Solve using Cramer's rule:
$$\Delta = \begin{vmatrix} A & B \\ B & -A \end{vmatrix} = -A^2 - B^2 = -(A^2+B^2)$$
$$x_0 = \frac{\begin{vmatrix} -C & B \\ Bx_1-Ay_1 & -A \end{vmatrix}}{\Delta} = \frac{AC - B(Bx_1-Ay_1)}{-(A^2+B^2)} = \frac{B^2x_1 - ABy_1 - AC}{A^2+B^2}$$
$$y_0 = \frac{\begin{vmatrix} A & -C \\ B & Bx_1-Ay_1 \end{vmatrix}}{\Delta} = \frac{A(Bx_1-Ay_1) + BC}{-(A^2+B^2)} = \frac{A^2y_1 - ABx_1 - BC}{A^2+B^2}$$

Distance $PM = \sqrt{(x_1-x_0)^2 + (y_1-y_0)^2}$:
$$x_1 - x_0 = \frac{A^2x_1 + A^2x_1 - B^2x_1 + ABy_1 + AC}{A^2+B^2} = \frac{A(Ax_1+By_1+C)}{A^2+B^2}$$
$$y_1 - y_0 = \frac{B(Ax_1+By_1+C)}{A^2+B^2}$$
$$PM^2 = \frac{(Ax_1+By_1+C)^2(A^2+B^2)}{(A^2+B^2)^2} = \frac{(Ax_1+By_1+C)^2}{A^2+B^2}$$
$$PM = \frac{|Ax_1+By_1+C|}{\sqrt{A^2+B^2}} \quad \square$$

**Alternative Proof (Projection Method):**

Let $\hat{n} = \frac{(A,B)}{\sqrt{A^2+B^2}}$ be unit normal vector.
For any point $Q(x,y)$ on line: $Ax + By + C = 0 \Rightarrow A(x-x_1) + B(y-y_1) = -(Ax_1+By_1+C)$.

Distance $d = |\text{proj}_{\hat{n}}(\vec{PQ})| = |\vec{PQ} \cdot \hat{n}|$:
$$d = \frac{|A(x-x_1) + B(y-y_1)|}{\sqrt{A^2+B^2}} = \frac{|Ax_1+By_1+C|}{\sqrt{A^2+B^2}} \quad \square$$

## 8. Distance Between Parallel Lines

**Theorem:** Distance between $Ax+By+C_1=0$ and $Ax+By+C_2=0$:
$$d = \frac{|C_1 - C_2|}{\sqrt{A^2+B^2}}$$

**Proof:**
Pick point on first line, e.g., $x=0 \Rightarrow y = -\frac{C_1}{B}$.
Distance to second line:
$$d = \frac{|A(0) + B(-\frac{C_1}{B}) + C_2|}{\sqrt{A^2+B^2}} = \frac{|-C_1 + C_2|}{\sqrt{A^2+B^2}} = \frac{|C_1-C_2|}{\sqrt{A^2+B^2}} \quad \square$$

## 9. Angle Bisectors

**Theorem:** Angle bisectors of lines $L_1: A_1x+B_1y+C_1=0$ and $L_2: A_2x+B_2y+C_2=0$:
$$\frac{A_1x+B_1y+C_1}{\sqrt{A_1^2+B_1^2}} = \pm \frac{A_2x+B_2y+C_2}{\sqrt{A_2^2+B_2^2}}$$

**Proof:**
Point $P(x,y)$ on angle bisector $\iff$ distance from $P$ to $L_1$ = distance from $P$ to $L_2$.
$$\frac{|A_1x+B_1y+C_1|}{\sqrt{A_1^2+B_1^2}} = \frac{|A_2x+B_2y+C_2|}{\sqrt{A_2^2+B_2^2}}$$
$$\frac{A_1x+B_1y+C_1}{\sqrt{A_1^2+B_1^2}} = \pm \frac{A_2x+B_2y+C_2}{\sqrt{A_2^2+B_2^2}} \quad \square$$

**Acute/Obtuse Bisector Identification:**

Let $\theta$ be angle between lines. Then $\tan\theta = \left|\frac{A_1B_2-A_2B_1}{A_1A_2+B_1B_2}\right|$.

If $A_1A_2 + B_1B_2 > 0$: $+$ sign gives **obtuse** angle bisector, $-$ gives **acute**.
If $A_1A_2 + B_1B_2 < 0$: $+$ sign gives **acute** angle bisector, $-$ gives **obtuse**.

**Proof:** Sign of $A_1A_2+B_1B_2$ relates to angle between normals $\phi$: $\cos\phi = \frac{A_1A_2+B_1B_2}{\sqrt{A_1^2+B_1^2}\sqrt{A_2^2+B_2^2}}$.
Angle between lines = $\phi$ or $\pi-\phi$. The sign determines which bisector corresponds to acute/obtuse $\quad \square$

## 10. Family of Lines Through Intersection

**Theorem:** Family of lines through intersection of $L_1=0$ and $L_2=0$:
$$L_1 + \lambda L_2 = 0 \quad (\lambda \in \mathbb{R})$$

**Proof:**
Let $P$ be intersection of $L_1=0$ and $L_2=0$.
Then $L_1(P)=0$ and $L_2(P)=0$.
For any $\lambda$: $L_1(P) + \lambda L_2(P) = 0$.
So $P$ lies on $L_1 + \lambda L_2 = 0$.
Conversely, any line through $P$ (except $L_2$) can be written this way $\quad \square$

**Note:** $L_2$ itself corresponds to $\lambda \to \infty$.

## 11. Concurrency of Three Lines

**Theorem:** Lines $L_i: A_ix+B_iy+C_i=0$ ($i=1,2,3$) are concurrent iff
$$\begin{vmatrix} A_1 & B_1 & C_1 \\ A_2 & B_2 & C_2 \\ A_3 & B_3 & C_3 \end{vmatrix} = 0$$

**Proof:**
Lines concurrent $\iff$ system has a solution $(x,y)$ satisfying all three.
$$\begin{cases}
A_1x + B_1y = -C_1 \\
A_2x + B_2y = -C_2 \\
A_3x + B_3y = -C_3
\end{cases}$$
For consistent system, rank of coefficient matrix = rank of augmented matrix.
This requires the 3×3 determinant to be zero (linear dependence of rows) $\quad \square$

## 12. Key Results Summary

| Result | Formula |
|--------|---------|
| Slope from general form | $m = -\frac{A}{B}$ |
| Angle between lines (gradients) | $\tan\theta = \left|\frac{m_1-m_2}{1+m_1m_2}\right|$ |
| Angle between lines (general) | $\tan\theta = \left|\frac{A_2B_1-A_1B_2}{A_1A_2+B_1B_2}\right|$ |
| Point-to-line distance | $d = \frac{|Ax_1+By_1+C|}{\sqrt{A^2+B^2}}$ |
| Parallel lines distance | $d = \frac{|C_1-C_2|}{\sqrt{A^2+B^2}}$ |
| Angle bisectors | $\frac{L_1}{\sqrt{A_1^2+B_1^2}} = \pm \frac{L_2}{\sqrt{A_2^2+B_2^2}}$ |
| Family through intersection | $L_1 + \lambda L_2 = 0$ |
| Concurrency condition | $\det(A_i, B_i, C_i) = 0$ |
