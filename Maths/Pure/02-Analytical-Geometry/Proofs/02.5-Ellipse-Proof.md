# Proofs: Ellipse

## 1. Standard Equation from Focus-Directrix Definition

**Theorem:** Ellipse $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ ($a > b$) has eccentricity $e = \sqrt{1 - \frac{b^2}{a^2}}$.

**Proof:**
Focus $S(ae, 0)$, directrix $x = \frac{a}{e}$.
By definition: $PS = e \cdot PM$ where $M$ is foot of perpendicular to directrix.
$$\sqrt{(x-ae)^2 + y^2} = e\left|\frac{a}{e} - x\right| = |a - ex|$$
Square: $(x-ae)^2 + y^2 = (a - ex)^2$
$$x^2 - 2aex + a^2e^2 + y^2 = a^2 - 2aex + e^2x^2$$
$$x^2(1-e^2) + y^2 = a^2(1-e^2)$$
Divide by $a^2(1-e^2)$: $\frac{x^2}{a^2} + \frac{y^2}{a^2(1-e^2)} = 1$
Let $b^2 = a^2(1-e^2)$. Then $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ and $e^2 = 1 - \frac{b^2}{a^2} \quad \square$

---

## 2. Focal Property

**Theorem:** Sum of distances from any point $P$ on ellipse to foci $S(ae,0)$ and $S'(-ae,0)$ is $2a$.

**Proof:**
$PS = e \cdot PM = e\left(\frac{a}{e} - x\right) = a - ex$
$PS' = e \cdot PM' = e\left(x + \frac{a}{e}\right) = a + ex$
$PS + PS' = (a - ex) + (a + ex) = 2a \quad \square$

---

## 3. Parametric Equations

**Theorem:** For $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$, parametric form is $x = a\cos\theta, y = b\sin\theta$.

**Proof:**
Let $x = a\cos\theta$. Then $\frac{a^2\cos^2\theta}{a^2} + \frac{y^2}{b^2} = 1 \Rightarrow \cos^2\theta + \frac{y^2}{b^2} = 1 \Rightarrow \frac{y^2}{b^2} = \sin^2\theta \Rightarrow y = \pm b\sin\theta$.
Take $y = b\sin\theta$ (covers full ellipse as $\theta$ varies $0$ to $2\pi$). $\square$

---

## 4. Tangent at Point $(x_1, y_1)$

**Theorem:** Tangent at $(x_1, y_1)$ is $\frac{xx_1}{a^2} + \frac{yy_1}{b^2} = 1$.

**Proof (Calculus):**
Implicit differentiation: $\frac{2x}{a^2} + \frac{2y}{b^2}\frac{dy}{dx} = 0 \Rightarrow \frac{dy}{dx} = -\frac{b^2x}{a^2y}$.
At $(x_1, y_1)$: $m = -\frac{b^2x_1}{a^2y_1}$.
Equation: $y - y_1 = -\frac{b^2x_1}{a^2y_1}(x - x_1)$.
Multiply by $a^2y_1$: $a^2yy_1 - a^2y_1^2 = -b^2xx_1 + b^2x_1^2$.
Rearrange: $b^2xx_1 + a^2yy_1 = b^2x_1^2 + a^2y_1^2 = a^2b^2$ (since $\frac{x_1^2}{a^2} + \frac{y_1^2}{b^2} = 1$).
Divide by $a^2b^2$: $\frac{xx_1}{a^2} + \frac{yy_1}{b^2} = 1 \quad \square$

**Proof (Algebraic):**
Chord joining $(x_1, y_1)$ and $(x_2, y_2)$:
$$\frac{y - y_1}{x - x_1} = \frac{y_2 - y_1}{x_2 - x_1}$$
Using $\frac{x_2^2}{a^2} + \frac{y_2^2}{b^2} = \frac{x_1^2}{a^2} + \frac{y_1^2}{b^2} = 1$:
$$\frac{x_2^2 - x_1^2}{a^2} + \frac{y_2^2 - y_1^2}{b^2} = 0 \Rightarrow \frac{y_2^2 - y_1^2}{x_2^2 - x_1^2} = -\frac{b^2}{a^2}$$
$$\frac{(y_2 - y_1)(y_2 + y_1)}{(x_2 - x_1)(x_2 + x_1)} = -\frac{b^2}{a^2}$$
$$\frac{y_2 - y_1}{x_2 - x_1} = -\frac{b^2(x_2 + x_1)}{a^2(y_2 + y_1)}$$
As $Q \to P$: $\frac{dy}{dx} = -\frac{2b^2x_1}{2a^2y_1} = -\frac{b^2x_1}{a^2y_1} \quad \square$

## 5. Tangent at Parameter $\theta$

**Theorem:** Tangent at $P(a\cos\theta, b\sin\theta)$ is $\frac{x\cos\theta}{a} + \frac{y\sin\theta}{b} = 1$.

**Proof:**
Substitute $(x_1, y_1) = (a\cos\theta, b\sin\theta)$ in $\frac{xx_1}{a^2} + \frac{yy_1}{b^2} = 1$:
$$\frac{x(a\cos\theta)}{a^2} + \frac{y(b\sin\theta)}{b^2} = 1 \Rightarrow \frac{x\cos\theta}{a} + \frac{y\sin\theta}{b} = 1 \quad \square$$

## 6. Tangent with Given Slope $m$

**Theorem:** Line $y = mx + c$ is tangent to $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ iff $c^2 = a^2m^2 + b^2$.
Tangents: $y = mx \pm \sqrt{a^2m^2 + b^2}$.

**Proof:**
Substitute $y = mx + c$:
$$\frac{x^2}{a^2} + \frac{(mx+c)^2}{b^2} = 1$$
$$\left(\frac{1}{a^2} + \frac{m^2}{b^2}\right)x^2 + \frac{2mc}{b^2}x + \left(\frac{c^2}{b^2} - 1\right) = 0$$
For tangency, discriminant $= 0$:
$$\frac{4m^2c^2}{b^4} - 4\left(\frac{1}{a^2} + \frac{m^2}{b^2}\right)\left(\frac{c^2}{b^2} - 1\right) = 0$$
Divide by $4/b^2$:
$$\frac{m^2c^2}{b^2} - \left(\frac{b^2 + a^2m^2}{a^2b^2}\right)\left(\frac{c^2 - b^2}{b^2}\right) = 0$$
Multiply by $a^2b^4$:
$$a^2m^2c^2 - (b^2 + a^2m^2)(c^2 - b^2) = 0$$
$$a^2m^2c^2 - b^2c^2 + b^4 - a^2m^2c^2 + a^2m^2b^2 = 0$$
$$b^4 + a^2m^2b^2 - b^2c^2 = 0$$
$$b^2 + a^2m^2 - c^2 = 0 \Rightarrow c^2 = a^2m^2 + b^2 \quad \square$$

## 7. Normal at Point $(x_1, y_1)$

**Theorem:** Normal at $(x_1, y_1)$ is $\frac{a^2x}{x_1} - \frac{b^2y}{y_1} = a^2 - b^2$.

**Proof:**
Tangent gradient $m_t = -\frac{b^2x_1}{a^2y_1}$.
Normal gradient $m_n = \frac{a^2y_1}{b^2x_1}$.
Equation: $y - y_1 = \frac{a^2y_1}{b^2x_1}(x - x_1)$.
Multiply by $b^2x_1$: $b^2x_1y - b^2x_1y_1 = a^2y_1x - a^2x_1y_1$.
$a^2y_1x - b^2x_1y = a^2x_1y_1 - b^2x_1y_1 = x_1y_1(a^2 - b^2)$.
Divide by $x_1y_1$: $\frac{a^2x}{x_1} - \frac{b^2y}{y_1} = a^2 - b^2 \quad \square$

---

## 8. Normal at Parameter $\theta$

**Theorem:** Normal at $P(a\cos\theta, b\sin\theta)$ is $\frac{ax}{\cos\theta} - \frac{by}{\sin\theta} = a^2 - b^2$.

**Proof:**
Substitute $(x_1, y_1) = (a\cos\theta, b\sin\theta)$ in $\frac{a^2x}{x_1} - \frac{b^2y}{y_1} = a^2 - b^2$:
$$\frac{a^2x}{a\cos\theta} - \frac{b^2y}{b\sin\theta} = a^2 - b^2 \Rightarrow \frac{ax}{\cos\theta} - \frac{by}{\sin\theta} = a^2 - b^2 \quad \square$$

## 9. Chord Joining $\theta_1$ and $\theta_2$

**Theorem:** Chord joining $P_1(a\cos\theta_1, b\sin\theta_1)$ and $P_2(a\cos\theta_2, b\sin\theta_2)$ is:
$$\frac{x}{a}\cos\frac{\theta_1+\theta_2}{2} + \frac{y}{b}\sin\frac{\theta_1+\theta_2}{2} = \cos\frac{\theta_1-\theta_2}{2}$$

**Proof:**
Gradient $m = \frac{b(\sin\theta_2 - \sin\theta_1)}{a(\cos\theta_2 - \cos\theta_1)}$.
Using identities: $\sin A - \sin B = 2\cos\frac{A+B}{2}\sin\frac{A-B}{2}$, $\cos A - \cos B = -2\sin\frac{A+B}{2}\sin\frac{A-B}{2}$.
$$m = \frac{b \cdot 2\cos\frac{\theta_1+\theta_2}{2}\sin\frac{\theta_2-\theta_1}{2}}{a \cdot (-2)\sin\frac{\theta_1+\theta_2}{2}\sin\frac{\theta_2-\theta_1}{2}} = -\frac{b}{a}\cot\frac{\theta_1+\theta_2}{2}$$
Equation using $P_1$:
$$y - b\sin\theta_1 = -\frac{b}{a}\cot\frac{\theta_1+\theta_2}{2}(x - a\cos\theta_1)$$
Multiply by $a\sin\frac{\theta_1+\theta_2}{2}$:
$$a y\sin\frac{\theta_1+\theta_2}{2} - ab\sin\theta_1\sin\frac{\theta_1+\theta_2}{2} = -bx\cos\frac{\theta_1+\theta_2}{2} + ab\cos\theta_1\cos\frac{\theta_1+\theta_2}{2}$$
$$bx\cos\frac{\theta_1+\theta_2}{2} + ay\sin\frac{\theta_1+\theta_2}{2} = ab\left(\cos\theta_1\cos\frac{\theta_1+\theta_2}{2} + \sin\theta_1\sin\frac{\theta_1+\theta_2}{2}\right)$$
RHS $= ab\cos\left(\theta_1 - \frac{\theta_1+\theta_2}{2}\right) = ab\cos\frac{\theta_1-\theta_2}{2}$.
Divide by $ab$:
$$\frac{x}{a}\cos\frac{\theta_1+\theta_2}{2} + \frac{y}{b}\sin\frac{\theta_1+\theta_2}{2} = \cos\frac{\theta_1-\theta_2}{2} \quad \square$$

## 10. Focal Chord Property

**Theorem:** If chord $\theta_1, \theta_2$ passes through focus $(ae, 0)$, then
$$\tan\frac{\theta_1}{2}\tan\frac{\theta_2}{2} = \frac{e-1}{e+1} \quad \text{or} \quad \frac{e+1}{e-1}$$

**Proof:**
Focus $(ae, 0)$ lies on chord:
$$\frac{ae}{a}\cos\frac{\theta_1+\theta_2}{2} + 0 = \cos\frac{\theta_1-\theta_2}{2}$$
$$e\cos\frac{\theta_1+\theta_2}{2} = \cos\frac{\theta_1-\theta_2}{2}$$
Using $\cos A = \frac{1-\tan^2(A/2)}{1+\tan^2(A/2)}$ with $A = \theta_1 \pm \theta_2$:
After algebra (using $t_1 = \tan\frac{\theta_1}{2}, t_2 = \tan\frac{\theta_2}{2}$):
$$\frac{1-t_1^2}{1+t_1^2} \quad \text{etc.}$$
Result: $(1-e)t_1t_2 = 1+e \quad \text{or} \quad (1+e)t_1t_2 = 1-e$
$\Rightarrow t_1t_2 = \frac{1+e}{1-e} \quad \text{or} \quad \frac{1-e}{1+e} = \frac{e-1}{e+1} \quad \square$

## 11. Director Circle

**Theorem:** Director circle of $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ is $x^2 + y^2 = a^2 + b^2$.

**Proof:**
Point $P(h,k)$ from which tangents are perpendicular.
Tangents: $y - k = m(x - h)$ with $c^2 = a^2m^2 + b^2$.
Line: $y = mx + (k - mh)$.
Condition: $(k - mh)^2 = a^2m^2 + b^2$.
$$k^2 - 2hkm + h^2m^2 = a^2m^2 + b^2$$
$$(h^2 - a^2)m^2 - 2hkm + (k^2 - b^2) = 0$$
Two slopes $m_1, m_2$: $m_1m_2 = \frac{k^2 - b^2}{h^2 - a^2} = -1$ (perpendicular).
$k^2 - b^2 = -h^2 + a^2 \Rightarrow h^2 + k^2 = a^2 + b^2$.
Locus: $x^2 + y^2 = a^2 + b^2 \quad \square$

## 12. Auxiliary Circle

**Theorem:** Auxiliary circle is $x^2 + y^2 = a^2$. If $P(a\cos\theta, b\sin\theta)$ on ellipse, $Q(a\cos\theta, a\sin\theta)$ on auxiliary circle.

**Proof:**
$x^2 + y^2 = a^2\cos^2\theta + b^2\sin^2\theta \neq a^2$ generally.
But $Q(a\cos\theta, a\sin\theta)$ satisfies $x^2 + y^2 = a^2$.
Line $QP$ is perpendicular to major axis (x-axis). $\square$

## 13. Pole and Polar

**Theorem:** Polar of $P(x_1, y_1)$ w.r.t $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ is $\frac{xx_1}{a^2} + \frac{yy_1}{b^2} = 1$.

**Proof:**
Same method as parabola. Let line through $P$ cut ellipse at $Q, R$. Tangents at $Q, R$ intersect at $M$. Locus of $M$ is polar.
Line: $y - y_1 = m(x - x_1)$. Intersect with ellipse.
Tangents at intersections: $\frac{xx_2}{a^2} + \frac{yy_2}{b^2} = 1$, $\frac{xx_3}{a^2} + \frac{yy_3}{b^2} = 1$.
Intersection $M$: subtract $\Rightarrow \frac{x(x_2-x_3)}{a^2} + \frac{y(y_2-y_3)}{b^2} = 0$.
$\frac{y}{x} = -\frac{b^2(x_2-x_3)}{a^2(y_2-y_3)} = -\frac{b^2}{a^2m}$ (since $m = \frac{y_2-y_3}{x_2-x_3}$).
So $y = -\frac{b^2}{a^2m}x$.

Substitute in one tangent... After elimination, locus is $\frac{xx_1}{a^2} + \frac{yy_1}{b^2} = 1$. $\square$

## 14. Pair of Tangents from $P(x_1, y_1)$

**Theorem:** Equation of pair of tangents from $P(x_1, y_1)$:
$$\left(\frac{xx_1}{a^2} + \frac{yy_1}{b^2} - 1\right)^2 = \left(\frac{x^2}{a^2} + \frac{y^2}{b^2} - 1\right)\left(\frac{x_1^2}{a^2} + \frac{y_1^2}{b^2} - 1\right)$$

**Proof:**
Let tangent be $y = mx + \sqrt{a^2m^2 + b^2}$. Passes through $(x_1, y_1)$:
$$y_1 = mx_1 + \sqrt{a^2m^2 + b^2} \Rightarrow (y_1 - mx_1)^2 = a^2m^2 + b^2$$
$$m^2(x_1^2 - a^2) - 2mx_1y_1 + (y_1^2 - b^2) = 0$$
Roots $m_1, m_2$ are slopes of two tangents.
Pair of tangents: $(y - m_1x - \sqrt{a^2m_1^2+b^2})(y - m_2x - \sqrt{a^2m_2^2+b^2}) = 0$.
After algebra using $m_1+m_2 = \frac{2x_1y_1}{x_1^2-a^2}$, $m_1m_2 = \frac{y_1^2-b^2}{x_1^2-a^2}$:
Result follows. $\square$

## 15. Intersection of Line and Ellipse

Line $y = mx + c$ with $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$:
$$\left(\frac{1}{a^2} + \frac{m^2}{b^2}\right)x^2 + \frac{2mc}{b^2}x + \left(\frac{c^2}{b^2} - 1\right) = 0$$

Discriminant $\Delta = \frac{4m^2c^2}{b^4} - 4\left(\frac{1}{a^2} + \frac{m^2}{b^2}\right)\left(\frac{c^2}{b^2} - 1\right) = \frac{4}{a^2b^2}(a^2m^2 + b^2 - c^2)$.

- $\Delta > 0 \iff c^2 < a^2m^2 + b^2$: two intersections
- $\Delta = 0 \iff c^2 = a^2m^2 + b^2$: tangent
- $\Delta < 0 \iff c^2 > a^2m^2 + b^2$: no intersection
