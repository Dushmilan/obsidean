
## Definition

An ellipse is a "stretched circle" with two foci, where the **sum of distances from any point to the foci is constant** ($= 2a$). Equivalently, focus-directrix ratio $e$ with $0 < e < 1$. Standard form:

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1, \qquad a > b > 0$$

- Eccentricity: $e = \sqrt{1 - b^2/a^2}$ (so $b^2 = a^2(1-e^2)$)
- $e = 0$ → circle; $e \to 1$ → very elongated
- $a = b$ recovers the circle

## The Intuition

Take a circle and stretch it horizontally. The two-pin construction: pins at the foci, a loop of string around both, a pencil pulling the string taut traces the ellipse — the total string length is constant ($= 2a$). The eccentricity measures how "squashed" it is.

## The Toolkit

For $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$, $a > b$:

| Result | Formula |
|--------|---------|
| Eccentricity | $e = \sqrt{1 - b^2/a^2}$ |
| Foci | $(\pm ae, 0)$ |
| Directrices | $x = \pm \dfrac{a}{e}$ |
| Latus rectum | $\dfrac{2b^2}{a}$ |
| Parametric | $(a\cos\theta,\ b\sin\theta)$ |
| Tangent at $(x_1,y_1)$ | $\dfrac{xx_1}{a^2} + \dfrac{yy_1}{b^2} = 1$ |
| Tangent, slope $m$ | $y = mx \pm \sqrt{a^2m^2 + b^2}$ |
| Condition of tangency | $c^2 = a^2m^2 + b^2$ |
| Normal at $(x_1,y_1)$ | $\dfrac{a^2x}{x_1} - \dfrac{b^2y}{y_1} = a^2 - b^2$ |
| Director circle | $x^2 + y^2 = a^2 + b^2$ (perpendicular tangents meet here) |

## Derivation

Sum-of-distances definition: $\sqrt{(x-c)^2+y^2} + \sqrt{(x+c)^2+y^2} = 2a$ — squaring twice and simplifying (with $c^2 = a^2 - b^2$) yields $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$. The tangent formula mirrors the circle's but with $a^2, b^2$ denominators: replace $\frac{x^2}{a^2} \to \frac{xx_1}{a^2}$, $\frac{y^2}{b^2} \to \frac{yy_1}{b^2}$. [Full derivations: 02.5-Ellipse-Proof]

## Method

1. **Identify $a$ (larger) and $b$ (smaller)** — everything else follows.
2. **Find elements:** $e = \sqrt{1-b^2/a^2}$, foci $(\pm ae,0)$, directrices $x = \pm a/e$.
3. **Tangents of slope $m$:** compute $c$ from $c^2 = a^2m^2 + b^2$; write $y = mx \pm c$.
4. **Tangency condition:** a line $y = mx + c$ is tangent iff $c^2 = a^2m^2 + b^2$.
5. **Parametric work:** use $(a\cos\theta, b\sin\theta)$ and the auxiliary circle.

## Worked Examples

**Setup:** Ellipse $\frac{x^2}{25} + \frac{y^2}{9} = 1$. Find all elements.

**Solution:** $a = 5$, $b = 3$. $e = \sqrt{1 - 9/25} = 4/5 = 0.8$. Foci $(\pm 4, 0)$; directrices $x = \pm 6.25$; latus rectum $18/5 = 3.6$.

**Key insight:** Identify $a$ (larger) and $b$ (smaller) first, then everything else follows.

---

**Setup:** Tangent to $\frac{x^2}{16} + \frac{y^2}{4} = 1$ with $m = \frac12$.

**Solution:** $c^2 = 16(\frac14) + 4 = 8$, so $c = \pm 2\sqrt{2}$. Tangents: $y = \frac12 x \pm 2\sqrt{2}$.

**Key insight:** The $\pm$ gives two tangents with the same slope.

## Common Traps

- Swapping $a$ and $b$ — the **larger** denominator's root is $a$ (major axis)
- $e < 1$ for ellipses; $e > 1$ would be a hyperbola
- Tangent formula assumes the point is **on** the ellipse
- Confusing foci $(\pm ae, 0)$ with the vertices $(\pm a, 0)$
- Vertical-major-axis ellipses ($\frac{x^2}{b^2} + \frac{y^2}{a^2} = 1$) swap the roles of $x, y$ in every formula
