
## Definition

A straight line is the set of all points satisfying

$$Ax + By + C = 0$$

described by its **gradient** $m$ and intercepts. The five standard forms are not different lines — they are different ways to specify the same line given different information.

## The Intuition

A line is a road. The gradient is the slope ("rise over run": every 1 unit right, you move $m$ units up). The $y$-intercept is where the road crosses the vertical axis. Parallel roads never meet; perpendicular roads cross at right angles.

## The Toolkit

| Result | Formula | Use when |
|--------|---------|----------|
| Gradient | $m = \dfrac{y_2-y_1}{x_2-x_1} = \tan\theta$ | two points |
| Slope-intercept | $y = mx + c$ | gradient + intercept |
| Point-slope | $y - y_1 = m(x - x_1)$ | point + gradient |
| Intercept form | $\dfrac{x}{a} + \dfrac{y}{b} = 1$ | intercepts $a, b$ |
| Normal form | $x\cos\alpha + y\sin\alpha = p$ | perpendicular distance $p$ |
| Angle between lines | $\tan\theta = \left|\dfrac{m_1-m_2}{1+m_1m_2}\right|$ | two gradients |
| Point-to-line distance | $d = \dfrac{|Ax_1+By_1+C|}{\sqrt{A^2+B^2}}$ | point $(x_1,y_1)$ |
| Parallel distance | $d = \dfrac{|C_1-C_2|}{\sqrt{A^2+B^2}}$ | parallel lines |
| Parallel condition | $m_1 = m_2$ or $\dfrac{A_1}{A_2} = \dfrac{B_1}{B_2}$ | — |
| Perpendicular condition | $m_1m_2 = -1$ or $A_1A_2 + B_1B_2 = 0$ | — |
| Family through intersection | $L_1 + \lambda L_2 = 0$ | two lines |

## Derivation

Gradient from two points is rise over run. The angle formula: $\theta = \theta_1 - \theta_2$ with $m = \tan\theta$, and the tangent-difference identity produces the fraction. Perpendicular lines: $\theta_2 = \theta_1 + 90^\circ$, so $m_2 = -\frac{1}{m_1}$. Point-to-line distance: drop a perpendicular and use the normal form $x\cos\alpha + y\sin\alpha = p$. [Full derivations: 02.2-Straight-Lines-Proof]

## Method

1. **Write the equation:** pick the form matching your data (point-slope for point+gradient, intercept form for intercepts, etc.).
2. **Distance from point to line:** read off $A, B, C$ from the line in general form, substitute the point, take absolute value.
3. **Angle between lines:** use the gradient formula; the absolute value gives the acute angle.
4. **Parallel/perpendicular tests:** compare gradients (or $A, B$ ratios).
5. **Family of lines through an intersection:** combine $L_1 + \lambda L_2 = 0$; note this family misses $L_2 = 0$ itself.

## Worked Examples

**Setup:** Line through $(2,-3)$ with gradient $4$.

**Solution:** $y - (-3) = 4(x-2) \Rightarrow y + 3 = 4x - 8 \Rightarrow 4x - y - 11 = 0$.

**Key insight:** Point-slope form is fastest with a point and gradient.

---

**Setup:** Distance from $P(1,-2)$ to $3x - 4y + 12 = 0$.

**Solution:** $d = \frac{|3(1) - 4(-2) + 12|}{\sqrt{9+16}} = \frac{|3+8+12|}{5} = \frac{23}{5}$.

**Key insight:** Substitute carefully; the absolute value ensures a positive distance.

## Common Traps

- Using point-slope when the gradient is undefined (vertical lines: $x = c$)
- Forgetting that $m_1m_2 = -1$ only holds for non-vertical lines
- The angle formula's $|1+m_1m_2|$ sign — use absolute value for the acute angle
- Writing lines in non-general form before the distance formula (divide by $\sqrt{A^2+B^2}$ needs $A,B$ explicit)
- The family $L_1 + \lambda L_2 = 0$ never produces $L_2 = 0$
