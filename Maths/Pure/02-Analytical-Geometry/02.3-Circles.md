# 2.3 Circles

## Definition

A **circle** is the locus of a point which moves in a plane such that its distance from a fixed point (centre) is constant (radius).

### Standard Form (Centre-Radius Form)
Centre $(a, b)$, radius $r$:
$$(x - a)^2 + (y - b)^2 = r^2$$

### Special Cases
| Circle | Equation |
|--------|----------|
| Centre at origin $(0,0)$ | $x^2 + y^2 = r^2$ |
| Radius $r=1$ (unit circle) | $x^2 + y^2 = 1$ |
| Centre $(a,0)$, touches y-axis | $(x-a)^2 + y^2 = a^2$ |
| Centre $(0,b)$, touches x-axis | $x^2 + (y-b)^2 = b^2$ |

---

## Formulae

| Formula | Expression |
|---------|------------|
| **Standard form** | $(x-a)^2 + (y-b)^2 = r^2$ |
| **General form centre** | $(-g, -f)$ from $x^2 + y^2 + 2gx + 2fy + c = 0$ |
| **General form radius** | $r = \sqrt{g^2 + f^2 - c}$ |
| **Parametric** | $x = a + r\cos\theta,\; y = b + r\sin\theta$ |
| **Tangent at $(x_1,y_1)$ (origin)** | $xx_1 + yy_1 = r^2$ |
| **Tangent with slope $m$** | $y = mx \pm r\sqrt{1+m^2}$ |
| **Normal at $(x_1,y_1)$** | $\frac{x}{x_1} = \frac{y}{y_1}$ |
| **Chord of contact / Polar** | $xx_1 + yy_1 + g(x+x_1) + f(y+y_1) + c = 0$ |
| **Orthogonal circles** | $2g_1g_2 + 2f_1f_2 = c_1 + c_2$ |
| **Director circle** | $x^2 + y^2 = 2r^2$ |
| **Radical axis** | $S_1 - S_2 = 0$ |
| **Direct common tangent length** | $\sqrt{d^2 - (r_1 - r_2)^2}$ |
| **Transverse common tangent length** | $\sqrt{d^2 - (r_1 + r_2)^2}$ |

### General Form

$$x^2 + y^2 + 2gx + 2fy + c = 0$$

**Conditions:**
- $g^2 + f^2 - c > 0$ → Real circle
- $g^2 + f^2 - c = 0$ → Point circle (radius 0)
- $g^2 + f^2 - c < 0$ → No real locus

### Intercepts
- **x-intercepts:** Set $y=0$: $x^2 + 2gx + c = 0$
- **y-intercepts:** Set $x=0$: $y^2 + 2fy + c = 0$

**Intercept lengths:**
- On x-axis: $2\sqrt{g^2 - c}$ (if $g^2 \ge c$)
- On y-axis: $2\sqrt{f^2 - c}$ (if $f^2 \ge c$)

### Tangent Equations

**Tangent at Point $(x_1, y_1)$ on Circle:**

| Circle | Tangent at $(x_1, y_1)$ |
|--------|-------------------------|
| $x^2 + y^2 = r^2$ | $xx_1 + yy_1 = r^2$ |
| $(x-a)^2 + (y-b)^2 = r^2$ | $(x_1-a)(x-a) + (y_1-b)(y-b) = r^2$ |
| $x^2 + y^2 + 2gx + 2fy + c = 0$ | $xx_1 + yy_1 + g(x+x_1) + f(y+y_1) + c = 0$ |

**Tangent with Given Slope $m$:**

| Circle | Tangent with slope $m$ |
|--------|------------------------|
| $x^2 + y^2 = r^2$ | $y = mx \pm r\sqrt{1+m^2}$ |
| $x^2 + y^2 + 2gx + 2fy + c = 0$ | $y + f = m(x + g) \pm r\sqrt{1+m^2}$ where $r = \sqrt{g^2+f^2-c}$ |

**Tangent in Parametric Form ($\theta$):**

For $x^2 + y^2 = r^2$ at $\theta$:
$$x\cos\theta + y\sin\theta = r$$

For $(x-a)^2 + (y-b)^2 = r^2$ at $\theta$:
$$(x-a)\cos\theta + (y-b)\sin\theta = r$$

### Normal Equations

| Circle | Normal at $(x_1, y_1)$ |
|--------|------------------------|
| $x^2 + y^2 = r^2$ | $\frac{x}{x_1} = \frac{y}{y_1}$ or $x y_1 - y x_1 = 0$ |
| $(x-a)^2 + (y-b)^2 = r^2$ | $\frac{x-x_1}{x_1-a} = \frac{y-y_1}{y_1-b}$ |
| General | $(y-y_1)(x_1+g) = (x-x_1)(y_1+f)$ |

**Property:** Normal always passes through centre of circle.

### Chord Equations

**Chord with Midpoint $(x_1, y_1)$:**
For $x^2 + y^2 + 2gx + 2fy + c = 0$:
$$xx_1 + yy_1 + g(x+x_1) + f(y+y_1) + c = x_1^2 + y_1^2 + 2gx_1 + 2fy_1 + c$$

**Or (T = S₁):**
$$T \equiv S_1$$
where $T$ = tangent form, $S_1$ = value of $S$ at $(x_1, y_1)$.

**Chord of Contact from $P(x_1, y_1)$:**
Same as tangent at $(x_1, y_1)$:
$$xx_1 + yy_1 + g(x+x_1) + f(y+y_1) + c = 0$$

**Polar of Point $P(x_1, y_1)$:**
Same equation as chord of contact.

## Properties / Key Concepts

### Intersection of Line and Circle

Line: $y = mx + c$ (or $Ax + By + C = 0$)
Circle: $x^2 + y^2 + 2gx + 2fy + c = 0$

Substitute line into circle → quadratic in $x$ (or $y$).

**Discriminant $\Delta$ determines:**
| $\Delta$ | Intersection |
|----------|--------------|
| $> 0$ | Two distinct points (secant) |
| $= 0$ | One point (tangent) |
| $< 0$ | No intersection |

### Relative Position of Two Circles

Two circles with centres $C_1, C_2$ and radii $r_1, r_2$.
Distance between centres: $d = C_1C_2$.

| Condition | Position |
|-----------|----------|
| $d > r_1 + r_2$ | One outside the other (no intersection) |
| $d = r_1 + r_2$ | Touch externally |
| $\|r_1 - r_2\| < d < r_1 + r_2$ | Intersect in two points |
| $d = \|r_1 - r_2\|$ | Touch internally |
| $d < \|r_1 - r_2\|$ | One inside the other (no intersection) |
| $d = 0, r_1 = r_2$ | Coincident |

### Orthogonal Circles

**Condition:** $2g_1g_2 + 2f_1f_2 = c_1 + c_2$

**Derivation:** At intersection, tangents are perpendicular → $C_1P \perp C_2P$ → $C_1C_2^2 = r_1^2 + r_2^2$ (Pythagoras).

### Radical Axis

For circles $S_1 = 0$ and $S_2 = 0$:
**Radical Axis:** $S_1 - S_2 = 0$ (a line)

**Properties:**
- Locus of points with equal tangent lengths to both circles
- Perpendicular to line of centres
- For intersecting circles: common chord
- For touching circles: common tangent at point of contact

### Family of Circles

| Family | Equation |
|--------|----------|
| Through intersection of $S=0$ and line $L=0$ | $S + \lambda L = 0$ |
| Through intersection of $S_1=0$ and $S_2=0$ | $S_1 + \lambda S_2 = 0$ |
| Touching line $L=0$ at $(x_1, y_1)$ | $(x-x_1)^2 + (y-y_1)^2 + \lambda L = 0$ |

### Director Circle

Locus of point from which tangents are perpendicular:
- For $x^2 + y^2 = r^2$: $x^2 + y^2 = 2r^2$
- For $(x-a)^2 + (y-b)^2 = r^2$: $(x-a)^2 + (y-b)^2 = 2r^2$

### Common Tangents

For circles $C_1(r_1)$ and $C_2(r_2)$ with distance $d$:

| Tangent Type | Number | Condition |
|--------------|--------|-----------|
| Direct (external) | 2 | $d > r_1 + r_2$ |
| Transverse (internal) | 2 | $d > \|r_1 - r_2\|$ |
| **Total** | **4** | $d > r_1 + r_2$ |
| **Total** | **3** | $d = r_1 + r_2$ (touch externally) |
| **Total** | **2** | $\|r_1 - r_2\| < d < r_1 + r_2$ (intersect) |
| **Total** | **1** | $d = \|r_1 - r_2\|$ (touch internally) |
| **Total** | **0** | $d < \|r_1 - r_2\|$ (one inside other) |

## Worked Examples

### Example 1: Find centre and radius
$x^2 + y^2 - 6x + 4y - 12 = 0$
Complete square: $(x-3)^2 + (y+2)^2 = 25$
Centre: $(3, -2)$, Radius: $5$

### Example 2: Tangent with slope
Circle: $x^2 + y^2 = 16$, slope $m = \frac{3}{4}$
Tangents: $y = \frac{3}{4}x \pm 4\sqrt{1+\frac{9}{16}} = \frac{3}{4}x \pm 5$
Equations: $3x - 4y \pm 20 = 0$

### Example 3: Orthogonal circles
$x^2 + y^2 + 2gx + 2fy + c = 0$ cuts $x^2 + y^2 = 9$ orthogonally.
Condition: $2g(0) + 2f(0) = c + 9 \Rightarrow c = -9$.

## Common Traps

| Mistake | Correction |
|---------|------------|
| ❌ Forgetting to divide by coefficient of $x^2, y^2$ | Always make $x^2, y^2$ coefficients $1$ first |
| ❌ Wrong sign in centre | Centre is $(-g, -f)$, not $(g, f)$ |
| ❌ Using tangent formula for external point | Tangent formula only works if point is ON the circle |
| ❌ Confusing chord of contact with polar | They have same equation but different geometric meanings |
| ❌ Missing $\pm$ in tangent with slope | Always two tangents for a given slope |
