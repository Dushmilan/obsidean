# 4.11 Special Functions

## Definition

Special functions arise as solutions to differential equations or as integrals with particular forms. They extend standard elementary functions and appear frequently in physics and engineering.

## Formulae

### Gamma Function

| Formula | Expression |
|---------|------------|
| **Definition** | $\Gamma(z) = \int_0^\infty t^{z-1} e^{-t} dt, \quad \text{Re}(z) > 0$ |
| **Recurrence** | $\Gamma(z+1) = z \Gamma(z)$ |
| **Integer values** | $\Gamma(n) = (n-1)!$ for $n \in \mathbb{N}$ |
| **Half-integer** | $\Gamma\left(\frac{1}{2}\right) = \sqrt{\pi}$ |
| **Euler's reflection** | $\Gamma(z)\Gamma(1-z) = \frac{\pi}{\sin(\pi z)}$ |
| **Legendre duplication** | $\Gamma(z)\Gamma\left(z+\frac{1}{2}\right) = 2^{1-2z}\sqrt{\pi}\,\Gamma(2z)$ |
| **Stirling's approximation** | $\Gamma(z) \sim \sqrt{2\pi} z^{z-1/2} e^{-z}$ |

### Beta Function

| Formula | Expression |
|---------|------------|
| **Definition** | $B(x,y) = \int_0^1 t^{x-1} (1-t)^{y-1} dt$ |
| **Gamma relation** | $B(x,y) = \frac{\Gamma(x)\Gamma(y)}{\Gamma(x+y)}$ |
| **Symmetry** | $B(x,y) = B(y,x)$ |
| **Alternative form** | $B(x,y) = 2 \int_0^{\pi/2} \sin^{2x-1}\theta \cos^{2y-1}\theta \, d\theta$ |

### Error Function

| Formula | Expression |
|---------|------------|
| **Definition** | $\text{erf}(x) = \frac{2}{\sqrt{\pi}} \int_0^x e^{-t^2} dt$ |
| **Complementary** | $\text{erfc}(x) = 1 - \text{erf}(x) = \frac{2}{\sqrt{\pi}} \int_x^\infty e^{-t^2} dt$ |
| **Derivative** | $\text{erf}'(x) = \frac{2}{\sqrt{\pi}} e^{-x^2}$ |
| **Normal distribution** | $\Phi(x) = \frac{1}{2}\left[1 + \text{erf}\left(\frac{x}{\sqrt{2}}\right)\right]$ |

### Gaussian Integral

| Formula | Expression |
|---------|------------|
| **Standard** | $\int_{-\infty}^\infty e^{-x^2} dx = \sqrt{\pi}$ |
| **Generalised** | $\int_{-\infty}^\infty e^{-ax^2 + bx} dx = \sqrt{\frac{\pi}{a}} e^{b^2/4a}, \quad a > 0$ |

### Elliptic Integrals

| Kind | Formula |
|------|---------|
| **First** $K(k)$ | $\int_0^{\pi/2} \frac{d\theta}{\sqrt{1 - k^2 \sin^2 \theta}}$ |
| **Second** $E(k)$ | $\int_0^{\pi/2} \sqrt{1 - k^2 \sin^2 \theta} \, d\theta$ |
| **Third** $\Pi(n,k)$ | $\int_0^{\pi/2} \frac{d\theta}{(1 - n \sin^2 \theta)\sqrt{1 - k^2 \sin^2 \theta}}$ |

### Other Special Functions

| Function | Formula |
|----------|---------|
| **Exponential integral** | $E_1(x) = \int_x^\infty \frac{e^{-t}}{t} dt = -\text{Ei}(-x)$ |
| **Sine integral** | $\text{Si}(x) = \int_0^x \frac{\sin t}{t} dt$, $\text{Si}(\infty) = \frac{\pi}{2}$ |
| **Cosine integral** | $\text{Ci}(x) = -\int_x^\infty \frac{\cos t}{t} dt$ |
| **Fresnel** $C(x)$ | $\int_0^x \cos\left(\frac{\pi t^2}{2}\right) dt$, $C(\infty) = \frac{1}{2}$ |
| **Fresnel** $S(x)$ | $\int_0^x \sin\left(\frac{\pi t^2}{2}\right) dt$, $S(\infty) = \frac{1}{2}$ |
| **Riemann zeta** | $\zeta(s) = \sum_{n=1}^\infty \frac{1}{n^s}$, $\zeta(2) = \frac{\pi^2}{6}$ |
| **Digamma** | $\psi(z) = \frac{\Gamma'(z)}{\Gamma(z)}$ |

### Wallis' Formula
$$\int_0^{\pi/2} \sin^n x \, dx = \int_0^{\pi/2} \cos^n x \, dx = \begin{cases} \frac{(n-1)!!}{n!!} \cdot \frac{\pi}{2} & n \text{ even} \\ \frac{(n-1)!!}{n!!} & n \text{ odd} \end{cases}$$

### Gamma/Beta Integrals

| Integral | Result |
|----------|--------|
| $\int_0^\infty x^{n-1} e^{-ax} dx$ | $\frac{\Gamma(n)}{a^n}$ |
| $\int_0^1 x^{p-1}(1-x)^{q-1} dx$ | $B(p,q) = \frac{\Gamma(p)\Gamma(q)}{\Gamma(p+q)}$ |
| $\int_0^{\pi/2} \sin^{2m-1}\theta \cos^{2n-1}\theta d\theta$ | $\frac{1}{2}B(m,n)$ |
| $\int_0^\infty \frac{x^{p-1}}{1+x} dx$ | $\frac{\pi}{\sin(\pi p)}$, $0<p<1$ |

## Properties / Key Concepts

### Important Gamma Values
- $\Gamma(1) = 1$
- $\Gamma\left(\frac{1}{2}\right) = \sqrt{\pi}$
- $\Gamma\left(\frac{3}{2}\right) = \frac{\sqrt{\pi}}{2}$
- $\Gamma\left(\frac{5}{2}\right) = \frac{3\sqrt{\pi}}{4}$
- $\Gamma(n+\frac{1}{2}) = \frac{(2n)!}{4^n n!}\sqrt{\pi}$

### Elliptic Integral Properties
- $K(0) = E(0) = \frac{\pi}{2}$
- $K(1) = \infty$, $E(1) = 1$
- Applications: arc length of ellipse, period of pendulum

### Error Function Properties
- $\text{erf}(-x) = -\text{erf}(x)$ (odd)
- $\text{erf}(0) = 0$
- $\lim_{x \to \infty} \text{erf}(x) = 1$

### Asymptotic Expansions
**Stirling's Formula:**
$$\ln \Gamma(z) \sim \left(z-\frac{1}{2}\right)\ln z - z + \frac{1}{2}\ln(2\pi) + \frac{1}{12z} - \cdots$$

**Error Function (Large $x$):**
$$\text{erfc}(x) \sim \frac{e^{-x^2}}{x\sqrt{\pi}} \left(1 - \frac{1}{2x^2} + \frac{3}{4x^4} - \cdots \right)$$

## Worked Examples

### Example 1: Gamma Function
$\int_0^\infty x^4 e^{-2x} dx$
$= \frac{\Gamma(5)}{2^5} = \frac{4!}{32} = \frac{24}{32} = \frac{3}{4}$

### Example 2: Beta Function
$\int_0^1 x^2 (1-x)^3 dx$
$= B(3,4) = \frac{\Gamma(3)\Gamma(4)}{\Gamma(7)} = \frac{2! \cdot 3!}{6!} = \frac{12}{720} = \frac{1}{60}$

### Example 3: Trigonometric Integral
$\int_0^{\pi/2} \sin^5 x \cos^2 x dx$
$= \frac{1}{2} B(3, \frac{3}{2}) = \frac{1}{2} \frac{\Gamma(3)\Gamma(3/2)}{\Gamma(9/2)} = \frac{8}{105}$

### Example 4: Using Beta and Reflection
$\int_0^\infty \frac{dx}{1+x^3}$
Substitute $x^3 = t \Rightarrow x = t^{1/3}, dx = \frac{1}{3}t^{-2/3}dt$
$= \frac{1}{3} B\left(\frac{1}{3}, \frac{2}{3}\right) = \frac{1}{3} \frac{\Gamma(1/3)\Gamma(2/3)}{\Gamma(1)} = \frac{\pi}{3\sin(\pi/3)} = \frac{2\pi}{3\sqrt{3}}$

## Common Traps

| Trap | ❌ Wrong | Correct |
|------|-------|---------|
| Gamma argument | $\Gamma(n) = n!$ | $\Gamma(n) = (n-1)!$ |
| Beta limits | $\int_0^\infty$ for Beta | Beta is $\int_0^1$ (or $0$ to $\infty$ with transform) |
| Error function | $\text{erf}(x) = \int_0^x e^{-t^2} dt$ | $\text{erf}(x) = \frac{2}{\sqrt{\pi}} \int_0^x e^{-t^2} dt$ |
| Gamma half-integer | $\Gamma(1/2) = \pi$ | $\Gamma(1/2) = \sqrt{\pi}$ |
| Legendre duplication | Missing factor | $\Gamma(z)\Gamma(z+\frac{1}{2}) = 2^{1-2z}\sqrt{\pi}\Gamma(2z)$ |
