### 1.1 $n$-th Term Test (Divergence Test)
**Theorem:** If $\sum a_n$ converges, then $\lim_{n \to \infty} a_n = 0$.
**Proof:** Let $S_n = \sum_{k=1}^n a_k \to S$. Then $a_n = S_n - S_{n-1} \to S - S = 0$.
**Contrapositive:** If $\lim a_n \neq 0$, series diverges.

---

### 1.2 Geometric Series
$\sum_{n=0}^\infty ar^n = a + ar + ar^2 + \cdots$
**Sum:** $S_n = a\frac{1-r^n}{1-r}$ for $r \neq 1$.
If $|r| < 1$, $r^n \to 0$, so $S = \frac{a}{1-r}$.
If $|r| \ge 1$, $r^n$ doesn't tend to $0$, series diverges.

---

### 1.3 $p$-Series
$\sum_{n=1}^\infty \frac{1}{n^p}$
**Integral Test:** $\int_1^\infty \frac{dx}{x^p} = \left[\frac{x^{1-p}}{1-p}\right]_1^\infty$ converges iff $p > 1$.

---

### 1.4 Comparison Test
If $0 \le a_n \le b_n$:
- $\sum b_n$ converges $\Rightarrow \sum a_n$ converges
- $\sum a_n$ diverges $\Rightarrow \sum b_n$ diverges
**Proof:** Partial sums $A_n = \sum_{k=1}^n a_k$, $B_n = \sum_{k=1}^n b_k$. $A_n \le B_n$. If $B_n$ bounded, $A_n$ bounded (monotone increasing).

---

### 1.5 Limit Comparison Test
$a_n, b_n > 0$, $\lim \frac{a_n}{b_n} = L \in (0,\infty)$.
Then $\sum a_n$ and $\sum b_n$ converge or diverge together.
**Proof:** For large $n$, $\frac{L}{2} < \frac{a_n}{b_n} < 2L \Rightarrow$ comparison with constant multiples of $b_n$.

---

### 1.6 Ratio Test (D'Alembert)
Let $L = \lim_{n \to \infty} \left|\frac{a_{n+1}}{a_n}\right|$.
- $L < 1$: converges absolutely
- $L > 1$: diverges
- $L = 1$: inconclusive

**Proof (L < 1):** Choose $r$ with $L < r < 1$. For large $n$, $\left|\frac{a_{n+1}}{a_n}\right| < r \Rightarrow |a_{n+1}| < r|a_n|$. By induction, $|a_n| < Cr^n$ (geometric series).

---

### 1.7 Root Test (Cauchy)
Let $L = \limsup_{n \to \infty} \sqrt[n]{|a_n|}$.
- $L < 1$: converges absolutely
- $L > 1$: diverges
- $L = 1$: inconclusive

**Proof:** Similar to ratio test. $\sqrt[n]{|a_n|} < r < 1 \Rightarrow |a_n| < r^n$.

---

### 1.8 Integral Test
$f(x)$ positive, continuous, decreasing on $[1,\infty)$, $a_n = f(n)$.
$\sum a_n$ converges $\iff \int_1^\infty f(x) dx$ converges.
**Proof:** Rectangles: $\int_1^{N+1} f(x) dx \le \sum_{n=1}^N a_n \le a_1 + \int_1^N f(x) dx$.

---

### 1.9 Alternating Series Test (Leibniz)
$\sum_{n=1}^\infty (-1)^{n-1} b_n$ with $b_n \ge 0$, $b_n \searrow 0$.
**Converges.** Error bound: $|R_n| \le b_{n+1}$.
**Proof:** Even partial sums $S_{2n}$ increasing, odd $S_{2n+1}$ decreasing, both bounded. Limit exists.

---


### 2.1 Absolute Convergence Implies Convergence
If $\sum |a_n|$ converges, then $\sum a_n$ converges.
**Proof:** $0 \le a_n + |a_n| \le 2|a_n|$. $\sum 2|a_n|$ converges $\Rightarrow \sum (a_n + |a_n|)$ converges $\Rightarrow \sum a_n = \sum (a_n + |a_n|) - \sum |a_n|$ converges.

### 2.2 Riemann Rearrangement Theorem
Conditionally convergent series can be rearranged to sum to any real number (or diverge).
**Proof sketch:** Separate positive and negative terms, both diverge. Add positive until exceeding target, then negative until below, etc.

### 3.1 Radius of Convergence
For $\sum a_n (x-c)^n$, define $R = \frac{1}{\limsup \sqrt[n]{|a_n|}}$ (or $R = \lim |\frac{a_n}{a_{n+1}}|$ if limit exists).
**Theorem:** Converges absolutely for $|x-c| < R$, diverges for $|x-c| > R$.
**Proof:** Root test: $\limsup \sqrt[n]{|a_n(x-c)^n|} = \frac{|x-c|}{R}$.

### 3.2 Uniform Convergence on Compact Subsets
Power series converges uniformly on any closed disk $|x-c| \le r < R$.
**Proof:** M-test with $|a_n x^n| \le |a_n| r^n$.

### 3.3 Termwise Differentiation/Integration
Within radius of convergence, can differentiate/integrate term by term.
**Proof:** Uniform convergence of derived series on compact subsets $\Rightarrow$ limit of derivatives = derivative of limit.

### 4.1 Statement
Let $f \in C^{n+1}(I)$ on interval $I$ containing $a$. Then for $x \in I$:
$$f(x) = \sum_{k=0}^n \frac{f^{(k)}(a)}{k!}(x-a)^k + R_n(x)$$

### 4.2 Lagrange Remainder
$$R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}, \quad \xi \text{ between } a \text{ and } x$$

**Proof (Cauchy Mean Value Theorem):**
Define $g(t) = f(x) - \sum_{k=0}^n \frac{f^{(k)}(t)}{k!}(x-t)^k$.
Then $g(a) = R_n(x)$, $g(x) = 0$.
Apply Cauchy MVT to $g$ and $h(t) = (x-t)^{n+1}$ on $[a,x]$:
$$\frac{g(x) - g(a)}{h(x) - h(a)} = \frac{g'(\xi)}{h'(\xi)}$$
Compute $g'(t) = -\frac{f^{(n+1)}(t)}{n!}(x-t)^n$, $h'(t) = -(n+1)(x-t)^n$.
Result follows.

### 4.3 Cauchy Remainder
$$R_n(x) = \frac{f^{(n+1)}(\xi)}{n!}(x-\xi)^n(x-a)$$

### 4.4 Integral Remainder
$$R_n(x) = \int_a^x \frac{f^{(n+1)}(t)}{n!}(x-t)^n dt$$
**Proof:** Induction on $n$ using integration by parts.

### 4.5 Taylor's Inequality
If $|f^{(n+1)}(t)| \le M$ for $t$ between $a$ and $x$, then
$$|R_n(x)| \le \frac{M}{(n+1)!}|x-a|^{n+1}$$

### 5.1 $e^x$
$f^{(n)}(x) = e^x$, $f^{(n)}(0) = 1$.
$$e^x = \sum_{n=0}^\infty \frac{x^n}{n!}$$
**Radius:** Ratio test $\frac{|x|}{n+1} \to 0 \Rightarrow R = \infty$.
**Remainder:** $|R_n(x)| \le \frac{e^{|x|}}{(n+1)!}|x|^{n+1} \to 0$ for all $x$.

### 5.2 $\sin x$ and $\cos x$
$f^{(n)}(0)$ cycles: $0, 1, 0, -1, \dots$
$$\sin x = \sum_{n=0}^\infty \frac{(-1)^n x^{2n+1}}{(2n+1)!}$$
$$\cos x = \sum_{n=0}^\infty \frac{(-1)^n x^{2n}}{(2n)!}$$
**Radius:** $R = \infty$ (factorials dominate).

### 5.3 $\ln(1+x)$
$f^{(n)}(x) = (-1)^{n-1} \frac{(n-1)!}{(1+x)^n}$ for $n \ge 1$, $f^{(n)}(0) = (-1)^{n-1}(n-1)!$.
$$\ln(1+x) = \sum_{n=1}^\infty \frac{(-1)^{n-1} x^n}{n}$$
**Radius:** Ratio test $\lim \frac{n}{n+1}|x| = |x| \Rightarrow R = 1$.
**Endpoints:** $x=1$ converges (alternating harmonic), $x=-1$ diverges (harmonic).

### 5.4 $(1+x)^\alpha$ (Binomial Series)
$f^{(n)}(x) = \alpha(\alpha-1)\cdots(\alpha-n+1)(1+x)^{\alpha-n}$, $f^{(n)}(0) = \alpha(\alpha-1)\cdots(\alpha-n+1) = n! \binom{\alpha}{n}$.
$$(1+x)^\alpha = \sum_{n=0}^\infty \binom{\alpha}{n} x^n$$
**Radius:** $R = 1$ (unless $\alpha \in \mathbb{N}_0$, then polynomial).
**Endpoints:** $x=1$ converges if $\alpha > -1$, $x=-1$ if $\alpha > 0$.

### 5.5 $\arctan x$
$\frac{d}{dx}\arctan x = \frac{1}{1+x^2} = \sum_{n=0}^\infty (-1)^n x^{2n}$ for $|x| < 1$.
Integrate termwise: $\arctan x = \sum_{n=0}^\infty \frac{(-1)^n x^{2n+1}}{2n+1}$.
**Radius:** $R = 1$. Converges at $x = \pm 1$ (alternating series).

---


### 6.1 Addition/Subtraction
$\sum a_n x^n \pm \sum b_n x^n = \sum (a_n \pm b_n) x^n$
**Radius:** $\ge \min(R_1, R_2)$

### 6.2 Multiplication (Cauchy Product)
$\left(\sum a_n x^n\right)\left(\sum b_n x^n\right) = \sum c_n x^n$, $c_n = \sum_{k=0}^n a_k b_{n-k}$
**Radius:** $\ge \min(R_1, R_2)$
**Proof:** Mertens' theorem — if one series converges absolutely, Cauchy product converges to product.

### 6.3 Division
$\frac{\sum a_n x^n}{\sum b_n x^n} = \sum c_n x^n$ where $c_n$ determined recursively:
$a_n = \sum_{k=0}^n b_k c_{n-k}$ (valid if $b_0 \neq 0$)

### 6.4 Composition
If $f(x) = \sum a_n x^n$ ($R_f$), $g(x) = \sum b_n x^n$ ($R_g$), $g(0)=0$, $|g(x)| < R_f$ near 0:
$f(g(x)) = \sum a_n (g(x))^n$
**Radius:** Limited by where $|g(x)| < R_f$

---


### 7.1 When Does Taylor Series Converge to $f(x)$?
Taylor series $\sum \frac{f^{(n)}(a)}{n!}(x-a)^n$ converges to $f(x)$ iff $R_n(x) \to 0$.

### 7.2 Analytic Functions
$f$ is **analytic** at $a$ if Taylor series converges to $f$ in some neighbourhood.
Examples: $e^x$, $\sin x$, $\cos x$, $\frac{1}{1-x}$, $(1+x)^\alpha$ (for $|x|<1$).

### 7.3 Classic Counterexample
$f(x) = e^{-1/x^2}$ for $x \neq 0$, $f(0) = 0$.
All derivatives at 0 are 0. Taylor series is identically 0, but $f(x) \neq 0$ for $x \neq 0$.
$f \in C^\infty$ but not analytic.

---


### 8.1 Limit Evaluation
$$\lim_{x \to 0} \frac{f(x)}{g(x)} = \lim_{x \to 0} \frac{\sum \frac{f^{(n)}(0)}{n!}x^n}{\sum \frac{g^{(n)}(0)}{n!}x^n}$$
Cancel lowest-order terms.

### 8.2 Approximate Integration
$\int_0^1 e^{-x^2} dx = \sum_{n=0}^\infty \frac{(-1)^n}{n!(2n+1)}$

### 8.3 Solving ODEs
Assume $y = \sum a_n x^n$, substitute, equate coefficients.

### 9.1 Definition
$\sum_{n=0}^\infty a_n (z - z_0)^n$, $z \in \mathbb{C}$

### 9.2 Radius of Convergence
Same formula: $R = 1/\limsup \sqrt[n]{|a_n|}$.
Converges on disk $|z - z_0| < R$, diverges for $|z - z_0| > R$.

### 9.3 Cauchy-Hadamard Theorem
$R = \liminf_{n \to \infty} |a_n|^{-1/n}$
