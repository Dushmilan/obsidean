# 4.2 Differentiation

## Definition

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h} = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$$

**Interpretation:** Slope of tangent line at $(x, f(x))$ = instantaneous rate of change.

### Notations

| Notation | Meaning |
|----------|---------|
| $f'(x)$ or $f'(a)$ | Lagrange (most common) |
| $\frac{dy}{dx}$ | Leibniz |
| $Df(x)$ or $D_x f$ | Euler/Differential operator |
| $\dot{y}$ | Newton (time derivative) |

## Formulae

### Basic Derivative Rules

| Formula | Expression |
|---------|------------|
| **Constant** | $\frac{d}{dx}(c) = 0$ |
| **Power** | $\frac{d}{dx}(x^n) = nx^{n-1}$ $\forall n \in \mathbb{R}$ |
| **Constant Multiple** | $\frac{d}{dx}[cf(x)] = c f'(x)$ |
| **Sum/Difference** | $\frac{d}{dx}[f(x) \pm g(x)] = f'(x) \pm g'(x)$ |
| **Product** | $\frac{d}{dx}[f(x)g(x)] = f'(x)g(x) + f(x)g'(x)$ |
| **Quotient** | $\frac{d}{dx}\left[\frac{f(x)}{g(x)}\right] = \frac{f'(x)g(x) - f(x)g'(x)}{[g(x)]^2}$ |
| **Chain** | $\frac{d}{dx}[f(g(x))] = f'(g(x)) \cdot g'(x)$ |

### Derivatives of Standard Functions

| Function | Derivative | Function | Derivative |
|----------|------------|----------|------------|
| $x^n$ | $nx^{n-1}$ | $e^x$ | $e^x$ |
| $\sqrt{x}$ | $\frac{1}{2\sqrt{x}}$ | $a^x$ | $a^x \ln a$ |
| $\frac{1}{x}$ | $-\frac{1}{x^2}$ | $\ln x$ | $\frac{1}{x}$ |
| $\sin x$ | $\cos x$ | $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x$ | $\cot x$ | $-\csc^2 x$ |
| $\sec x$ | $\sec x \tan x$ | $\csc x$ | $-\csc x \cot x$ |
| $\sin^{-1} x$ | $\frac{1}{\sqrt{1-x^2}}$ | $\cos^{-1} x$ | $-\frac{1}{\sqrt{1-x^2}}$ |
| $\tan^{-1} x$ | $\frac{1}{1+x^2}$ | $\cot^{-1} x$ | $-\frac{1}{1+x^2}$ |

### Higher-Order Derivatives

| Order | Notation | Leibniz |
|-------|----------|---------|
| 1st | $f'(x)$ | $\frac{dy}{dx}$ |
| 2nd | $f''(x)$ | $\frac{d^2y}{dx^2}$ |
| 3rd | $f'''(x)$ | $\frac{d^3y}{dx^3}$ |
| $n$th | $f^{(n)}(x)$ | $\frac{d^n y}{dx^n}$ |

### Leibniz Rule (Product of Two Functions)
$$(fg)^{(n)} = \sum_{k=0}^n \binom{n}{k} f^{(k)} g^{(n-k)}$$

### Tangent & Normal
- **Tangent at $x = a$:** $y - f(a) = f'(a)(x - a)$
- **Normal at $x = a$:** $y - f(a) = -\frac{1}{f'(a)}(x - a)$

### Mean Value Theorem
$$f'(c) = \frac{f(b) - f(a)}{b - a}$$

## Properties / Key Concepts

### Implicit Differentiation
For equations of the form $F(x,y) = 0$ where $y$ is defined implicitly as a function of $x$:
1. Differentiate both sides w.r.t. $x$
2. Treat $y$ as function of $x$: $\frac{d}{dx}(y^n) = n y^{n-1} \frac{dy}{dx}$
3. Collect $\frac{dy}{dx}$ terms and solve

### Parametric Differentiation
If $x = f(t)$, $y = g(t)$:
$$\frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{g'(t)}{f'(t)}$$

**Second derivative:**
$$\frac{d^2y}{dx^2} = \frac{d}{dx}\left(\frac{dy}{dx}\right) = \frac{d}{dt}\left(\frac{dy}{dx}\right) \div \frac{dx}{dt}$$

### Logarithmic Differentiation
For functions of the form $y = [f(x)]^{g(x)}$ or products/quotients with many factors:
1. Take $\ln$ of both sides: $\ln y = g(x) \ln f(x)$
2. Differentiate implicitly: $\frac{1}{y} \frac{dy}{dx} = g'(x)\ln f(x) + g(x)\frac{f'(x)}{f(x)}$
3. Multiply by $y$: $\frac{dy}{dx} = y \left[g'(x)\ln f(x) + g(x)\frac{f'(x)}{f(x)}\right]$

### Maxima & Minima

**First Derivative Test:**
- $f'(c) = 0$ (critical point)
- $f'$ changes $+$ to $-$ $\Rightarrow$ local maximum
- $f'$ changes $-$ to $+$ $\Rightarrow$ local minimum

**Second Derivative Test:**
- If $f'(c) = 0$ and $f''(c) < 0$ $\Rightarrow$ local maximum
- If $f'(c) = 0$ and $f''(c) > 0$ $\Rightarrow$ local minimum
- If $f''(c) = 0$, test is inconclusive (use first derivative test)

**Absolute Extrema on $[a,b]$:**
1. Find critical points in $(a,b)$
2. Evaluate $f$ at critical points and endpoints $a,b$
3. Largest = absolute max, smallest = absolute min

### Curve Sketching

| Feature | Method |
|---------|--------|
| Domain | Find where function defined |
| Intercepts | $f(0)$ (y-int), $f(x)=0$ (x-ints) |
| Symmetry | $f(-x) = f(x)$ (even), $f(-x) = -f(x)$ (odd) |
| Asymptotes | Vertical: $\lim f(x) = \pm\infty$; Horizontal: $\lim_{x\to\pm\infty} f(x)$; Oblique: polynomial division |
| Increasing/Decreasing | $f'(x) > 0$ (inc), $f'(x) < 0$ (dec) |
| Local Extrema | Critical points + 1st/2nd derivative test |
| Concavity | $f''(x) > 0$ (concave up), $f''(x) < 0$ (concave down) |
| Inflection Points | $f''(x) = 0$ and changes sign |

## Worked Examples

### Example 1: Product + Chain Rule
Differentiate $y = x^2 \sin(x^3)$
$$y' = 2x \sin(x^3) + x^2 \cos(x^3) \cdot 3x^2 = 2x \sin(x^3) + 3x^4 \cos(x^3)$$

### Example 2: Quotient + Trig
Differentiate $y = \frac{\tan x}{x}$
$$y' = \frac{x \sec^2 x - \tan x}{x^2}$$

### Example 3: Implicit Differentiation
$x^2 + xy + y^2 = 7$
$$2x + y + x\frac{dy}{dx} + 2y\frac{dy}{dx} = 0$$
$$\frac{dy}{dx}(x + 2y) = -2x - y \Rightarrow \frac{dy}{dx} = -\frac{2x+y}{x+2y}$$

### Example 4: Parametric Differentiation
$x = t^2, y = t^3 - 3t$
$$\frac{dy}{dx} = \frac{3t^2 - 3}{2t} = \frac{3(t^2-1)}{2t}$$
$$\frac{d^2y}{dx^2} = \frac{d}{dt}\left(\frac{3(t^2-1)}{2t}\right) \div 2t = \frac{3(t^2+1)}{4t^2}$$

### Example 5: Logarithmic Differentiation
$y = x^x \quad (x > 0)$
$\ln y = x \ln x$
$\frac{1}{y} y' = \ln x + 1$
$y' = x^x (\ln x + 1)$

### Example 6: Optimization
**Find max area of rectangle inscribed in semicircle $y = \sqrt{r^2 - x^2}$**
Area $A = 2x \cdot y = 2x\sqrt{r^2 - x^2}$
$A' = 2\sqrt{r^2 - x^2} + 2x \cdot \frac{-x}{\sqrt{r^2 - x^2}} = \frac{2(r^2 - 2x^2)}{\sqrt{r^2 - x^2}}$
$A' = 0 \Rightarrow x = r/\sqrt{2}$, $y = r/\sqrt{2}$
Max area = $2 \cdot \frac{r}{\sqrt{2}} \cdot \frac{r}{\sqrt{2}} = r^2$

### Example 7: Related Rates
**Conical tank (radius 4m, height 10m) filling at 2 m³/min. Find rate of height increase when water is 5m deep.**
Volume $V = \frac{1}{3}\pi r^2 h$. By similar triangles, $r/h = 4/10 = 2/5$, so $r = 2h/5$.
$V = \frac{1}{3}\pi (\frac{4h^2}{25}) h = \frac{4\pi}{75} h^3$
$\frac{dV}{dt} = \frac{4\pi}{25} h^2 \frac{dh}{dt}$
$2 = \frac{4\pi}{25} (25) \frac{dh}{dt} \Rightarrow \frac{dh}{dt} = \frac{1}{2\pi}$ m/min

## Common Traps

| Trap | ❌ Wrong | Correct |
|------|-------|---------|
| Chain rule on $\sin x^2$ | $\cos x^2$ | $\cos(x^2) \cdot 2x$ |
| Quotient rule order | $\frac{f'g - fg'}{g^2}$ or $\frac{fg' - f'g}{g^2}$ | **Always** $\frac{f'g - fg'}{g^2}$ |
| $\frac{d}{dx}(\ln x)$ | $\frac{1}{x}$ (for all $x$) | $\frac{1}{x}$ for $x > 0$ |
| $\frac{d}{dx}(\sin^{-1} x)$ | $\frac{1}{\sqrt{1-x^2}}$ (for all $x$) | $\frac{1}{\sqrt{1-x^2}}$ for $|x| < 1$ |
| Implicit diff | Forget $\frac{dy}{dx}$ on $y$ terms | $y^n \to n y^{n-1} \frac{dy}{dx}$ |
| Parametric $\frac{d^2y}{dx^2}$ | Differentiate $\frac{dy}{dx}$ w.r.t. $x$ directly | $\frac{d}{dt}(\frac{dy}{dx}) / \frac{dx}{dt}$ |
| Max/min | Only check $f'(c)=0$ | Check endpoints + where $f'$ undefined |
| $\sqrt{x^2}$ | $x$ | $|x|$ |
