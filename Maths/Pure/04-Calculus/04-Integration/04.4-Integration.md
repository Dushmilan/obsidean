
## Definition

Integration reverses differentiation: $\int f(x)\,dx = F(x) + C$ where $F'(x) = f(x)$. As a definite integral it computes the **signed area** under a curve. The **Fundamental Theorem of Calculus** connects the two:

- **FTC 1:** $g(x) = \int_a^x f(t)\,dt \Rightarrow g'(x) = f(x)$
- **FTC 2:** $\int_a^b f(x)\,dx = F(b) - F(a)$

## The Intuition

If differentiation reads a speedometer (instantaneous rate), integration reads an odometer (total distance). Stack infinitely many thin rectangles under the curve — each width $dx$, height $f(x)$ — and the total area is the integral.

## The Toolkit

| Rule | Formula | Valid when |
|------|---------|-----------|
| Power | $\int x^n\,dx = \frac{x^{n+1}}{n+1} + C$ | $n \neq -1$ |
| Reciprocal | $\int \frac{1}{x}\,dx = \ln\|x\| + C$ | $x \neq 0$ |
| Exponential | $\int e^x\,dx = e^x + C$ | — |
| Trig | $\int\sin x\,dx = -\cos x + C$; $\int\cos x\,dx = \sin x + C$ | — |
| Substitution | $\int f(g(x))g'(x)\,dx = \int f(u)\,du$ | $u = g(x)$ |
| By parts | $\int u\,dv = uv - \int v\,du$ | choose $u$ by LIATE |
| Improper | $\int_a^\infty f(x)\,dx = \lim_{b\to\infty}\int_a^b f(x)\,dx$ | convergence check |

**LIATE** (choose $u$): Logarithmic, Inverse trig, Algebraic, Trigonometric, Exponential.

## Derivation

The FTC follows from the definition of the derivative applied to the area function $g(x) = \int_a^x f$. By parts is the integral form of the product rule: $(uv)' = u'v + uv' \Rightarrow \int u\,dv = uv - \int v\,du$. Substitution is the chain rule in reverse. [Full derivations: 04.4-Integration-Proofs]

## Method

1. **Recognise the form:** a function and its derivative present → substitution.
2. **Product of unrelated functions** → by parts (LIATE picks $u$; the goal is $\int v\,du$ simpler than $\int u\,dv$).
3. **Odd power of $\sin$ or $\cos$:** peel off one factor, convert the rest via Pythagorean identity.
4. **Even powers:** half-angle / double-angle formulas.
5. **Rational functions:** partial fractions (see 05-Partial-Fractions).
6. **Definite integrals:** evaluate, then $F(b) - F(a)$ — substitution needs the limits changed.

## Worked Examples

**Setup:** Evaluate $\int_0^1 x e^x\,dx$.

**Solution:** LIATE: $u = x$, $dv = e^x dx$, so $du = dx$, $v = e^x$. $\int xe^x\,dx = xe^x - e^x + C$. Definite: $[xe^x - e^x]_0^1 = (e-e) - (0-1) = 1$.

**Key insight:** Follow LIATE; $\int v\,du$ should be simpler than $\int u\,dv$.

---

**Setup:** Evaluate $\int \sin^3 x\cos^2 x\,dx$.

**Solution:** $\sin^3 x = \sin x(1-\cos^2 x)$. Let $u = \cos x$: $\int -(1-u^2)u^2\,du = \frac{u^5}{5} - \frac{u^3}{3} + C = \frac{\cos^5 x}{5} - \frac{\cos^3 x}{3} + C$.

**Key insight:** Odd power of $\sin$ → peel one off and convert the rest to $\cos$.

## Common Traps

- Forgetting $+C$ for indefinite integrals
- Substitution with definite integrals: forgetting to change the limits
- Power rule at $n = -1$ — that's $\ln|x|$, not $\frac{x^0}{0}$
- By parts with $u, dv$ chosen wrongly — the integral gets harder, not easier
- Missing absolute value in $\ln|x|$
