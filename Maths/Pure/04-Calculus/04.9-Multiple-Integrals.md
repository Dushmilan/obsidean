# 4.9 Multiple Integrals

## Definition

$$\iint_R f(x,y) \, dA = \lim_{m,n \to \infty} \sum_{i=1}^m \sum_{j=1}^n f(x_{ij}^*, y_{ij}^*) \Delta A$$

$$\iiint_E f(x,y,z) \, dV$$

## Formulae

### Double Integrals

| Formula | Expression |
|---------|------------|
| **Type I (x-simple)** | $\int_a^b \int_{g_1(x)}^{g_2(x)} f(x,y) \, dy \, dx$ |
| **Type II (y-simple)** | $\int_c^d \int_{h_1(y)}^{h_2(y)} f(x,y) \, dx \, dy$ |
| **Polar** | $\int_\alpha^\beta \int_{r_1(\theta)}^{r_2(\theta)} f(r\cos\theta, r\sin\theta) \, r \, dr \, d\theta$ |
| **Area** | $\iint_R 1 \, dA$ |
| **Volume** | $\iint_R f(x,y) \, dA$ ($f \ge 0$) |
| **Average value** | $\frac{1}{\text{Area}(R)} \iint_R f(x,y) \, dA$ |

### Triple Integrals

| Formula | Expression |
|---------|------------|
| **Rectangular** | $\int \int \int f(x,y,z) \, dz \, dy \, dx$ |
| **Cylindrical** | $\int \int \int f(r,\theta,z) \, r \, dz \, dr \, d\theta$ |
| **Spherical** | $\int \int \int f(\rho,\theta,\phi) \, \rho^2 \sin \phi \, d\rho \, d\phi \, d\theta$ |

### Coordinate Transformations

| System | Transformation | Jacobian |
|--------|----------------|----------|
| **Polar** | $x=r\cos\theta, y=r\sin\theta$ | $r$ |
| **Cylindrical** | $x=r\cos\theta, y=r\sin\theta, z=z$ | $r$ |
| **Spherical** | $x=\rho\sin\phi\cos\theta, y=\rho\sin\phi\sin\theta, z=\rho\cos\phi$ | $\rho^2 \sin \phi$ |

### Jacobian Determinant
For $x = x(u,v), y = y(u,v)$:
$$\frac{\partial(x,y)}{\partial(u,v)} = \begin{vmatrix} \frac{\partial x}{\partial u} & \frac{\partial x}{\partial v} \\ \frac{\partial y}{\partial u} & \frac{\partial y}{\partial v} \end{vmatrix}$$

### Change of Variables Formula
$$\iint_R f(x,y) \, dx \, dy = \iint_S f(x(u,v), y(u,v)) \left| \frac{\partial(x,y)}{\partial(u,v)} \right| \, du \, dv$$

### Physical Applications

| Application | Formula |
|-------------|---------|
| **Mass** | $m = \iint_R \rho(x,y) \, dA$ |
| **Centre of mass** | $\bar{x} = \frac{1}{m} \iint_R x \rho \, dA$, $\bar{y} = \frac{1}{m} \iint_R y \rho \, dA$ |
| **Moment of inertia $I_x$** | $\iint_R y^2 \rho \, dA$ |
| **Moment of inertia $I_y$** | $\iint_R x^2 \rho \, dA$ |
| **Polar moment $J$** | $\iint_R (x^2 + y^2) \rho \, dA$ |

## Properties / Key Concepts

### Fubini's Theorem
If $f$ continuous on rectangle $R = [a,b] \times [c,d]$:
$$\iint_R f(x,y) \, dA = \int_a^b \int_c^d f(x,y) \, dy \, dx = \int_c^d \int_a^b f(x,y) \, dx \, dy$$

### Changing Order of Integration
Sketch region, find new bounds, rewrite integral.

### Types of Regions (Triple)

- **Type 1 (z-simple):** $E = \{(x,y,z) : (x,y) \in D, \, u_1(x,y) \le z \le u_2(x,y)\}$
- **Type 2 (y-simple):** $E = \{(x,y,z) : (x,z) \in D, \, v_1(x,z) \le y \le v_2(x,z)\}$
- **Type 3 (x-simple):** $E = \{(x,y,z) : (y,z) \in D, \, w_1(y,z) \le x \le w_2(y,z)\}$

### Common Polar Regions
- Circle $x^2+y^2 \le a^2$: $0 \le r \le a$, $0 \le \theta \le 2\pi$
- Sector: $\alpha \le \theta \le \beta$
- Annulus: $a \le r \le b$

### Common Spherical Regions
- Sphere $\rho \le a$: $0 \le \rho \le a, 0 \le \phi \le \pi, 0 \le \theta \le 2\pi$
- Cone $\phi = \alpha$

### Mass and Centre of Mass (3D)
Density $\rho(x,y,z)$:
- $m = \iiint \rho \, dV$
- $\bar{x} = \frac{1}{m} \iiint x \rho \, dV$, etc.

### Moments of Inertia (3D)
$$I_x = \iiint (y^2+z^2) \rho \, dV, \quad I_y = \iiint (x^2+z^2) \rho \, dV, \quad I_z = \iiint (x^2+y^2) \rho \, dV$$

### Probability
Joint density $f(x,y)$: $P((X,Y) \in R) = \iint_R f(x,y) \, dA$

## Worked Examples

### Example 1: Double Integral
$\iint_R (x+y) \, dA$, $R$ bounded by $y=x^2, y=2x$
Intersections: $x^2 = 2x \Rightarrow x = 0, 2$
Type I: $0 \le x \le 2, \; x^2 \le y \le 2x$
$$\int_0^2 \int_{x^2}^{2x} (x+y) \, dy \, dx = \frac{16}{5}$$

### Example 2: Change Order
$\int_0^1 \int_x^1 \sin(y^2) \, dy \, dx$
Region: $0 \le x \le y \le 1$
New: $0 \le y \le 1, \; 0 \le x \le y$
$$\int_0^1 y \sin(y^2) \, dy = \frac{1}{2}(1 - \cos 1)$$

### Example 3: Volume in Spherical
Volume inside sphere $x^2+y^2+z^2 = 4$ and above $z=1$
Spherical: $\rho^2 = 4 \Rightarrow \rho = 2$. $z = \rho \cos \phi = 1 \Rightarrow \phi = \pi/3$.
$$V = 2\pi \int_0^{\pi/3} \sin \phi \left[ \frac{\rho^3}{3} \right]_{\sec \phi}^2 d\phi$$

### Example 4: Jacobian
$u = x+y, v = x-y \Rightarrow x = \frac{u+v}{2}, y = \frac{u-v}{2}$
$$J = \begin{vmatrix} 1/2 & 1/2 \\ 1/2 & -1/2 \end{vmatrix} = -\frac{1}{2} \Rightarrow |J| = \frac{1}{2}$$

## Common Traps

| Trap | ❌ Wrong | Correct |
|------|-------|---------|
| Bounds | Mix up inner/outer limits | Inner limits depend on outer variable |
| Order change | Same limits | Must re-sketch region |
| Polar Jacobian | Forget $r$ | $dx\,dy = r\,dr\,d\theta$ |
| Spherical Jacobian | Use $r^2$ | $\rho^2 \sin \phi$ |
| Cylindrical | Use $\rho$ | Use $r$ for cylindrical |
| Triple integral bounds | Constant limits for general regions | Limits depend on other variables |
| Jacobian sign | Forget absolute value | Use $|J|$ |
