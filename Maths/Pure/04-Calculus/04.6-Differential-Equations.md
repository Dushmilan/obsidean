A differential equation is an equation involving a function and its derivatives. Solving it means finding the function that satisfies the equation. Differential equations model nearly everything that changes: population growth, radioactive decay, oscillations, heat flow, fluid motion, and electrical circuits. Most natural phenomena involve rates of change, and each story translates into a differential equation.

**The Intuition:** A differential equation is like a recipe that tells you how a function changes at every point. Solving it is like following the recipe backwards to figure out what the original dish was. Picture a slope field — a grid of small line segments showing the slope $dy/dx$ at each point. The solution curve is a path that follows these slopes.

**The Math:** Separable: $\frac{dy}{dx} = g(x)h(y) \implies \int \frac{dy}{h(y)} = \int g(x)\,dx$. Linear first-order: $\frac{dy}{dx} + P(x)y = Q(x)$, integrating factor $\mu = e^{\int P\,dx}$, solution $y = \frac{1}{\mu}\int \mu Q\,dx$.

Second-order constant coefficient: $ay'' + by' + cy = 0$. Auxiliary equation: $am^2 + bm + c = 0$. Real distinct roots $m_1, m_2$: $y_c = Ae^{m_1 x} + Be^{m_2 x}$. Repeated root $m$: $y_c = (A + Bx)e^{mx}$. Complex $m = \alpha \pm i\beta$: $y_c = e^{\alpha x}(A\cos\beta x + B\sin\beta x)$.

Non-homogeneous: $y = y_c + y_p$. Trial forms for $y_p$: polynomial, exponential, trig, or combinations. If trial overlaps with CF, multiply by $x$ (or $x^2$). Applications: exponential growth $dN/dt = kN \implies N = N_0 e^{kt}$; Newton's cooling $dT/dt = -k(T - T_s)$; SHM $d^2x/dt^2 + \omega^2 x = 0 \implies x = A\cos(\omega t + \phi)$.

**What does this mean for Pure Mathematics?** For first-order equations, the main techniques are separation of variables and integrating factors. For second-order constant coefficient equations, you find the complementary function and a particular integral, then add them. The general solution contains arbitrary constants; initial conditions pin down the specific solution.

**Setup:** Solve $\frac{dy}{dx} + 2xy = x$. **Solution:** $P(x) = 2x$, $\mu = e^{x^2}$. Multiply: $\frac{d}{dx}[y e^{x^2}] = x e^{x^2}$. Integrate: $y e^{x^2} = \frac{1}{2}e^{x^2} + C$. So $y = \frac{1}{2} + Ce^{-x^2}$. **Key insight:** The integrating factor turns the left side into an exact derivative.

**Setup:** Solve $y'' + 4y = \sin(2x)$. **Solution:** CF: $y_c = A\cos 2x + B\sin 2x$. PI trial: $\sin(2x)$ overlaps with CF, try $y_p = x(C\cos 2x + D\sin 2x)$. After substitution: $y_p = -\frac{x}{4}\cos 2x$. General: $y = A\cos 2x + B\sin 2x - \frac{x}{4}\cos 2x$. **Key insight:** Resonance causes the amplitude to grow linearly with $x$. This is why bridges collapse when soldiers march in step.
