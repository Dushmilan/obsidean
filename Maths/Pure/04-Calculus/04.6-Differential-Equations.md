# 4.6 Differential Equations

## Definition

An equation involving a function and its derivatives. Solutions are functions that satisfy the equation.

## Formulae

### First-Order Equations

| Type | Form | Solution Method |
|------|------|-----------------|
| **Separable** | $\frac{dy}{dx} = g(x)h(y)$ | $\int \frac{dy}{h(y)} = \int g(x) dx$ |
| **Linear 1st Order** | $\frac{dy}{dx} + P(x)y = Q(x)$ | $\mu = e^{\int P dx}, \quad y = \frac{1}{\mu} \int \mu Q dx$ |
| **Homogeneous** | $\frac{dy}{dx} = F(y/x)$ | $v = y/x \to$ separable |
| **Exact** | $M dx + N dy = 0, M_y = N_x$ | $\psi_x = M, \psi_y = N \Rightarrow \psi = C$ |

### Second-Order Constant Coefficient

| Type | Form | Solution Method |
|------|------|-----------------|
| **Homogeneous** | $ay''+by'+cy=0$ | Aux eq: $am^2+bm+c=0$, roots $\to$ CF |
| **Non-homogeneous** | $ay''+by'+cy=f(x)$ | $y = y_c + y_p$ (undetermined coeffs) |
| **Variation of Parameters** | $y''+P(x)y'+Q(x)y=R(x)$ | $y_p = -y_1\int \frac{y_2 R}{W} + y_2\int \frac{y_1 R}{W}$ |

### Complementary Function (CF)

| Roots | CF |
|-------|-----|
| Real distinct $m_1, m_2$ | $y_c = A e^{m_1 x} + B e^{m_2 x}$ |
| Real repeated $m$ | $y_c = (A + Bx) e^{m x}$ |
| Complex $m = \alpha \pm i\beta$ | $y_c = e^{\alpha x} (A \cos \beta x + B \sin \beta x)$ |

### Particular Integral (PI) Trial Forms

| $f(x)$ | Trial PI |
|--------|----------|
| $P_n(x)$ (polynomial) | $Q_n(x)$ (degree $n$) |
| $e^{kx}$ ($k$ not root) | $A e^{kx}$ |
| $e^{kx}$ ($k$ single root) | $A x e^{kx}$ |
| $e^{kx}$ ($k$ double root) | $A x^2 e^{kx}$ |
| $\cos \omega x$ or $\sin \omega x$ | $A \cos \omega x + B \sin \omega x$ |
| $e^{\alpha x} \cos \beta x$ | $e^{\alpha x} (A \cos \beta x + B \sin \beta x)$ |

**If trial PI overlaps with CF:** Multiply by $x$ (or $x^2$ if double overlap).

### Exact Equation Method
1. Check exactness: $M_y = N_x$
2. Integrate $M$ wrt $x$: $\psi = \int M dx + h(y)$
3. Differentiate $\psi$ wrt $y$, equate to $N$
4. Solve for $h(y)$, write $\psi(x,y) = C$

### Integrating Factors for Non-Exact
- If $\frac{M_y - N_x}{N}$ is function of $x$ only: $\mu(x) = \exp\left(\int \frac{M_y - N_x}{N} dx\right)$
- If $\frac{N_x - M_y}{M}$ is function of $y$ only: $\mu(y) = \exp\left(\int \frac{N_x - M_y}{M} dy\right)$

### Applications

**Exponential Growth/Decay:** $\frac{dN}{dt} = kN \Rightarrow N = N_0 e^{kt}$

**Newton's Law of Cooling:** $\frac{dT}{dt} = -k(T - T_s) \Rightarrow T = T_s + (T_0 - T_s)e^{-kt}$

**Simple Harmonic Motion:** $\frac{d^2x}{dt^2} + \omega^2 x = 0 \Rightarrow x = A \cos(\omega t + \phi)$

**Damped Harmonic Motion:** $\frac{d^2x}{dt^2} + 2\lambda \frac{dx}{dt} + \omega^2 x = 0$

| Case | Condition | Solution |
|------|-----------|----------|
| Underdamped | $\lambda < \omega$ | $e^{-\lambda t}(A \cos \omega_d t + B \sin \omega_d t)$ |
| Critically damped | $\lambda = \omega$ | $(A + Bt)e^{-\omega t}$ |
| Overdamped | $\lambda > \omega$ | $A e^{-m_1 t} + B e^{-m_2 t}$ |

### Existence and Uniqueness (Picard-Lindelöf)
For $\frac{dy}{dx} = f(x,y), \quad y(x_0) = y_0$: If $f$ and $\frac{\partial f}{\partial y}$ continuous in rectangle $R$ containing $(x_0, y_0)$, then unique solution exists on some interval $|x - x_0| < h$.

## Properties / Key Concepts

### Initial/Boundary Value Problems
**IVP:** Given $y(x_0) = y_0$, $y'(x_0) = y_1$ (for 2nd order). Find general solution, apply conditions to determine constants.

**BVP:** Given conditions at different points: $y(a) = A$, $y(b) = B$.

### General Solution Structure
$$y = y_c + y_p$$
where $y_c$ is the complementary function (solution to homogeneous) and $y_p$ is a particular integral.

## Worked Examples

### Example 1: Separable
$\frac{dy}{dx} = \frac{y^2}{x}$
$\frac{dy}{y^2} = \frac{dx}{x} \Rightarrow -\frac{1}{y} = \ln|x| + C \Rightarrow y = \frac{1}{C - \ln|x|}$

### Example 2: Linear 1st Order
$\frac{dy}{dx} + 2xy = x$
$P(x) = 2x, Q(x) = x$
$\mu = e^{\int 2x dx} = e^{x^2}$
$e^{x^2} y = \int x e^{x^2} dx = \frac{1}{2} e^{x^2} + C$
$y = \frac{1}{2} + C e^{-x^2}$

### Example 3: Exact DE
$(2xy + 3x^2) dx + (x^2 + 2y) dy = 0$
$M = 2xy + 3x^2, N = x^2 + 2y$
$M_y = 2x = N_x$ ✓ Exact
$\psi = x^2 y + x^3 + y^2 = C$

### Example 4: 2nd Order Homogeneous
$y'' - 3y' + 2y = 0$
Aux: $m^2 - 3m + 2 = 0 \Rightarrow m=1,2$
$y = A e^x + B e^{2x}$

### Example 5: 2nd Order Non-homogeneous
$y'' - 3y' + 2y = e^{2x}$
CF: $y_c = A e^x + B e^{2x}$
PI trial: $e^{2x}$ overlaps $\rightarrow$ try $y_p = C x e^{2x}$
$C = 1$, so $y = A e^x + B e^{2x} + x e^{2x}$

### Example 6: Resonance
$y'' + 4y = \sin 2x$
CF: $y_c = A \cos 2x + B \sin 2x$
PI trial: $\sin 2x$ overlaps $\rightarrow$ try $y_p = x(A \cos 2x + B \sin 2x)$
$y_p = -\frac{1}{4} x \cos 2x$

## Common Traps

| Trap | ❌ Wrong | Correct |
|------|-------|---------|
| Separable | $\int f(y) dy = \int g(x) dx$ without $dy/dx$ | Write as $\frac{1}{f(y)} \frac{dy}{dx} = g(x)$ |
| Linear 1st order | Forget integrating factor | $\mu = e^{\int P dx}$ essential |
| Exact DE | Assume exact without checking | Always verify $M_y = N_x$ |
| 2nd order CF | Wrong auxiliary equation | $am^2 + bm + c = 0$ for $ay''+by'+cy=0$ |
| PI overlap | Use standard trial when overlaps CF | Multiply by $x$ (or $x^2$) |
| IVP | Apply conditions to CF only | Apply to full general solution $y_c + y_p$ |
| Particular integral | Wrong form for $f(x)$ | Check table of standard forms |
