
## Definition

Multiple integrals extend single-variable integration to functions of several variables:
- **Double integral** $\iint_R f(x,y)\,dA$ — volume under the surface $z = f(x,y)$ over region $R$.
- **Triple integral** $\iiint_V f(x,y,z)\,dV$ — mass/quantity over a solid.

Evaluated as **iterated integrals**: integrate with respect to one variable first, then the next (Fubini's theorem permits the order swap for continuous $f$).

## The Intuition

A double integral is the volume of a building: divide the floor into tiny squares, multiply each square's area by the building's height there, sum the tiny volumes. A triple integral divides space into tiny cubes and sums.

## The Toolkit

| Setup | Integral |
|-------|----------|
| Type I region | $\int_a^b \int_{g_1(x)}^{g_2(x)} f(x,y)\,dy\,dx$ |
| Polar | $\iint f(r\cos\theta, r\sin\theta)\,r\,dr\,d\theta$ |
| Cylindrical | $\iiint f \cdot r\,dz\,dr\,d\theta$ |
| Spherical | $\iiint f \cdot \rho^2\sin\phi\,d\rho\,d\phi\,d\theta$ |
| Change of variables | $\iint_R f\,dx\,dy = \iint_S f\,|J|\,du\,dv$ |

**Jacobians:** polar $r$, cylindrical $r$, spherical $\rho^2\sin\phi$.

## Derivation

The Jacobian $|J|$ is the area/volume scaling factor of the coordinate transformation — the determinant of the derivative matrix. Fubini's theorem justifies treating the double integral as iterated single integrals. The coordinate forms come from the area element in each coordinate system (e.g. the polar area element $r\,dr\,d\theta$). [Full derivations: 04.9-Multiple-Integrals-Proofs]

## Method

1. **Sketch the region** — limits come from the geometry, not algebra.
2. **Choose the order** ($dy\,dx$ vs $dx\,dy$) that gives simple limits; if one order is impossible, **switch**.
3. **Convert to iterated integrals**, integrate inner first, then outer.
4. **Coordinate systems:** polar for circular symmetry, spherical/cylindrical for 3D symmetry — the Jacobian multiplies the integrand.

## Worked Examples

**Setup:** $\iint_R (x+y)\,dA$, $R$ bounded by $y = x^2$ and $y = 2x$.

**Solution:** Intersections $x = 0, 2$. Type I: $0 \le x \le 2$, $x^2 \le y \le 2x$. $\int_0^2\int_{x^2}^{2x}(x+y)\,dy\,dx = \int_0^2\left(4x^2 - x^3 - \frac{x^4}{2}\right)dx = \frac{16}{5}$.

**Key insight:** Set up the region first; determine limits from geometry; integrate inner first.

---

**Setup:** Evaluate $\int_0^1\int_x^1 \sin(y^2)\,dy\,dx$.

**Solution:** $\sin(y^2)$ has no elementary antiderivative — switch order: $\int_0^1\int_0^y \sin(y^2)\,dx\,dy = \int_0^1 y\sin(y^2)\,dy = \frac{1-\cos 1}{2}$.

**Key insight:** If one order is impossible, switch it — sketch the region for the new limits.

## Common Traps

- Forgetting the Jacobian ($r$, $\rho^2\sin\phi$) in coordinate changes
- Wrong limits from an unsketched region
- Inner integral evaluated with the wrong variable — limits depend on the outer variable in Type I/II
- Switching order without recomputing the limits
- Using polar where the region has no circular symmetry
