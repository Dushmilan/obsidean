# 4.8 Partial Differentiation

## Definition

For $f: \mathbb{R}^n \supseteq D \to \mathbb{R}$ (e.g., $z = f(x, y)$), the partial derivative treats all variables except the differentiated one as constants.

$$\frac{\partial f}{\partial x}(x_0, y_0) = \lim_{h \to 0} \frac{f(x_0+h, y_0) - f(x_0, y_0)}{h}$$

## Formulae

### Partial Derivatives

| Formula | Expression |
|---------|------------|
| **First partial (x)** | $f_x = \frac{\partial f}{\partial x} = \partial_x f = D_1 f$ |
| **First partial (y)** | $f_y = \frac{\partial f}{\partial y} = \partial_y f = D_2 f$ |
| **Second partial (xx)** | $f_{xx} = \frac{\partial^2 f}{\partial x^2}$ |
| **Second partial (yy)** | $f_{yy} = \frac{\partial^2 f}{\partial y^2}$ |
| **Mixed partial (xy)** | $f_{xy} = \frac{\partial^2 f}{\partial y \partial x}$ |
| **Mixed partial (yx)** | $f_{yx} = \frac{\partial^2 f}{\partial x \partial y}$ |

### Chain Rule

**Case 1:** $z = f(x,y)$, $x = x(t)$, $y = y(t)$
$$\frac{dz}{dt} = \frac{\partial f}{\partial x} \frac{dx}{dt} + \frac{\partial f}{\partial y} \frac{dy}{dt}$$

**Case 2:** $z = f(x,y)$, $x = x(u,v)$, $y = y(u,v)$
$$\frac{\partial z}{\partial u} = \frac{\partial f}{\partial x} \frac{\partial x}{\partial u} + \frac{\partial f}{\partial y} \frac{\partial y}{\partial u}$$

**Case 3 (Implicit):** $F(x,y,z) = 0$
$$\frac{\partial z}{\partial x} = -\frac{F_x}{F_z}, \quad \frac{\partial z}{\partial y} = -\frac{F_y}{F_z}$$

### Total Differential
$$dz = df = \frac{\partial f}{\partial x} dx + \frac{\partial f}{\partial y} dy$$

**Approximation:** $\Delta f \approx df = f_x \Delta x + f_y \Delta y$

**Error Estimation:** $|\Delta f| \approx |f_x| |\Delta x| + |f_y| |\Delta y|$

### Gradient Vector
$$\nabla f = \left( \frac{\partial f}{\partial x}, \frac{\partial f}{\partial y} \right) = f_x \mathbf{i} + f_y \mathbf{j}$$

### Directional Derivative
$$D_{\mathbf{u}} f = \nabla f \cdot \mathbf{u} = f_x a + f_y b$$
where $\mathbf{u} = (a,b)$ is a unit vector.

### Tangent Plane
**To $z = f(x,y)$ at $(x_0, y_0, z_0)$:**
$$z - z_0 = f_x(x_0, y_0)(x - x_0) + f_y(x_0, y_0)(y - y_0)$$

**To level surface $F(x,y,z) = k$:**
$$F_x(x-x_0) + F_y(y-y_0) + F_z(z-z_0) = 0$$

### Normal Line
$$\frac{x-x_0}{F_x} = \frac{y-y_0}{F_y} = \frac{z-z_0}{F_z}$$

### Second Derivative Test
Let $D = f_{xx} f_{yy} - (f_{xy})^2$ at critical point $(a,b)$.

| Condition | Type |
|-----------|------|
| $D > 0$, $f_{xx} > 0$ | Local minimum |
| $D > 0$, $f_{xx} < 0$ | Local maximum |
| $D < 0$ | Saddle point |
| $D = 0$ | Test inconclusive |

### Lagrange Multipliers
Max/min $f(x,y)$ subject to $g(x,y) = c$:
$$\frac{\partial f}{\partial x} = \lambda \frac{\partial g}{\partial x}, \quad \frac{\partial f}{\partial y} = \lambda \frac{\partial g}{\partial y}, \quad g(x,y) = c$$

**Two constraints:** $\nabla f = \lambda \nabla g + \mu \nabla h$

### Taylor Series for Two Variables (Second-Order)
$$f(x_0+h, y_0+k) \approx f + f_x h + f_y k + \frac{1}{2}(f_{xx} h^2 + 2f_{xy} hk + f_{yy} k^2)$$

## Properties / Key Concepts

### Young's Theorem (Clairaut's Theorem)
If $f_{xy}$ and $f_{yx}$ are continuous at $(a,b)$, then $f_{xy}(a,b) = f_{yx}(a,b)$.

### Critical Points
Points where $\nabla f = \mathbf{0}$ (i.e., $f_x = 0$ and $f_y = 0$) or partial derivatives don't exist.

### Absolute Extrema on Closed Bounded Region
1. Find critical points in interior
2. Find extrema on boundary (use Lagrange multipliers or parametrise)
3. Compare all values

### Maximum Rate of Change
- Maximum: $\|\nabla f\|$ in direction of $\nabla f$
- Minimum: $-\|\nabla f\|$ in direction of $-\nabla f$
- Zero: perpendicular to $\nabla f$

### Level Curves
$f(x,y) = k$ for constant $k$ — contour lines on $xy$-plane.

## Worked Examples

### Example 1: Compute Partials
$f(x,y) = x^2 y + \sin(xy)$
$f_x = 2xy + y\cos(xy)$
$f_y = x^2 + x\cos(xy)$
$f_{xy} = 2x + \cos(xy) - xy\sin(xy)$

### Example 2: Chain Rule
$z = x^2 + y^2$, $x = t^2$, $y = \sin t$
$\frac{dz}{dt} = 2x(2t) + 2y(\cos t) = 4t^3 + 2\sin t \cos t$

### Example 3: Max/Min
$f(x,y) = x^2 + y^2 - 2x - 4y + 5$
$f_x = 2x-2=0 \Rightarrow x=1$
$f_y = 2y-4=0 \Rightarrow y=2$
$D = 2 \cdot 2 - 0 = 4 > 0$, $f_{xx}=2>0 \Rightarrow$ local min at $(1,2)$, $f(1,2) = 0$

### Example 4: Tangent Plane
Tangent to $z = x^2 + y^2$ at $(1,2,5)$
$f_x = 2$, $f_y = 4$
$z - 5 = 2(x-1) + 4(y-2) \Rightarrow z = 2x + 4y - 5$

### Example 5: Lagrange Multipliers
Maximise $f = xy$ subject to $x^2 + y^2 = 1$
$\nabla f = (y, x)$, $\nabla g = (2x, 2y)$
$y = 2\lambda x$, $x = 2\lambda y \Rightarrow x^2 = y^2$
Constraint: $2x^2 = 1 \Rightarrow x = \pm \frac{1}{\sqrt{2}}$
Max: $\frac{1}{2}$ at $(\frac{1}{\sqrt{2}}, \frac{1}{\sqrt{2}})$ and $(-\frac{1}{\sqrt{2}}, -\frac{1}{\sqrt{2}})$

## Common Traps

| Trap | ❌ Wrong | Correct |
|------|-------|---------|
| Partial derivative | Treat all variables as functions | Hold others constant |
| Mixed partials | Assume always equal | Check continuity (Young's theorem) |
| Chain rule | Forget terms | Draw dependency diagram |
| Critical points | Only check $f_x=0, f_y=0$ | Also check where derivatives DNE |
| Second derivative test | Forget $D = f_{xx}f_{yy} - f_{xy}^2$ | Use correct discriminant |
| Lagrange multipliers | Forget constraint equation | Always include $g(x,y)=c$ |
| Tangent plane | Use $f(x,y)$ formula for $F(x,y,z)=k$ | Use $\nabla F \cdot (\mathbf{r}-\mathbf{r}_0)=0$ |
