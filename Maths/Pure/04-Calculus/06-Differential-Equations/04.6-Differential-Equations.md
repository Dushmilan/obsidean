# Differential Equations — Linear Module Overview

A differential equation is an equation involving a function and its derivatives; solving it means finding the function that satisfies it. This module — a 2-credit university course — covers **linear differential equations only**: first-order linear equations via the integrating factor, and second-order linear equations with constant coefficients via the complementary function + particular integral. Nonlinear equations (separable nonlinear forms, Bernoulli, etc.) are out of scope.

**The Intuition:** A differential equation is a recipe that tells you how a function changes at every point; solving it is following the recipe backwards to recover the dish. *Linear* equations are the well-behaved ones — if $y_1$ and $y_2$ both solve the homogeneous equation, then so does any combination $c_1y_1 + c_2y_2$. That superposition property is what makes linear equations systematic to solve: you break the problem into pieces, solve each, and add the answers.

**The Math — what linear means:**
$$a_n(x)\frac{d^n y}{dx^n} + a_{n-1}(x)\frac{d^{n-1}y}{dx^{n-1}} + \cdots + a_1(x)\frac{dy}{dx} + a_0(x)y = f(x)$$

The left side is linear in $y$ and its derivatives (no $y^2$, no $\sin y$, no $y\frac{dy}{dx}$). The equation is **homogeneous** when $f(x) = 0$, **non-homogeneous** otherwise.

**Key insight:** every technique in this module is a consequence of linearity. The integrating factor turns the first-order left side into an exact derivative. The auxiliary equation converts the second-order problem into an algebra problem. And the general solution is always *homogeneous solution + particular solution* — the structure is the same every time.

---

**Setup:** Classify $y' + 2y = e^x$ and $\frac{dy}{dx} = y^2$ — which belongs in this module?

**Solution:** $y' + 2y = e^x$ is **linear** (first-order, $P(x)=2$, $Q(x)=e^x$) → in scope. $\frac{dy}{dx} = y^2$ is **nonlinear** (the $y^2$ term) → out of scope for this module.

**Key insight:** the $y^2$ breaks linearity — no integrating factor, no superposition. Nonlinear equations need different machinery (separation, substitution), which is exactly why this module deliberately draws the line at linear.

---

**Setup:** The general solution of a second-order linear non-homogeneous equation has what shape?

**Solution:** $y = y_c + y_p$ where $y_c$ is the complementary function (solves the homogeneous version, carries the arbitrary constants) and $y_p$ is a particular integral (one solution of the full equation).

**Key insight:** because of superposition, $y_c$ covers "all solutions of the zero-forcing problem" and $y_p$ "one solution of the forced problem" — adding them satisfies the full equation and contains every possible solution.

## Practice (try before peeking)

1. Is $\frac{dy}{dx} + xy = x^3$ linear? What are $P(x)$ and $Q(x)$?
2. Why does linearity guarantee that $y_c + y_p$ is the *general* solution?
3. Which of these are in the linear module: $y'' - 3y' + 2y = 0$ · $y' = \cos y$ · $yy' + y = 1$?

<details><summary>Answers</summary>

1. Yes — linear. $P(x) = x$, $Q(x) = x^3$. The independent variable $x$ may appear freely; only $y$ and its derivatives must appear linearly.
2. Because the homogeneous solutions form a vector space (closed under addition and scaling), and adding any particular solution shifts that whole space to cover every solution of the forced equation. The two arbitrary constants in $y_c$ give exactly the degrees of freedom a second-order equation needs.
3. $y'' - 3y' + 2y = 0$ ✓ linear. $y' = \cos y$ ✗ (nonlinear in $y$). $yy' + y = 1$ ✗ (the $yy'$ product is nonlinear).

</details>

---

**Common traps:**
- Treating nonlinear equations ($y^2$, $\sin y$, $yy'$) with linear techniques — they won't work
- Forgetting the arbitrary constants in $y_c$ — the general solution needs them
- Mixing up which root case of the auxiliary equation gives which form
- Adding $y_c$ and $y_p$ but keeping $y_p$'s constant — absorb it into $y_c$
