# Second-Order Linear Homogeneous Differential Equations

A second-order linear homogeneous equation with constant coefficients:
$$ay'' + by' + cy = 0 \qquad (a, b, c \text{ constants})$$
The **auxiliary equation** $am^2 + bm + c = 0$ converts the differential problem into an algebra problem — substitute $y = e^{mx}$ and the exponential becomes the key that unlocks the solution.

**The Intuition:** Try a solution of the form $y = e^{mx}$. Since $y' = me^{mx}$ and $y'' = m^2 e^{mx}$, the equation becomes $e^{mx}(am^2 + bm + c) = 0$. Because $e^{mx}$ is never zero, we need $am^2 + bm + c = 0$ — a quadratic. The three cases of that quadratic (two real roots, one repeated root, complex conjugate roots) give the three solution shapes.

## The auxiliary equation & three cases

$$y = e^{mx} \implies am^2 + bm + c = 0$$

| Discriminant | Roots | Complementary function |
|---|---|---|
| $b^2 - 4ac > 0$ | distinct real $m_1 \neq m_2$ | $y_c = Ae^{m_1 x} + Be^{m_2 x}$ |
| $b^2 - 4ac = 0$ | repeated $m$ | $y_c = (A + Bx)e^{mx}$ |
| $b^2 - 4ac < 0$ | complex $m = \alpha \pm i\beta$ | $y_c = e^{\alpha x}(A\cos\beta x + B\sin\beta x)$ |

## Case 1 — distinct real roots

$$y'' - 3y' + 2y = 0 \implies m^2 - 3m + 2 = 0 \implies m = 1, 2$$
$$y = Ae^{x} + Be^{2x}$$

## Case 2 — repeated root

$$y'' - 4y' + 4y = 0 \implies (m-2)^2 = 0 \implies m = 2, 2$$
$$y = (A + Bx)e^{2x}$$

**Why the extra $x$:** with only one root we'd get just $Ae^{2x}$ — one arbitrary constant, but a second-order equation needs two. The second independent solution is $xe^{2x}$ (reduction of order). The $x$ factor is what rescues the missing degree of freedom.

## Case 3 — complex conjugate roots

$$y'' + 4y = 0 \implies m^2 + 4 = 0 \implies m = \pm 2i$$
$$y = A\cos 2x + B\sin 2x$$

More generally $m = \alpha \pm i\beta$:
$$y = e^{\alpha x}\big(A\cos\beta x + B\sin\beta x\big)$$
The $e^{\alpha x}$ factor is a growing ($\alpha>0$) or decaying ($\alpha<0$) envelope; the trig part oscillates at frequency $\beta$.

## Superposition

Because the equation is **linear and homogeneous**, if $y_1$ and $y_2$ solve it, so does $y = c_1y_1 + c_2y_2$:
$$a(c_1y_1+c_2y_2)'' + b(c_1y_1+c_2y_2)' + c(c_1y_1+c_2y_2) = c_1(ay_1''+by_1'+cy_1) + c_2(ay_2''+by_2'+cy_2) = 0$$

---

**Setup:** Solve $y'' + 6y' + 13y = 0$.

**Solution:** $m^2 + 6m + 13 = 0 \Rightarrow m = -3 \pm 2i$. So $\alpha = -3$, $\beta = 2$:
$$y = e^{-3x}\big(A\cos 2x + B\sin 2x\big)$$

**Key insight:** complex roots always come in conjugate pairs (real coefficients), and they always produce a damped/amplified oscillation of the form $e^{\alpha x}(\ldots)$.

---

**Setup:** Solve $y'' - 6y' + 9y = 0$ with $y(0) = 1$, $y'(0) = 0$.

**Solution:** $(m-3)^2 = 0$, repeated root $m = 3$:
$$y = (A + Bx)e^{3x}, \qquad y' = \big(B + 3(A + Bx)\big)e^{3x}$$
Initial conditions: $y(0) = A = 1$; $y'(0) = B + 3A = 0 \Rightarrow B = -3$. Hence
$$y = (1 - 3x)e^{3x}$$

**Key insight:** the repeated-root case is the only one where the solution grows like a *polynomial times* an exponential — the $x$ factor can make it dip negative before the exponential dominates.

---

**Setup:** Why can't $y = A\cos 2x$ alone (dropping the $\sin$ term) be the general solution of $y'' + 4y = 0$?

**Solution:** One function gives one arbitrary constant, but the equation is second-order and needs *two* independent constants. $\cos 2x$ and $\sin 2x$ are linearly independent, so $A\cos 2x + B\sin 2x$ carries exactly two degrees of freedom — the general solution.

**Key insight:** "general" means *every* solution is captured. You need as many independent functions as the order of the equation, each with its own constant.

## Practice (try before peeking)

1. For $y'' - 5y' + 6y = 0$, write the auxiliary equation and its roots.
2. What form does the solution take when the auxiliary equation has a double root?
3. The auxiliary equation has roots $-1 \pm 3i$ — what is $y_c$?

<details><summary>Answers</summary>

1. $m^2 - 5m + 6 = 0 \Rightarrow (m-2)(m-3) = 0$, roots $m = 2, 3$ → $y = Ae^{2x} + Be^{3x}$.
2. $y = (A + Bx)e^{mx}$ — the extra $x$ provides the second independent solution.
3. $\alpha = -1$, $\beta = 3$ → $y = e^{-x}(A\cos 3x + B\sin 3x)$.

</details>

---

**Common traps:**
- Forgetting the $x$ in the repeated-root case (only $Ae^{mx}$ — missing a constant)
- Writing $e^{i\beta x}$ instead of converting to $\cos/\sin$ for real solutions
- Using the wrong sign in $\alpha$ from $m = \alpha \pm i\beta$ (careful with the quadratic formula)
- Applying initial conditions before writing the full general solution
