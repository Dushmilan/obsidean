# Second-Order Linear Non-homogeneous Differential Equations

A second-order linear non-homogeneous equation with constant coefficients:
$$ay'' + by' + cy = f(x)$$
The general solution is the **sum of the complementary function and a particular integral**:
$$y = y_c + y_p$$
where $y_c$ solves the homogeneous version ($f(x) = 0$) and $y_p$ is any single solution of the full equation. The method of **undetermined coefficients** builds $y_p$ from a trial form matching $f(x)$.

**The Intuition:** Think of a swing being pushed. The complementary function is how the swing moves on its own (damping determines that); the particular integral is how the *pushes* ($f(x)$) drive it. The total motion is both added together. And because the equation is linear, the two effects don't interfere — you solve each separately and add.

## The structure

$$y = \underbrace{y_c}_{\text{solves } ay''+by'+cy=0} + \underbrace{y_p}_{\text{one solution of } ay''+by'+cy=f(x)}$$

## Trial forms (undetermined coefficients)

| $f(x)$ | Trial $y_p$ |
|--------|-------------|
| polynomial $x^n$ | $A_n x^n + A_{n-1}x^{n-1} + \cdots + A_0$ |
| $ke^{rx}$ | $Ae^{rx}$ |
| $k\cos\omega x$ or $k\sin\omega x$ | $A\cos\omega x + B\sin\omega x$ |
| product/combination of the above | matching product/combination |

Then substitute $y_p$ into the equation, equate coefficients, and solve for the constants $A, B, \dots$.

## The modification rule (resonance)

If the trial form **overlaps** with $y_c$ (a term already in the complementary function), multiply the trial by $x$ (or $x^2$ for a repeated root in $y_c$):

- $f(x) = e^{2x}$ and $y_c = Ae^{2x} + Be^{3x}$ → trial $y_p = Cxe^{2x}$
- $f(x) = \sin 2x$ and $y_c = A\cos 2x + B\sin 2x$ → trial $y_p = x(C\cos 2x + D\sin 2x)$

**Why:** an unmodified trial would just duplicate part of $y_c$ — substituting it yields an inconsistency (the constants can't satisfy the equation). The $x$ factor produces an independent function that survives substitution.

---

**Setup:** Solve $y'' - 3y' + 2y = 6$.

**Solution:** Homogeneous: $m^2 - 3m + 2 = 0 \Rightarrow m = 1, 2$, so $y_c = Ae^x + Be^{2x}$.
Trial for constant $f = 6$: $y_p = C$. Then $y_p' = y_p'' = 0$, giving $2C = 6 \Rightarrow C = 3$.
$$y = Ae^x + Be^{2x} + 3$$

**Key insight:** for a constant forcing, the particular integral is just the constant that balances the equation — here, $3$ because $2 \cdot 3 = 6$.

---

**Setup:** Solve $y'' + y = \sin x$.

**Solution:** $m^2 + 1 = 0 \Rightarrow m = \pm i$, so $y_c = A\cos x + B\sin x$. The trial $C\cos x + D\sin x$ **overlaps** $y_c$ → multiply by $x$: $y_p = x(C\cos x + D\sin x)$. Then:
$$y_p' = C\cos x + D\sin x + x(-C\sin x + D\cos x)$$
$$y_p'' = -2C\sin x + 2D\cos x - x(C\cos x + D\sin x)$$
Substituting into $y'' + y = \sin x$, the $-x(\ldots)$ terms cancel, leaving $-2C\sin x + 2D\cos x = \sin x$, so $D = 0$, $-2C = 1 \Rightarrow C = -\tfrac{1}{2}$:
$$y_p = -\frac{x}{2}\cos x, \qquad y = A\cos x + B\sin x - \frac{x}{2}\cos x$$

**Key insight:** the solution grows linearly ($-\tfrac{x}{2}\cos x$) — this is **resonance**. The forcing oscillates at exactly the natural frequency, so each push adds energy and the amplitude grows without bound. It's why bridges collapse when soldiers march in step.

---

**Setup:** Why must the trial form include both $\cos$ and $\sin$ when $f(x) = \sin x$ only?

**Solution:** Differentiating a sine introduces cosines, and the equation mixes both. If you trial only $C\sin x$, the cosine terms from $y_p''$ have nothing to match — substitution fails. The full pair $A\cos x + B\sin x$ closes the loop.

**Key insight:** trial forms must be *closed under differentiation* — include every function the derivatives can produce. That's why trig forcing needs both $\cos$ and $\sin$, and why polynomials need all powers down to the constant.

## Practice (try before peeking)

1. For $y'' - 4y = e^{2x}$, what trial $y_p$ do you use — and why?
2. $y'' + 2y' + y = 3e^{-x}$: homogeneous solution? Trial after modification?
3. What does it mean when the particular integral contains an $x$ factor?

<details><summary>Answers</summary>

1. $y_c = Ae^{2x} + Be^{-2x}$ (roots $\pm 2$). The naive trial $Ce^{2x}$ overlaps $y_c$, so use $y_p = Cxe^{2x}$.
2. $m^2 + 2m + 1 = (m+1)^2 = 0$ → repeated root $-1$, so $y_c = (A + Bx)e^{-x}$. The trial $Ce^{-x}$ overlaps *twice* → modify by $x^2$: $y_p = Cx^2e^{-x}$.
3. Resonance — the forcing hits a natural frequency of the system, so the response amplitude grows linearly with time (or $x$).

</details>

---

**Common traps:**
- Forgetting the modification rule — trial overlaps $y_c$ and substitution fails
- Missing the $\sin$ term (or $\cos$ term) in trig trials
- Not checking whether $y_p$ actually works — always substitute and equate coefficients
- Using the same symbol for the constant in $y_c$ and $y_p$ — they're different unknowns
