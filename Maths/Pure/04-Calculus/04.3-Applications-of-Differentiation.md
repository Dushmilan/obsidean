# 4.3 Applications of Differentiation

## Definition

Applications of derivatives to solve real-world and geometric problems: tangents, normals, optimisation, related rates, curve sketching, and mean value theorems.

## Formulae

| Formula | Expression |
|---------|------------|
| **Tangent line** | $y - y_0 = f'(x_0)(x - x_0)$ |
| **Normal line** | $y - y_0 = -\frac{1}{f'(x_0)}(x - x_0)$ |
| **Rolle's Theorem** | $f'(c) = 0$ if $f$ continuous on $[a,b]$, differentiable on $(a,b)$, $f(a)=f(b)$ |
| **Lagrange's MVT** | $f'(c) = \frac{f(b) - f(a)}{b - a}$ |
| **Cauchy's MVT** | $\frac{f'(c)}{g'(c)} = \frac{f(b)-f(a)}{g(b)-g(a)}$ |
| **Newton's Method** | $x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$ |
| **Disc (x-axis)** | $\pi \int y^2 dx$ |
| **Washer (x-axis)** | $\pi \int (y_1^2 - y_2^2) dx$ |
| **Shell (y-axis)** | $2\pi \int x y dx$ |
| **Arc Length** | $\int_a^b \sqrt{1 + [f'(x)]^2} dx$ |

## Properties / Key Concepts

### Stationary Points
$f'(x) = 0$ (or $f'(x)$ undefined) — potential max, min, or inflection.

### First Derivative Test

| Sign Change of $f'$ | Conclusion |
|---------------------|------------|
| $+ \to -$ | Local Maximum |
| $- \to +$ | Local Minimum |
| No change | Not extremum (inflection possible) |

### Second Derivative Test
At stationary point $x = c$:
- $f''(c) > 0 \Rightarrow$ Local Minimum
- $f''(c) < 0 \Rightarrow$ Local Maximum
- $f''(c) = 0 \Rightarrow$ Inconclusive (use first derivative test)

### Absolute Extrema on $[a,b]$
1. Find critical points in $(a,b)$ where $f'(x) = 0$ or undefined
2. Evaluate $f(x)$ at critical points and endpoints $a, b$
3. Largest = absolute max, smallest = absolute min

### Maxima/Minima Word Problems (Optimisation)
1. **Define variables** — identify quantity to optimise
2. **Express as function** $f(x)$ of one variable (use constraints)
3. **Find domain** — physical constraints (e.g., $x > 0$)
4. **Differentiate** — find $f'(x) = 0$
5. **Verify** — 2nd derivative test or endpoints
6. **Interpret** — answer in context

### Common Optimisation Problem Types

| Problem Type | Constraint | Objective Function |
|--------------|------------|-------------------|
| **Max area, fixed perimeter** | $2x + 2y = P$ | $A = xy$ |
| **Min perimeter, fixed area** | $xy = A$ | $P = 2(x+y)$ |
| **Max volume, fixed surface** | $2(xy+yz+zx) = S$ | $V = xyz$ |
| **Rectangle in semicircle** | $x^2 + y^2 = r^2$ | $A = 2xy$ |
| **Cone in sphere** | $r^2 + h^2 = R^2$ | $V = \frac{1}{3}\pi r^2 h$ |
| **Cylinder in cone** | $r/h = R/H$ | $V = \pi r^2 h$ |

### Related Rates Strategy
1. **Identify** all quantities changing with time $t$
2. **Write equation** relating them (geometry, physics formula)
3. **Differentiate implicitly** w.r.t. $t$ using chain rule
4. **Substitute** known values and solve for unknown rate

### Common Related Rates Scenarios

| Scenario | Relation | Differentiate w.r.t. $t$ |
|----------|----------|--------------------------|
| **Expanding circle** | $A = \pi r^2$ | $\frac{dA}{dt} = 2\pi r \frac{dr}{dt}$ |
| **Expanding sphere** | $V = \frac{4}{3}\pi r^3$ | $\frac{dV}{dt} = 4\pi r^2 \frac{dr}{dt}$ |
| **Ladder sliding** | $x^2 + y^2 = L^2$ | $x\frac{dx}{dt} + y\frac{dy}{dt} = 0$ |
| **Conical tank** | $V = \frac{1}{3}\pi r^2 h$, $r/h = \text{const}$ | Substitute $r = kh$ first |
| **Angle of elevation** | $\tan \theta = h/x$ | $\sec^2 \theta \frac{d\theta}{dt} = \dots$ |

### Curve Sketching Checklist

| Feature | How to Find |
|---------|-------------|
| **Domain** | Where $f(x)$ defined |
| **Intercepts** | $x$-int: $f(x)=0$; $y$-int: $f(0)$ |
| **Symmetry** | Even: $f(-x)=f(x)$; Odd: $f(-x)=-f(x)$ |
| **Asymptotes** | Vertical: $f(x)\to\pm\infty$; Horizontal: $\lim_{x\to\pm\infty}f(x)$; Oblique: polynomial division |
| **Critical points** | $f'(x)=0$ or undefined |
| **Intervals of increase/decrease** | Sign of $f'(x)$ |
| **Local extrema** | First/second derivative test at critical points |
| **Concavity** | Sign of $f''(x)$ |
| **Inflection points** | $f''(x)=0$ and changes sign |
| **Behaviour at boundaries** | Limits at domain edges |

### Mean Value Theorems
**Rolle's Theorem:** If $f$ continuous on $[a,b]$, differentiable on $(a,b)$, and $f(a) = f(b)$, then $\exists c \in (a,b)$ such that $f'(c) = 0$.

**Lagrange's MVT:** If $f$ continuous on $[a,b]$, differentiable on $(a,b)$, then $\exists c \in (a,b)$:
$$f'(c) = \frac{f(b) - f(a)}{b - a}$$

**Cauchy's MVT:** If $f,g$ continuous on $[a,b]$, differentiable on $(a,b)$, $g'(x) \neq 0$, then $\exists c \in (a,b)$:
$$\frac{f'(c)}{g'(c)} = \frac{f(b)-f(a)}{g(b)-g(a)}$$

### Applications of MVT
- **Proving inequalities:** $e^x \ge 1+x$ for all $x$ (MVT on $e^x$)
- **Error estimation:** $|f(x) - f(a)| \le M|x-a|$ where $M = \max|f'|$
- **L'Hôpital's Rule proof:** Uses Cauchy MVT

## Worked Examples

### Example 1: Tangent/Normal to Curve
"Find equation of tangent to $y = x^3 - 3x + 2$ at $x = 1$"
$m = f'(1) = 3(1)^2 - 3 = 0$; use point-slope form.

### Example 2: Rectangle in Semicircle
Maximise area of rectangle inscribed in semicircle $x^2 + y^2 = r^2$ ($y \ge 0$).
- $A(x) = 2x \cdot \sqrt{r^2 - x^2}$, domain $0 \le x \le r$
- $A'(x) = 2\sqrt{r^2 - x^2} - \frac{2x^2}{\sqrt{r^2 - x^2}} = 0$
- $2(r^2 - x^2) = 2x^2 \Rightarrow x = r/\sqrt{2}, y = r/\sqrt{2}$
- $A_{\max} = r^2$

### Example 3: Related Rates
"A ladder 5m long slides down a wall. If bottom moves at 1 m/s, how fast does top descend when bottom is 3m from wall?"
Pythagoras: $x^2 + y^2 = 25$. Differentiate w.r.t. $t$: $2x \frac{dx}{dt} + 2y \frac{dy}{dt} = 0$. Substitute known values.

### Example 4: Curve Sketching
"Sketch $y = \frac{x^2-1}{x^2+1}$"
**Method:** Domain, intercepts, asymptotes, symmetry, $f'$ (inc/dec, extrema), $f''$ (concavity, inflection), plot key points.

### Example 5: Prove Inequality
"Show $x > \ln(1+x)$ for $x > 0$"
MVT on $\ln(1+x)$ or define $g(x) = x - \ln(1+x)$.

### Pattern: Tangent/Normal Problems
- "Find points where tangent is parallel to $y = mx + c$" → $f'(x) = m$
- "Tangent passes through point $(p,q)$ not on curve" → solve $q - f(x) = f'(x)(p - x)$

### Pattern: Related Rates
"Water poured into cone at $5\,\text{cm}^3/\text{s}$. Find $dh/dt$ when $h = 3\,\text{cm}$."
Write $V(h)$ using similar triangles, differentiate w.r.t. $t$

## Common Traps

| Trap | ❌ Wrong | Correct |
|------|-------|---------|
| Tangent slope | Use $f(x)$ instead of $f'(x)$ | Slope is $f'(x_0)$ |
| Normal slope | Use $-f'(x)$ | Use $-\frac{1}{f'(x_0)}$ |
| Optimisation domain | Ignore physical constraints | Always find domain first |
| Related rates | Differentiate w.r.t. wrong variable | Always differentiate w.r.t. $t$ |
| Curve sketch | Forget asymptotes | Check vertical, horizontal, oblique |
| MVT conditions | Apply without continuity | Must be continuous on $[a,b]$ |
