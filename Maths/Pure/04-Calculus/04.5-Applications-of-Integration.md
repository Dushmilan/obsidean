# 4.5 Applications of Integration

## Definition

Physical and geometric applications of definite integrals: areas, volumes, arc lengths, surface areas, work, centroids, and moments of inertia.

## Formulae

| Formula | Expression |
|---------|------------|
| **Area between curves (vertical)** | $\int_a^b [f(x) - g(x)] dx$ |
| **Area between curves (horizontal)** | $\int_c^d [f(y) - g(y)] dy$ |
| **Volume Disc (x-axis)** | $\pi \int_a^b [f(x)]^2 dx$ |
| **Volume Washer (x-axis)** | $\pi \int_a^b ([f(x)]^2 - [g(x)]^2) dx$ |
| **Volume Shell (y-axis)** | $2\pi \int_a^b x f(x) dx$ |
| **Arc Length ($y=f(x)$)** | $\int_a^b \sqrt{1 + [f'(x)]^2} dx$ |
| **Arc Length (parametric)** | $\int_\alpha^\beta \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2} dt$ |
| **Surface Area (x-axis)** | $2\pi \int_a^b f(x) \sqrt{1 + [f'(x)]^2} dx$ |
| **Work** | $\int_a^b F(x) dx$ |
| **Centroid $\bar{x}$** | $\frac{1}{A} \int_a^b x [f(x) - g(x)] dx$ |
| **Centroid $\bar{y}$** | $\frac{1}{2A} \int_a^b [f(x)^2 - g(x)^2] dx$ |
| **Moment of Inertia $I_x$** | $\frac{1}{3} \int_a^b [f(x)^3 - g(x)^3] dx$ |
| **Hydrostatic Force** | $\rho g \int_{y_1}^{y_2} y w(y) dy$ |

### Choosing Volume Method

| Axis | Slices | Best Method |
|------|--------|-------------|
| x-axis | vertical | Disc/Washer |
| x-axis | horizontal | Shell |
| y-axis | vertical | Shell |
| y-axis | horizontal | Disc/Washer |

## Properties / Key Concepts

### Area Between Curves
If $f(x) \ge g(x)$ on $[a,b]$:
$$A = \int_a^b [f(x) - g(x)] \, dx$$

For curves that cross, find intersection points, split integral:
$$A = \sum \int_{x_i}^{x_{i+1}} |f(x) - g(x)| \, dx$$

### Volumes of Revolution

**Disc Method (about x-axis):** Region bounded by $y = f(x) \ge 0$, x-axis, $x=a$, $x=b$:
$$V = \pi \int_a^b [f(x)]^2 \, dx$$

**Washer Method:** Region between $y = f(x)$ and $y = g(x)$ where $f(x) \ge g(x) \ge 0$:
$$V = \pi \int_a^b \left( [f(x)]^2 - [g(x)]^2 \right) \, dx$$

**Shell Method (about y-axis):** Region under $y = f(x) \ge 0$ on $[a,b]$ ($0 \le a < b$):
$$V = 2\pi \int_a^b x f(x) \, dx$$

### Arc Length
$f'$ continuous:
$$L = \int_a^b \sqrt{1 + [f'(x)]^2} \, dx$$

### Surface Area of Revolution
About x-axis ($y = f(x) \ge 0$):
$$S = \int_a^b 2\pi f(x) \sqrt{1 + [f'(x)]^2} \, dx$$

### Work
Variable force $F(x)$ from $x=a$ to $x=b$:
$$W = \int_a^b F(x) \, dx$$

**Spring (Hooke's Law):** $F = kx$: $W = \frac{1}{2} k x^2$

**Pumping Liquid:** $W = \rho g \int_a^b A(y) (h - y) \, dy$

### Centroids
Region between $y = f(x)$ and $y = g(x)$ on $[a,b]$, $f(x) \ge g(x)$:
$$\bar{x} = \frac{1}{A} \int_a^b x [f(x) - g(x)] \, dx$$
$$\bar{y} = \frac{1}{2A} \int_a^b [f(x)^2 - g(x)^2] \, dx$$

### Pappus's Centroid Theorems
**Volume:** $V = A \cdot 2\pi d$ where $d$ = distance from centroid to axis.

**Surface Area:** $S = L \cdot 2\pi d$ where $L$ = arc length.

### Moments of Inertia
$$I_x = \frac{1}{3} \int_a^b [f(x)^3 - g(x)^3] \, dx$$
$$I_y = \int_a^b x^2 [f(x) - g(x)] \, dx$$
**Parallel Axis Theorem:** $I = I_{cm} + A d^2$

### Hydrostatic Force
Plate width $w(y)$ at depth $y$:
$$F = \rho g \int_{y_1}^{y_2} y w(y) \, dy$$

## Worked Examples

### Example 1: Area between $y = x^2$ and $y = 2x - x^2$
Intersections: $x^2 = 2x - x^2 \Rightarrow x = 0, 1$
Top: $2x - x^2$, Bottom: $x^2$
$$A = \int_0^1 [(2x - x^2) - x^2] dx = \int_0^1 (2x - 2x^2) dx = \left[x^2 - \frac{2}{3}x^3\right]_0^1 = \frac{1}{3}$$

### Example 2: Volume by Disc
$y = \sqrt{x}$ about x-axis from 0 to 4
$$V = \pi \int_0^4 (\sqrt{x})^2 dx = \pi \int_0^4 x dx = \pi \left[\frac{x^2}{2}\right]_0^4 = 8\pi$$

### Example 3: Volume by Shell
$y = x^2$, $x=2$, x-axis about y-axis
$$V = 2\pi \int_0^2 x(x^2) dx = 2\pi \int_0^2 x^3 dx = 2\pi \left[\frac{x^4}{4}\right]_0^2 = 8\pi$$

### Example 4: Arc Length
$y = \frac{x^3}{6} + \frac{1}{2x}$ on $[1,2]$
$y' = \frac{x^2}{2} - \frac{1}{2x^2}$
$1 + (y')^2 = \left(\frac{x^2}{2} + \frac{1}{2x^2}\right)^2$
$$L = \int_1^2 \left(\frac{x^2}{2} + \frac{1}{2x^2}\right) dx = \frac{17}{12}$$

### Example 5: Centroid
Region bounded by $y = x^2$, $y = 0$, $x = 1$
$A = \frac{1}{3}$
$\bar{x} = 3 \int_0^1 x^3 dx = \frac{3}{4}$
$\bar{y} = \frac{3}{2} \int_0^1 x^4 dx = \frac{3}{10}$
Centroid: $\left(\frac{3}{4}, \frac{3}{10}\right)$

## Common Traps

| Trap | ❌ Wrong | Correct |
|------|-------|---------|
| Area between curves | $\int (f-g) dx$ without checking order | Always do top minus bottom |
| Volume disc vs shell | Use wrong axis formula | Sketch! Disc: slices $\perp$ axis. Shell: slices $\parallel$ axis |
| Washer method | $\pi \int (f-g)^2 dx$ | $\pi \int (f^2 - g^2) dx$ |
| Arc length | Forget $dx$ or use wrong formula | $L = \int \sqrt{1+(y')^2} dx$ |
| Surface area | Use $2\pi \int y dx$ | $S = 2\pi \int y \sqrt{1+(y')^2} dx$ |
| Centroid $\bar{y}$ | $\frac{1}{A} \int \frac{f+g}{2}(f-g) dx$ | $\frac{1}{2A} \int (f^2 - g^2) dx$ |
