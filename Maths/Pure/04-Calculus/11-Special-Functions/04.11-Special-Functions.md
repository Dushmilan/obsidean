
## Definition

Special functions are defined by integrals, series, or differential equations that arise frequently in physics and engineering. They extend elementary functions where ordinary calculus can't produce closed forms.

- **Gamma:** $\Gamma(z) = \int_0^\infty t^{z-1}e^{-t}\,dt$, $\text{Re}(z) > 0$ — the factorial, generalised.
- **Beta:** $B(x,y) = \int_0^1 t^{x-1}(1-t)^{y-1}\,dt = \dfrac{\Gamma(x)\Gamma(y)}{\Gamma(x+y)}$.
- **Error function:** $\text{erf}(x) = \frac{2}{\sqrt\pi}\int_0^x e^{-t^2}\,dt$.
- **Gaussian integral:** $\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt\pi$.

## The Intuition

Special functions are "named constants" for integrals. Just as $\pi$ is the named ratio of circumference to diameter, $\Gamma$ is the named result of $\int_0^\infty t^{z-1}e^{-t}\,dt$. Once named, these results can be tabulated, studied, and reused.

## The Toolkit

| Function | Definition / key property |
|----------|---------------------------|
| Gamma recurrence | $\Gamma(z+1) = z\,\Gamma(z)$ |
| Integer values | $\Gamma(n) = (n-1)!$ |
| Half-integer | $\Gamma(\tfrac12) = \sqrt\pi$ |
| Reflection | $\Gamma(z)\Gamma(1-z) = \dfrac{\pi}{\sin(\pi z)}$ |
| Stirling | $\Gamma(z) \sim \sqrt{2\pi}\,z^{z-1/2}e^{-z}$ |
| Beta | $B(x,y) = \dfrac{\Gamma(x)\Gamma(y)}{\Gamma(x+y)}$ |
| Error function | $\text{erf}(\infty) = 1$ |
| Key integral | $\int_0^\infty x^{n-1}e^{-ax}\,dx = \dfrac{\Gamma(n)}{a^n}$ |
| Key integral | $\int_0^{\pi/2}\sin^{2m-1}\theta\cos^{2n-1}\theta\,d\theta = \tfrac12 B(m,n)$ |

## Derivation

$\Gamma(z+1) = z\Gamma(z)$ from integration by parts on the defining integral — this recurrence is why $\Gamma(n) = (n-1)!$. $\Gamma(\tfrac12) = \sqrt\pi$ from the Gaussian integral via the substitution $t = u^2$. The Beta function connects to Gamma by writing $B(x,y)$ as a product of two Gamma integrals and switching to polar coordinates. [Full derivations: 04.11-Special-Functions-Proofs]

## Method

1. **Recognise the form** — match the integral to a Gamma or Beta template (identify $n, a$ or $m, n$).
2. **Apply the formula**, using $\Gamma(n) = (n-1)!$ for integers and $\Gamma(\tfrac12) = \sqrt\pi$ for half-integers.
3. **Trig power integrals:** substitute $t = \sin^2\theta$ to convert to Beta form.
4. **Large values:** use Stirling's approximation.

## Worked Examples

**Setup:** Evaluate $\int_0^\infty x^4 e^{-2x}\,dx$.

**Solution:** Use $\int_0^\infty x^{n-1}e^{-ax}\,dx = \frac{\Gamma(n)}{a^n}$ with $n = 5$, $a = 2$: $\frac{\Gamma(5)}{2^5} = \frac{4!}{32} = \frac{24}{32} = \frac34$.

**Key insight:** Recognise the Gamma form; identify $n$ and $a$, then apply.

---

**Setup:** Evaluate $\int_0^{\pi/2}\sin^5 x\cos^2 x\,dx$.

**Solution:** $2m-1 = 5 \Rightarrow m = 3$; $2n-1 = 2 \Rightarrow n = \frac32$. $\frac12 B(3, \tfrac32) = \frac12\cdot\frac{\Gamma(3)\Gamma(\tfrac32)}{\Gamma(\tfrac92)} = \frac{8}{105}$.

**Key insight:** Convert trig power integrals to Beta form with $\sin^2 x = t$.

## Common Traps

- $\Gamma(n) = n!$ instead of $(n-1)!$ — the classic off-by-one
- Gamma integral needs $\text{Re}(z) > 0$ for convergence
- Reflection formula's $\sin(\pi z)$ — singularities at integers
- Beta symmetry $B(x,y) = B(y,x)$ — use it to simplify
- Applying $\Gamma(n)/a^n$ without checking the $e^{-ax}$ form
