# 4.4 Integration

## Definition

$F(x)$ is an **antiderivative** of $f(x)$ on interval $I$ if $F'(x) = f(x)$ for all $x \in I$.

**Notation:**
$$\int f(x)\,dx = F(x) + C$$
where $C$ is the **constant of integration**.

**Uniqueness Theorem:** If $F_1$ and $F_2$ are both antiderivatives of $f$ on $I$, then $F_1(x) - F_2(x) = C$.

## Formulae

### Basic Integration Rules

| Formula | Expression |
|---------|------------|
| **Constant** | $\int k\,dx = kx + C$ |
| **Power ($n \neq -1$)** | $\int x^n\,dx = \frac{x^{n+1}}{n+1} + C$ |
| **Power ($n = -1$)** | $\int \frac{1}{x}\,dx = \ln|x| + C$ |
| **Sum/Difference** | $\int [f(x) \pm g(x)]\,dx = \int f\,dx \pm \int g\,dx$ |
| **Constant Multiple** | $\int k f(x)\,dx = k \int f(x)\,dx$ |

### Standard Integrals (Memorise)

| Function | Integral | Function | Integral |
|----------|----------|----------|----------|
| $x^n$ ($n \neq -1$) | $\frac{x^{n+1}}{n+1} + C$ | $e^x$ | $e^x + C$ |
| $\frac{1}{x}$ | $\ln|x| + C$ | $e^{ax}$ | $\frac{1}{a}e^{ax} + C$ |
| $\frac{1}{ax+b}$ | $\frac{1}{a}\ln|ax+b| + C$ | $a^x$ | $\frac{a^x}{\ln a} + C$ |
| $\sin x$ | $-\cos x + C$ | $\cos x$ | $\sin x + C$ |
| $\sec^2 x$ | $\tan x + C$ | $\csc^2 x$ | $-\cot x + C$ |
| $\sec x \tan x$ | $\sec x + C$ | $\csc x \cot x$ | $-\csc x + C$ |
| $\frac{1}{\sqrt{a^2 - x^2}}$ | $\sin^{-1}\frac{x}{a} + C$ | $\frac{1}{a^2 + x^2}$ | $\frac{1}{a}\tan^{-1}\frac{x}{a} + C$ |
| $\frac{1}{x\sqrt{x^2 - a^2}}$ | $\frac{1}{a}\sec^{-1}\left|\frac{x}{a}\right| + C$ | | |

### Integration Techniques

**Substitution:** $\int f(g(x))g'(x)\,dx = \int f(u)\,du$ where $u = g(x)$

**By Parts:** $\int u\,dv = uv - \int v\,du$

**LIATE Rule for choosing $u$:** L $\to$ I $\to$ A $\to$ T $\to$ E (Logarithmic, Inverse trig, Algebraic, Trigonometric, Exponential)

### Partial Fractions

| Factor in $Q(x)$ | Partial Fraction Form |
|------------------|----------------------|
| $(ax+b)$ | $\frac{A}{ax+b}$ |
| $(ax+b)^n$ | $\frac{A_1}{ax+b} + \cdots + \frac{A_n}{(ax+b)^n}$ |
| $ax^2+bx+c$ (irreducible) | $\frac{Ax+B}{ax^2+bx+c}$ |

### Fundamental Theorem of Calculus (FTC)

**FTC Part 1:** If $f$ continuous on $[a,b]$, $g(x) = \int_a^x f(t)\,dt$, then $g'(x) = f(x)$.

**FTC Part 2:** $\int_a^b f(x)\,dx = F(b) - F(a)$ where $F$ is any antiderivative.

### Properties of Definite Integrals

| Formula | Expression |
|---------|------------|
| **Linearity** | $\int_a^b [cf \pm g] = c\int_a^b f \pm \int_a^b g$ |
| **Additivity** | $\int_a^b f + \int_b^c f = \int_a^c f$ |
| **Reversal** | $\int_a^b f = -\int_b^a f$ |
| **Comparison** | $f \le g \Rightarrow \int_a^b f \le \int_a^b g$ |
| **Mean Value** | $\exists c \in [a,b]: \int_a^b f = f(c)(b-a)$ |

### Improper Integrals

**Type 1 (Infinite Limits):** $\int_a^\infty f(x)\,dx = \lim_{b \to \infty} \int_a^b f(x)\,dx$

**Type 2 (Discontinuous):** $\int_a^b f(x)\,dx = \lim_{t \to c^-} \int_a^t f + \lim_{t \to c^+} \int_t^b f$

**p-Integrals:**
| Integral | Converges if | Value |
|----------|--------------|-------|
| $\int_1^\infty \frac{1}{x^p}\,dx$ | $p > 1$ | $\frac{1}{p-1}$ |
| $\int_0^1 \frac{1}{x^p}\,dx$ | $p < 1$ | $\frac{1}{1-p}$ |

### Reduction Formulas

| Integral | Formula |
|----------|---------|
| $I_n = \int \sin^n x\,dx$ | $I_n = -\frac{1}{n}\sin^{n-1}x\cos x + \frac{n-1}{n}I_{n-2}$ |
| $I_n = \int \cos^n x\,dx$ | $I_n = \frac{1}{n}\cos^{n-1}x\sin x + \frac{n-1}{n}I_{n-2}$ |
| $I_n = \int \tan^n x\,dx$ | $I_n = \frac{1}{n-1}\tan^{n-1}x - I_{n-2}$ |
| $I_n = \int \sec^n x\,dx$ | $I_n = \frac{1}{n-1}\sec^{n-2}x\tan x + \frac{n-2}{n-1}I_{n-2}$ |

### Symmetry in Definite Integrals

| Function Type | $\int_{-a}^a f(x)\,dx$ |
|---------------|------------------------|
| **Even** ($f(-x)=f(x)$) | $2\int_0^a f(x)\,dx$ |
| **Odd** ($f(-x)=-f(x)$) | $0$ |

### Logarithmic Integrals
- $\int \tan x\,dx = -\ln|\cos x| + C = \ln|\sec x| + C$
- $\int \cot x\,dx = \ln|\sin x| + C$
- $\int \sec x\,dx = \ln|\sec x + \tan x| + C$
- $\int \csc x\,dx = \ln|\csc x - \cot x| + C$

## Properties / Key Concepts

### Riemann Integral
Partition $P: a = x_0 < x_1 < \cdots < x_n = b$, $\Delta x_i = x_i - x_{i-1}$, sample points $x_i^* \in [x_{i-1}, x_i]$

**Riemann sum:** $S(P, f) = \sum_{i=1}^n f(x_i^*)\Delta x_i$

**Definite integral:** $\int_a^b f(x)\,dx = \lim_{||P||\to 0} S(P, f)$

### Integrability
- Continuous on $[a,b]$ $\Rightarrow$ integrable
- Finitely many jump discontinuities $\Rightarrow$ integrable

### Comparison Tests for Improper Integrals
If $0 \le f(x) \le g(x)$ on $[a,\infty)$:
- $\int_a^\infty g$ converges $\Rightarrow$ $\int_a^\infty f$ converges
- $\int_a^\infty f$ diverges $\Rightarrow$ $\int_a^\infty g$ diverges

**Limit Comparison:** If $\lim_{x\to\infty} \frac{f(x)}{g(x)} = L$ with $0 < L < \infty$, both converge or both diverge.

### Choosing Integration Method

| Technique | When to Use |
|-----------|-------------|
| **Substitution** | Composite function + derivative present |
| **By Parts** | Product of different types (LIATE) |
| **Partial Fractions** | Rational function, $\deg P < \deg Q$ |
| **Trig Substitution** | $\sqrt{a^2 \pm x^2}$, $\sqrt{x^2 \pm a^2}$ |
| **Trig Powers** | $\sin^m \cos^n$, $\tan^m \sec^n$ |
| **Improper** | Infinite limit or discontinuity in interval |

## Worked Examples

### Example 1: Indefinite Integral
"Find $\int \frac{x^2+3x+1}{x+2}\,dx$"
Long division + integrate

### Example 2: Trig Power Reduction
"Find $\int \sin^3 x \cos^2 x\,dx$"
$m$ odd: $u = \cos x$, use $\sin^2 x = 1 - \cos^2 x$

### Example 3: Definite Integral by Parts
"Evaluate $\int_0^1 x e^x\,dx$"
$u = x, dv = e^x dx$, then $\int_0^1 x e^x dx = [xe^x]_0^1 - \int_0^1 e^x dx = e - (e-1) = 1$

### Example 4: Reduction Formula
"Evaluate $\int_0^{\pi/2} \sin^4 x\,dx$"
Use reduction formula or power reduction

### Example 5: Improper Integral
"Determine if $\int_1^\infty \frac{1}{x^2+1}\,dx$ converges"
Compare with p-integral: $\frac{1}{x^2+1} < \frac{1}{x^2}$, converges

### Example 6: Trig Substitution
"Use substitution $x = 2\sin\theta$ to evaluate $\int \frac{dx}{\sqrt{4-x^2}}$"
$= \sin^{-1}(x/2) + C$

### Example 7: Complete Square
"Find $\int \frac{dx}{x^2+4x+13}$"
Complete the square: $(x+2)^2 + 9$, then $\frac{1}{3}\tan^{-1}\frac{x+2}{3} + C$

## Common Traps

| Trap | ❌ Wrong | Correct |
|------|-------|---------|
| $\int \frac{1}{x} dx$ | $\frac{1}{x^2}$ | $\ln|x| + C$ |
| $\int e^{kx} dx$ | $e^{kx}$ | $\frac{1}{k}e^{kx} + C$ |
| By parts order | Random $u,dv$ | Follow LIATE rule |
| Partial fractions | Forget to check degree | Must have $\deg P < \deg Q$ |
| Definite integral | Forget to apply limits | $F(b) - F(a)$ always |
| Trig substitution | Forget $dx$ | $dx = a\cos\theta\,d\theta$ |
| Reduction formula | Wrong index | Check formula for $n$ vs $n-2$ |
| Symmetry | Apply to any function | Only even/odd functions |
