Integration is the reverse of differentiation — it finds the antiderivative of a function and, when done as a definite integral, computes the signed area under a curve. It is the second pillar of calculus. If differentiation breaks things apart to find rates of change, integration puts things back together to find totals. The Fundamental Theorem of Calculus connects them: the integral of a rate of change gives the total change.

**The Intuition:** If differentiation is like reading a speedometer (instantaneous rate), integration is like reading an odometer (total distance travelled). Imagine stacking infinitely many thin rectangles under a curve. Each rectangle has width $dx$ and height $f(x)$. The sum of all these tiny areas is the integral.

**The Math:** $\int f(x)\,dx = F(x) + C$ where $F'(x) = f(x)$. Power rule: $\int x^n\,dx = \frac{x^{n+1}}{n+1} + C$ ($n \neq -1$). $\int \frac{1}{x}\,dx = \ln|x| + C$. $\int e^x\,dx = e^x + C$. $\int \sin x\,dx = -\cos x + C$, $\int \cos x\,dx = \sin x + C$.

Substitution: $\int f(g(x))g'(x)\,dx = \int f(u)\,du$ where $u = g(x)$. By parts: $\int u\,dv = uv - \int v\,du$. LIATE rule for choosing $u$: Logarithmic, Inverse trig, Algebraic, Trigonometric, Exponential.

Fundamental Theorem: Part 1: if $g(x) = \int_a^x f(t)\,dt$, then $g'(x) = f(x)$. Part 2: $\int_a^b f(x)\,dx = F(b) - F(a)$. Improper integrals: $\int_a^\infty f(x)\,dx = \lim_{b \to \infty} \int_a^b f(x)\,dx$.

**What does this mean for Pure Mathematics?** Integration calculates areas, volumes, work, probability, and accumulation of any quantity. Unlike differentiation, which has a systematic set of rules, integration often requires creativity and pattern recognition. Choosing the right technique is half the battle.

**Setup:** Evaluate $\int_0^1 x e^x\,dx$. **Solution:** LIATE: $u = x$, $dv = e^x\,dx$. Then $du = dx$, $v = e^x$. $\int x e^x\,dx = x e^x - \int e^x\,dx = x e^x - e^x + C$. Definite: $[x e^x - e^x]_0^1 = (e - e) - (0 - 1) = 1$. **Key insight:** Follow LIATE to choose $u$. The goal is that $\int v\,du$ should be simpler than $\int u\,dv$.

**Setup:** Evaluate $\int \sin^3 x \cos^2 x\,dx$. **Solution:** $\sin^3 x = \sin x(1 - \cos^2 x)$. Let $u = \cos x$, $du = -\sin x\,dx$. $\int -(1 - u^2)u^2\,du = \frac{u^5}{5} - \frac{u^3}{3} + C = \frac{\cos^5 x}{5} - \frac{\cos^3 x}{3} + C$. **Key insight:** When $\sin$ has an odd power, peel off one $\sin$ and convert the rest to $\cos$.
