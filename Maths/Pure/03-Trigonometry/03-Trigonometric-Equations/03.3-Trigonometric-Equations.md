
## Definition

Trig equations have **infinitely many solutions** because $\sin, \cos, \tan$ are periodic. Solving has two parts: find the **principal value** (the smallest angle that works), then express **all solutions** with an integer parameter $n$.

Every trig equation reduces to one of three master forms:

$$\sin\theta = \sin\alpha \Rightarrow \theta = n\pi + (-1)^n\alpha$$
$$\cos\theta = \cos\alpha \Rightarrow \theta = 2n\pi \pm \alpha$$
$$\tan\theta = \tan\alpha \Rightarrow \theta = n\pi + \alpha$$

## The Intuition

A sine wave repeating forever. If $\sin\theta = \frac12$, you're asking where the horizontal line $y = \frac12$ crosses the wave — infinitely many crossings, but in a predictable pattern. The general solution formula encodes the intervals between crossings.

## The Toolkit

| Master equation | General solution |
|---|---|
| $\sin\theta = \sin\alpha$ | $\theta = n\pi + (-1)^n\alpha$ |
| $\cos\theta = \cos\alpha$ | $\theta = 2n\pi \pm \alpha$ |
| $\tan\theta = \tan\alpha$ | $\theta = n\pi + \alpha$ |
| Amplitude-phase | $a\sin\theta + b\cos\theta = c \Rightarrow R\sin(\theta+\alpha) = c$, solutions iff $\|c\| \le R$ |

**Principal ranges:** $\sin^{-1} \in [-\pi/2, \pi/2]$, $\cos^{-1} \in [0, \pi]$, $\tan^{-1} \in (-\pi/2, \pi/2)$.

## Derivation

Periodicity: $\sin$ has period $2\pi$ and odd symmetry, giving the $n\pi + (-1)^n\alpha$ pattern; $\cos$ is even, giving $\pm\alpha$ about each $2n\pi$; $\tan$ has period $\pi$. The amplitude-phase form comes from $a\sin\theta + b\cos\theta = R\sin(\theta+\alpha)$ with $R = \sqrt{a^2+b^2}$. [Full derivations: 03.3-Trigonometric-Equations-Proof]

## Method

1. **Reduce** the equation to a single trig function: factorise, substitute $u = \sin\theta$ (etc.), or use amplitude-phase.
2. **Never divide by a trig function** — factor instead (you can lose solutions).
3. **Find principal values** using the inverse-function ranges.
4. **Write the general solution** with the master formulas.
5. If restricted to $[0, 2\pi]$ or similar, **list only the solutions in range**.
6. Squaring or $t$-substitution can introduce extraneous roots — **verify**.

## Worked Examples

**Setup:** Solve $2\cos^2\theta - 3\cos\theta + 1 = 0$.

**Solution:** Let $u = \cos\theta$: $(2u-1)(u-1) = 0$. So $\cos\theta = \frac12 \Rightarrow \theta = 2n\pi \pm \frac{\pi}{3}$, and $\cos\theta = 1 \Rightarrow \theta = 2n\pi$.

**Key insight:** Substitution $u = \cos\theta$ turns it into a standard quadratic.

---

**Setup:** Solve $3\sin\theta + 4\cos\theta = 5$.

**Solution:** $R = 5$, $\tan\alpha = \frac43$, so $5\sin(\theta+\alpha) = 5$, i.e. $\sin(\theta+\alpha) = 1$. Thus $\theta = \frac{\pi}{2} - \arctan\frac43 + 2n\pi$.

**Key insight:** Since $|c| = R$ exactly, there is exactly one family of solutions.

## Common Traps

- Listing only the principal value instead of the general solution
- Dividing by $\sin\theta$ / $\cos\theta$ — silently losing solutions
- Forgetting the two branches in $\cos\theta = \cos\alpha$ ($\pm$)
- Amplitude-phase: no solutions when $|c| > R$
- Extraneous roots after squaring — verify in the original equation
