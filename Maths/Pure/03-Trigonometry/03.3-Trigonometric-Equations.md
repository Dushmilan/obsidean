# 3.3 Trigonometric Equations

## Definition

Trigonometric equations involve finding angles that satisfy a given trigonometric relationship. Solutions consist of **principal values** (smallest angle in absolute value within standard range) and **general solutions** (all angles satisfying the equation, expressed using integer parameter $n$).

### Principal Solutions
| Equation | Principal Range |
|----------|----------------|
| $\sin\theta = k$ | $\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$ |
| $\cos\theta = k$ | $\theta \in [0, \pi]$ |
| $\tan\theta = k$ | $\theta \in (-\frac{\pi}{2}, \frac{\pi}{2})$ |

## Formulae

| Formula | Expression |
|---------|------------|
| General sin | $\sin\theta = \sin\alpha \Rightarrow \theta = n\pi + (-1)^n\alpha,\; n \in \mathbb{Z}$ |
| General cos | $\cos\theta = \cos\alpha \Rightarrow \theta = 2n\pi \pm \alpha,\; n \in \mathbb{Z}$ |
| General tan | $\tan\theta = \tan\alpha \Rightarrow \theta = n\pi + \alpha,\; n \in \mathbb{Z}$ |
| $\sin\theta = 0$ | $\theta = n\pi$ |
| $\cos\theta = 0$ | $\theta = \frac{\pi}{2} + n\pi$ |
| $\sin\theta = 1$ | $\theta = \frac{\pi}{2} + 2n\pi$ |
| $\sin\theta = -1$ | $\theta = -\frac{\pi}{2} + 2n\pi$ |
| $\cos\theta = 1$ | $\theta = 2n\pi$ |
| $\cos\theta = -1$ | $\theta = \pi + 2n\pi$ |
| $a\sin\theta + b\cos\theta = c$ | $R\sin(\theta+\alpha) = c$ where $R=\sqrt{a^2+b^2}$, $\tan\alpha=\frac{b}{a}$; solutions exist iff $|c| \le R$ |

## Properties / Key Concepts

### Solving Strategies

**Strategy 1 — Factorisation:** Factor the equation and set each factor to zero.
**Strategy 2 — Use Identities:** Convert to a single trig function using Pythagorean/double-angle identities.
**Strategy 3 — $a\sin\theta + b\cos\theta = c$ form:** Convert to $R\sin(\theta+\alpha)=c$. Condition: $|c| \le R$.
**Strategy 4 — Substitution $t = \tan\frac{\theta}{2}$:** Converts rational trig functions to algebraic. Check $\theta=\pi$ separately.
**Strategy 5 — Squaring:** May introduce extraneous roots. Always verify solutions.

### Equations with Multiple Angles
- **$\sin n\theta = \sin\alpha$:** Let $\phi = n\theta$, solve for $\phi$, then $\theta = \frac{\phi}{n}$.
- **Mixing multiples:** Use identities to reduce to common angle.
- **Sum-to-product:** For sums like $\sin\theta + \sin 3\theta = 0$.

### Equations with Squares
Use $\sin^2\theta = 1 - \cos^2\theta$ (or vice versa) to get a quadratic in one function.

### Finding Solutions in a Specific Interval
1. Find general solution
2. Substitute integer values of $n$ to find solutions in the required interval
3. **Always verify** each solution by substituting back

### Trigonometric Inequalities
1. Solve corresponding equation (find boundary points)
2. Test intervals between boundary points
3. Use sign of trig function in each interval

## Worked Examples

### Example 1: Solve $2\cos^2\theta - 3\cos\theta + 1 = 0$
Let $u = \cos\theta$: $2u^2 - 3u + 1 = 0$
$(2u-1)(u-1) = 0 \Rightarrow u = \frac{1}{2}, 1$
$\cos\theta = \frac{1}{2} \Rightarrow \theta = 2n\pi \pm \frac{\pi}{3}$
$\cos\theta = 1 \Rightarrow \theta = 2n\pi$

### Example 2: Solve $\sin 3\theta = \cos 2\theta$
$\sin 3\theta = \sin(\frac{\pi}{2} - 2\theta)$
$3\theta = n\pi + (-1)^n(\frac{\pi}{2} - 2\theta)$

**Case $n$ even ($n=2k$):**
$3\theta = 2k\pi + \frac{\pi}{2} - 2\theta \Rightarrow 5\theta = 2k\pi + \frac{\pi}{2} \Rightarrow \theta = \frac{2k\pi}{5} + \frac{\pi}{10}$

**Case $n$ odd ($n=2k+1$):**
$3\theta = (2k+1)\pi - \frac{\pi}{2} + 2\theta \Rightarrow \theta = 2k\pi + \frac{\pi}{2}$

### Example 3: Solve $3\sin\theta + 4\cos\theta = 5$
$R = \sqrt{3^2+4^2} = 5$, $\tan\alpha = \frac{4}{3}$
$5\sin(\theta + \alpha) = 5 \Rightarrow \sin(\theta + \alpha) = 1$
$\theta + \alpha = \frac{\pi}{2} + 2n\pi \Rightarrow \theta = \frac{\pi}{2} - \alpha + 2n\pi$

### Example 4: Solve $\tan\theta + \cot\theta = 2$
$\tan\theta + \frac{1}{\tan\theta} = 2 \Rightarrow \tan^2\theta - 2\tan\theta + 1 = 0$
$(\tan\theta - 1)^2 = 0 \Rightarrow \tan\theta = 1 \Rightarrow \theta = n\pi + \frac{\pi}{4}$

## Common Traps

| ❌ Mistake | Correction |
|---------|------------|
| Dividing by $\sin\theta$ or $\cos\theta$ | Factor instead; $\sin\theta=0$ may be a solution |
| Squaring without checking | Always substitute back into original |
| Missing $\theta = \pi$ when using $t = \tan\frac{\theta}{2}$ | Check $\theta = \pi$ separately |
| Forgetting $|c| \le R$ condition | $a\sin\theta + b\cos\theta = c$ has solutions only if $|c| \le \sqrt{a^2+b^2}$ |
| Not considering all integer $n$ for interval | List all solutions in required range |
