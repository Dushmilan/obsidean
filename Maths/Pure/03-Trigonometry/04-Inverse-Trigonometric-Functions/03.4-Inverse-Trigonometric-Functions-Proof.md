### 1.1 Why Restriction is Needed

Trigonometric functions are not one-to-one on their natural domains.
To define inverses, restrict domains to intervals where functions are bijective:

| Function | Restricted Domain | Range (Principal Values) |
|----------|-------------------|--------------------------|
| $\sin x$ | $[-\frac{\pi}{2}, \frac{\pi}{2}]$ | $[-1, 1]$ |
| $\cos x$ | $[0, \pi]$ | $[-1, 1]$ |
| $\tan x$ | $(-\frac{\pi}{2}, \frac{\pi}{2})$ | $\mathbb{R}$ |
| $\cot x$ | $(0, \pi)$ | $\mathbb{R}$ |
| $\sec x$ | $[0, \pi] \setminus \{\frac{\pi}{2}\}$ | $(-\infty, -1] \cup [1, \infty)$ |
| $\csc x$ | $[-\frac{\pi}{2}, \frac{\pi}{2}] \setminus \{0\}$ | $(-\infty, -1] \cup [1, \infty)$ |

**Proof of bijectivity:** On each restricted domain, function is strictly monotonic and continuous, hence one-to-one and onto its range. $\square$

### 2.1 $\sin(\sin^{-1}x) = x$ for $x \in [-1, 1]$

**Proof:** By definition, $\sin^{-1}x$ is the unique angle $\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$ such that $\sin\theta = x$.
Then $\sin(\sin^{-1}x) = \sin\theta = x$. $\square$

### 2.2 $\sin^{-1}(\sin\theta) = \theta$ only for $\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$

**Proof:** If $\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$, then $\sin^{-1}(\sin\theta) = \theta$ by definition.
If $\theta \notin [-\frac{\pi}{2}, \frac{\pi}{2}]$, find equivalent angle in range.
E.g., $\theta = \frac{2\pi}{3}$: $\sin\frac{2\pi}{3} = \sin\frac{\pi}{3} \Rightarrow \sin^{-1}(\sin\frac{2\pi}{3}) = \frac{\pi}{3} \neq \frac{2\pi}{3}$. $\square$

### 3.1 $\sin^{-1}(-x) = -\sin^{-1}x$

**Proof:** Let $\theta = \sin^{-1}x \Rightarrow \sin\theta = x$, $\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$.
Then $\sin(-\theta) = -\sin\theta = -x$, and $-\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$.
Thus $\sin^{-1}(-x) = -\theta = -\sin^{-1}x$. $\square$

### 3.2 $\cos^{-1}(-x) = \pi - \cos^{-1}x$

**Proof:** Let $\theta = \cos^{-1}x \Rightarrow \cos\theta = x$, $\theta \in [0, \pi]$.
Then $\cos(\pi - \theta) = -\cos\theta = -x$, and $\pi - \theta \in [0, \pi]$.
Thus $\cos^{-1}(-x) = \pi - \theta = \pi - \cos^{-1}x$. $\square$

### 3.3 $\tan^{-1}(-x) = -\tan^{-1}x$

**Proof:** Let $\theta = \tan^{-1}x \Rightarrow \tan\theta = x$, $\theta \in (-\frac{\pi}{2}, \frac{\pi}{2})$.
Then $\tan(-\theta) = -\tan\theta = -x$, $-\theta \in (-\frac{\pi}{2}, \frac{\pi}{2})$.
Thus $\tan^{-1}(-x) = -\theta = -\tan^{-1}x$. $\square$

### 3.4 $\cot^{-1}(-x) = \pi - \cot^{-1}x$

**Proof:** Similar using $\cot(\pi - \theta) = -\cot\theta$. $\square$

### 4.1 $\sin^{-1}x + \cos^{-1}x = \frac{\pi}{2}$ for $x \in [-1, 1]$

**Proof:** Let $\theta = \sin^{-1}x$. Then $\sin\theta = x$, $\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$.
$\cos(\frac{\pi}{2} - \theta) = \sin\theta = x$, and $\frac{\pi}{2} - \theta \in [0, \pi]$.
Thus $\cos^{-1}x = \frac{\pi}{2} - \theta = \frac{\pi}{2} - \sin^{-1}x$. $\square$

### 4.2 $\tan^{-1}x + \cot^{-1}x = \frac{\pi}{2}$ for $x \in \mathbb{R}$

**Proof:** $\tan^{-1}x = \frac{\pi}{2} - \cot^{-1}x$ (complementary angles in right triangle).
Or: Let $\theta = \tan^{-1}x \Rightarrow \tan\theta = x \Rightarrow \cot(\frac{\pi}{2} - \theta) = x \Rightarrow \cot^{-1}x = \frac{\pi}{2} - \theta$. $\square$

### 4.3 $\sec^{-1}x + \csc^{-1}x = \frac{\pi}{2}$ for $|x| \ge 1$

**Proof:** Similar using complementary angles. $\square$

### 5.1 $\sin^{-1}(\frac{1}{x}) = \csc^{-1}x$ for $|x| \ge 1$

**Proof:** Let $\theta = \csc^{-1}x$. Then $\csc\theta = x$, $\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}] \setminus \{0\}$.
Then $\sin\theta = \frac{1}{x} \Rightarrow \theta = \sin^{-1}(\frac{1}{x})$. $\square$

### 5.2 $\cos^{-1}(\frac{1}{x}) = \sec^{-1}x$ for $|x| \ge 1$

**Proof:** Similar. $\square$

### 5.3 $\tan^{-1}(\frac{1}{x}) = \begin{cases} \cot^{-1}x & x > 0 \\ \cot^{-1}x - \pi & x < 0 \end{cases}$

**Proof:** For $x > 0$: $\tan\theta = \frac{1}{x} \Rightarrow \cot\theta = x \Rightarrow \theta = \cot^{-1}x$.
For $x < 0$: Range of $\tan^{-1}$ is $(-\frac{\pi}{2}, \frac{\pi}{2})$, range of $\cot^{-1}$ is $(0, \pi)$.
Adjustment of $-\pi$ needed to bring into correct range. $\square$

### 6.1 $\sin^{-1}x + \sin^{-1}y = \sin^{-1}(x\sqrt{1-y^2} + y\sqrt{1-x^2})$

**Condition:** $x, y \in [-1, 1]$ and $x^2 + y^2 \le 1$ (ensures sum in range $[-\frac{\pi}{2}, \frac{\pi}{2}]$).

**Proof:** Let $\alpha = \sin^{-1}x$, $\beta = \sin^{-1}y$. Then $\sin\alpha = x$, $\sin\beta = y$.
$\sin(\alpha + \beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta = x\sqrt{1-y^2} + y\sqrt{1-x^2}$.
Since $\alpha, \beta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$, $\alpha + \beta \in [-\pi, \pi]$.
If $x^2+y^2 \le 1$, then $\alpha + \beta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$, so $\sin^{-1}(\sin(\alpha+\beta)) = \alpha+\beta$. $\square$

### 6.2 $\sin^{-1}x - \sin^{-1}y = \sin^{-1}(x\sqrt{1-y^2} - y\sqrt{1-x^2})$

**Proof:** Similar with $\sin(\alpha - \beta)$. $\square$

### 6.3 $\cos^{-1}x + \cos^{-1}y = \cos^{-1}(xy - \sqrt{1-x^2}\sqrt{1-y^2})$

**Condition:** $x, y \in [-1, 1]$.

**Proof:** Let $\alpha = \cos^{-1}x$, $\beta = \cos^{-1}y$. Then $\cos\alpha = x$, $\cos\beta = y$.
$\cos(\alpha + \beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta = xy - \sqrt{1-x^2}\sqrt{1-y^2}$.
Since $\alpha, \beta \in [0, \pi]$, $\alpha + \beta \in [0, 2\pi]$.
If $\alpha + \beta \le \pi$, then $\cos^{-1}(\cos(\alpha+\beta)) = \alpha + \beta$. $\square$

### 6.4 $\cos^{-1}x - \cos^{-1}y = \cos^{-1}(xy + \sqrt{1-x^2}\sqrt{1-y^2})$

**Proof:** $\cos(\alpha - \beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta$. $\square$


**Cases:**
- $xy < 1$: $\tan^{-1}x + \tan^{-1}y = \tan^{-1}\left(\frac{x+y}{1-xy}\right)$
- $x > 0, xy > 1$: $= \pi + \tan^{-1}\left(\frac{x+y}{1-xy}\right)$
- $x < 0, xy > 1$: $= -\pi + \tan^{-1}\left(\frac{x+y}{1-xy}\right)$

**Proof:** Let $\alpha = \tan^{-1}x$, $\beta = \tan^{-1}y$. $\tan\alpha = x$, $\tan\beta = y$.
$\tan(\alpha + \beta) = \frac{x+y}{1-xy}$.
Range of $\alpha + \beta$ is $(-\pi, \pi)$.
- If $xy < 1$, then $-\frac{\pi}{2} < \alpha + \beta < \frac{\pi}{2}$, so $\tan^{-1}(\tan(\alpha+\beta)) = \alpha+\beta$.
- If $x > 0, xy > 1$, then $\frac{\pi}{2} < \alpha + \beta < \pi$, so subtract $\pi$. $\square$

### 6.6 $\tan^{-1}x - \tan^{-1}y = \tan^{-1}\left(\frac{x-y}{1+xy}\right)$ for $xy > -1$

**Proof:** $\tan(\alpha - \beta) = \frac{\tan\alpha - \tan\beta}{1+\tan\alpha\tan\beta} = \frac{x-y}{1+xy}$. $\square$

### 7.1 $2\tan^{-1}x = \sin^{-1}\frac{2x}{1+x^2} = \cos^{-1}\frac{1-x^2}{1+x^2} = \tan^{-1}\frac{2x}{1-x^2}$

**Proof:** Let $\theta = \tan^{-1}x \Rightarrow \tan\theta = x$, $\theta \in (-\frac{\pi}{2}, \frac{\pi}{2})$.
Then $\sin 2\theta = \frac{2\tan\theta}{1+\tan^2\theta} = \frac{2x}{1+x^2}$.
Since $2\theta \in (-\pi, \pi)$, for $\sin^{-1}$ we need $2\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$.
If $|x| \le 1$, then $2\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$ and formula holds.
If $x > 1$, $2\theta \in (\frac{\pi}{2}, \pi)$, adjust using $\sin(\pi - 2\theta) = \sin 2\theta$. $\square$

### 7.2 $3\tan^{-1}x = \tan^{-1}\frac{3x - x^3}{1 - 3x^2}$

**Proof:** $\tan 3\theta = \frac{3\tan\theta - \tan^3\theta}{1 - 3\tan^2\theta}$ with $\theta = \tan^{-1}x$. $\square$

### 8.1 $\sin^{-1}x = \cos^{-1}\sqrt{1-x^2} = \tan^{-1}\frac{x}{\sqrt{1-x^2}}$ for $x \in [0, 1]$

**Proof:** Let $\theta = \sin^{-1}x$. Then $\sin\theta = x$, $\theta \in [0, \frac{\pi}{2}]$.
$\cos\theta = \sqrt{1-x^2} \Rightarrow \theta = \cos^{-1}\sqrt{1-x^2}$.
$\tan\theta = \frac{x}{\sqrt{1-x^2}} \Rightarrow \theta = \tan^{-1}\frac{x}{\sqrt{1-x^2}}$. $\square$

### 8.2 $\tan^{-1}x = \sin^{-1}\frac{x}{\sqrt{1+x^2}} = \cos^{-1}\frac{1}{\sqrt{1+x^2}}$ for $x > 0$

**Proof:** Let $\theta = \tan^{-1}x$. Then $\tan\theta = x$, $\theta \in (0, \frac{\pi}{2})$.
Draw right triangle: opposite $= x$, adjacent $= 1$, hypotenuse $= \sqrt{1+x^2}$.
$\sin\theta = \frac{x}{\sqrt{1+x^2}}$, $\cos\theta = \frac{1}{\sqrt{1+x^2}}$. $\square$

### 9.1 $\frac{d}{dx}\sin^{-1}x = \frac{1}{\sqrt{1-x^2}}$ for $|x| < 1$

**Proof:** Let $y = \sin^{-1}x \Rightarrow x = \sin y$.
Differentiate: $1 = \cos y \frac{dy}{dx} \Rightarrow \frac{dy}{dx} = \frac{1}{\cos y} = \frac{1}{\sqrt{1-\sin^2 y}} = \frac{1}{\sqrt{1-x^2}}$.
Since $y \in [-\frac{\pi}{2}, \frac{\pi}{2}]$, $\cos y \ge 0$, so positive root. $\square$

### 9.2 $\frac{d}{dx}\cos^{-1}x = -\frac{1}{\sqrt{1-x^2}}$

**Proof:** Let $y = \cos^{-1}x \Rightarrow x = \cos y$.
$1 = -\sin y \frac{dy}{dx} \Rightarrow \frac{dy}{dx} = -\frac{1}{\sin y} = -\frac{1}{\sqrt{1-\cos^2 y}} = -\frac{1}{\sqrt{1-x^2}}$.
Since $y \in [0, \pi]$, $\sin y \ge 0$. $\square$

### 9.3 $\frac{d}{dx}\tan^{-1}x = \frac{1}{1+x^2}$

**Proof:** $y = \tan^{-1}x \Rightarrow x = \tan y$.
$1 = \sec^2 y \frac{dy}{dx} \Rightarrow \frac{dy}{dx} = \frac{1}{\sec^2 y} = \frac{1}{1+\tan^2 y} = \frac{1}{1+x^2}$. $\square$

### 9.4 $\frac{d}{dx}\cot^{-1}x = -\frac{1}{1+x^2}$

**Proof:** $\cot^{-1}x = \frac{\pi}{2} - \tan^{-1}x \Rightarrow \frac{d}{dx}\cot^{-1}x = -\frac{1}{1+x^2}$. $\square$

### 9.5 $\frac{d}{dx}\sec^{-1}x = \frac{1}{|x|\sqrt{x^2-1}}$

**Proof:** $y = \sec^{-1}x \Rightarrow x = \sec y$.
$1 = \sec y\tan y \frac{dy}{dx} \Rightarrow \frac{dy}{dx} = \frac{1}{\sec y\tan y} = \frac{1}{x\sqrt{x^2-1}}$.
Sign consideration: For $x > 0$, $y \in [0, \frac{\pi}{2})$, $\tan y > 0$, positive.
For $x < 0$, $y \in (\frac{\pi}{2}, \pi]$, $\tan y < 0$, negative.
Thus $\frac{1}{|x|\sqrt{x^2-1}}$. $\square$

### 9.6 $\frac{d}{dx}\csc^{-1}x = -\frac{1}{|x|\sqrt{x^2-1}}$

**Proof:** $\csc^{-1}x = \frac{\pi}{2} - \sec^{-1}x$. $\square$
