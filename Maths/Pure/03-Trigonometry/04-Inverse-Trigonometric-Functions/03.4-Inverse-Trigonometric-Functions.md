
## Definition

The inverse trig functions return the **angle** whose trig ratio is given:

$$y = \sin^{-1}x \iff \sin y = x, \qquad x \in [-1, 1]$$

They are the **restricted** inverses (trig functions aren't one-to-one globally), so each has a defined principal range:

| Function | Domain | Range |
|----------|--------|-------|
| $\sin^{-1}x$ | $[-1, 1]$ | $[-\pi/2,\ \pi/2]$ |
| $\cos^{-1}x$ | $[-1, 1]$ | $[0,\ \pi]$ |
| $\tan^{-1}x$ | all real | $(-\pi/2,\ \pi/2)$ |

## The Intuition

The sine function is like a wave that repeats — not one-to-one, so no true inverse. The fix: **cut the wave down** to one monotonic piece (the principal range) and invert that. $\sin^{-1}(0.5)$ asks "which angle, in $[-\pi/2, \pi/2]$, has sine $0.5$?" — it's an angle-finder with a range contract.

## The Toolkit

| Result | Formula | Notes |
|--------|---------|-------|
| Inverse definitions | $\sin(\sin^{-1}x) = x$ | for $x \in [-1,1]$ |
| Composition | $\sin^{-1}(\sin\theta) = \theta$ | only if $\theta$ in the principal range |
| Pythagorean combo | $\cos(\sin^{-1}x) = \sqrt{1-x^2}$ | right-triangle substitution |
| Derivative | $\frac{d}{dx}\sin^{-1}x = \frac{1}{\sqrt{1-x^2}}$ | $|x| < 1$ |
| Derivative | $\frac{d}{dx}\tan^{-1}x = \frac{1}{1+x^2}$ | all $x$ |
| Derivative | $\frac{d}{dx}\cos^{-1}x = -\frac{1}{\sqrt{1-x^2}}$ | $|x| < 1$ |

## Derivation

$\sin^{-1}$ is the inverse of $\sin$ restricted to $[-\pi/2, \pi/2]$ — that's why $\sin^{-1}(\sin\theta) = \theta$ fails outside it. Derivatives: implicit differentiation of $y = \sin^{-1}x$ gives $\frac{dy}{dx} = \frac{1}{\cos y} = \frac{1}{\sqrt{1-x^2}}$ (taking the positive root from the range). The Pythagorean combos come from drawing the right triangle: if $\sin\theta = x$, the third side is $\sqrt{1-x^2}$. [Full derivations: 03.4-Inverse-Trigonometric-Functions-Proof]

## Method

1. **Evaluate an inverse at a ratio:** ask "which angle in the principal range has this ratio?" — draw the unit circle or the triangle.
2. **Simplify $\cos(\sin^{-1}x)$-type expressions:** build the right triangle with the ratio, read off the remaining sides.
3. **Check the range:** $\sin^{-1}(\sin\frac{3\pi}{4}) \neq \frac{3\pi}{4}$ — the answer must lie in $[-\pi/2, \pi/2]$.
4. **Differentiating:** use the derivative formulas directly, or substitute $x = \sin u$ for harder integrals.

## Worked Examples

**Setup:** Evaluate $\cos(\sin^{-1}\tfrac35)$.

**Solution:** Let $\theta = \sin^{-1}\tfrac35$. Then $\sin\theta = \tfrac35$, and the triangle's third side is $\sqrt{25-9} = 4$, so $\cos\theta = \tfrac45$.

**Key insight:** The right-triangle substitution turns an inverse-trig expression into a ratio.

---

**Setup:** Find $\tan(\cos^{-1}(-\tfrac12))$.

**Solution:** $\cos^{-1}(-\tfrac12) = \tfrac{2\pi}{3}$ (in $[0,\pi]$). Then $\tan\frac{2\pi}{3} = -\sqrt{3}$.

**Key insight:** Always place the angle in its principal range first; the quadrant follows automatically.

## Common Traps

- $\sin^{-1}(\sin\theta) = \theta$ assumed for all $\theta$ — only true inside the principal range
- $\sin^{-1}x$ and $\csc x$ are different functions — don't confuse the notation
- Forgetting the domain $[-1, 1]$ — $\sin^{-1}(2)$ doesn't exist
- Sign errors in derivatives ($\cos^{-1}$ has the negative)
- Mixing up $\tan^{-1}$ range $(-\pi/2, \pi/2)$ with $\cos^{-1}$ range $[0, \pi]$
