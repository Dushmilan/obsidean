# 3.1 Trigonometric Functions & Identities

## Definition

For any angle $\theta$ (in radians), let $P(x, y)$ be the point on the unit circle $x^2 + y^2 = 1$ corresponding to $\theta$ measured anticlockwise from the positive x-axis. The six trigonometric functions are defined in terms of the coordinates of $P$.

| Function | Definition | Domain | Range |
|----------|------------|--------|-------|
| $\sin\theta$ | $y$-coordinate of $P$ | $\mathbb{R}$ | $[-1, 1]$ |
| $\cos\theta$ | $x$-coordinate of $P$ | $\mathbb{R}$ | $[-1, 1]$ |
| $\tan\theta$ | $\frac{\sin\theta}{\cos\theta} = \frac{y}{x}$ | $\mathbb{R} \setminus \{\frac{\pi}{2} + k\pi\}$ | $\mathbb{R}$ |
| $\csc\theta$ | $\frac{1}{\sin\theta}$ | $\mathbb{R} \setminus \{k\pi\}$ | $(-\infty, -1] \cup [1, \infty)$ |
| $\sec\theta$ | $\frac{1}{\cos\theta}$ | $\mathbb{R} \setminus \{\frac{\pi}{2} + k\pi\}$ | $(-\infty, -1] \cup [1, \infty)$ |
| $\cot\theta$ | $\frac{\cos\theta}{\sin\theta} = \frac{x}{y}$ | $\mathbb{R} \setminus \{k\pi\}$ | $\mathbb{R}$ |

## Formulae

| Formula | Expression |
|---------|------------|
| Pythagorean | $\sin^2\theta + \cos^2\theta = 1$ |
| Pythagorean (tan) | $1 + \tan^2\theta = \sec^2\theta$ |
| Pythagorean (cot) | $1 + \cot^2\theta = \csc^2\theta$ |
| Reciprocal | $\csc\theta = \frac{1}{\sin\theta},\; \sec\theta = \frac{1}{\cos\theta},\; \cot\theta = \frac{1}{\tan\theta}$ |
| Quotient | $\tan\theta = \frac{\sin\theta}{\cos\theta},\; \cot\theta = \frac{\cos\theta}{\sin\theta}$ |
| Sum/Difference sin | $\sin(A \pm B) = \sin A\cos B \pm \cos A\sin B$ |
| Sum/Difference cos | $\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B$ |
| Sum/Difference tan | $\tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A\tan B}$ |
| Double angle sin | $\sin 2\theta = 2\sin\theta\cos\theta$ |
| Double angle cos | $\cos 2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta$ |
| Double angle tan | $\tan 2\theta = \frac{2\tan\theta}{1 - \tan^2\theta}$ |
| Triple angle sin | $\sin 3\theta = 3\sin\theta - 4\sin^3\theta$ |
| Triple angle cos | $\cos 3\theta = 4\cos^3\theta - 3\cos\theta$ |
| Half angle sin | $\sin\frac{\theta}{2} = \pm\sqrt{\frac{1 - \cos\theta}{2}}$ |
| Half angle cos | $\cos\frac{\theta}{2} = \pm\sqrt{\frac{1 + \cos\theta}{2}}$ |
| Half angle tan | $\tan\frac{\theta}{2} = \frac{1 - \cos\theta}{\sin\theta} = \frac{\sin\theta}{1 + \cos\theta}$ |
| Sum-to-product sin | $\sin A + \sin B = 2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$ |
| Sum-to-product cos | $\cos A + \cos B = 2\cos\frac{A+B}{2}\cos\frac{A-B}{2}$ |
| Product-to-sum sin·sin | $\sin A\sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$ |
| Amplitude-phase | $a\sin\theta + b\cos\theta = R\sin(\theta + \alpha)$ where $R = \sqrt{a^2 + b^2}$, $\tan\alpha = \frac{b}{a}$ |

## Properties / Key Concepts

### Periodicity
- $\sin\theta$, $\cos\theta$, $\csc\theta$, $\sec\theta$: period $2\pi$
- $\tan\theta$, $\cot\theta$: period $\pi$

### Even/Odd Symmetry
| Function | Property |
|----------|----------|
| $\sin$, $\tan$, $\csc$, $\cot$ | **Odd**: $f(-\theta) = -f(\theta)$ |
| $\cos$, $\sec$ | **Even**: $f(-\theta) = f(\theta)$ |

### Complementary Angle Identities
$$\sin\left(\frac{\pi}{2} - \theta\right) = \cos\theta, \quad \cos\left(\frac{\pi}{2} - \theta\right) = \sin\theta$$
$$\tan\left(\frac{\pi}{2} - \theta\right) = \cot\theta, \quad \cot\left(\frac{\pi}{2} - \theta\right) = \tan\theta$$
$$\sec\left(\frac{\pi}{2} - \theta\right) = \csc\theta, \quad \csc\left(\frac{\pi}{2} - \theta\right) = \sec\theta$$

### Supplementary Angle Identities
$$\sin(\pi - \theta) = \sin\theta, \quad \cos(\pi - \theta) = -\cos\theta, \quad \tan(\pi - \theta) = -\tan\theta$$
$$\sin(\pi + \theta) = -\sin\theta, \quad \cos(\pi + \theta) = -\cos\theta, \quad \tan(\pi + \theta) = \tan\theta$$

### Signs in Quadrants (ASTC Rule)

| Quadrant | Angle Range | $\sin$ | $\cos$ | $\tan$ |
|----------|-------------|--------|--------|--------|
| I | $(0, \frac{\pi}{2})$ | + | + | + |
| II | $(\frac{\pi}{2}, \pi)$ | + | - | - |
| III | $(\pi, \frac{3\pi}{2})$ | - | - | + |
| IV | $(\frac{3\pi}{2}, 2\pi)$ | - | + | - |

**Mnemonic:** **A**ll **S**tudents **T**ake **C**alculus

### Amplitude-Phase Form
$$a\sin\theta + b\cos\theta = R\sin(\theta + \alpha) \quad \text{where } R = \sqrt{a^2 + b^2},\; \tan\alpha = \frac{b}{a}$$
$$a\sin\theta + b\cos\theta = R\cos(\theta - \beta) \quad \text{where } R = \sqrt{a^2 + b^2},\; \tan\beta = \frac{a}{b}$$

**Useful for:** Finding max/min values ($\pm R$), solving $a\sin\theta + b\cos\theta = c \Rightarrow \sin(\theta + \alpha) = \frac{c}{R}$

### Standard Angles (Exact Values)

| $\theta$ (rad) | $\theta$ (deg) | $\sin\theta$ | $\cos\theta$ | $\tan\theta$ |
|----------------|----------------|--------------|--------------|--------------|
| $0$ | $0^\circ$ | $0$ | $1$ | $0$ |
| $\frac{\pi}{6}$ | $30^\circ$ | $\frac{1}{2}$ | $\frac{\sqrt{3}}{2}$ | $\frac{1}{\sqrt{3}}$ |
| $\frac{\pi}{4}$ | $45^\circ$ | $\frac{1}{\sqrt{2}}$ | $\frac{1}{\sqrt{2}}$ | $1$ |
| $\frac{\pi}{3}$ | $60^\circ$ | $\frac{\sqrt{3}}{2}$ | $\frac{1}{2}$ | $\sqrt{3}$ |
| $\frac{\pi}{2}$ | $90^\circ$ | $1$ | $0$ | undefined |
| $\pi$ | $180^\circ$ | $0$ | $-1$ | $0$ |
| $\frac{3\pi}{2}$ | $270^\circ$ | $-1$ | $0$ | undefined |
| $2\pi$ | $360^\circ$ | $0$ | $1$ | $0$ |

## Worked Examples

### Example 1: Prove $\frac{\sin\theta}{1-\cos\theta} = \csc\theta + \cot\theta$
$$\text{LHS} = \frac{\sin\theta}{1-\cos\theta} \cdot \frac{1+\cos\theta}{1+\cos\theta} = \frac{\sin\theta(1+\cos\theta)}{1-\cos^2\theta} = \frac{\sin\theta(1+\cos\theta)}{\sin^2\theta} = \frac{1+\cos\theta}{\sin\theta} = \csc\theta + \cot\theta$$

### Example 2: Find max value of $3\sin\theta + 4\cos\theta$
$R = \sqrt{3^2 + 4^2} = 5$. Maximum value = $5$.

### Example 3: Solve $\sin\theta + \cos\theta = 1$
$$\sqrt{2}\sin\left(\theta + \frac{\pi}{4}\right) = 1 \Rightarrow \sin\left(\theta + \frac{\pi}{4}\right) = \frac{1}{\sqrt{2}}$$
$$\theta + \frac{\pi}{4} = \frac{\pi}{4}, \frac{3\pi}{4} \Rightarrow \theta = 0, \frac{\pi}{2}$$

## Common Traps

| ❌ Mistake | Correction |
|---------|------------|
| $\sin^2\theta = 2\sin\theta$ | $\sin^2\theta = (\sin\theta)^2$ |
| $\sin(A+B) = \sin A + \sin B$ | Use compound angle formula |
| $\sqrt{\sin^2\theta} = \sin\theta$ | $\sqrt{\sin^2\theta} = |\sin\theta|$ |
| Forgetting $\pm$ in half-angle formulas | Sign depends on quadrant of $\theta/2$ |
| Not checking domain of $\tan$, $\sec$, $\cot$, $\csc$ | Exclude points where denominator = 0 |
