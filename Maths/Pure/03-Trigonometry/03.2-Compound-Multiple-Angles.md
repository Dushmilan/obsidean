# 3.2 Compound & Multiple Angles

## Definition

Compound angle formulas express trigonometric functions of $A \pm B$ in terms of functions of $A$ and $B$ individually. They form the foundation for double, triple, and half-angle formulas, and are derived using rotation matrices or geometric construction on the unit circle.

## Formulae

| Formula | Expression |
|---------|------------|
| $\sin(A + B)$ | $\sin A\cos B + \cos A\sin B$ |
| $\sin(A - B)$ | $\sin A\cos B - \cos A\sin B$ |
| $\cos(A + B)$ | $\cos A\cos B - \sin A\sin B$ |
| $\cos(A - B)$ | $\cos A\cos B + \sin A\sin B$ |
| $\tan(A + B)$ | $\frac{\tan A + \tan B}{1 - \tan A\tan B}$ |
| $\tan(A - B)$ | $\frac{\tan A - \tan B}{1 + \tan A\tan B}$ |
| $\cot(A + B)$ | $\frac{\cot A\cot B - 1}{\cot A + \cot B}$ |
| $\cot(A - B)$ | $\frac{\cot A\cot B + 1}{\cot B - \cot A}$ |
| $\sin 2A$ | $2\sin A\cos A$ |
| $\cos 2A$ | $\cos^2 A - \sin^2 A = 2\cos^2 A - 1 = 1 - 2\sin^2 A$ |
| $\tan 2A$ | $\frac{2\tan A}{1 - \tan^2 A}$ |
| $\cot 2A$ | $\frac{\cot^2 A - 1}{2\cot A} = \frac{\cot A - \tan A}{2}$ |
| $\sin 3A$ | $3\sin A - 4\sin^3 A$ |
| $\cos 3A$ | $4\cos^3 A - 3\cos A$ |
| $\tan 3A$ | $\frac{3\tan A - \tan^3 A}{1 - 3\tan^2 A}$ |
| $\sin 4A$ | $4\sin A\cos A(1 - 2\sin^2 A)$ |
| $\cos 4A$ | $8\cos^4 A - 8\cos^2 A + 1$ |
| $\tan 4A$ | $\frac{4\tan A - 4\tan^3 A}{1 - 6\tan^2 A + \tan^4 A}$ |
| Half-angle sin | $\sin\frac{A}{2} = \pm\sqrt{\frac{1 - \cos A}{2}}$ |
| Half-angle cos | $\cos\frac{A}{2} = \pm\sqrt{\frac{1 + \cos A}{2}}$ |
| Half-angle tan | $\tan\frac{A}{2} = \frac{1 - \cos A}{\sin A} = \frac{\sin A}{1 + \cos A}$ |
| Tangent half-angle sub | $t = \tan\frac{\theta}{2} \Rightarrow \sin\theta = \frac{2t}{1+t^2},\; \cos\theta = \frac{1-t^2}{1+t^2}$ |
| $a\sin\theta+b\cos\theta$ | $R\sin(\theta + \alpha)$ where $R = \sqrt{a^2+b^2}$, $\tan\alpha = \frac{b}{a}$ |

### Sum-to-Product

| Formula | Expression |
|---------|------------|
| $\sin A + \sin B$ | $2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$ |
| $\sin A - \sin B$ | $2\cos\frac{A+B}{2}\sin\frac{A-B}{2}$ |
| $\cos A + \cos B$ | $2\cos\frac{A+B}{2}\cos\frac{A-B}{2}$ |
| $\cos A - \cos B$ | $-2\sin\frac{A+B}{2}\sin\frac{A-B}{2}$ |

### Product-to-Sum

| Formula | Expression |
|---------|------------|
| $\sin A\sin B$ | $\frac{1}{2}[\cos(A-B) - \cos(A+B)]$ |
| $\cos A\cos B$ | $\frac{1}{2}[\cos(A-B) + \cos(A+B)]$ |
| $\sin A\cos B$ | $\frac{1}{2}[\sin(A+B) + \sin(A-B)]$ |
| $\cos A\sin B$ | $\frac{1}{2}[\sin(A+B) - \sin(A-B)]$ |

## Properties / Key Concepts

### General n-Angle (via De Moivre)
$$\sin nA = \binom{n}{1}\cos^{n-1}A\sin A - \binom{n}{3}\cos^{n-3}A\sin^3 A + \cdots$$
$$\cos nA = \cos^n A - \binom{n}{2}\cos^{n-2}A\sin^2 A + \binom{n}{4}\cos^{n-4}A\sin^4 A - \cdots$$

### Half-Angle Sign Rule
Choose sign based on quadrant of $\frac{A}{2}$.

### Tangent Half-Angle Substitution
Let $t = \tan\frac{\theta}{2}$: converts trig equations to rational algebraic equations. **Check $\theta = \pi$ separately** (where $t$ is undefined).

### Applications of $a\sin\theta + b\cos\theta$
- **Max/Min values:** Maximum = $R$, Minimum = $-R$
- **Solving equations:** $a\sin\theta + b\cos\theta = c \Rightarrow \sin(\theta + \alpha) = \frac{c}{R}$ (requires $|c| \le R$)
- **Integration:** $\int (a\sin\theta + b\cos\theta)\,d\theta$

### Double Angle Values

| $\theta$ | $\sin 2\theta$ | $\cos 2\theta$ | $\tan 2\theta$ |
|----------|----------------|----------------|----------------|
| $15^\circ$ | $\frac{1}{2}$ | $\frac{\sqrt{3}}{2}$ | $\frac{1}{\sqrt{3}}$ |
| $22.5^\circ$ | $\frac{1}{\sqrt{2}}$ | $\frac{1}{\sqrt{2}}$ | $1$ |
| $30^\circ$ | $\frac{\sqrt{3}}{2}$ | $\frac{1}{2}$ | $\sqrt{3}$ |
| $45^\circ$ | $1$ | $0$ | undefined |

### Half Angle Values

| $\theta$ | $\sin\frac{\theta}{2}$ | $\cos\frac{\theta}{2}$ | $\tan\frac{\theta}{2}$ |
|----------|------------------------|------------------------|------------------------|
| $30^\circ$ | $\sin 15^\circ = \frac{\sqrt{6}-\sqrt{2}}{4}$ | $\cos 15^\circ = \frac{\sqrt{6}+\sqrt{2}}{4}$ | $2-\sqrt{3}$ |
| $45^\circ$ | $\sin 22.5^\circ = \frac{\sqrt{2-\sqrt{2}}}{2}$ | $\cos 22.5^\circ = \frac{\sqrt{2+\sqrt{2}}}{2}$ | $\sqrt{2}-1$ |
| $60^\circ$ | $\sin 30^\circ = \frac{1}{2}$ | $\cos 30^\circ = \frac{\sqrt{3}}{2}$ | $\frac{1}{\sqrt{3}}$ |
| $90^\circ$ | $\sin 45^\circ = \frac{1}{\sqrt{2}}$ | $\cos 45^\circ = \frac{1}{\sqrt{2}}$ | $1$ |

## Worked Examples

### Example 1: Prove $\tan 3\theta = \frac{3\tan\theta - \tan^3\theta}{1 - 3\tan^2\theta}$
$$\tan 3\theta = \tan(2\theta + \theta) = \frac{\tan 2\theta + \tan\theta}{1 - \tan 2\theta\tan\theta}$$
$$= \frac{\frac{2\tan\theta}{1-\tan^2\theta} + \tan\theta}{1 - \frac{2\tan\theta}{1-\tan^2\theta}\tan\theta}$$
$$= \frac{2\tan\theta + \tan\theta(1-\tan^2\theta)}{1-\tan^2\theta - 2\tan^2\theta} = \frac{3\tan\theta - \tan^3\theta}{1 - 3\tan^2\theta}$$

### Example 2: Express $3\sin\theta + 4\cos\theta$ in $R\sin(\theta+\alpha)$ form
$R = \sqrt{3^2 + 4^2} = 5$, $\tan\alpha = \frac{4}{3} \Rightarrow \alpha \approx 53.13^\circ$
$$3\sin\theta + 4\cos\theta = 5\sin(\theta + \alpha)$$

### Example 3: Find exact value of $\sin 15^\circ$
$$\sin 15^\circ = \sin(45^\circ - 30^\circ) = \sin 45^\circ\cos 30^\circ - \cos 45^\circ\sin 30^\circ$$
$$= \frac{1}{\sqrt{2}}\cdot\frac{\sqrt{3}}{2} - \frac{1}{\sqrt{2}}\cdot\frac{1}{2} = \frac{\sqrt{3}-1}{2\sqrt{2}} = \frac{\sqrt{6}-\sqrt{2}}{4}$$

### Example 4: Solve $\sin 2\theta = \cos\theta$
$$2\sin\theta\cos\theta = \cos\theta \Rightarrow \cos\theta(2\sin\theta - 1) = 0$$
$\cos\theta = 0 \Rightarrow \theta = \frac{\pi}{2}, \frac{3\pi}{2}$
$2\sin\theta - 1 = 0 \Rightarrow \sin\theta = \frac{1}{2} \Rightarrow \theta = \frac{\pi}{6}, \frac{5\pi}{6}$

## Common Traps

| ❌ Mistake | Correction |
|---------|------------|
| $\sin 2\theta = 2\sin\theta$ | $\sin 2\theta = 2\sin\theta\cos\theta$ |
| $\cos 2\theta = 2\cos\theta$ | $\cos 2\theta = 2\cos^2\theta - 1$ |
| Forgetting $\pm$ in half-angle | Sign depends on quadrant of $\theta/2$ |
| $\tan(A+B) = \tan A + \tan B$ | Use formula with denominator |
| Using $t = \tan\frac{\theta}{2}$ when $\theta = \pi$ | $t$ undefined at $\theta = \pi$; check separately |
