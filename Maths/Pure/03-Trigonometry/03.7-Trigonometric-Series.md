# 3.7 Trigonometric Series

## Definition

Trigonometric series involve sums of sine and cosine terms, often in arithmetic progression. The $C + iS$ method (using complex exponentials and geometric series) provides elegant derivations for sum formulas.

## Formulae

| Formula | Expression |
|---------|------------|
| Sum of sines (AP) | $S_{\sin} = \frac{\sin\left(\frac{n\alpha}{2}\right) \sin\left(\theta + \frac{(n-1)\alpha}{2}\right)}{\sin\left(\frac{\alpha}{2}\right)}$ |
| Sum of cosines (AP) | $S_{\cos} = \frac{\sin\left(\frac{n\alpha}{2}\right) \cos\left(\theta + \frac{(n-1)\alpha}{2}\right)}{\sin\left(\frac{\alpha}{2}\right)}$ |
| Condition | $\sin\frac{\alpha}{2} \neq 0$ (i.e., $\alpha \neq 2k\pi$) |
| $\sum_{k=1}^n \cos k\theta$ | $\frac{\sin\frac{n\theta}{2} \cos\frac{(n+1)\theta}{2}}{\sin\frac{\theta}{2}}$ |
| $\sum_{k=1}^n \sin k\theta$ | $\frac{\sin\frac{n\theta}{2} \sin\frac{(n+1)\theta}{2}}{\sin\frac{\theta}{2}}$ |
| $\sum_{k=0}^{n-1} \cos(\theta+k\alpha)$ | $\frac{\sin\frac{n\alpha}{2} \cos\left(\theta + \frac{(n-1)\alpha}{2}\right)}{\sin\frac{\alpha}{2}}$ |
| $\sum_{k=0}^{n-1} \sin(\theta+k\alpha)$ | $\frac{\sin\frac{n\alpha}{2} \sin\left(\theta + \frac{(n-1)\alpha}{2}\right)}{\sin\frac{\alpha}{2}}$ |
| Fourier-type sin | $\sum_{k=1}^\infty \frac{\sin k\theta}{k} = \frac{\pi - \theta}{2} \quad (0 < \theta < 2\pi)$ |
| Fourier-type cos | $\sum_{k=1}^\infty \frac{\cos k\theta}{k} = -\ln\left(2\sin\frac{\theta}{2}\right)$ |

## Properties / Key Concepts

### Derivation Using Complex Numbers ($C + iS$ Method)
Let $C = \sum_{k=0}^{n-1} \cos(\theta + k\alpha)$, $S = \sum_{k=0}^{n-1} \sin(\theta + k\alpha)$.

Then $C + iS = \sum_{k=0}^{n-1} e^{i(\theta + k\alpha)} = e^{i\theta} \sum_{k=0}^{n-1} (e^{i\alpha})^k$

This is a geometric series with ratio $r = e^{i\alpha}$:
$$\sum_{k=0}^{n-1} r^k = \frac{1 - e^{in\alpha}}{1 - e^{i\alpha}} = \frac{\sin\frac{n\alpha}{2}}{\sin\frac{\alpha}{2}} e^{i\frac{(n-1)\alpha}{2}}$$

Equating real and imaginary parts yields the sum formulas.

### Special Cases

**$\theta = 0$:**
$$\sin\alpha + \sin 2\alpha + \cdots + \sin n\alpha = \frac{\sin\frac{n\alpha}{2} \sin\frac{(n+1)\alpha}{2}}{\sin\frac{\alpha}{2}}$$
$$\cos\alpha + \cos 2\alpha + \cdots + \cos n\alpha = \frac{\sin\frac{n\alpha}{2} \cos\frac{(n+1)\alpha}{2}}{\sin\frac{\alpha}{2}}$$

**Roots of unity ($\alpha = \frac{2\pi}{n}$):**
$$\sum_{k=0}^{n-1} \cos\left(\theta + \frac{2k\pi}{n}\right) = 0, \quad \sum_{k=0}^{n-1} \sin\left(\theta + \frac{2k\pi}{n}\right) = 0$$

### Sums of Powers
$$\cos^2\theta = \frac{1+\cos 2\theta}{2}, \quad \sin^2\theta = \frac{1-\cos 2\theta}{2}$$
$$\sum_{k=0}^{n-1} \cos^2(\theta + k\alpha) = \frac{n}{2} + \frac{\sin(n\alpha) \cos(2\theta + (n-1)\alpha)}{2\sin\alpha}$$

### Convergence Conditions
- $\sum \sin k\theta$, $\sum \cos k\theta$: partial sums bounded but series **diverges**
- $\sum \frac{\sin k\theta}{k}$: converges conditionally (Dirichlet's test)
- $\sum \frac{\cos k\theta}{k^2}$: converges absolutely

## Worked Examples

### Example 1: Find $\sin 10^\circ + \sin 20^\circ + \cdots + \sin 170^\circ$
This is AP with $\theta = 10^\circ$, $\alpha = 10^\circ$, $n = 17$.
$$S = \frac{\sin\frac{17 \times 10^\circ}{2} \sin\left(10^\circ + \frac{16 \times 10^\circ}{2}\right)}{\sin\frac{10^\circ}{2}} = \frac{\sin 85^\circ \sin 90^\circ}{\sin 5^\circ} = \frac{\cos 5^\circ}{\sin 5^\circ} = \cot 5^\circ$$

### Example 2: Prove $\cos\frac{\pi}{7}\cos\frac{2\pi}{7}\cos\frac{3\pi}{7} = \frac{1}{8}$
Let $P = \cos\frac{\pi}{7}\cos\frac{2\pi}{7}\cos\frac{3\pi}{7}$.
Multiply by $8\sin\frac{\pi}{7}$:
$$8\sin\frac{\pi}{7}P = 4\sin\frac{2\pi}{7}\cos\frac{2\pi}{7}\cos\frac{3\pi}{7} = 2\sin\frac{4\pi}{7}\cos\frac{3\pi}{7} = \sin\frac{7\pi}{7} + \sin\frac{\pi}{7} = 0 + \sin\frac{\pi}{7}$$
$\Rightarrow 8P = 1 \Rightarrow P = \frac{1}{8}$.

### Example 3: Evaluate $\sum_{k=1}^{n-1} \sin\frac{k\pi}{n}$
Using formula with $\theta = \frac{\pi}{n}$, $\alpha = \frac{\pi}{n}$:
$$S = \frac{\sin\frac{(n-1)\pi}{2n} \sin\frac{n\pi}{2n}}{\sin\frac{\pi}{2n}} = \frac{\cos\frac{\pi}{2n}}{\sin\frac{\pi}{2n}} = \cot\frac{\pi}{2n}$$

### Example 4: Sum $\sin x + \sin 3x + \sin 5x + \cdots + \sin(2n-1)x$
$\theta = x$, $\alpha = 2x$, $n$ terms.
$$S = \frac{\sin(nx) \sin(nx)}{\sin x} = \frac{\sin^2(nx)}{\sin x}$$

## Common Traps

| ❌ Mistake | Correction |
|---------|------------|
| Forgetting $\sin\frac{\alpha}{2} \neq 0$ condition | Formula invalid when $\alpha = 2k\pi$ |
| Wrong number of terms | Check: first term $\theta$, last term $\theta+(n-1)\alpha$ |
| Confusing $C+iS$ with direct formula | Use $C+iS$ for complex cases; direct formula for simple sums |
| Not simplifying final answer | Often simplifies using complementary/half-angle identities |
| Using degrees in calculus context | Convert to radians for differentiation/integration |
