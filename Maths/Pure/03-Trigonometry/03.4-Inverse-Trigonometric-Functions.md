# 3.4 Inverse Trigonometric Functions

## Definition

Inverse trig functions are defined by restricting domains to make trigonometric functions one-to-one, allowing well-defined inverses.

| Function | Notation | Domain | Range (Principal Values) |
|----------|----------|--------|--------------------------|
| **Arcsine** | $\sin^{-1}x$ or $\arcsin x$ | $[-1, 1]$ | $[-\frac{\pi}{2}, \frac{\pi}{2}]$ |
| **Arccosine** | $\cos^{-1}x$ or $\arccos x$ | $[-1, 1]$ | $[0, \pi]$ |
| **Arctangent** | $\tan^{-1}x$ or $\arctan x$ | $\mathbb{R}$ | $(-\frac{\pi}{2}, \frac{\pi}{2})$ |
| **Arccotangent** | $\cot^{-1}x$ or $\operatorname{arccot} x$ | $\mathbb{R}$ | $(0, \pi)$ |
| **Arcsecant** | $\sec^{-1}x$ or $\operatorname{arcsec} x$ | $(-\infty, -1] \cup [1, \infty)$ | $[0, \pi] \setminus \{\frac{\pi}{2}\}$ |
| **Arccosecant** | $\csc^{-1}x$ or $\operatorname{arccsc} x$ | $(-\infty, -1] \cup [1, \infty)$ | $[-\frac{\pi}{2}, \frac{\pi}{2}] \setminus \{0\}$ |

## Formulae

| Formula | Expression |
|---------|------------|
| $\frac{d}{dx}\sin^{-1}x$ | $\frac{1}{\sqrt{1-x^2}}$ |
| $\frac{d}{dx}\cos^{-1}x$ | $-\frac{1}{\sqrt{1-x^2}}$ |
| $\frac{d}{dx}\tan^{-1}x$ | $\frac{1}{1+x^2}$ |
| $\frac{d}{dx}\cot^{-1}x$ | $-\frac{1}{1+x^2}$ |
| $\frac{d}{dx}\sec^{-1}x$ | $\frac{1}{|x|\sqrt{x^2-1}}$ |
| $\frac{d}{dx}\csc^{-1}x$ | $-\frac{1}{|x|\sqrt{x^2-1}}$ |
| $\int \frac{1}{\sqrt{a^2-x^2}}\,dx$ | $\sin^{-1}\frac{x}{a} + C$ |
| $\int \frac{1}{a^2+x^2}\,dx$ | $\frac{1}{a}\tan^{-1}\frac{x}{a} + C$ |
| $\int \frac{1}{x\sqrt{x^2-a^2}}\,dx$ | $\frac{1}{a}\sec^{-1}\frac{|x|}{a} + C$ |
| $\sin^{-1}x + \cos^{-1}x$ | $\frac{\pi}{2}$ for $x \in [-1, 1]$ |
| $\tan^{-1}x + \cot^{-1}x$ | $\frac{\pi}{2}$ for $x \in \mathbb{R}$ |
| $\sec^{-1}x + \csc^{-1}x$ | $\frac{\pi}{2}$ for $|x| \ge 1$ |
| $\sin^{-1}x + \sin^{-1}y$ | $\sin^{-1}(x\sqrt{1-y^2} + y\sqrt{1-x^2})$ when $x^2+y^2 \le 1$ |
| $\cos^{-1}x + \cos^{-1}y$ | $\cos^{-1}(xy - \sqrt{1-x^2}\sqrt{1-y^2})$ |
| $\tan^{-1}x + \tan^{-1}y$ | $\tan^{-1}\frac{x+y}{1-xy}$ when $xy < 1$ |
| $2\tan^{-1}x$ | $\sin^{-1}\frac{2x}{1+x^2} = \cos^{-1}\frac{1-x^2}{1+x^2} = \tan^{-1}\frac{2x}{1-x^2}$ |
| $3\tan^{-1}x$ | $\tan^{-1}\frac{3x - x^3}{1 - 3x^2}$ |

## Properties / Key Concepts

### Inverse Relationships
$$\sin(\sin^{-1}x) = x \quad (x \in [-1, 1])$$
$$\sin^{-1}(\sin\theta) = \theta \quad (\theta \in [-\tfrac{\pi}{2}, \tfrac{\pi}{2}])$$

### Symmetry Properties
| Function | Property |
|----------|----------|
| $\sin^{-1}(-x)$ | $-\sin^{-1}x$ |
| $\cos^{-1}(-x)$ | $\pi - \cos^{-1}x$ |
| $\tan^{-1}(-x)$ | $-\tan^{-1}x$ |
| $\cot^{-1}(-x)$ | $\pi - \cot^{-1}x$ |
| $\sec^{-1}(-x)$ | $\pi - \sec^{-1}x$ |
| $\csc^{-1}(-x)$ | $-\csc^{-1}x$ |

### Reciprocal Relations
$$\sin^{-1}\left(\frac{1}{x}\right) = \csc^{-1}x \quad (|x| \ge 1)$$
$$\cos^{-1}\left(\frac{1}{x}\right) = \sec^{-1}x \quad (|x| \ge 1)$$
$$\tan^{-1}\left(\frac{1}{x}\right) = \begin{cases} \cot^{-1}x & x > 0 \\ \cot^{-1}x - \pi & x < 0 \end{cases}$$

### Conversions Between Inverse Functions
For $x \in [-1, 1]$:
$$\sin^{-1}x = \cos^{-1}\sqrt{1-x^2} = \tan^{-1}\left(\frac{x}{\sqrt{1-x^2}}\right)$$
For $x > 0$:
$$\tan^{-1}x = \sin^{-1}\left(\frac{x}{\sqrt{1+x^2}}\right) = \cos^{-1}\left(\frac{1}{\sqrt{1+x^2}}\right)$$

### Additional Integral Forms
$$\int \frac{1}{\sqrt{x^2+a^2}}\,dx = \sinh^{-1}\frac{x}{a} = \ln\left(x+\sqrt{x^2+a^2}\right) + C$$
$$\int \frac{1}{\sqrt{x^2-a^2}}\,dx = \ln\left|x+\sqrt{x^2-a^2}\right| + C = \cosh^{-1}\frac{x}{a} + C$$

## Worked Examples

### Example 1: Find exact value of $\sin(\tan^{-1}2)$
Let $\theta = \tan^{-1}2$. Then $\tan\theta = 2 = \frac{2}{1}$.
Draw right triangle: opposite = 2, adjacent = 1, hypotenuse = $\sqrt{5}$.
$\sin\theta = \frac{2}{\sqrt{5}}$.

### Example 2: Simplify $\sin(2\sin^{-1}x)$
Let $\theta = \sin^{-1}x$. Then $\sin\theta = x$, $\cos\theta = \sqrt{1-x^2}$.
$\sin(2\theta) = 2\sin\theta\cos\theta = 2x\sqrt{1-x^2}$.

### Example 3: Solve $\sin^{-1}x + \sin^{-1}(1-x) = \cos^{-1}x$
Let $\sin^{-1}x = \alpha$, $\sin^{-1}(1-x) = \beta$.
$\alpha + \beta = \cos^{-1}x = \frac{\pi}{2} - \alpha \Rightarrow 2\alpha + \beta = \frac{\pi}{2}$
$\beta = \frac{\pi}{2} - 2\alpha$
$\sin\beta = \sin(\frac{\pi}{2} - 2\alpha) = \cos 2\alpha = 1 - 2\sin^2\alpha = 1 - 2x^2$
But $\sin\beta = 1-x$, so $1-x = 1-2x^2 \Rightarrow 2x^2 - x = 0 \Rightarrow x(2x-1) = 0$
$x = 0$ or $x = \frac{1}{2}$. Both valid.

### Example 4: Evaluate $\tan^{-1}1 + \tan^{-1}2 + \tan^{-1}3$
$\tan^{-1}1 = \frac{\pi}{4}$
$\tan^{-1}2 + \tan^{-1}3 = \tan^{-1}\left(\frac{2+3}{1-6}\right) = \tan^{-1}(-1) = -\frac{\pi}{4} + \pi = \frac{3\pi}{4}$ (since $xy=6>1$, add $\pi$)
Sum = $\frac{\pi}{4} + \frac{3\pi}{4} = \pi$.

### Example 5: Differentiate $\sin^{-1}\left(\frac{2x}{1+x^2}\right)$
Let $y = \sin^{-1}\left(\frac{2x}{1+x^2}\right)$.
Put $x = \tan\theta \Rightarrow \frac{2x}{1+x^2} = \frac{2\tan\theta}{1+\tan^2\theta} = \sin 2\theta$.
$y = \sin^{-1}(\sin 2\theta)$.
For $-\frac{\pi}{4} \le \theta \le \frac{\pi}{4}$ (i.e., $-1 \le x \le 1$), $y = 2\theta = 2\tan^{-1}x$.
$\frac{dy}{dx} = \frac{2}{1+x^2}$.

## Common Traps

| ❌ Mistake | Correction |
|---------|------------|
| $\sin^{-1}(\sin\theta) = \theta$ for all $\theta$ | Only true for $\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$ |
| $\tan^{-1}x + \tan^{-1}y = \tan^{-1}\frac{x+y}{1-xy}$ always | Must check $xy < 1$ condition; add $\pi$ if needed |
| Forgetting absolute value in $\sec^{-1}$, $\csc^{-1}$ derivatives | $\frac{1}{|x|\sqrt{x^2-1}}$ not $\frac{1}{x\sqrt{x^2-1}}$ |
| $\sin^{-1}x$ vs $(\sin x)^{-1}$ | $\sin^{-1}x = \arcsin x$; $(\sin x)^{-1} = \csc x$ |
| Not checking domain in equations | $\sin^{-1}x$ requires $x \in [-1, 1]$ |
