Inverse trig functions (arcsin, arccos, arctan) are defined by restricting trig domains to make them one-to-one. They let you solve equations like $\sin\theta = x$ for $\theta$, and they appear as antiderivatives in calculus. The key identity is $\sin^{-1}(x) + \cos^{-1}(x) = \pi/2$ for all $x \in [-1, 1]$.

**The Intuition:** If $\sin\theta = x$ tells you the y-coordinate, then $\arcsin(x) = \theta$ tells you which angle gives that y-coordinate. But since infinitely many angles give the same y-coordinate, we pick the canonical one in $[-\pi/2, \pi/2]$. The arcsin function is like a lookup table.

**The Math:** Restricted ranges: $\sin^{-1}: [-1,1] \to [-\pi/2, \pi/2]$, $\cos^{-1}: [-1,1] \to [0, \pi]$, $\tan^{-1}: \mathbb{R} \to (-\pi/2, \pi/2)$

Complementary: $\sin^{-1}(x) + \cos^{-1}(x) = \pi/2$, $\tan^{-1}(x) + \cot^{-1}(x) = \pi/2$

Derivatives: $\frac{d}{dx}\sin^{-1}(x) = \frac{1}{\sqrt{1-x^2}}$, $\frac{d}{dx}\tan^{-1}(x) = \frac{1}{1+x^2}$

Standard integrals: $\int\frac{1}{\sqrt{a^2-x^2}}\,dx = \sin^{-1}(x/a)+C$, $\int\frac{1}{a^2+x^2}\,dx = \frac{1}{a}\tan^{-1}(x/a)+C$

Addition: $\tan^{-1}(x) + \tan^{-1}(y) = \tan^{-1}\frac{x+y}{1-xy}$ when $xy < 1$

Double: $2\tan^{-1}(x) = \sin^{-1}\frac{2x}{1+x^2} = \cos^{-1}\frac{1-x^2}{1+x^2}$

**What does this mean for Pure Mathematics?** The derivatives of inverse trig functions give the standard integrals for $1/\sqrt{a^2-x^2}$ and $1/(a^2+x^2)$, which appear constantly in integration. $\sin^{-1}x$ means arcsin(x), NOT $1/\sin(x)$.

### Worked Examples

**Setup:** Find the exact value of $\sin(\tan^{-1}(2))$.

**Solution:**
1. Let $\theta = \tan^{-1}(2)$, so $\tan\theta = 2/1$
2. Right triangle: opposite = 2, adjacent = 1, hypotenuse = $\sqrt{5}$
3. $\sin\theta = 2/\sqrt{5} = 2\sqrt{5}/5$

**Key insight:** Drawing the right triangle makes composition of inverse and direct trig functions straightforward.

---

**Setup:** Evaluate $\tan^{-1}(1) + \tan^{-1}(2) + \tan^{-1}(3)$.

**Solution:**
1. $\tan^{-1}(1) = \pi/4$
2. $\tan^{-1}(2) + \tan^{-1}(3)$: $xy = 6 > 1$, so add $\pi$: $\tan^{-1}(-1) + \pi = 3\pi/4$
3. Sum $= \pi/4 + 3\pi/4 = \pi$

**Key insight:** When $xy > 1$, the formula gives the wrong quadrant. Add $\pi$ to correct.
