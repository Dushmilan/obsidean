# 3.8 Complex Numbers & De Moivre's Theorem

## Definition

A complex number $z = x + iy$ can be expressed in polar form as $z = r(\cos\theta + i\sin\theta) = re^{i\theta}$, where $r = |z| = \sqrt{x^2+y^2}$ is the modulus and $\theta = \arg(z)$ is the principal argument ($-\pi < \theta \le \pi$). De Moivre's Theorem provides a compact formula for powers and roots of complex numbers in polar form.

## Formulae

| Formula | Expression |
|---------|------------|
| De Moivre's Theorem | $(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta$ |
| Rational index | $(\cos\theta + i\sin\theta)^{p/q} = \cos\frac{p\theta+2k\pi}{q} + i\sin\frac{p\theta+2k\pi}{q}$, $k=0,\ldots,q-1$ |
| Euler's formula | $e^{i\theta} = \cos\theta + i\sin\theta$ |
| Cosine exponential | $\cos\theta = \frac{e^{i\theta} + e^{-i\theta}}{2}$ |
| Sine exponential | $\sin\theta = \frac{e^{i\theta} - e^{-i\theta}}{2i}$ |
| $n$th roots of unity | $\omega_k = e^{2\pi ik/n}$, $k = 0, 1, \ldots, n-1$ |
| Sum of roots of unity | $1 + \omega + \omega^2 + \cdots + \omega^{n-1} = 0$ |
| Product of roots | $\prod_{k=1}^{n-1} (1 - \omega_k) = n$ |
| General $n$th root | $z_k = r^{1/n}\left[\cos\frac{\theta+2k\pi}{n} + i\sin\frac{\theta+2k\pi}{n}\right]$ |
| Circle | $|z - z_0| = r$ |
| Line | $\operatorname{Im}\left(\frac{z - z_1}{z_2 - z_1}\right) = 0$ |
| Perp. bisector | $|z - z_1| = |z - z_2|$ |
| Argument ray | $\arg(z - z_1) = \theta$ |

## Properties / Key Concepts

### Principal Argument by Quadrant
- QI: $\theta = \tan^{-1}(y/x)$
- QII: $\theta = \pi + \tan^{-1}(y/x)$
- QIII: $\theta = -\pi + \tan^{-1}(y/x)$
- QIV: $\theta = \tan^{-1}(y/x)$

### Expressing $\cos n\theta$, $\sin n\theta$ as Polynomials
Using binomial expansion on $(\cos\theta + i\sin\theta)^n$ and separating real/imaginary parts.

### Expressing $\cos^n\theta$, $\sin^n\theta$ as Multiple Angles
$$\cos^n\theta = \frac{1}{2^n} \sum_{k=0}^n \binom{n}{k} \cos((n-2k)\theta)$$

**Examples:**
$$\cos^2\theta = \frac{1}{2}(1 + \cos 2\theta), \quad \cos^3\theta = \frac{1}{4}(3\cos\theta + \cos 3\theta)$$
$$\cos^4\theta = \frac{1}{8}(3 + 4\cos 2\theta + \cos 4\theta)$$
$$\sin^2\theta = \frac{1}{2}(1 - \cos 2\theta), \quad \sin^3\theta = \frac{1}{4}(3\sin\theta - \sin 3\theta)$$
$$\sin^4\theta = \frac{1}{8}(3 - 4\cos 2\theta + \cos 4\theta)$$

### $n$th Roots of Unity Properties
- $\omega_0 = 1$ (real root)
- $\omega_k = \omega_1^k$ where $\omega_1 = e^{2\pi i/n}$ (primitive root)
- $\sum_{k=0}^{n-1} \omega_k^m = \begin{cases} n & \text{if } n \mid m \\ 0 & \text{otherwise} \end{cases}$

### Hyperbolic Connection
$$\cos(i\theta) = \cosh\theta, \quad \sin(i\theta) = i\sinh\theta$$

## Worked Examples

### Example 1: Express $\cos 5\theta$ and $\sin 5\theta$ in powers of $\cos\theta$, $\sin\theta$
$$(\cos\theta + i\sin\theta)^5 = \cos^5\theta + 5i\cos^4\theta\sin\theta - 10\cos^3\theta\sin^2\theta - 10i\cos^2\theta\sin^3\theta + 5\cos\theta\sin^4\theta + i\sin^5\theta$$

Real part:
$$\cos 5\theta = \cos^5\theta - 10\cos^3\theta(1-\cos^2\theta) + 5\cos\theta(1-\cos^2\theta)^2 = 16\cos^5\theta - 20\cos^3\theta + 5\cos\theta$$

Imaginary part:
$$\sin 5\theta = 5(1-\sin^2\theta)^2\sin\theta - 10(1-\sin^2\theta)\sin^3\theta + \sin^5\theta = 16\sin^5\theta - 20\sin^3\theta + 5\sin\theta$$

### Example 2: Express $\cos^4\theta$ as sum of multiple angles
$$\cos^4\theta = \left(\frac{e^{i\theta} + e^{-i\theta}}{2}\right)^4 = \frac{1}{16}(2\cos 4\theta + 8\cos 2\theta + 6) = \frac{1}{8}\cos 4\theta + \frac{1}{2}\cos 2\theta + \frac{3}{8}$$

### Example 3: Find all roots of $z^6 + 1 = 0$
$z^6 = -1 = e^{i\pi} = e^{i(\pi + 2k\pi)}$
$z = e^{i(\pi + 2k\pi)/6} = e^{i\pi/6} \cdot e^{ik\pi/3}$, $k = 0, 1, 2, 3, 4, 5$

Roots: $e^{i\pi/6}, e^{i\pi/2}, e^{i5\pi/6}, e^{i7\pi/6}, e^{i3\pi/2}, e^{i11\pi/6}$
$= \frac{\sqrt{3}}{2} \pm \frac{i}{2}, \pm i, -\frac{\sqrt{3}}{2} \pm \frac{i}{2}$

### Example 4: Evaluate $(1+i)^{20}$
$1+i = \sqrt{2}e^{i\pi/4}$
$(1+i)^{20} = 2^{10} e^{i5\pi} = 1024(\cos 5\pi + i\sin 5\pi) = 1024(-1) = -1024$

### Example 5: Prove $\frac{1}{1-\omega} + \frac{1}{1-\omega^2} + \cdots + \frac{1}{1-\omega^{n-1}} = \frac{n-1}{2}$ where $\omega$ is primitive $n$th root of unity
Let $P(x) = x^{n-1} + x^{n-2} + \cdots + 1 = \frac{x^n - 1}{x - 1} = \prod_{k=1}^{n-1}(x - \omega^k)$
$\frac{P'(x)}{P(x)} = \sum_{k=1}^{n-1} \frac{1}{x - \omega^k}$
At $x=1$: $P(1) = n$, $P'(1) = \frac{n(n-1)}{2}$
$\sum_{k=1}^{n-1} \frac{1}{1 - \omega^k} = \frac{P'(1)}{P(1)} = \frac{n-1}{2}$

### Example 6: If $z = \cos\theta + i\sin\theta$, show $\frac{1+z}{1-z} = i\cot\frac{\theta}{2}$
$$\frac{1+\cos\theta + i\sin\theta}{1-\cos\theta - i\sin\theta} = \frac{2\cos\frac{\theta}{2}(\cos\frac{\theta}{2} + i\sin\frac{\theta}{2})}{2\sin\frac{\theta}{2}(\sin\frac{\theta}{2} - i\cos\frac{\theta}{2})} = \cot\frac{\theta}{2} \cdot \frac{e^{i\theta/2}}{-ie^{i\theta/2}} = i\cot\frac{\theta}{2}$$

## Common Traps

| ❌ Mistake | Correction |
|---------|------------|
| Using De Moivre for non-integer powers directly | For rational powers, get multiple values; use Euler for real powers |
| Forgetting all $n$ roots of unity | Always $n$ distinct roots for $z^n = w$ |
| $\arg(z_1z_2) = \arg z_1 + \arg z_2$ always | May need to adjust by $\pm 2\pi$ to get principal value |
| Confusing $e^{i\theta}$ with $\operatorname{cis}\theta$ | They're equivalent; use whichever is convenient |
| Not simplifying $\cos^n\theta$ expansions | Use binomial on exponential form |
