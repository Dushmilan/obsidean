# 3.5 Properties of Triangles

## Definition

For $\triangle ABC$ with sides $a = BC$, $b = CA$, $c = AB$, angles $A = \angle BAC$, $B = \angle ABC$, $C = \angle ACB$, semiperimeter $s = \frac{a+b+c}{2}$, area $\Delta$, circumradius $R$, inradius $r$, and exradii $r_1, r_2, r_3$ (opposite to $A, B, C$).

## Formulae

| Formula | Expression |
|---------|------------|
| Sine Rule | $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$ |
| Cosine Rule | $a^2 = b^2 + c^2 - 2bc\cos A$ |
| Cosine Rule (angle) | $\cos A = \frac{b^2 + c^2 - a^2}{2bc}$ |
| Projection Rule | $a = b\cos C + c\cos B$ |
| Area (SAS) | $\Delta = \frac{1}{2}bc\sin A = \frac{1}{2}ca\sin B = \frac{1}{2}ab\sin C$ |
| Heron's Formula | $\Delta = \sqrt{s(s-a)(s-b)(s-c)}$ |
| Area (circumradius) | $\Delta = \frac{abc}{4R}$ |
| Area (inradius) | $\Delta = rs$ |
| Area (exradii) | $\Delta = r_1(s-a) = r_2(s-b) = r_3(s-c)$ |
| Circumradius | $R = \frac{a}{2\sin A} = \frac{abc}{4\Delta}$ |
| Inradius | $r = \frac{\Delta}{s} = (s-a)\tan\frac{A}{2}$ |
| Exradius | $r_1 = \frac{\Delta}{s-a} = s\tan\frac{A}{2} = 4R\sin\frac{A}{2}\cos\frac{B}{2}\cos\frac{C}{2}$ |
| Napier's (Tangent Rule) | $\tan\frac{B-C}{2} = \frac{b-c}{b+c}\cot\frac{A}{2}$ |
| Half-angle sin | $\sin\frac{A}{2} = \sqrt{\frac{(s-b)(s-c)}{bc}}$ |
| Half-angle cos | $\cos\frac{A}{2} = \sqrt{\frac{s(s-a)}{bc}}$ |
| Half-angle tan | $\tan\frac{A}{2} = \sqrt{\frac{(s-b)(s-c)}{s(s-a)}} = \frac{r}{s-a}$ |
| Euler's | $OI^2 = R^2 - 2Rr$ |
| Exradii relation | $r_1 + r_2 + r_3 = 4R + r$ |
| Exradii product sum | $r_1r_2 + r_2r_3 + r_3r_1 = s^2$ |

## Properties / Key Concepts

### Sine Rule — Ambiguous Case (SSA)
Given $a, b, A$:
- $a < b\sin A$: No triangle
- $a = b\sin A$: One right triangle
- $b\sin A < a < b$: Two triangles (acute & obtuse $B$)
- $a \ge b$: One triangle

### Important Triangle Centers

| Center | Notation | Properties |
|--------|----------|------------|
| **Centroid** | $G$ | Intersection of medians; divides each median in ratio $2:1$ |
| **Incentre** | $I$ | Intersection of angle bisectors; distance to sides = $r$ |
| **Circumcentre** | $O$ | Intersection of perpendicular bisectors; distance to vertices = $R$ |
| **Orthocentre** | $H$ | Intersection of altitudes |
| **Nine-point centre** | $N$ | Midpoint of $OH$; radius = $\frac{R}{2}$ |

### Euler Line
$O, G, H$ are collinear with $OG:GH = 1:2$ (or $GH = 2OG$).

### Distance Formulas
$$OI^2 = R^2 - 2Rr$$
$$OH^2 = R^2(1 - 8\cos A\cos B\cos C)$$
$$IG = \frac{1}{3}\sqrt{s^2 - 16Rr + 5r^2}$$

### Special Triangles

**Equilateral ($a=b=c$, $A=B=C=60^\circ$):**
$$R = \frac{a}{\sqrt{3}}, \quad r = \frac{a}{2\sqrt{3}}, \quad \Delta = \frac{\sqrt{3}}{4}a^2, \quad R = 2r, \quad \text{all centers coincide}$$

**Right ($C = 90^\circ$):**
$$R = \frac{c}{2}, \quad r = s - c = \frac{a+b-c}{2}, \quad R + r = \frac{a+b}{2}$$

**Isosceles ($a=b$):**
$$R = \frac{a^2}{2\sqrt{4a^2-c^2}}, \quad r = \frac{c}{2}\sqrt{\frac{2a-c}{2a+c}}$$

### Solving Triangles
- **SSS:** Cosine rule for largest angle, then sine rule for remaining angles
- **SAS:** Cosine rule for third side, then sine rule for remaining angles
- **ASA/AAS:** Find third angle, then sine rule for remaining sides
- **SSA:** Ambiguous case — compute $b\sin A$, compare with $a$ and $b$

## Worked Examples

### Example 1: In $\triangle ABC$, $a=7, b=8, c=9$. Find $A, B, C$ and $\Delta$.
$\cos A = \frac{8^2+9^2-7^2}{2\cdot8\cdot9} = \frac{96}{144} = \frac{2}{3}$
$A = \cos^{-1}\frac{2}{3} \approx 48.19^\circ$

$\cos B = \frac{9^2+7^2-8^2}{2\cdot9\cdot7} = \frac{66}{126} = \frac{11}{21}$
$B \approx 58.41^\circ$

$C = 180^\circ - A - B \approx 73.4^\circ$

$s = \frac{7+8+9}{2} = 12$
$\Delta = \sqrt{12\cdot5\cdot4\cdot3} = \sqrt{720} = 12\sqrt{5} \approx 26.83$

### Example 2: Solve triangle with $a=5, b=7, A=30^\circ$
$b\sin A = 7 \times \frac{1}{2} = 3.5$
Since $a = 5 > 3.5$ and $a < b$, **two triangles** exist.

**Triangle 1:** $\sin B = \frac{b\sin A}{a} = \frac{3.5}{5} = 0.7 \Rightarrow B \approx 44.43^\circ$
$C = 180^\circ - 30^\circ - 44.43^\circ = 105.57^\circ$

**Triangle 2:** $B = 180^\circ - 44.43^\circ = 135.57^\circ$
$C = 180^\circ - 30^\circ - 135.57^\circ = 14.43^\circ$

### Example 3: Prove $r_1 + r_2 + r_3 = 4R + r$
Using $r_1 = 4R\sin\frac{A}{2}\cos\frac{B}{2}\cos\frac{C}{2}$ etc.
Sum = $4R\left[\sin\frac{A}{2}\cos\frac{B}{2}\cos\frac{C}{2} + \cos\frac{A}{2}\sin\frac{B}{2}\cos\frac{C}{2} + \cos\frac{A}{2}\cos\frac{B}{2}\sin\frac{C}{2}\right]$
Using trig identities, this simplifies to $4R + r$.

## Common Traps

| ❌ Mistake | Correction |
|---------|------------|
| Using sine rule for obtuse angles without checking | $\sin\theta = \sin(180^\circ-\theta)$; consider both |
| Forgetting ambiguous case in SSA | Check $a$ vs $b\sin A$ and $b$ |
| $\Delta = \frac{1}{2}ab\sin C$ with wrong angle | Angle must be **included** between sides $a$ and $b$ |
| Not checking triangle inequality | $a+b>c, b+c>a, c+a>b$ must hold |
| Confusing $r$ and $R$ formulas | $r = \frac{\Delta}{s}$, $R = \frac{abc}{4\Delta}$ |
