### 1.1 Conversion Formulas

For $z = x + iy$:
- Modulus: $r = |z| = \sqrt{x^2 + y^2} \ge 0$
- Argument: $\theta = \arg(z)$ where $\tan\theta = \frac{y}{x}$ (with quadrant adjustment)

**Cartesian to Polar:**
$$x = r\cos\theta, \quad y = r\sin\theta \Rightarrow z = r(\cos\theta + i\sin\theta) = re^{i\theta}$$

**Polar to Cartesian:**
Given $z = re^{i\theta}$, $x = r\cos\theta$, $y = r\sin\theta$. $\square$

### 1.2 Principal Argument
$\arg(z) \in (-\pi, \pi]$ (or $[0, 2\pi)$).

### 2.1 Statement for Integer $n$
$$(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta, \quad n \in \mathbb{Z}$$

### 2.2 Proof by Mathematical Induction (for $n \in \mathbb{N}$)

**Base case ($n=1$):** Trivial.

**Inductive step:** Assume true for $n=k$:
$$(\cos\theta + i\sin\theta)^k = \cos k\theta + i\sin k\theta$$

Multiply both sides by $(\cos\theta + i\sin\theta)$:
$$(\cos\theta + i\sin\theta)^{k+1} = (\cos k\theta + i\sin k\theta)(\cos\theta + i\sin\theta)$$
$$= \cos k\theta\cos\theta - \sin k\theta\sin\theta + i(\sin k\theta\cos\theta + \cos k\theta\sin\theta)$$
$$= \cos(k\theta + \theta) + i\sin(k\theta + \theta) = \cos(k+1)\theta + i\sin(k+1)\theta$$

Thus true for $k+1$. $\square$

### 2.3 Extension to Negative Integers

For $n = -m$ ($m > 0$):
$$(\cos\theta + i\sin\theta)^{-m} = \frac{1}{(\cos\theta + i\sin\theta)^m} = \frac{1}{\cos m\theta + i\sin m\theta}$$
$$= \frac{\cos m\theta - i\sin m\theta}{\cos^2 m\theta + \sin^2 m\theta} = \cos(-m\theta) + i\sin(-m\theta)$$
$$= \cos n\theta + i\sin n\theta \quad \square$$

### 2.4 Proof using Euler's Formula (for all real $n$)

$$e^{i\theta} = \cos\theta + i\sin\theta$$
$$(e^{i\theta})^n = e^{in\theta} = \cos n\theta + i\sin n\theta \quad \text{for any real } n \quad \square$$

### 3.1 $n = \frac{p}{q}$ in lowest terms ($q > 0$)

$$(\cos\theta + i\sin\theta)^{p/q} = \cos\left(\frac{p\theta + 2k\pi}{q}\right) + i\sin\left(\frac{p\theta + 2k\pi}{q}\right), \quad k = 0, 1, \ldots, q-1$$

**Proof:** Let $w = (\cos\theta + i\sin\theta)^{p/q}$. Then $w^q = (\cos\theta + i\sin\theta)^p = \cos p\theta + i\sin p\theta$.
The $q$ solutions to $w^q = \cos p\theta + i\sin p\theta$ are the $q$th roots:
$$w_k = \cos\left(\frac{p\theta + 2k\pi}{q}\right) + i\sin\left(\frac{p\theta + 2k\pi}{q}\right), \quad k = 0, \ldots, q-1 \quad \square$$

### 4.1 Binomial Expansion Method

$$(\cos\theta + i\sin\theta)^n = \sum_{k=0}^n \binom{n}{k} \cos^{n-k}\theta (i\sin\theta)^k$$

Separate real and imaginary parts:

**Real part (even $k = 2j$):**
$$\cos n\theta = \sum_{j=0}^{\lfloor n/2 \rfloor} \binom{n}{2j} \cos^{n-2j}\theta (i\sin\theta)^{2j}$$
$$= \sum_{j=0}^{\lfloor n/2 \rfloor} \binom{n}{2j} \cos^{n-2j}\theta (-1)^j \sin^{2j}\theta$$

**Imaginary part (odd $k = 2j+1$):**
$$\sin n\theta = \sum_{j=0}^{\lfloor (n-1)/2 \rfloor} \binom{n}{2j+1} \cos^{n-2j-1}\theta (i\sin\theta)^{2j+1}$$
$$= \sum_{j=0}^{\lfloor (n-1)/2 \rfloor} \binom{n}{2j+1} \cos^{n-2j-1}\theta (-1)^j \sin^{2j+1}\theta$$


**$n=3$:**
$$\cos 3\theta = \binom{3}{0}\cos^3\theta - \binom{3}{2}\cos\theta\sin^2\theta = \cos^3\theta - 3\cos\theta(1-\cos^2\theta) = 4\cos^3\theta - 3\cos\theta$$
$$\sin 3\theta = \binom{3}{1}\cos^2\theta\sin\theta - \binom{3}{3}\sin^3\theta = 3\cos^2\theta\sin\theta - \sin^3\theta = 3(1-\sin^2\theta)\sin\theta - \sin^3\theta = 3\sin\theta - 4\sin^3\theta$$

**$n=5$:**
$$\cos 5\theta = 16\cos^5\theta - 20\cos^3\theta + 5\cos\theta$$
$$\sin 5\theta = 16\sin^5\theta - 20\sin^3\theta + 5\sin\theta$$

### 5.1 Using Euler's Formula

$$\cos\theta = \frac{e^{i\theta} + e^{-i\theta}}{2}, \quad \sin\theta = \frac{e^{i\theta} - e^{-i\theta}}{2i}$$

### 5.2 $\cos^n\theta$

$$\cos^n\theta = \left(\frac{e^{i\theta} + e^{-i\theta}}{2}\right)^n = \frac{1}{2^n} \sum_{k=0}^n \binom{n}{k} e^{i(n-k)\theta} e^{-ik\theta}$$
$$= \frac{1}{2^n} \sum_{k=0}^n \binom{n}{k} e^{i(n-2k)\theta}$$
$$= \frac{1}{2^n} \sum_{k=0}^n \binom{n}{k} \cos((n-2k)\theta) \quad \text{(since imaginary parts cancel)}$$

**Examples:**
$$\cos^2\theta = \frac{1}{4}(2\cos 2\theta + 2) = \frac{1}{2}(\cos 2\theta + 1)$$
$$\cos^3\theta = \frac{1}{8}(\cos 3\theta + 3\cos\theta + 3\cos\theta + \cos 3\theta) = \frac{1}{4}(\cos 3\theta + 3\cos\theta)$$
$$\cos^4\theta = \frac{1}{16}(\cos 4\theta + 4\cos 2\theta + 6 + 4\cos 2\theta + \cos 4\theta) = \frac{1}{8}(\cos 4\theta + 4\cos 2\theta + 3)$$

### 5.3 $\sin^n\theta$

$$\sin^n\theta = \left(\frac{e^{i\theta} - e^{-i\theta}}{2i}\right)^n = \frac{1}{(2i)^n} \sum_{k=0}^n \binom{n}{k} (-1)^k e^{i(n-2k)\theta}$$

Separate cases for even/odd $n$:

**For even $n = 2m$:**
$$\sin^{2m}\theta = \frac{1}{2^{2m}} \sum_{k=0}^{2m} \binom{2m}{k} (-1)^k \cos((2m-2k)\theta) \cdot (-1)^m$$
$$\sin^{2m}\theta = \frac{(-1)^m}{2^{2m}} \sum_{k=0}^{2m} \binom{2m}{k} (-1)^k \cos(2(m-k)\theta)$$

**Examples:**
$$\sin^2\theta = \frac{1}{4}(2 - 2\cos 2\theta) = \frac{1}{2}(1 - \cos 2\theta)$$
$$\sin^3\theta = \frac{1}{8}(\sin 3\theta - 3\sin\theta) = \frac{1}{4}(3\sin\theta - \sin 3\theta)$$
$$\sin^4\theta = \frac{1}{16}(3 - 4\cos 2\theta + \cos 4\theta)$$

### 6.1 Definition and Roots

Solutions to $z^n = 1$:
$$\omega_k = e^{2\pi i k / n} = \cos\frac{2k\pi}{n} + i\sin\frac{2k\pi}{n}, \quad k = 0, 1, \ldots, n-1$$

**Primitive root:** $\omega = e^{2\pi i / n} = \cos\frac{2\pi}{n} + i\sin\frac{2\pi}{n}$
All roots: $1, \omega, \omega^2, \ldots, \omega^{n-1}$

### 6.2 Sum of Roots

$$\sum_{k=0}^{n-1} \omega_k = 0$$

**Proof 1:** $1 + x + x^2 + \cdots + x^{n-1} = \frac{x^n - 1}{x - 1}$. Set $x = \omega \neq 1$, then $\omega^n = 1$, so sum $= 0$. $\square$

**Proof 2:** Geometric series sum $\frac{1 - \omega^n}{1 - \omega} = 0$. $\square$

### 6.3 Sum of Powers

$$\sum_{k=0}^{n-1} \omega_k^m = \begin{cases} n & \text{if } n \mid m \\ 0 & \text{otherwise} \end{cases}$$

**Proof:** If $n \mid m$, each $\omega_k^m = 1$, sum $= n$.
If $n \nmid m$, $\omega_k^m$ are the $n$th roots of unity (possibly permuted), sum $= 0$. $\square$

### 6.4 Product of Roots

$$\prod_{k=0}^{n-1} \omega_k = (-1)^{n-1}$$

**Proof:** $z^n - 1 = (z - \omega_0)(z - \omega_1)\cdots(z - \omega_{n-1})$. Constant term $(-1)^n \prod \omega_k = -1 \Rightarrow \prod \omega_k = (-1)^{n-1}$. $\square$

### 6.5 Product $\prod_{k=1}^{n-1} (1 - \omega_k) = n$

**Proof:** $1 + z + z^2 + \cdots + z^{n-1} = \prod_{k=1}^{n-1} (z - \omega_k)$. Set $z = 1$: $n = \prod_{k=1}^{n-1} (1 - \omega_k)$. $\square$

## 7. General $n$th Roots of a Complex Number

For $w = re^{i\theta}$, solutions to $z^n = w$:
$$z_k = r^{1/n} \left[\cos\left(\frac{\theta + 2k\pi}{n}\right) + i\sin\left(\frac{\theta + 2k\pi}{n}\right)\right], \quad k = 0, 1, \ldots, n-1$$

**Proof:** Raise to $n$th power using De Moivre: $(z_k)^n = r(\cos(\theta + 2k\pi) + i\sin(\theta + 2k\pi)) = r(\cos\theta + i\sin\theta) = w$. $\square$

### 8.1 Circle
$|z - z_0| = r$ : circle centre $z_0$, radius $r$

### 8.2 Line
$\frac{z - z_1}{z_2 - z_1} \in \mathbb{R}$ or $\operatorname{Im}\left(\frac{z - z_1}{z_2 - z_1}\right) = 0$

### 8.3 Perpendicular Bisector
$|z - z_1| = |z - z_2|$

### 8.4 Argument Loci
$\arg(z - z_1) = \alpha$ : ray from $z_1$ at angle $\alpha$
$\arg\left(\frac{z - z_1}{z - z_2}\right) = \alpha$ : arc of circle (angle in same segment)

### 9.1 Euler's Formula
$$e^{i\theta} = \cos\theta + i\sin\theta$$
$$e^{-i\theta} = \cos\theta - i\sin\theta$$

### 9.2 Trigonometric Functions
$$\cos\theta = \frac{e^{i\theta} + e^{-i\theta}}{2}$$
$$\sin\theta = \frac{e^{i\theta} - e^{-i\theta}}{2i}$$
$$\tan\theta = -i\frac{e^{i\theta} - e^{-i\theta}}{e^{i\theta} + e^{-i\theta}}$$

### 9.3 Hyperbolic Connection
$$\cos(i\theta) = \cosh\theta$$
$$\sin(i\theta) = i\sinh\theta$$

**Proof:** $\cos(i\theta) = \frac{e^{i(i\theta)} + e^{-i(i\theta)}}{2} = \frac{e^{-\theta} + e^{\theta}}{2} = \cosh\theta$. $\square$
