# Proofs: Trigonometric Functions & Identities

## 1. Unit Circle Definitions

**Definition:** In a plane, draw a circle with centre $O$ and radius 1 (unit circle). For any angle $\theta$ measured anticlockwise from positive $x$-axis, let $P(x, y)$ be the point on the circle.

Then by definition:
- $\sin\theta = y = y$-coordinate of $P$
- $\cos\theta = x = x$-coordinate of $P$
- $\tan\theta = \frac{y}{x} = \frac{\sin\theta}{\cos\theta}$ (when $x \neq 0$)

Since $P$ lies on $x^2 + y^2 = 1$:
$$\cos^2\theta + \sin^2\theta = 1$$

---

## 2. Fundamental Identity: $\sin^2\theta + \cos^2\theta = 1$

**Proof 1 (Geometric):**
In unit circle, $OP = 1$, $PM = |\sin\theta|$, $OM = |\cos\theta|$.
In right $\triangle OPM$: $OP^2 = OM^2 + PM^2 \Rightarrow 1 = \cos^2\theta + \sin^2\theta$. $\square$

**Proof 2 (Algebraic using Euler's formula):**
$$e^{i\theta} = \cos\theta + i\sin\theta$$
$$e^{-i\theta} = \cos\theta - i\sin\theta$$
Multiplying: $1 = e^{i\theta}e^{-i\theta} = (\cos\theta + i\sin\theta)(\cos\theta - i\sin\theta) = \cos^2\theta + \sin^2\theta$. $\square$

---

## 3. Reciprocal Identities

**Proof:**
By definition:
$$\csc\theta = \frac{1}{\sin\theta}, \quad \sec\theta = \frac{1}{\cos\theta}, \quad \cot\theta = \frac{1}{\tan\theta} = \frac{\cos\theta}{\sin\theta}$$
All hold where denominators are non-zero. $\square$

---

## 4. Pythagorean Identities

### 4.1 $1 + \tan^2\theta = \sec^2\theta$

**Proof:**
$$\sin^2\theta + \cos^2\theta = 1$$
Divide by $\cos^2\theta$ ($\cos\theta \neq 0$):
$$\frac{\sin^2\theta}{\cos^2\theta} + 1 = \frac{1}{\cos^2\theta}$$
$$\tan^2\theta + 1 = \sec^2\theta \quad \square$$

### 4.2 $1 + \cot^2\theta = \csc^2\theta$

**Proof:**
Divide $\sin^2\theta + \cos^2\theta = 1$ by $\sin^2\theta$ ($\sin\theta \neq 0$):
$$1 + \frac{\cos^2\theta}{\sin^2\theta} = \frac{1}{\sin^2\theta}$$
$$1 + \cot^2\theta = \csc^2\theta \quad \square$$

## 5. Symmetry Identities

### 5.1 Odd/Even Properties

**Proof for $\sin(-\theta) = -\sin\theta$, $\cos(-\theta) = \cos\theta$:**

In unit circle, point for $\theta$ is $(\cos\theta, \sin\theta)$.
Point for $-\theta$ is $(\cos\theta, -\sin\theta)$ (reflection in $x$-axis).
Thus $\cos(-\theta) = \cos\theta$, $\sin(-\theta) = -\sin\theta$. $\square$

**Consequences:**
- $\tan(-\theta) = -\tan\theta$ (odd)
- $\cot(-\theta) = -\cot\theta$ (odd)
- $\sec(-\theta) = \sec\theta$ (even)
- $\csc(-\theta) = -\csc\theta$ (odd)

## 6. Complementary Angle Identities (Cofunction Identities)

**Theorem:** $\sin\left(\frac{\pi}{2} - \theta\right) = \cos\theta$, $\cos\left(\frac{\pi}{2} - \theta\right) = \sin\theta$

**Proof:**
In right triangle with angle $\theta$:
- Opposite side to $\theta$ = adjacent to $\frac{\pi}{2} - \theta$
- $\sin\theta = \frac{\text{opp}}{\text{hyp}} = \cos\left(\frac{\pi}{2} - \theta\right)$
- $\cos\theta = \frac{\text{adj}}{\text{hyp}} = \sin\left(\frac{\pi}{2} - \theta\right)$ $\square$

**Using unit circle:**
Rotate by $-\frac{\pi}{2}$: $e^{i(\frac{\pi}{2}-\theta)} = i e^{-i\theta} = i(\cos\theta - i\sin\theta) = \sin\theta + i\cos\theta$
Real part: $\sin\theta$, Imaginary part: $\cos\theta$. $\square$

---

## 7. Supplementary Angle Identities

**Proof for $\sin(\pi - \theta) = \sin\theta$:**
$e^{i(\pi-\theta)} = e^{i\pi}e^{-i\theta} = -(\cos\theta - i\sin\theta) = -\cos\theta + i\sin\theta$
Imaginary part: $\sin\theta$. $\square$

**Proof for $\cos(\pi - \theta) = -\cos\theta$:**
Real part of above: $-\cos\theta$. $\square$

## 8. Standard Angle Values

### 8.1 $\theta = 30^\circ = \frac{\pi}{6}$

**Construction:** Equilateral triangle side 2, bisected.
Hypotenuse = 2, opposite = 1, adjacent = $\sqrt{3}$.
$$\sin\frac{\pi}{6} = \frac{1}{2}, \quad \cos\frac{\pi}{6} = \frac{\sqrt{3}}{2}, \quad \tan\frac{\pi}{6} = \frac{1}{\sqrt{3}}$$

### 8.2 $\theta = 45^\circ = \frac{\pi}{4}$

**Construction:** Isosceles right triangle, legs = 1, hypotenuse = $\sqrt{2}$.
$$\sin\frac{\pi}{4} = \cos\frac{\pi}{4} = \frac{1}{\sqrt{2}}, \quad \tan\frac{\pi}{4} = 1$$

### 8.3 $\theta = 60^\circ = \frac{\pi}{3}$

Complementary to $30^\circ$:
$$\sin\frac{\pi}{3} = \cos\frac{\pi}{6} = \frac{\sqrt{3}}{2}, \quad \cos\frac{\pi}{3} = \sin\frac{\pi}{6} = \frac{1}{2}, \quad \tan\frac{\pi}{3} = \sqrt{3}$$

## 9. Periodicity

**Proof for $\sin(\theta + 2\pi) = \sin\theta$:**
On unit circle, angle $\theta + 2\pi$ represents same point as $\theta$ (full revolution).
Thus coordinates identical $\Rightarrow \sin(\theta + 2\pi) = \sin\theta$. $\square$

**Proof for $\tan(\theta + \pi) = \tan\theta$:**
$\tan(\theta + \pi) = \frac{\sin(\theta+\pi)}{\cos(\theta+\pi)} = \frac{-\sin\theta}{-\cos\theta} = \tan\theta$. $\square$

---

## 10. $a\sin\theta + b\cos\theta = R\sin(\theta + \alpha)$ Form

**Theorem:** For $R = \sqrt{a^2+b^2} > 0$, there exists $\alpha$ such that:
$$a\sin\theta + b\cos\theta = R\sin(\theta + \alpha)$$
where $\sin\alpha = \frac{b}{R}$, $\cos\alpha = \frac{a}{R}$.

**Proof:**
$$R\sin(\theta + \alpha) = R(\sin\theta\cos\alpha + \cos\theta\sin\alpha)$$
$$= (R\cos\alpha)\sin\theta + (R\sin\alpha)\cos\theta = a\sin\theta + b\cos\theta$$
provided $\cos\alpha = \frac{a}{R}$, $\sin\alpha = \frac{b}{R}$.
Since $\left(\frac{a}{R}\right)^2 + \left(\frac{b}{R}\right)^2 = 1$, such $\alpha$ exists uniquely modulo $2\pi$. $\square$

**Maximum value:** $R$, **Minimum value:** $-R$.

---

## 11. Absolute Value Identities

**Proof for $\sqrt{\sin^2\theta} = |\sin\theta|$:**
By definition, $\sqrt{x^2} = |x|$ for any real $x$.
Thus $\sqrt{\sin^2\theta} = |\sin\theta|$, not $\sin\theta$ (which could be negative). $\square$
