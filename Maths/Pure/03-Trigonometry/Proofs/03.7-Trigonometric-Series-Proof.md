# Proofs: Trigonometric Series

## 1. Sum of Sines/Cosines in Arithmetic Progression

### 1.1 $C + iS$ Method (Complex Numbers)

Let:
$$C = \sum_{k=0}^{n-1} \cos(\theta + k\alpha)$$
$$S = \sum_{k=0}^{n-1} \sin(\theta + k\alpha)$$

Using Euler's formula $e^{i\phi} = \cos\phi + i\sin\phi$:
$$C + iS = \sum_{k=0}^{n-1} e^{i(\theta + k\alpha)} = e^{i\theta} \sum_{k=0}^{n-1} (e^{i\alpha})^k$$

The sum is a geometric series with ratio $r = e^{i\alpha}$:
$$\sum_{k=0}^{n-1} r^k = \frac{1 - r^n}{1 - r} = \frac{1 - e^{in\alpha}}{1 - e^{i\alpha}}$$

Multiply numerator and denominator by $e^{-i\alpha/2}$:
$$\frac{e^{-in\alpha/2} - e^{in\alpha/2}}{e^{-i\alpha/2} - e^{i\alpha/2}} = \frac{-2i\sin\frac{n\alpha}{2}}{-2i\sin\frac{\alpha}{2}} = \frac{\sin\frac{n\alpha}{2}}{\sin\frac{\alpha}{2}} e^{i\frac{(n-1)\alpha}{2}}$$

Thus:
$$C + iS = e^{i\theta} \cdot \frac{\sin\frac{n\alpha}{2}}{\sin\frac{\alpha}{2}} e^{i\frac{(n-1)\alpha}{2}} = \frac{\sin\frac{n\alpha}{2}}{\sin\frac{\alpha}{2}} e^{i\left(\theta + \frac{(n-1)\alpha}{2}\right)}$$

Equating real and imaginary parts:

**Real part (C):**
$$C = \frac{\sin\left(\frac{n\alpha}{2}\right) \cos\left(\theta + \frac{(n-1)\alpha}{2}\right)}{\sin\left(\frac{\alpha}{2}\right)}$$

**Imaginary part (S):**
$$S = \frac{\sin\left(\frac{n\alpha}{2}\right) \sin\left(\theta + \frac{(n-1)\alpha}{2}\right)}{\sin\left(\frac{\alpha}{2}\right)}$$

**Condition:** $\sin\frac{\alpha}{2} \neq 0$, i.e., $\alpha \neq 2k\pi$. $\square$

---

### 1.2 Special Case: $\theta = 0$

$$\sum_{k=1}^{n} \cos k\alpha = \frac{\sin\frac{n\alpha}{2} \cos\frac{(n+1)\alpha}{2}}{\sin\frac{\alpha}{2}}$$
$$\sum_{k=1}^{n} \sin k\alpha = \frac{\sin\frac{n\alpha}{2} \sin\frac{(n+1)\alpha}{2}}{\sin\frac{\alpha}{2}}$$

**Proof:** Set $\theta = \alpha$ in general formula (shift index). $\square$

---

### 1.3 Special Case: $\alpha = \frac{2\pi}{n}$ (Roots of Unity)

$$\sum_{k=0}^{n-1} \cos\left(\theta + \frac{2k\pi}{n}\right) = 0$$
$$\sum_{k=0}^{n-1} \sin\left(\theta + \frac{2k\pi}{n}\right) = 0$$

**Proof:** $\sin\frac{n\alpha}{2} = \sin\pi = 0$, but limit as $\alpha \to \frac{2\pi}{n}$ gives 0. Alternatively, sum of $n$ equally spaced vectors on unit circle is zero. $\square$

## 2. Alternative Derivation Using Product-to-Sum

### 2.1 Formula for $2\sin\frac{\alpha}{2}\sin(\theta + k\alpha)$

Using $\sin A\sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$:
$$2\sin\frac{\alpha}{2}\sin(\theta + k\alpha) = \cos\left(\theta + k\alpha - \frac{\alpha}{2}\right) - \cos\left(\theta + k\alpha + \frac{\alpha}{2}\right)$$
$$= \cos\left(\theta + \frac{(2k-1)\alpha}{2}\right) - \cos\left(\theta + \frac{(2k+1)\alpha}{2}\right)$$

### 2.2 Telescoping Sum

Sum from $k=0$ to $n-1$:
$$2\sin\frac{\alpha}{2} \sum_{k=0}^{n-1} \sin(\theta + k\alpha) = \sum_{k=0}^{n-1} \left[\cos\left(\theta + \frac{(2k-1)\alpha}{2}\right) - \cos\left(\theta + \frac{(2k+1)\alpha}{2}\right)\right]$$

All intermediate terms cancel (telescoping):
$$= \cos\left(\theta - \frac{\alpha}{2}\right) - \cos\left(\theta + \frac{(2n-1)\alpha}{2}\right)$$

Using $\cos P - \cos Q = -2\sin\frac{P+Q}{2}\sin\frac{P-Q}{2}$:
$$= -2\sin\left(\theta + \frac{(n-1)\alpha}{2}\right)\sin\left(-\frac{n\alpha}{2}\right)$$
$$= 2\sin\left(\theta + \frac{(n-1)\alpha}{2}\right)\sin\frac{n\alpha}{2}$$

Dividing by $2\sin\frac{\alpha}{2}$:
$$\sum_{k=0}^{n-1} \sin(\theta + k\alpha) = \frac{\sin\frac{n\alpha}{2} \sin\left(\theta + \frac{(n-1)\alpha}{2}\right)}{\sin\frac{\alpha}{2}}$$

Similarly for cosines using $2\sin\frac{\alpha}{2}\cos(\theta + k\alpha)$. $\square$

## 3. Sum of Cosines in AP

Using similar method or taking real part of $C+iS$:

$$\sum_{k=0}^{n-1} \cos(\theta + k\alpha) = \frac{\sin\frac{n\alpha}{2} \cos\left(\theta + \frac{(n-1)\alpha}{2}\right)}{\sin\frac{\alpha}{2}}$$

## 4. Sum of $\cos k\theta$ and $\sin k\theta$ from $k=1$ to $n$

Set $\theta \to \alpha$, $\alpha \to \theta$:
$$\sum_{k=1}^{n} \cos k\theta = \frac{\sin\frac{n\theta}{2} \cos\frac{(n+1)\theta}{2}}{\sin\frac{\theta}{2}}$$
$$\sum_{k=1}^{n} \sin k\theta = \frac{\sin\frac{n\theta}{2} \sin\frac{(n+1)\theta}{2}}{\sin\frac{\theta}{2}}$$

---

## 5. Product-to-Sum and Sum-to-Product in Series

### 5.1 Sum of $\sin k\theta \sin(k+1)\theta$

Using $\sin A\sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$:
$$\sin k\theta \sin(k+1)\theta = \frac{1}{2}[\cos\theta - \cos(2k+1)\theta]$$

Sum:
$$\sum_{k=1}^{n} \sin k\theta \sin(k+1)\theta = \frac{n}{2}\cos\theta - \frac{1}{2}\sum_{k=1}^{n} \cos(2k+1)\theta$$

The remaining sum is a cosine series with first term $\cos 3\theta$, last $\cos(2n+1)\theta$, step $2\theta$.
Using formula:
$$\sum_{k=1}^{n} \cos(2k+1)\theta = \frac{\sin n\theta \cos(n+2)\theta}{\sin\theta}$$

### 5.2 Sum of $\cos k\theta \cos(k+1)\theta$

$$\cos k\theta \cos(k+1)\theta = \frac{1}{2}[\cos\theta + \cos(2k+1)\theta]$$

Sum:
$$\sum_{k=1}^{n} \cos k\theta \cos(k+1)\theta = \frac{n}{2}\cos\theta + \frac{1}{2}\sum_{k=1}^{n} \cos(2k+1)\theta$$

## 6. Sums of Powers

### 6.1 $\cos^2$ Series

$$\cos^2\theta = \frac{1+\cos 2\theta}{2}$$

$$\sum_{k=0}^{n-1} \cos^2(\theta + k\alpha) = \sum_{k=0}^{n-1} \frac{1+\cos(2\theta + 2k\alpha)}{2}$$
$$= \frac{n}{2} + \frac{1}{2}\sum_{k=0}^{n-1} \cos(2\theta + 2k\alpha)$$
$$= \frac{n}{2} + \frac{1}{2} \cdot \frac{\sin(n\alpha) \cos(2\theta + (n-1)\alpha)}{\sin\alpha}$$

### 6.2 $\sin^2$ Series

$$\sin^2\theta = \frac{1-\cos 2\theta}{2}$$

$$\sum_{k=0}^{n-1} \sin^2(\theta + k\alpha) = \frac{n}{2} - \frac{1}{2} \cdot \frac{\sin(n\alpha) \cos(2\theta + (n-1)\alpha)}{\sin\alpha}$$

## 7. Infinite Trigonometric Series

### 7.1 $\sum_{k=1}^\infty \frac{\sin k\theta}{k}$

Consider $f(\theta) = \sum_{k=1}^\infty \frac{\sin k\theta}{k}$.

Differentiate term by term (valid for $0 < \theta < 2\pi$):
$$f'(\theta) = \sum_{k=1}^\infty \cos k\theta = -\frac{1}{2} \quad (\text{for } \theta \neq 2m\pi)$$

Integrate:
$$f(\theta) = -\frac{\theta}{2} + C$$

At $\theta = \pi$: $f(\pi) = \sum \frac{\sin k\pi}{k} = 0 = -\frac{\pi}{2} + C \Rightarrow C = \frac{\pi}{2}$

Thus: $f(\theta) = \frac{\pi - \theta}{2}$ for $0 < \theta < 2\pi$. $\square$

### 7.2 $\sum_{k=1}^\infty \frac{\cos k\theta}{k}$

Consider $g(\theta) = \sum_{k=1}^\infty \frac{\cos k\theta}{k}$.

Differentiate:
$$g'(\theta) = -\sum_{k=1}^\infty \sin k\theta$$

But $\sum_{k=1}^\infty \sin k\theta$ diverges. Alternative: Use complex series.
$$\sum_{k=1}^\infty \frac{e^{ik\theta}}{k} = -\ln(1 - e^{i\theta}) \quad (\text{for } \theta \neq 2m\pi)$$

Real part:
$$\sum_{k=1}^\infty \frac{\cos k\theta}{k} = -\operatorname{Re}\ln(1 - e^{i\theta}) = -\frac{1}{2}\ln|1 - e^{i\theta}|^2$$
$$= -\frac{1}{2}\ln(2 - 2\cos\theta) = -\ln\left(2\sin\frac{\theta}{2}\right) \quad \square$$

## 8. Weighted Sums (e.g., $\sum k\sin k\theta$)

### 8.1 Using Derivative of Geometric Series

Let $r = e^{i\theta}$. Then:
$$\sum_{k=1}^n k r^k = \frac{r - (n+1)r^{n+1} + nr^{n+2}}{(1-r)^2}$$

Take imaginary part for $\sum k\sin k\theta$, real part for $\sum k\cos k\theta$.

Alternatively, use:
$$\sum_{k=1}^n k\sin k\theta = \frac{\sin(n+1)\theta - (n+1)\sin n\theta + n\sin(n+1)\theta}{(1-\cos\theta)^2 + \sin^2\theta} \cdots$$
Full formula available via standard results. $\square$
