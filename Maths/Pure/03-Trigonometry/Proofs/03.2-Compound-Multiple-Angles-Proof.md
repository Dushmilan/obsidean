# Proofs: Compound & Multiple Angles

## 1. Compound Angle Formulas

### 1.1 $\cos(A - B) = \cos A\cos B + \sin A\sin B$

**Proof (Unit Circle / Rotation Matrix):**
Let $P(\cos A, \sin A)$ and $Q(\cos B, \sin B)$ on unit circle.
Distance $PQ^2 = (\cos A - \cos B)^2 + (\sin A - \sin B)^2$
$= \cos^2 A - 2\cos A\cos B + \cos^2 B + \sin^2 A - 2\sin A\sin B + \sin^2 B$
$= 2 - 2(\cos A\cos B + \sin A\sin B)$.

Alternatively, rotate $Q$ by $-A$: new coordinates $(\cos B\cos A + \sin B\sin A, -\cos B\sin A + \sin B\cos A)$.
$x$-coordinate $= \cos(B-A) = \cos(B)\cos(A) + \sin(B)\sin(A)$.
Thus $\cos(A-B) = \cos A\cos B + \sin A\sin B$. $\square$

### 1.2 $\cos(A + B) = \cos A\cos B - \sin A\sin B$

**Proof:** Replace $B$ with $-B$ in $\cos(A-B)$:
$\cos(A + B) = \cos A\cos(-B) + \sin A\sin(-B) = \cos A\cos B - \sin A\sin B$. $\square$

### 1.3 $\sin(A + B) = \sin A\cos B + \cos A\sin B$

**Proof:** Use $\sin\theta = \cos(\frac{\pi}{2} - \theta)$:
$\sin(A+B) = \cos(\frac{\pi}{2} - A - B) = \cos((\frac{\pi}{2} - A) - B)$
$= \cos(\frac{\pi}{2} - A)\cos B + \sin(\frac{\pi}{2} - A)\sin B = \sin A\cos B + \cos A\sin B$. $\square$

### 1.4 $\sin(A - B) = \sin A\cos B - \cos A\sin B$

**Proof:** Replace $B$ with $-B$:
$\sin(A-B) = \sin A\cos(-B) + \cos A\sin(-B) = \sin A\cos B - \cos A\sin B$. $\square$

### 1.5 $\tan(A + B) = \frac{\tan A + \tan B}{1 - \tan A\tan B}$

**Proof:**
$$\tan(A+B) = \frac{\sin(A+B)}{\cos(A+B)} = \frac{\sin A\cos B + \cos A\sin B}{\cos A\cos B - \sin A\sin B}$$
Divide numerator and denominator by $\cos A\cos B$:
$$= \frac{\tan A + \tan B}{1 - \tan A\tan B} \quad \square$$

### 1.6 $\tan(A - B) = \frac{\tan A - \tan B}{1 + \tan A\tan B}$

**Proof:** Replace $B$ with $-B$: $\tan(-B) = -\tan B$. $\square$

## 2. Double Angle Formulas

### 2.1 $\sin 2\theta = 2\sin\theta\cos\theta$

**Proof:** Set $A = B = \theta$ in $\sin(A+B)$. $\square$

### 2.2 $\cos 2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta$

**Proof:** Set $A = B = \theta$ in $\cos(A+B)$:
$\cos 2\theta = \cos^2\theta - \sin^2\theta$.
Using $\sin^2\theta = 1 - \cos^2\theta$: $\cos 2\theta = 2\cos^2\theta - 1$.
Using $\cos^2\theta = 1 - \sin^2\theta$: $\cos 2\theta = 1 - 2\sin^2\theta$. $\square$

### 2.3 $\tan 2\theta = \frac{2\tan\theta}{1 - \tan^2\theta}$

**Proof:** Set $A = B = \theta$ in $\tan(A+B)$. $\square$

## 3. Triple Angle Formulas

### 3.1 $\sin 3\theta = 3\sin\theta - 4\sin^3\theta$

**Proof:**
$$\sin 3\theta = \sin(2\theta + \theta) = \sin 2\theta\cos\theta + \cos 2\theta\sin\theta$$
$$= (2\sin\theta\cos\theta)\cos\theta + (1 - 2\sin^2\theta)\sin\theta$$
$$= 2\sin\theta\cos^2\theta + \sin\theta - 2\sin^3\theta$$
$$= 2\sin\theta(1 - \sin^2\theta) + \sin\theta - 2\sin^3\theta$$
$$= 2\sin\theta - 2\sin^3\theta + \sin\theta - 2\sin^3\theta = 3\sin\theta - 4\sin^3\theta \quad \square$$

### 3.2 $\cos 3\theta = 4\cos^3\theta - 3\cos\theta$

**Proof:**
$$\cos 3\theta = \cos(2\theta + \theta) = \cos 2\theta\cos\theta - \sin 2\theta\sin\theta$$
$$= (2\cos^2\theta - 1)\cos\theta - (2\sin\theta\cos\theta)\sin\theta$$
$$= 2\cos^3\theta - \cos\theta - 2\sin^2\theta\cos\theta$$
$$= 2\cos^3\theta - \cos\theta - 2(1 - \cos^2\theta)\cos\theta$$
$$= 2\cos^3\theta - \cos\theta - 2\cos\theta + 2\cos^3\theta = 4\cos^3\theta - 3\cos\theta \quad \square$$

### 3.3 $\tan 3\theta = \frac{3\tan\theta - \tan^3\theta}{1 - 3\tan^2\theta}$

**Proof:**
$$\tan 3\theta = \tan(2\theta + \theta) = \frac{\tan 2\theta + \tan\theta}{1 - \tan 2\theta\tan\theta}$$
$$= \frac{\frac{2\tan\theta}{1-\tan^2\theta} + \tan\theta}{1 - \frac{2\tan\theta}{1-\tan^2\theta}\tan\theta} = \frac{2\tan\theta + \tan\theta(1-\tan^2\theta)}{1-\tan^2\theta - 2\tan^2\theta}$$
$$= \frac{3\tan\theta - \tan^3\theta}{1 - 3\tan^2\theta} \quad \square$$

## 4. Half Angle Formulas

### 4.1 $\sin\frac{\theta}{2} = \pm\sqrt{\frac{1 - \cos\theta}{2}}$

**Proof:** From $\cos\theta = 1 - 2\sin^2\frac{\theta}{2}$:
$2\sin^2\frac{\theta}{2} = 1 - \cos\theta \Rightarrow \sin\frac{\theta}{2} = \pm\sqrt{\frac{1-\cos\theta}{2}}$. $\square$

### 4.2 $\cos\frac{\theta}{2} = \pm\sqrt{\frac{1 + \cos\theta}{2}}$

**Proof:** From $\cos\theta = 2\cos^2\frac{\theta}{2} - 1$:
$2\cos^2\frac{\theta}{2} = 1 + \cos\theta \Rightarrow \cos\frac{\theta}{2} = \pm\sqrt{\frac{1+\cos\theta}{2}}$. $\square$

### 4.3 $\tan\frac{\theta}{2} = \frac{1 - \cos\theta}{\sin\theta} = \frac{\sin\theta}{1 + \cos\theta} = \pm\sqrt{\frac{1 - \cos\theta}{1 + \cos\theta}}$

**Proof:**
$$\frac{1 - \cos\theta}{\sin\theta} = \frac{2\sin^2\frac{\theta}{2}}{2\sin\frac{\theta}{2}\cos\frac{\theta}{2}} = \tan\frac{\theta}{2}$$
$$\frac{\sin\theta}{1 + \cos\theta} = \frac{2\sin\frac{\theta}{2}\cos\frac{\theta}{2}}{2\cos^2\frac{\theta}{2}} = \tan\frac{\theta}{2} \quad \square$$

## 5. Sum-to-Product Formulas

### 5.1 $\sin A + \sin B = 2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$

**Proof:**
Let $P = \frac{A+B}{2}$, $Q = \frac{A-B}{2}$. Then $A = P+Q$, $B = P-Q$.
$$\sin A + \sin B = \sin(P+Q) + \sin(P-Q)$$
$$= (\sin P\cos Q + \cos P\sin Q) + (\sin P\cos Q - \cos P\sin Q)$$
$$= 2\sin P\cos Q = 2\sin\frac{A+B}{2}\cos\frac{A-B}{2} \quad \square$$

### 5.2 $\sin A - \sin B = 2\cos\frac{A+B}{2}\sin\frac{A-B}{2}$

**Proof:** Similar with $P, Q$ as above:
$$\sin A - \sin B = \sin(P+Q) - \sin(P-Q) = 2\cos P\sin Q \quad \square$$

### 5.3 $\cos A + \cos B = 2\cos\frac{A+B}{2}\cos\frac{A-B}{2}$

**Proof:**
$$\cos A + \cos B = \cos(P+Q) + \cos(P-Q)$$
$$= (\cos P\cos Q - \sin P\sin Q) + (\cos P\cos Q + \sin P\sin Q)$$
$$= 2\cos P\cos Q \quad \square$$

### 5.4 $\cos A - \cos B = -2\sin\frac{A+B}{2}\sin\frac{A-B}{2}$

**Proof:**
$$\cos A - \cos B = \cos(P+Q) - \cos(P-Q) = -2\sin P\sin Q \quad \square$$

## 6. Product-to-Sum Formulas

### 6.1 $\sin A\sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$

**Proof:** From $\cos(A-B) = \cos A\cos B + \sin A\sin B$ and $\cos(A+B) = \cos A\cos B - \sin A\sin B$:
Subtract: $\cos(A-B) - \cos(A+B) = 2\sin A\sin B$. $\square$

### 6.2 $\cos A\cos B = \frac{1}{2}[\cos(A-B) + \cos(A+B)]$

**Proof:** Add the two cosine formulas. $\square$

### 6.3 $\sin A\cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$

**Proof:** $\sin(A+B) + \sin(A-B) = (\sin A\cos B + \cos A\sin B) + (\sin A\cos B - \cos A\sin B) = 2\sin A\cos B$. $\square$

## 7. Universal Substitution ($t = \tan\frac{\theta}{2}$)

### 7.1 $\sin\theta = \frac{2t}{1+t^2}$

**Proof:** $t = \tan\frac{\theta}{2}$. $\sin\theta = 2\sin\frac{\theta}{2}\cos\frac{\theta}{2} = 2\frac{t}{\sqrt{1+t^2}}\frac{1}{\sqrt{1+t^2}} = \frac{2t}{1+t^2}$. $\square$

### 7.2 $\cos\theta = \frac{1-t^2}{1+t^2}$

**Proof:** $\cos\theta = \cos^2\frac{\theta}{2} - \sin^2\frac{\theta}{2} = \frac{1}{1+t^2} - \frac{t^2}{1+t^2} = \frac{1-t^2}{1+t^2}$. $\square$

### 7.3 $\tan\theta = \frac{2t}{1-t^2}$

**Proof:** $\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{2t}{1-t^2}$. $\square$

## 8. $a\sin\theta + b\cos\theta = R\sin(\theta + \alpha)$

**Proof:**
Let $R = \sqrt{a^2+b^2}$, $\cos\alpha = \frac{a}{R}$, $\sin\alpha = \frac{b}{R}$.
Then $R\sin(\theta+\alpha) = R(\sin\theta\cos\alpha + \cos\theta\sin\alpha) = a\sin\theta + b\cos\theta$. $\square$
