# Proofs: Trigonometric Equations

## 1. General Solutions of Basic Equations

### 1.1 $\sin\theta = \sin\alpha$

**Proof:**
$\sin\theta - \sin\alpha = 0$
$2\cos\frac{\theta+\alpha}{2}\sin\frac{\theta-\alpha}{2} = 0$

Either $\cos\frac{\theta+\alpha}{2} = 0$ or $\sin\frac{\theta-\alpha}{2} = 0$.

**Case 1:** $\cos\frac{\theta+\alpha}{2} = 0 \Rightarrow \frac{\theta+\alpha}{2} = \frac{\pi}{2} + n\pi$
$\theta + \alpha = \pi + 2n\pi \Rightarrow \theta = \pi - \alpha + 2n\pi = (2n+1)\pi - \alpha$

**Case 2:** $\sin\frac{\theta-\alpha}{2} = 0 \Rightarrow \frac{\theta-\alpha}{2} = n\pi$
$\theta - \alpha = 2n\pi \Rightarrow \theta = \alpha + 2n\pi$

Combining: $\theta = n\pi + (-1)^n\alpha$. $\square$

### 1.2 $\cos\theta = \cos\alpha$

**Proof:**
$\cos\theta - \cos\alpha = 0$
$-2\sin\frac{\theta+\alpha}{2}\sin\frac{\theta-\alpha}{2} = 0$

Either $\sin\frac{\theta+\alpha}{2} = 0$ or $\sin\frac{\theta-\alpha}{2} = 0$.

**Case 1:** $\sin\frac{\theta+\alpha}{2} = 0 \Rightarrow \frac{\theta+\alpha}{2} = n\pi \Rightarrow \theta = -\alpha + 2n\pi$

**Case 2:** $\sin\frac{\theta-\alpha}{2} = 0 \Rightarrow \frac{\theta-\alpha}{2} = n\pi \Rightarrow \theta = \alpha + 2n\pi$

Combining: $\theta = 2n\pi \pm \alpha$. $\square$

### 1.3 $\tan\theta = \tan\alpha$

**Proof:**
$\tan\theta - \tan\alpha = 0 \Rightarrow \frac{\sin\theta}{\cos\theta} - \frac{\sin\alpha}{\cos\alpha} = 0$
$\frac{\sin\theta\cos\alpha - \cos\theta\sin\alpha}{\cos\theta\cos\alpha} = 0 \Rightarrow \sin(\theta - \alpha) = 0$
$\theta - \alpha = n\pi \Rightarrow \theta = \alpha + n\pi$. $\square$

## 2. Special Cases

### 2.1 $\sin\theta = 0$

**Proof:** $\sin\theta = \sin 0 \Rightarrow \theta = n\pi + (-1)^n \cdot 0 = n\pi$. $\square$

### 2.2 $\cos\theta = 0$

**Proof:** $\cos\theta = \cos\frac{\pi}{2} \Rightarrow \theta = 2n\pi \pm \frac{\pi}{2} = \frac{\pi}{2} + n\pi$. $\square$

### 2.3 $\tan\theta = 0$

**Proof:** $\tan\theta = \tan 0 \Rightarrow \theta = n\pi$. $\square$

## 3. Equations Reducible to Basic Forms

### 3.1 Factorisation Method

**Example:** $\sin\theta(2\cos\theta - 1) = 0$

**Proof of solutions:**
$\sin\theta = 0 \Rightarrow \theta = n\pi$
$2\cos\theta - 1 = 0 \Rightarrow \cos\theta = \frac{1}{2} \Rightarrow \theta = 2n\pi \pm \frac{\pi}{3}$

Union of solutions gives complete set. $\square$

### 3.2 $a\sin\theta + b\cos\theta = c$

**Method:** Write as $R\sin(\theta + \alpha) = c$ where $R = \sqrt{a^2+b^2}$, $\tan\alpha = \frac{b}{a}$.

**Proof of condition for solutions:**
$|R\sin(\theta + \alpha)| \le R \Rightarrow |c| \le R = \sqrt{a^2+b^2}$.
If $|c| > \sqrt{a^2+b^2}$, no solution exists. $\square$

**General solution:**
$\sin(\theta + \alpha) = \frac{c}{R} \Rightarrow \theta + \alpha = n\pi + (-1)^n\sin^{-1}\frac{c}{R}$
$\theta = n\pi + (-1)^n\sin^{-1}\frac{c}{R} - \alpha$. $\square$

## 4. Equations with Multiple Angles

### 4.1 $\sin n\theta = \sin\alpha$

**Proof:** Let $\phi = n\theta$. Then $\sin\phi = \sin\alpha \Rightarrow \phi = m\pi + (-1)^m\alpha$.
Thus $n\theta = m\pi + (-1)^m\alpha \Rightarrow \theta = \frac{m\pi}{n} + (-1)^m\frac{\alpha}{n}$.

**Note:** For $n$ even, period is $\frac{\pi}{n}$; for $n$ odd, period is $\frac{2\pi}{n}$. $\square$

### 4.2 $\cos n\theta = \cos\alpha$

**Proof:** $n\theta = 2m\pi \pm \alpha \Rightarrow \theta = \frac{2m\pi}{n} \pm \frac{\alpha}{n}$. $\square$

### 4.3 $\tan n\theta = \tan\alpha$

**Proof:** $n\theta = m\pi + \alpha \Rightarrow \theta = \frac{m\pi}{n} + \frac{\alpha}{n}$. $\square$

---

## 5. Mixed Multiple Angle Equations

### 5.1 $\sin 2\theta = \cos\theta$

**Proof:**
$2\sin\theta\cos\theta = \cos\theta$
$\cos\theta(2\sin\theta - 1) = 0$

Either $\cos\theta = 0 \Rightarrow \theta = \frac{\pi}{2} + n\pi$
Or $2\sin\theta - 1 = 0 \Rightarrow \sin\theta = \frac{1}{2} \Rightarrow \theta = n\pi + (-1)^n\frac{\pi}{6}$ $\square$

### 5.2 $\sin n\theta = \cos m\theta$

**Method:** Convert to same function:
$\sin n\theta = \sin(\frac{\pi}{2} - m\theta)$
$n\theta = k\pi + (-1)^k(\frac{\pi}{2} - m\theta)$

Solve for $\theta$ in terms of $k$. $\square$

## 6. Quadratic in Trigonometric Functions

### 6.1 $a\sin^2\theta + b\sin\theta + c = 0$

**Proof:** Let $u = \sin\theta$. Solve $au^2 + bu + c = 0$ for $u$.
For each valid root $u \in [-1, 1]$, solve $\sin\theta = u$.
$\theta = n\pi + (-1)^n\sin^{-1}u$. $\square$

### 6.2 Using $\sin^2\theta = 1 - \cos^2\theta$ or $\cos^2\theta = 1 - \sin^2\theta$

**Proof:** Substitute to get equation in single trig function, solve as above. $\square$

## 7. Universal Substitution Method

### 7.1 $t = \tan\frac{\theta}{2}$

**Proof of formulas:**
$\sin\theta = \frac{2t}{1+t^2}$, $\cos\theta = \frac{1-t^2}{1+t^2}$, $\tan\theta = \frac{2t}{1-t^2}$

**Application:** Any rational equation in $\sin\theta$, $\cos\theta$ becomes polynomial in $t$.

**Caution:** $t$ undefined when $\theta = \pi + 2k\pi$. Check $\theta = \pi + 2k\pi$ separately. $\square$

---

## 8. Trigonometric Inequalities

### 8.1 $\sin\theta > k$ or $\cos\theta > k$

**Method:**
1. Solve equality $\sin\theta = k$ or $\cos\theta = k$ for boundary points.
2. Use graph/unit circle to determine intervals where inequality holds.
3. Write general solution by adding $2n\pi$.

**Example:** $\sin\theta > \frac{1}{2}$
Boundary: $\sin\theta = \frac{1}{2} \Rightarrow \theta = \frac{\pi}{6}, \frac{5\pi}{6}$ in $[0, 2\pi)$
$\sin\theta > \frac{1}{2}$ for $\theta \in (\frac{\pi}{6}, \frac{5\pi}{6})$
General: $\theta \in (2n\pi + \frac{\pi}{6}, 2n\pi + \frac{5\pi}{6})$. $\square$

---

## 9. Verification of Solutions

### 9.1 Extraneous Roots

**Source:** Squaring both sides, multiplying by variable expression, using universal substitution without checking $\theta = \pi$.

**Proof that verification needed:**
If $\sin\theta = k$, squaring gives $\sin^2\theta = k^2 \Rightarrow \sin\theta = \pm k$.
Introduces solutions of $\sin\theta = -k$ which may not satisfy original.

**Always:** Substitute each candidate back into original equation. $\square$
