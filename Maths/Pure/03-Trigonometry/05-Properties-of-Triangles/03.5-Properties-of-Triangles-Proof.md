### Theorem
In any $\triangle ABC$: $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$

### Proof

**Part 1: $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$**

Drop perpendicular from $A$ to $BC$ at $D$.

In $\triangle ABD$: $\sin B = \frac{AD}{c} \Rightarrow AD = c\sin B$

In $\triangle ACD$: $\sin C = \frac{AD}{b} \Rightarrow AD = b\sin C$

Equating: $c\sin B = b\sin C \Rightarrow \frac{b}{\sin B} = \frac{c}{\sin C}$

Similarly, dropping perpendicular from $B$ to $AC$: $\frac{a}{\sin A} = \frac{c}{\sin C}$

Thus $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$. $\square$

**Part 2: $\frac{a}{\sin A} = 2R$ (Circumradius)**

Let $O$ be circumcentre. Draw diameter $BOB'$ through $O$, join $B'C$.

$\angle B' = \angle A$ (angles in same segment).

In right $\triangle BB'C$ (angle in semicircle): $\sin B' = \frac{BC}{BB'} = \frac{a}{2R}$

But $\sin B' = \sin A$, so $\sin A = \frac{a}{2R} \Rightarrow \frac{a}{\sin A} = 2R$. $\square$

### Theorem
$a^2 = b^2 + c^2 - 2bc\cos A$

### Proof

**Method 1: Using Coordinates**
Place $A$ at origin, $AB$ along positive $x$-axis.
$A = (0, 0)$, $B = (c, 0)$, $C = (b\cos A, b\sin A)$

$BC^2 = a^2 = (c - b\cos A)^2 + (b\sin A)^2$
$= c^2 - 2bc\cos A + b^2\cos^2 A + b^2\sin^2 A$
$= b^2 + c^2 - 2bc\cos A$. $\square$

**Method 2: Using Perpendiculars**
Drop $AD \perp BC$.

Case 1: $D$ lies on $BC$ (acute $A$)
$BD = c\cos B$, $DC = b\cos C$, $AD = c\sin B = b\sin C$

$a = BD + DC = c\cos B + b\cos C$

Also $b^2 = AD^2 + DC^2 = c^2\sin^2 B + (b - c\cos B)^2$
$= c^2\sin^2 B + b^2 - 2bc\cos B + c^2\cos^2 B$
$= b^2 + c^2 - 2bc\cos B$

But we want $a^2$. Using symmetry: $a^2 = b^2 + c^2 - 2bc\cos A$. $\square$

### Theorem
$a = b\cos C + c\cos B$


**Using Cosine Rule:**
$b\cos C + c\cos B = b\left(\frac{a^2+b^2-c^2}{2ab}\right) + c\left(\frac{a^2+c^2-b^2}{2ac}\right)$
$= \frac{a^2+b^2-c^2}{2a} + \frac{a^2+c^2-b^2}{2a} = \frac{2a^2}{2a} = a$. $\square$

**Geometric Proof:**
Drop perpendicular $AD$ on $BC$.
$BD = c\cos B$, $DC = b\cos C$
$a = BC = BD + DC = c\cos B + b\cos C$. $\square$

### Theorem
$\sin\frac{A}{2} = \sqrt{\frac{(s-b)(s-c)}{bc}}$
$\cos\frac{A}{2} = \sqrt{\frac{s(s-a)}{bc}}$
$\tan\frac{A}{2} = \sqrt{\frac{(s-b)(s-c)}{s(s-a)}} = \frac{r}{s-a}$


**$\cos A$ from cosine rule:**
$\cos A = \frac{b^2+c^2-a^2}{2bc} = \frac{(b+c)^2-a^2 - 2bc}{2bc} = \frac{(b+c-a)(b+c+a)}{2bc} - 1$
$= \frac{2(s-a) \cdot 2s}{2bc} - 1 = \frac{2s(s-a)}{bc} - 1$

**Using $\sin^2\frac{A}{2} = \frac{1-\cos A}{2}$:**
$\sin^2\frac{A}{2} = \frac{1}{2}\left(2 - \frac{2s(s-a)}{bc}\right) = \frac{bc - s(s-a)}{bc}$

But $bc - s(s-a) = bc - \frac{(a+b+c)(b+c-a)}{4} = \frac{4bc - (b+c)^2 + a^2}{4}$
$= \frac{4bc - b^2 - 2bc - c^2 + a^2}{4} = \frac{a^2 - (b-c)^2}{4} = \frac{(a-b+c)(a+b-c)}{4} = \frac{2(s-b) \cdot 2(s-c)}{4} = (s-b)(s-c)$

Thus $\sin\frac{A}{2} = \sqrt{\frac{(s-b)(s-c)}{bc}}$. $\square$

**$\cos\frac{A}{2}$:**
$\cos^2\frac{A}{2} = \frac{1+\cos A}{2} = \frac{1}{2}\left(\frac{2s(s-a)}{bc}\right) = \frac{s(s-a)}{bc}$. $\square$

**$\tan\frac{A}{2}$:**
$\tan\frac{A}{2} = \frac{\sin\frac{A}{2}}{\cos\frac{A}{2}} = \sqrt{\frac{(s-b)(s-c)}{s(s-a)}} = \frac{r}{s-a}$ (since $r = \frac{\Delta}{s} = \frac{\sqrt{s(s-a)(s-b)(s-c)}}{s}$). $\square$

### Theorem
$\tan\frac{B-C}{2} = \frac{b-c}{b+c}\cot\frac{A}{2}$

### Proof

From Sine Rule: $\frac{b}{\sin B} = \frac{c}{\sin C} = 2R$

$\frac{b-c}{b+c} = \frac{\sin B - \sin C}{\sin B + \sin C}$
$= \frac{2\cos\frac{B+C}{2}\sin\frac{B-C}{2}}{2\sin\frac{B+C}{2}\cos\frac{B-C}{2}}$
$= \cot\frac{B+C}{2}\tan\frac{B-C}{2} = \tan\frac{A}{2}\tan\frac{B-C}{2}$

Thus $\tan\frac{B-C}{2} = \frac{b-c}{b+c}\cot\frac{A}{2}$. $\square$

### 9.1 Equilateral Triangle
$a=b=c$, $A=B=C=60^\circ$
$R = \frac{a}{\sqrt{3}}$, $r = \frac{a}{2\sqrt{3}}$, $\Delta = \frac{\sqrt{3}}{4}a^2$, $R = 2r$

### 9.2 Right Triangle ($C = 90^\circ$)
$R = \frac{c}{2}$ (circumcentre = midpoint of hypotenuse)
$r = \frac{a+b-c}{2} = s-c$
Orthocentre = vertex $C$

### 9.3 Isosceles Triangle ($a=b$)
$R = \frac{a^2}{2\sqrt{4a^2-c^2}}$, $r = \frac{c}{2}\sqrt{\frac{2a-c}{2a+c}}$
