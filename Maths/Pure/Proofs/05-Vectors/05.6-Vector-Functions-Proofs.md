# Vector Functions — Full Derivations

## 1. Derivative Definition

$$\mathbf{r}'(t) = \lim_{h \to 0} \frac{\mathbf{r}(t+h) - \mathbf{r}(t)}{h} = \lim_{h \to 0} \frac{x(t+h)-x(t)}{h}\mathbf{i} + \cdots = x'(t)\mathbf{i} + y'(t)\mathbf{j} + z'(t)\mathbf{k}$$

---

## 2. Differentiation Rules

### 2.1 Sum
$$\frac{d}{dt}(\mathbf{u}+\mathbf{v}) = \mathbf{u}' + \mathbf{v}'$$

### 2.2 Scalar Multiplication
$$\frac{d}{dt}(f\mathbf{u}) = f'\mathbf{u} + f\mathbf{u}'$$

### 2.3 Dot Product
$$\frac{d}{dt}(\mathbf{u} \cdot \mathbf{v}) = \mathbf{u}' \cdot \mathbf{v} + \mathbf{u} \cdot \mathbf{v}'$$

**Proof:**
$$\mathbf{u} \cdot \mathbf{v} = u_1v_1 + u_2v_2 + u_3v_3$$
$$\frac{d}{dt} = u_1'v_1 + u_1v_1' + u_2'v_2 + u_2v_2' + u_3'v_3 + u_3v_3' = \mathbf{u}' \cdot \mathbf{v} + \mathbf{u} \cdot \mathbf{v}'$$

### 2.4 Cross Product
$$\frac{d}{dt}(\mathbf{u} \times \mathbf{v}) = \mathbf{u}' \times \mathbf{v} + \mathbf{u} \times \mathbf{v}'$$

**Proof:** Component-wise or use determinant expansion.

## 3. Arc Length

### 3.1 Derivation
Partition $[a,b]$ into $n$ subintervals. Chord length on $[t_{i-1}, t_i]$:
$$\|\mathbf{r}(t_i) - \mathbf{r}(t_{i-1})\| = \|\mathbf{r}'(c_i)\| \Delta t_i \quad \text{(MVT)}$$
$$L = \lim_{n \to \infty} \sum \|\mathbf{r}'(c_i)\| \Delta t_i = \int_a^b \|\mathbf{r}'(t)\| dt$$

### 3.2 Arc Length Parameter
$$s(t) = \int_{t_0}^t \|\mathbf{r}'(u)\| du \Rightarrow \frac{ds}{dt} = \|\mathbf{r}'(t)\|$$
$$\frac{d\mathbf{r}}{ds} = \frac{d\mathbf{r}/dt}{ds/dt} = \frac{\mathbf{r}'(t)}{\|\mathbf{r}'(t)\|}, \quad \left\|\frac{d\mathbf{r}}{ds}\right\| = 1$$

---

## 4. Curvature

### 4.1 Definition
$$\kappa = \left\|\frac{d\mathbf{T}}{ds}\right\|, \quad \mathbf{T}(s) = \frac{d\mathbf{r}}{ds}$$

### 4.2 Formula in Terms of $t$
$$\mathbf{T} = \frac{\mathbf{r}'}{\|\mathbf{r}'\|}$$
$$\frac{d\mathbf{T}}{dt} = \frac{\mathbf{r}''\|\mathbf{r}'\| - \mathbf{r}'\frac{d}{dt}\|\mathbf{r}'\|}{\|\mathbf{r}'\|^2}$$
Since $\mathbf{T} \cdot \mathbf{T} = 1$, differentiate: $2\mathbf{T} \cdot \frac{d\mathbf{T}}{dt} = 0$, so $\frac{d\mathbf{T}}{dt} \perp \mathbf{T}$.

$$\frac{d\mathbf{T}}{ds} = \frac{d\mathbf{T}/dt}{ds/dt} = \frac{1}{\|\mathbf{r}'\|}\frac{d\mathbf{T}}{dt}$$

Using vector identity:
$$\kappa = \frac{\|\mathbf{r}' \times \mathbf{r}''\|}{\|\mathbf{r}'\|^3}$$

**Proof:**
$$\mathbf{r}' \times \mathbf{r}'' = \|\mathbf{r}'\|^3 \frac{d\mathbf{T}}{ds} \times \mathbf{T} \quad \text{(after algebra)}$$
Taking magnitude: $\|\mathbf{r}' \times \mathbf{r}''\| = \|\mathbf{r}'\|^3 \kappa$.

---

## 5. Kinematics

### 5.1 Velocity and Acceleration
$$\mathbf{v} = \mathbf{r}', \quad \mathbf{a} = \mathbf{r}''$$

### 5.2 Speed and Tangential/Normal Components
$$v = \|\mathbf{v}\|$$
$$\mathbf{a} = \frac{dv}{dt}\mathbf{T} + v^2\kappa\mathbf{N}$$
where $\mathbf{N} = \frac{1}{\kappa}\frac{d\mathbf{T}}{ds}$ (unit normal).

**Proof:**
$$\mathbf{v} = v\mathbf{T}$$
$$\mathbf{a} = \frac{dv}{dt}\mathbf{T} + v\frac{d\mathbf{T}}{dt} = \frac{dv}{dt}\mathbf{T} + v\frac{d\mathbf{T}}{ds}\frac{ds}{dt} = \frac{dv}{dt}\mathbf{T} + v^2\kappa\mathbf{N}$$

### 5.3 Circular Motion
$\mathbf{r}(t) = R\cos(\omega t)\mathbf{i} + R\sin(\omega t)\mathbf{j}$
$\mathbf{v} = -R\omega\sin(\omega t)\mathbf{i} + R\omega\cos(\omega t)\mathbf{j}$
$\|\mathbf{v}\| = R\omega$
$\mathbf{a} = -R\omega^2\cos(\omega t)\mathbf{i} - R\omega^2\sin(\omega t)\mathbf{j} = -\omega^2\mathbf{r}$

Centripetal acceleration magnitude: $R\omega^2 = \frac{v^2}{R}$, direction toward centre.

---

## 6. Integration

### 6.1 Component-wise
$$\int \mathbf{r}(t) dt = \left(\int x(t) dt\right)\mathbf{i} + \left(\int y(t) dt\right)\mathbf{j} + \left(\int z(t) dt\right)\mathbf{k} + \mathbf{c}$$

### 6.2 From Acceleration to Position
$$\mathbf{v}(t) = \int \mathbf{a}(t) dt + \mathbf{v}_0$$
$$\mathbf{r}(t) = \int \mathbf{v}(t) dt + \mathbf{r}_0$$

---

## 7. Tangent Vector and Line

### 7.1 Tangent Line
At $t = t_0$: $\mathbf{r} = \mathbf{r}(t_0) + \lambda \mathbf{r}'(t_0)$

### 7.2 Normal Plane
Plane through $\mathbf{r}(t_0)$ perpendicular to $\mathbf{r}'(t_0)$:
$$(\mathbf{r} - \mathbf{r}(t_0)) \cdot \mathbf{r}'(t_0) = 0$$
