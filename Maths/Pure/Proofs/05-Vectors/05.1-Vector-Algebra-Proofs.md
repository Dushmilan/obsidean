# Vector Algebra — Full Derivations

## 1. Vector Operations

### 1.1 Addition
For $\mathbf{a} = a_1\mathbf{i} + a_2\mathbf{j} + a_3\mathbf{k}$ and $\mathbf{b} = b_1\mathbf{i} + b_2\mathbf{j} + b_3\mathbf{k}$:
$$\mathbf{a} + \mathbf{b} = (a_1+b_1)\mathbf{i} + (a_2+b_2)\mathbf{j} + (a_3+b_3)\mathbf{k}$$

**Commutativity:** $\mathbf{a} + \mathbf{b} = \mathbf{b} + \mathbf{a}$ (component-wise)
**Associativity:** $(\mathbf{a} + \mathbf{b}) + \mathbf{c} = \mathbf{a} + (\mathbf{b} + \mathbf{c})$ (component-wise)

### 1.2 Scalar Multiplication
$$k\mathbf{a} = (ka_1)\mathbf{i} + (ka_2)\mathbf{j} + (ka_3)\mathbf{k}$$

**Magnitude:** $\|k\mathbf{a}\| = \sqrt{(ka_1)^2 + (ka_2)^2 + (ka_3)^2} = |k|\|\mathbf{a}\|$

## 2. Position Vectors

### 2.1 Vector Between Points
$A(\mathbf{a})$, $B(\mathbf{b})$. Position vectors relative to origin $O$:
$$\overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA} = \mathbf{b} - \mathbf{a}$$

**Proof:** $\overrightarrow{OA} + \overrightarrow{AB} = \overrightarrow{OB}$ (triangle law)

### 2.2 Section Formula
If $P$ divides $AB$ in ratio $m:n$ (internally):
$$\overrightarrow{AP} = \frac{m}{m+n}\overrightarrow{AB}$$
$$\mathbf{p} = \mathbf{a} + \frac{m}{m+n}(\mathbf{b} - \mathbf{a}) = \frac{n\mathbf{a} + m\mathbf{b}}{m+n}$$

For external division, one of $m,n$ is negative.

## 3. Linear Independence

### 3.1 Definition
Vectors $\{\mathbf{v}_1, \dots, \mathbf{v}_k\}$ are linearly independent iff:
$$\alpha_1\mathbf{v}_1 + \cdots + \alpha_k\mathbf{v}_k = \mathbf{0} \implies \alpha_1 = \cdots = \alpha_k = 0$$

### 3.2 In $\mathbb{R}^3$
- 2 vectors: dependent $\iff$ one is scalar multiple of the other (collinear)
- 3 vectors: dependent $\iff$ they are coplanar
- 4+ vectors: always dependent

### 3.3 Determinant Test
Matrix $M = [\mathbf{v}_1 \; \mathbf{v}_2 \; \mathbf{v}_3]$ (vectors as columns).
$\det M \neq 0 \iff \mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3$ linearly independent.

**Proof:** $\det M = 0 \iff \exists \mathbf{x} \neq \mathbf{0}$ such that $M\mathbf{x} = \mathbf{0} \iff \sum x_i \mathbf{v}_i = \mathbf{0}$.

## 4. Basis and Dimension

### 4.1 Standard Basis
$\mathcal{B} = \{\mathbf{i}, \mathbf{j}, \mathbf{k}\}$ with $\mathbf{i} = (1,0,0)$, etc.
Any $\mathbf{v} = v_1\mathbf{i} + v_2\mathbf{j} + v_3\mathbf{k}$ uniquely.

### 4.2 General Basis
$\{\mathbf{e}_1, \mathbf{e}_2, \mathbf{e}_3\}$ is a basis iff linearly independent and spans $\mathbb{R}^3$.
Coordinates relative to basis: $\mathbf{v} = x_1\mathbf{e}_1 + x_2\mathbf{e}_2 + x_3\mathbf{e}_3$.

### 4.3 Change of Basis
If $\mathbf{e}_i' = \sum_j P_{ji} \mathbf{e}_j$, then coordinates transform as $\mathbf{x}' = P^{-1}\mathbf{x}$.

## 5. Direction Cosines

### 5.1 Definition
For $\mathbf{a} = a_1\mathbf{i} + a_2\mathbf{j} + a_3\mathbf{k}$ with $\|\mathbf{a}\| > 0$:
$$\cos\alpha = \frac{a_1}{\|\mathbf{a}\|}, \quad \cos\beta = \frac{a_2}{\|\mathbf{a}\|}, \quad \cos\gamma = \frac{a_3}{\|\mathbf{a}\|}$$

### 5.2 Identity
$$\cos^2\alpha + \cos^2\beta + \cos^2\gamma = \frac{a_1^2 + a_2^2 + a_3^2}{\|\mathbf{a}\|^2} = 1$$

**Proof:** Unit vector $\hat{\mathbf{a}} = \frac{\mathbf{a}}{\|\mathbf{a}\|} = \cos\alpha \mathbf{i} + \cos\beta \mathbf{j} + \cos\gamma \mathbf{k}$, and $\|\hat{\mathbf{a}}\| = 1$.

## 6. Vector Equation of a Line

Line through $\mathbf{a}$ parallel to $\mathbf{b}$:
$$\mathbf{r} = \mathbf{a} + \lambda \mathbf{b}, \quad \lambda \in \mathbb{R}$$

**Proof:** For any point $\mathbf{r}$ on line, $\overrightarrow{\mathbf{a}\mathbf{r}} \parallel \mathbf{b}$, so $\mathbf{r} - \mathbf{a} = \lambda \mathbf{b}$.
