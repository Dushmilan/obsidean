# Applications of Differentiation — Full Derivations

## 1. Tangent and Normal Lines

### Tangent Line Derivation
For curve $y = f(x)$ at point $P(x_0, y_0)$ where $y_0 = f(x_0)$:

The slope of the tangent is the derivative:
$$m = f'(x_0) = \lim_{h \to 0} \frac{f(x_0+h) - f(x_0)}{h}$$

Using point-slope form of a line:
$$y - y_0 = m(x - x_0) = f'(x_0)(x - x_0)$$

### Normal Line Derivation
The normal is perpendicular to the tangent. If $m$ is the tangent slope, normal slope is $m_\perp = -1/m$ (provided $m \neq 0$):
$$y - y_0 = -\frac{1}{f'(x_0)}(x - x_0)$$

**Special cases:**
- Horizontal tangent ($f'(x_0) = 0$): tangent $y = y_0$, normal $x = x_0$
- Vertical tangent ($f'(x_0)$ undefined): tangent $x = x_0$, normal $y = y_0$

---

## 2. Tangent/Normal to Parametric Curves

Given $x = f(t)$, $y = g(t)$:
$$\frac{dy}{dx} = \frac{g'(t)}{f'(t)} \quad (f'(t) \neq 0)$$

At parameter $t = t_0$:
- Point: $(x_0, y_0) = (f(t_0), g(t_0))$
- Slope: $m = \frac{g'(t_0)}{f'(t_0)}$
- Tangent: $y - g(t_0) = \frac{g'(t_0)}{f'(t_0)}(x - f(t_0))$

**Derivation:** By chain rule, $\frac{dy}{dt} = \frac{dy}{dx} \cdot \frac{dx}{dt} \Rightarrow \frac{dy}{dx} = \frac{dy/dt}{dx/dt}$.

---

## 3. Stationary Points and Extrema

### Fermat's Theorem (Necessary Condition)
If $f$ has a local extremum at $c$ and $f'(c)$ exists, then $f'(c) = 0$.

**Proof:** Suppose $f$ has local maximum at $c$. For $h > 0$ small:
$$\frac{f(c+h) - f(c)}{h} \le 0 \quad \text{and} \quad \frac{f(c-h) - f(c)}{-h} \ge 0$$
Taking $h \to 0^+$ and $h \to 0^-$ gives $f'(c) \le 0$ and $f'(c) \ge 0$, so $f'(c) = 0$.

---

## 4. Second Derivative Test

**Theorem:** Let $f$ be twice differentiable near $c$ with $f'(c) = 0$.
- If $f''(c) > 0$, then $f$ has a local minimum at $c$.
- If $f''(c) < 0$, then $f$ has a local maximum at $c$.
- If $f''(c) = 0$, test is inconclusive.

**Proof (for $f''(c) > 0$):**
By definition of derivative:
$$f''(c) = \lim_{h \to 0} \frac{f'(c+h) - f'(c)}{h} = \lim_{h \to 0} \frac{f'(c+h)}{h} > 0$$

For sufficiently small $h$:
- If $h > 0$, then $f'(c+h)/h > 0 \Rightarrow f'(c+h) > 0$
- If $h < 0$, then $f'(c+h)/h > 0 \Rightarrow f'(c+h) < 0$

So $f'$ changes from negative to positive at $c$ ⇒ local minimum.

---

## 5. First Derivative Test (Complete)

**Theorem:** Let $f$ be continuous at $c$ and differentiable on $(c-\delta, c) \cup (c, c+\delta)$.
- If $f'$ changes from $+$ to $-$ at $c$ ⇒ local maximum
- If $f'$ changes from $-$ to $+$ at $c$ ⇒ local minimum
- If $f'$ does not change sign ⇒ not an extremum (possible inflection)

**Proof:** Direct consequence of Mean Value Theorem and monotonicity.

---

## 6. Extreme Value Theorem (EVT)

**Theorem:** If $f$ is continuous on closed interval $[a,b]$, then $f$ attains both absolute maximum and absolute minimum on $[a,b]$.

**Proof Sketch:** 
- $f([a,b])$ is compact (continuous image of compact set)
- In $\mathbb{R}$, compact = closed and bounded
- Bounded $\Rightarrow$ $\sup$ and $\inf$ exist
- Closed $\Rightarrow$ $\sup$ and $\inf$ are attained

**Corollary:** To find absolute extrema on $[a,b]$:
1. Find critical points in $(a,b)$
2. Evaluate $f$ at critical points and endpoints $a, b$
3. Largest = absolute max, smallest = absolute min

---

## 7. Mean Value Theorem (MVT) — Lagrange

**Theorem:** If $f$ continuous on $[a,b]$, differentiable on $(a,b)$, then $\exists c \in (a,b)$:
$$f'(c) = \frac{f(b) - f(a)}{b - a}$$

**Proof:**
Define $g(x) = f(x) - \frac{f(b)-f(a)}{b-a}(x-a) - f(a)$.
Then $g(a) = g(b) = 0$. $g$ satisfies Rolle's Theorem conditions.
$\exists c \in (a,b): g'(c) = 0$.
$g'(x) = f'(x) - \frac{f(b)-f(a)}{b-a} \Rightarrow f'(c) = \frac{f(b)-f(a)}{b-a}$.

---

## 8. Rolle's Theorem

**Theorem:** If $f$ continuous on $[a,b]$, differentiable on $(a,b)$, and $f(a) = f(b)$, then $\exists c \in (a,b): f'(c) = 0$.

**Proof:**
- $f$ attains max and min on $[a,b]$ (EVT)
- If both at endpoints $\Rightarrow$ $f$ constant $\Rightarrow$ $f' \equiv 0$
- Otherwise, extremum at some $c \in (a,b)$ $\Rightarrow$ $f'(c) = 0$ (Fermat)

---

## 9. Cauchy Mean Value Theorem

**Theorem:** If $f,g$ continuous on $[a,b]$, differentiable on $(a,b)$, $g'(x) \neq 0$, then $\exists c \in (a,b)$:
$$\frac{f'(c)}{g'(c)} = \frac{f(b)-f(a)}{g(b)-g(a)}$$

**Proof:** Apply Rolle's Theorem to:
$$h(x) = f(x) - f(a) - \frac{f(b)-f(a)}{g(b)-g(a)}(g(x)-g(a))$$

---

## 10. L'Hôpital's Rule (Complete Proof)

### $0/0$ Case
**Theorem:** If $\lim_{x \to a} f(x) = \lim_{x \to a} g(x) = 0$, $f,g$ differentiable near $a$, $g'(x) \neq 0$, and $\lim_{x \to a} \frac{f'(x)}{g'(x)}$ exists, then
$$\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}$$

**Proof (Cauchy MVT):**
For $x \neq a$ near $a$, apply Cauchy MVT on $[a,x]$ (or $[x,a]$):
$$\frac{f(x)-f(a)}{g(x)-g(a)} = \frac{f'(c)}{g'(c)} \quad (c \text{ between } a \text{ and } x)$$
Since $f(a)=g(a)=0$, $\frac{f(x)}{g(x)} = \frac{f'(c)}{g'(c)}$.
As $x \to a$, $c \to a$, so RHS $\to \lim_{c \to a} \frac{f'(c)}{g'(c)}$.

### $\infty/\infty$ Case
**Proof:** Write $\frac{f}{g} = \frac{1/g}{1/f}$ and apply $0/0$ case to reciprocals, or use Cauchy MVT directly on $f/g$ after algebraic manipulation.

---

## 11. Taylor's Theorem with Lagrange Remainder

**Theorem:** If $f \in C^{n+1}(I)$ for interval $I$ containing $a$, then $\forall x \in I$:
$$f(x) = \sum_{k=0}^n \frac{f^{(k)}(a)}{k!}(x-a)^k + R_n(x)$$
where $R_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}$ for some $c$ between $a$ and $x$.

**Proof:**
Fix $x \neq a$. Define $g(t) = f(t) - \sum_{k=0}^n \frac{f^{(k)}(t)}{k!}(x-t)^k - M\frac{(x-t)^{n+1}}{(n+1)!}$ where $M$ is chosen so $g(a) = 0$.
Then $g(x) = 0$. By Rolle's Theorem, $g'(c_1)=0$, $g''(c_2)=0$, ..., $g^{(n+1)}(c)=0$ for some $c$ between $a$ and $x$.
Computing $g^{(n+1)}(t) = f^{(n+1)}(t) - M$ gives $M = f^{(n+1)}(c)$.

**Maclaurin Series:** Special case $a=0$.
$$f(x) = \sum_{k=0}^n \frac{f^{(k)}(0)}{k!}x^k + \frac{f^{(n+1)}(c)}{(n+1)!}x^{n+1}$$

## 12. Convexity and Concavity

### Definitions
- $f$ is **convex** on $I$ if $f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda)f(y)$ for all $x,y \in I$, $\lambda \in [0,1]$
- $f$ is **concave** if $-f$ is convex

### Second Derivative Test for Convexity
**Theorem:** If $f''(x) \ge 0$ on $I$, then $f$ is convex on $I$. If $f''(x) \le 0$, $f$ is concave.

**Proof (convex case):** By Taylor's theorem with remainder:
$$f(y) = f(x) + f'(x)(y-x) + \frac{f''(c)}{2}(y-x)^2 \ge f(x) + f'(x)(y-x)$$
since $f''(c) \ge 0$. This is the tangent line inequality characterising convexity.

---

## 13. Inflection Points

**Definition:** $c$ is an inflection point if $f$ changes concavity at $c$ (from convex to concave or vice versa).

**Necessary condition:** If $f''(c)$ exists, then $f''(c) = 0$ at inflection point.

**Note:** $f''(c) = 0$ is NOT sufficient (e.g., $f(x) = x^4$ at $x=0$). Must check sign change of $f''$.

---

## 14. Newton's Method Convergence Analysis

### Iteration Formula
For $f(r) = 0$, $f'(r) \neq 0$:
$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

### Error Recurrence
Let $e_n = x_n - r$. By Taylor expansion:
$$f(x_n) = f(r + e_n) = f'(r)e_n + \frac{f''(c_n)}{2}e_n^2$$
$$f'(x_n) = f'(r + e_n) = f'(r) + f''(c_n')e_n$$

Substituting:
$$e_{n+1} = e_n - \frac{f'(r)e_n + \frac{f''(c_n)}{2}e_n^2}{f'(r) + f''(c_n')e_n} = \frac{f''(c_n)}{2f'(r)} e_n^2 + O(e_n^3)$$

Thus $|e_{n+1}| \approx \frac{|f''(r)|}{2|f'(r)|} |e_n|^2$ — **quadratic convergence**.

## 15. Optimisation with Constraints (Lagrange Multipliers)

### Theorem (Lagrange Multipliers)
To optimise $f(x,y)$ subject to $g(x,y) = 0$, solve:
$$\nabla f = \lambda \nabla g \quad \text{and} \quad g(x,y) = 0$$

**Proof (intuitive):** At constrained extremum, $\nabla f$ must be orthogonal to the constraint surface, so parallel to $\nabla g$.

### Generalisation to $n$ variables, $m$ constraints
Optimise $f(\mathbf{x})$ subject to $g_1(\mathbf{x}) = \cdots = g_m(\mathbf{x}) = 0$:
$$\nabla f = \sum_{i=1}^m \lambda_i \nabla g_i$$

## 16. Related Rates — General Derivation

If variables $x, y, z, \dots$ related by equation $F(x,y,z,\dots) = 0$, and all depend on time $t$:
$$\frac{d}{dt}F(x(t), y(t), z(t), \dots) = \frac{\partial F}{\partial x}\frac{dx}{dt} + \frac{\partial F}{\partial y}\frac{dy}{dt} + \frac{\partial F}{\partial z}\frac{dz}{dt} + \cdots = 0$$

This is the **multivariable chain rule** applied to the constraint.

### Example: Conical Tank
Volume $V = \frac{1}{3}\pi r^2 h$. By similar triangles, $r/h = R/H = k$ (constant).
So $r = kh$, $V = \frac{1}{3}\pi k^2 h^3$.
$$\frac{dV}{dt} = \pi k^2 h^2 \frac{dh}{dt} \Rightarrow \frac{dh}{dt} = \frac{1}{\pi k^2 h^2} \frac{dV}{dt}$$

## 17. Tangent Line Approximation (Linear Approximation)

For $f$ differentiable at $a$:
$$f(x) \approx f(a) + f'(a)(x-a) \quad \text{for } x \text{ near } a$$

**Error bound:** If $|f''(x)| \le M$ on interval $I$, then for $x \in I$:
$$|f(x) - [f(a) + f'(a)(x-a)]| \le \frac{M}{2}|x-a|^2$$

---

## 18. Curvature of Plane Curves

For $y = f(x)$, curvature at $x$:
$$\kappa(x) = \frac{|f''(x)|}{(1 + [f'(x)]^2)^{3/2}}$$

**Derivation:** For parametric curve $(x(t), y(t))$, $\kappa = \frac{|x'y'' - y'x''|}{(x'^2 + y'^2)^{3/2}}$. Set $x=t$, $y=f(t)$.

**Radius of curvature:** $R = 1/\kappa$.

---

## 19. Asymptotes — Formal Treatment

### Vertical Asymptote
$x = a$ is a vertical asymptote iff $\lim_{x \to a^\pm} f(x) = \pm\infty$.

### Horizontal Asymptote
$y = L$ is a horizontal asymptote iff $\lim_{x \to \pm\infty} f(x) = L$.

### Oblique Asymptote
$y = mx + c$ is an oblique asymptote iff
$$\lim_{x \to \pm\infty} [f(x) - (mx + c)] = 0$$
with $m = \lim_{x \to \pm\infty} \frac{f(x)}{x}$, $c = \lim_{x \to \pm\infty} [f(x) - mx]$.

**Rational functions:** If $f(x) = P(x)/Q(x)$ with $\deg P = \deg Q + 1$, perform polynomial division to find oblique asymptote.

---

## 20. Curve Sketching — Theoretical Foundation

The complete sketch of $y = f(x)$ is determined by:

1. **Domain** — from algebraic definition
2. **Intercepts** — solve $f(x)=0$, evaluate $f(0)$
3. **Symmetry** — $f(-x) = f(x)$ (even), $f(-x) = -f(x)$ (odd)
4. **Asymptotes** — limits at boundaries and infinity
5. **Critical points** — $f'(x) = 0$ or undefined
6. **Monotonicity** — sign of $f'$ on intervals
7. **Extrema** — First/Second Derivative Test
8. **Concavity** — sign of $f''$
9. **Inflection points** — where $f''$ changes sign
10. **Behaviour at boundaries** — limits at domain edges

**Theorem:** Two continuous functions with same monotonicity intervals, concavity intervals, and same limits at boundaries have the same qualitative shape.
