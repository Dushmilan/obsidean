# Integration — Full Derivations

## 1. Antiderivatives and Indefinite Integral

### Definition
$F$ is an **antiderivative** of $f$ on interval $I$ if $F'(x) = f(x)$ for all $x \in I$.

### Uniqueness Theorem
If $F_1$ and $F_2$ are antiderivatives of $f$ on $I$, then $F_1(x) - F_2(x) = C$ (constant) on $I$.

**Proof:** Let $G(x) = F_1(x) - F_2(x)$. Then $G'(x) = F_1'(x) - F_2'(x) = f(x) - f(x) = 0$. By MVT, $G$ is constant on $I$.

### Notation
$\int f(x)\,dx = F(x) + C$ denotes the **family** of all antiderivatives.

## 2. Basic Integration Rules (Derived from Derivatives)

### Constant Rule
$$\int k\,dx = kx + C \quad \text{since } \frac{d}{dx}(kx + C) = k$$

### Power Rule ($n \neq -1$)
$$\int x^n\,dx = \frac{x^{n+1}}{n+1} + C \quad \text{since } \frac{d}{dx}\left(\frac{x^{n+1}}{n+1}\right) = x^n$$

### Power Rule ($n = -1$)
$$\int \frac{1}{x}\,dx = \ln|x| + C$$

**Proof:** For $x > 0$, $\frac{d}{dx}\ln x = \frac{1}{x}$. For $x < 0$, let $u = -x > 0$, $\frac{d}{dx}\ln|x| = \frac{d}{dx}\ln(-x) = \frac{1}{-x}(-1) = \frac{1}{x}$. So $\frac{d}{dx}\ln|x| = \frac{1}{x}$ for all $x \neq 0$.

### Sum/Difference Rule
$$\int [f(x) \pm g(x)]\,dx = \int f(x)\,dx \pm \int g(x)\,dx$$

**Proof:** $(F \pm G)' = F' \pm G' = f \pm g$.

### Constant Multiple Rule
$$\int k f(x)\,dx = k \int f(x)\,dx$$

**Proof:** $(kF)' = kF' = kf$.

## 3. Standard Integrals (Direct from Derivatives)

### Exponential & Logarithmic
| Derivative | Integral |
|------------|----------|
| $\frac{d}{dx}e^x = e^x$ | $\int e^x\,dx = e^x + C$ |
| $\frac{d}{dx}e^{ax} = ae^{ax}$ | $\int e^{ax}\,dx = \frac{1}{a}e^{ax} + C$ |
| $\frac{d}{dx}a^x = a^x\ln a$ | $\int a^x\,dx = \frac{a^x}{\ln a} + C$ |

### Trigonometric
| Derivative | Integral |
|------------|----------|
| $\frac{d}{dx}\sin x = \cos x$ | $\int \cos x\,dx = \sin x + C$ |
| $\frac{d}{dx}\cos x = -\sin x$ | $\int \sin x\,dx = -\cos x + C$ |
| $\frac{d}{dx}\tan x = \sec^2 x$ | $\int \sec^2 x\,dx = \tan x + C$ |
| $\frac{d}{dx}\cot x = -\csc^2 x$ | $\int \csc^2 x\,dx = -\cot x + C$ |
| $\frac{d}{dx}\sec x = \sec x\tan x$ | $\int \sec x\tan x\,dx = \sec x + C$ |
| $\frac{d}{dx}\csc x = -\csc x\cot x$ | $\int \csc x\cot x\,dx = -\csc x + C$ |

### Inverse Trigonometric
| Derivative | Integral |
|------------|----------|
| $\frac{d}{dx}\sin^{-1}\frac{x}{a} = \frac{1}{\sqrt{a^2-x^2}}$ | $\int \frac{dx}{\sqrt{a^2-x^2}} = \sin^{-1}\frac{x}{a} + C$ |
| $\frac{d}{dx}\tan^{-1}\frac{x}{a} = \frac{a}{a^2+x^2}$ | $\int \frac{dx}{a^2+x^2} = \frac{1}{a}\tan^{-1}\frac{x}{a} + C$ |
| $\frac{d}{dx}\sec^{-1}\left|\frac{x}{a}\right| = \frac{a}{x\sqrt{x^2-a^2}}$ | $\int \frac{dx}{x\sqrt{x^2-a^2}} = \frac{1}{a}\sec^{-1}\left|\frac{x}{a}\right| + C$ |

## 4. Integration by Substitution (Change of Variable)

### Indefinite Integral
**Theorem:** If $u = g(x)$ is differentiable and $f$ is continuous on range of $g$, then
$$\int f(g(x))g'(x)\,dx = \int f(u)\,du$$

**Proof:** Let $F$ be antiderivative of $f$. By chain rule:
$$\frac{d}{dx}F(g(x)) = F'(g(x))g'(x) = f(g(x))g'(x)$$
So $F(g(x))$ is antiderivative of $f(g(x))g'(x)$. But $\int f(u)\,du = F(u) + C = F(g(x)) + C$. ✓

### Definite Integral
**Theorem:** $\int_a^b f(g(x))g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du$

**Proof:** By FTC and chain rule:
$$\int_a^b f(g(x))g'(x)\,dx = F(g(x))\Big|_a^b = F(g(b)) - F(g(a)) = \int_{g(a)}^{g(b)} f(u)\,du$$

## 5. Integration by Parts

### Theorem
$$\int u\,dv = uv - \int v\,du$$
or
$$\int u(x)v'(x)\,dx = u(x)v(x) - \int u'(x)v(x)\,dx$$

### Proof
Product rule: $(uv)' = u'v + uv'$.
Integrate both sides:
$$\int (uv)'\,dx = \int u'v\,dx + \int uv'\,dx$$
$$uv = \int u'v\,dx + \int uv'\,dx$$
$$\int uv'\,dx = uv - \int u'v\,dx$$

### Definite Version
$$\int_a^b u\,dv = uv\Big|_a^b - \int_a^b v\,du$$

### Tabular Integration (DI Method)
For $\int P(x)e^{ax}\,dx$, $\int P(x)\sin(ax)\,dx$, $\int P(x)\cos(ax)\,dx$ where $P$ is polynomial:

| D (Differentiate) | I (Integrate) | Sign |
|-------------------|---------------|------|
| $P(x)$ | $f(x)$ | $+$ |
| $P'(x)$ | $\int f$ | $-$ |
| $P''(x)$ | $\int\int f$ | $+$ |
| $\vdots$ | $\vdots$ | $\vdots$ |
| $0$ | | |

Result = sum of diagonal products with signs.

**Justification:** Repeated application of integration by parts.

## 6. Partial Fractions Decomposition

### Theorem
Any rational function $\frac{P(x)}{Q(x)}$ with $\deg P < \deg Q$ can be decomposed into:
- $\frac{A}{(ax+b)^k}$ for linear factors
- $\frac{Bx+C}{(ax^2+bx+c)^k}$ for irreducible quadratics ($b^2 - 4ac < 0$)

### Proof Sketch
1. Factor $Q(x)$ over $\mathbb{R}$ (linear + irreducible quadratics)
2. Write ansatz with unknown constants
3. Multiply by $Q(x)$ → polynomial identity
4. Solve linear system (unique solution exists by linear algebra)

### Integration of Components
- $\int \frac{A}{ax+b}\,dx = \frac{A}{a}\ln|ax+b| + C$
- $\int \frac{A}{(ax+b)^k}\,dx = \frac{A}{a(1-k)(ax+b)^{k-1}} + C$ ($k > 1$)
- $\int \frac{Bx+C}{ax^2+bx+c}\,dx$:
  - Split: $Bx+C = \frac{B}{2a}(2ax+b) + \left(C - \frac{Bb}{2a}\right)$
  - First part: $\frac{B}{2a}\ln|ax^2+bx+c|$
  - Second part: complete square $\to$ arctan or log

## 7. Trigonometric Integrals

### $\int \sin^m x \cos^n x\,dx$

**Case 1: $m$ odd** ($m = 2k+1$)
$$\int \sin^{2k+1} x \cos^n x\,dx = \int \sin x (1-\cos^2 x)^k \cos^n x\,dx$$
Let $u = \cos x$, $du = -\sin x\,dx$:
$$= -\int (1-u^2)^k u^n\,du \quad \text{(polynomial in $u$)}$$

**Case 2: $n$ odd** ($n = 2k+1$)
$$\int \sin^m x \cos^{2k+1} x\,dx = \int \sin^m x (1-\sin^2 x)^k \cos x\,dx$$
Let $u = \sin x$, $du = \cos x\,dx$:
$$= \int u^m (1-u^2)^k\,du$$

**Case 3: Both even**
Use power reduction:
$$\sin^2 x = \frac{1-\cos 2x}{2}, \quad \cos^2 x = \frac{1+\cos 2x}{2}$$
Reduce powers iteratively.

### $\int \tan^m x \sec^n x\,dx$

**Case 1: $n$ even** ($n = 2k$)
$$\int \tan^m x \sec^{2k} x\,dx = \int \tan^m x (1+\tan^2 x)^{k-1} \sec^2 x\,dx$$
Let $u = \tan x$, $du = \sec^2 x\,dx$:
$$= \int u^m (1+u^2)^{k-1}\,du$$

**Case 2: $m$ odd** ($m = 2k+1$)
$$\int \tan^{2k+1} x \sec^n x\,dx = \int \tan x (\sec^2 x - 1)^k \sec^n x\,dx$$
$$= \int (\sec^2 x - 1)^k \sec^{n-1} x \cdot \sec x \tan x\,dx$$
Let $u = \sec x$, $du = \sec x \tan x\,dx$:
$$= \int (u^2 - 1)^k u^{n-1}\,du$$

### Product-to-Sum Identities
$$\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$$
$$\sin A \sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$$
$$\cos A \cos B = \frac{1}{2}[\cos(A-B) + \cos(A+B)]$$

## 8. Riemann Integral — Rigorous Definition

### Partition
$P = \{x_0, x_1, \dots, x_n\}$ with $a = x_0 < x_1 < \cdots < x_n = b$
$\Delta x_i = x_i - x_{i-1}$, $||P|| = \max \Delta x_i$

### Riemann Sum
Choose sample points $x_i^* \in [x_{i-1}, x_i]$.
$$S(P, f) = \sum_{i=1}^n f(x_i^*)\Delta x_i$$

### Definition
$f$ is **Riemann integrable** on $[a,b]$ if $\lim_{||P||\to 0} S(P, f)$ exists and is independent of sample points.
$$\int_a^b f(x)\,dx = \lim_{||P||\to 0} \sum_{i=1}^n f(x_i^*)\Delta x_i$$

### Integrability Theorems
1. **Continuous $\Rightarrow$ Integrable:** If $f \in C[a,b]$, then $f$ is Riemann integrable.
2. **Monotone $\Rightarrow$ Integrable:** If $f$ monotone on $[a,b]$, then integrable.
3. **Finitely many discontinuities $\Rightarrow$ Integrable:** Jump discontinuities allowed.

### Darboux Sums (Equivalent Definition)
$m_i = \inf_{[x_{i-1},x_i]} f$, $M_i = \sup_{[x_{i-1},x_i]} f$
Lower sum: $L(P, f) = \sum m_i \Delta x_i$
Upper sum: $U(P, f) = \sum M_i \Delta x_i$

$f$ integrable $\iff \sup_P L(P, f) = \inf_P U(P, f)$

## 9. Fundamental Theorem of Calculus (FTC)

### FTC Part 1
If $f$ continuous on $[a,b]$, define $g(x) = \int_a^x f(t)\,dt$ for $x \in [a,b]$.
Then $g$ is differentiable on $(a,b)$ and $g'(x) = f(x)$.

**Proof:**
$$g'(x) = \lim_{h \to 0} \frac{g(x+h) - g(x)}{h} = \lim_{h \to 0} \frac{1}{h} \int_x^{x+h} f(t)\,dt$$
Since $f$ continuous, for small $h$, $f(t) \approx f(x)$ on $[x, x+h]$.
By MVT for integrals, $\exists c \in [x, x+h]: \int_x^{x+h} f(t)\,dt = f(c) \cdot h$.
As $h \to 0$, $c \to x$, so $f(c) \to f(x)$.
Thus $g'(x) = f(x)$.

### FTC Part 2 (Evaluation Theorem)
If $f$ continuous on $[a,b]$ and $F$ is any antiderivative of $f$, then
$$\int_a^b f(x)\,dx = F(b) - F(a)$$

**Proof:** Let $g(x) = \int_a^x f(t)\,dt$. By Part 1, $g'(x) = f(x)$.
So $g$ and $F$ have same derivative $\Rightarrow g(x) = F(x) + C$.
$g(a) = 0 = F(a) + C \Rightarrow C = -F(a)$.
$g(b) = F(b) - F(a)$. But $g(b) = \int_a^b f(t)\,dt$. ✓

## 10. Properties of Definite Integrals

| Property | Statement | Proof |
|----------|-----------|-------|
| **Linearity** | $\int_a^b [cf + g] = c\int_a^b f + \int_a^b g$ | Limit of Riemann sums |
| **Additivity** | $\int_a^b f + \int_b^c f = \int_a^c f$ | Combine partitions |
| **Reversal** | $\int_a^b f = -\int_b^a f$ | $\Delta x_i$ sign change |
| **Comparison** | $f \le g \Rightarrow \int_a^b f \le \int_a^b g$ | $f(x_i^*) \le g(x_i^*)$ termwise |
| **Mean Value** | $\exists c \in [a,b]: \int_a^b f = f(c)(b-a)$ | Apply MVT to $F(x) = \int_a^x f$ |

## 11. Improper Integrals

### Type 1: Infinite Limits
$$\int_a^\infty f(x)\,dx = \lim_{b \to \infty} \int_a^b f(x)\,dx$$
$$\int_{-\infty}^b f(x)\,dx = \lim_{a \to -\infty} \int_a^b f(x)\,dx$$
$$\int_{-\infty}^\infty f(x)\,dx = \int_{-\infty}^c f + \int_c^\infty f$$

**Converges** if limit exists and is finite; **diverges** otherwise.

### Type 2: Discontinuous Integrand
If $f$ has vertical asymptote at $c \in (a,b)$:
$$\int_a^b f(x)\,dx = \lim_{t \to c^-} \int_a^t f + \lim_{t \to c^+} \int_t^b f$$

If $f$ has asymptote at $a$:
$$\int_a^b f(x)\,dx = \lim_{t \to a^+} \int_t^b f$$

### p-Integrals
| Integral | Converges if | Value (if converges) |
|----------|--------------|---------------------|
| $\int_1^\infty x^{-p}\,dx$ | $p > 1$ | $\frac{1}{p-1}$ |
| $\int_0^1 x^{-p}\,dx$ | $p < 1$ | $\frac{1}{1-p}$ |

### Comparison Tests
**Direct Comparison:** If $0 \le f(x) \le g(x)$ on $[a,\infty)$:
- $\int_a^\infty g$ converges $\Rightarrow$ $\int_a^\infty f$ converges
- $\int_a^\infty f$ diverges $\Rightarrow$ $\int_a^\infty g$ diverges

**Limit Comparison:** If $\lim_{x\to\infty} \frac{f(x)}{g(x)} = L$ with $0 < L < \infty$:
- $\int_a^\infty f$ and $\int_a^\infty g$ both converge or both diverge

## 12. Symmetry Properties

### Even Functions ($f(-x) = f(x)$)
$$\int_{-a}^a f(x)\,dx = 2\int_0^a f(x)\,dx$$

**Proof:** $\int_{-a}^a f = \int_{-a}^0 f + \int_0^a f$. Let $u = -x$ in first integral:
$\int_{-a}^0 f(x)\,dx = \int_a^0 f(-u)(-du) = \int_0^a f(u)\,du = \int_0^a f$.

### Odd Functions ($f(-x) = -f(x)$)
$$\int_{-a}^a f(x)\,dx = 0$$

**Proof:** $\int_{-a}^0 f = -\int_0^a f$ by same substitution.

### Periodic Functions ($f(x+T) = f(x)$)
$$\int_a^{a+T} f(x)\,dx = \int_0^T f(x)\,dx \quad \text{for any } a$$

## 13. Reduction Formulas

### $\int \sin^n x\,dx$ ($n \ge 2$)
$$I_n = \int \sin^n x\,dx = -\frac{1}{n}\sin^{n-1}x\cos x + \frac{n-1}{n}I_{n-2}$$

**Proof:** $I_n = \int \sin^{n-1}x \sin x\,dx$. Integration by parts: $u = \sin^{n-1}x$, $dv = \sin x\,dx$.
$du = (n-1)\sin^{n-2}x\cos x\,dx$, $v = -\cos x$.
$I_n = -\sin^{n-1}x\cos x + (n-1)\int \sin^{n-2}x\cos^2 x\,dx$.
Use $\cos^2 x = 1 - \sin^2 x$: $I_n = -\sin^{n-1}x\cos x + (n-1)(I_{n-2} - I_n)$.
Solve for $I_n$: $nI_n = -\sin^{n-1}x\cos x + (n-1)I_{n-2}$. ✓

### $\int \cos^n x\,dx$
$$I_n = \frac{1}{n}\cos^{n-1}x\sin x + \frac{n-1}{n}I_{n-2}$$

### $\int \tan^n x\,dx$ ($n \ge 2$)
$$I_n = \frac{1}{n-1}\tan^{n-1}x - I_{n-2}$$

**Proof:** $\tan^n x = \tan^{n-2}x(\sec^2 x - 1) = \tan^{n-2}x\sec^2 x - \tan^{n-2}x$.
$I_n = \int \tan^{n-2}x\sec^2 x\,dx - I_{n-2} = \frac{1}{n-1}\tan^{n-1}x - I_{n-2}$.

### $\int \sec^n x\,dx$ ($n \ge 2$)
$$I_n = \frac{1}{n-1}\sec^{n-2}x\tan x + \frac{n-2}{n-1}I_{n-2}$$

**Proof:** $I_n = \int \sec^{n-2}x\sec^2 x\,dx$. Parts: $u = \sec^{n-2}x$, $dv = \sec^2 x\,dx$.

## 14. Special Integrals

### $\int \frac{f'(x)}{f(x)}\,dx = \ln|f(x)| + C$
**Proof:** $u = f(x)$, $du = f'(x)dx \Rightarrow \int \frac{du}{u} = \ln|u| + C$.

### $\int \tan x\,dx = \ln|\sec x| + C$
$\tan x = \frac{\sin x}{\cos x}$, let $u = \cos x$: $\int \frac{-du}{u} = -\ln|u| + C = \ln|\sec x| + C$.

### $\int \sec x\,dx = \ln|\sec x + \tan x| + C$
Multiply by $\frac{\sec x + \tan x}{\sec x + \tan x}$:
$$\int \frac{\sec x(\sec x + \tan x)}{\sec x + \tan x}\,dx = \int \frac{\sec^2 x + \sec x\tan x}{\sec x + \tan x}\,dx$$
Let $u = \sec x + \tan x$, $du = (\sec x\tan x + \sec^2 x)\,dx$:
$$= \int \frac{du}{u} = \ln|u| + C = \ln|\sec x + \tan x| + C$$

### $\int \csc x\,dx = \ln|\csc x - \cot x| + C$
Similar trick: multiply by $\frac{\csc x + \cot x}{\csc x + \cot x}$.

## 15. Change of Variables in Definite Integrals (Rigorous)

### Theorem
If $\varphi \in C^1([\alpha,\beta])$ and $f$ continuous on $\varphi([\alpha,\beta])$, then
$$\int_{\varphi(\alpha)}^{\varphi(\beta)} f(x)\,dx = \int_\alpha^\beta f(\varphi(t))\varphi'(t)\,dt$$

**Proof:** Let $F$ be antiderivative of $f$. By FTC:
$$\int_{\varphi(\alpha)}^{\varphi(\beta)} f(x)\,dx = F(\varphi(\beta)) - F(\varphi(\alpha))$$
Define $G(t) = F(\varphi(t))$. Then $G'(t) = F'(\varphi(t))\varphi'(t) = f(\varphi(t))\varphi'(t)$.
So $\int_\alpha^\beta f(\varphi(t))\varphi'(t)\,dt = G(\beta) - G(\alpha) = F(\varphi(\beta)) - F(\varphi(\alpha))$. ✓

## 16. Mean Value Theorem for Integrals

### Theorem
If $f$ continuous on $[a,b]$, $\exists c \in [a,b]$ such that
$$\int_a^b f(x)\,dx = f(c)(b-a)$$

**Proof:** By EVT, $m \le f(x) \le M$ on $[a,b]$. Then $m(b-a) \le \int_a^b f \le M(b-a)$.
So $\frac{1}{b-a}\int_a^b f \in [m, M]$. By IVT, $\exists c: f(c) = \frac{1}{b-a}\int_a^b f$. ✓

### Generalised MVT (Cauchy)
If $f,g$ continuous on $[a,b]$, $g \ge 0$, $\exists c \in [a,b]$:
$$\int_a^b f(x)g(x)\,dx = f(c)\int_a^b g(x)\,dx$$

## 17. Differentiation Under the Integral Sign (Leibniz Rule)

### Theorem
If $f(x,t)$ and $\frac{\partial f}{\partial t}$ continuous on $[a,b] \times [c,d]$, then
$$\frac{d}{dt} \int_a^b f(x,t)\,dx = \int_a^b \frac{\partial f}{\partial t}(x,t)\,dx$$

**Proof:** Let $F(t) = \int_a^b f(x,t)\,dx$.
$$\frac{F(t+h) - F(t)}{h} = \int_a^b \frac{f(x,t+h) - f(x,t)}{h}\,dx$$
As $h \to 0$, integrand $\to \frac{\partial f}{\partial t}(x,t)$ uniformly (by continuity of partial).
Limit and integral can be interchanged. ✓

### Leibniz Rule (Variable Limits)
$$\frac{d}{dx} \int_{g(x)}^{h(x)} f(t)\,dt = f(h(x))h'(x) - f(g(x))g'(x)$$

**Proof:** Let $F(x) = \int_a^x f(t)\,dt$. Then $\int_{g(x)}^{h(x)} f = F(h(x)) - F(g(x))$.
Differentiate: $F'(h(x))h'(x) - F'(g(x))g'(x) = f(h(x))h'(x) - f(g(x))g'(x)$. ✓

## 18. Beta and Gamma Functions (Preview)

### Gamma Function
$$\Gamma(z) = \int_0^\infty t^{z-1}e^{-t}\,dt \quad (\Re(z) > 0)$$

**Properties:**
- $\Gamma(n) = (n-1)!$ for $n \in \mathbb{N}$
- $\Gamma(z+1) = z\Gamma(z)$
- $\Gamma(1/2) = \sqrt{\pi}$

### Beta Function
$$B(x,y) = \int_0^1 t^{x-1}(1-t)^{y-1}\,dt = \frac{\Gamma(x)\Gamma(y)}{\Gamma(x+y)} \quad (\Re(x),\Re(y) > 0)$$

**Relation:** $B(x,y) = 2\int_0^{\pi/2} \sin^{2x-1}\theta \cos^{2y-1}\theta\,d\theta$

## 19. Numerical Integration (Preview)

### Trapezoidal Rule
$$\int_a^b f(x)\,dx \approx \frac{b-a}{2}[f(a) + f(b)]$$
Error: $-\frac{(b-a)^3}{12}f''(\xi)$

### Simpson's Rule
$$\int_a^b f(x)\,dx \approx \frac{b-a}{6}\left[f(a) + 4f\left(\frac{a+b}{2}\right) + f(b)\right]$$
Error: $-\frac{(b-a)^5}{90 \cdot 2^4}f^{(4)}(\xi)$
