# Differential Equations — Full Derivations

## 1. First-Order Equations

### 1.1 Separable Equations
**Form:** $\frac{dy}{dx} = g(x)h(y)$

**Derivation:**
$$\frac{1}{h(y)} \frac{dy}{dx} = g(x)$$
Integrate both sides wrt $x$:
$$\int \frac{1}{h(y)} \frac{dy}{dx} dx = \int g(x) dx$$
$$\int \frac{1}{h(y)} dy = \int g(x) dx + C$$

**General Solution:** $H(y) = G(x) + C$ where $H' = 1/h$, $G' = g$.

---

### 1.2 Linear First-Order Equations
**Form:** $\frac{dy}{dx} + P(x)y = Q(x)$

**Integrating Factor:**
$$\mu(x) = e^{\int P(x) dx}$$

**Derivation:**
Multiply equation by $\mu$:
$$\mu \frac{dy}{dx} + \mu P(x) y = \mu Q(x)$$
Left side is $\frac{d}{dx}(\mu y)$ since $\frac{d\mu}{dx} = \mu P(x)$:
$$\frac{d}{dx}(\mu y) = \mu Q(x)$$
Integrate:
$$\mu y = \int \mu Q(x) dx + C$$
$$y = \frac{1}{\mu} \left( \int \mu Q(x) dx + C \right)$$

---

### 1.3 Homogeneous Equations
**Form:** $\frac{dy}{dx} = F\left(\frac{y}{x}\right)$

**Substitution:** $v = \frac{y}{x} \Rightarrow y = vx, \frac{dy}{dx} = v + x\frac{dv}{dx}$

**Derivation:**
$$v + x\frac{dv}{dx} = F(v)$$
$$x\frac{dv}{dx} = F(v) - v$$
$$\frac{dv}{F(v) - v} = \frac{dx}{x}$$
Integrate both sides (separable).

---

### 1.4 Exact Equations
**Form:** $M(x,y) dx + N(x,y) dy = 0$

**Condition for Exactness:**
$$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$$

**Derivation:**
If exact, $\exists \psi(x,y)$ such that $d\psi = M dx + N dy = 0$.
Then $\frac{\partial \psi}{\partial x} = M$, $\frac{\partial \psi}{\partial y} = N$.
$$\psi(x,y) = \int M dx + g(y)$$
Differentiate wrt $y$:
$$\frac{\partial \psi}{\partial y} = \frac{\partial}{\partial y}\int M dx + g'(y) = N$$
Solve for $g'(y)$, integrate to get $g(y)$.
General solution: $\psi(x,y) = C$.

**Integrating Factor for Non-Exact:**
If $\frac{M_y - N_x}{N}$ is function of $x$ only: $\mu(x) = e^{\int \frac{M_y - N_x}{N} dx}$
If $\frac{N_x - M_y}{M}$ is function of $y$ only: $\mu(y) = e^{\int \frac{N_x - M_y}{M} dy}$

---

### 1.5 Bernoulli Equation
**Form:** $\frac{dy}{dx} + P(x)y = Q(x)y^n$ ($n \neq 0,1$)

**Substitution:** $v = y^{1-n}$

**Derivation:**
Divide by $y^n$:
$$y^{-n}\frac{dy}{dx} + P(x)y^{1-n} = Q(x)$$
Let $v = y^{1-n}$, then $\frac{dv}{dx} = (1-n)y^{-n}\frac{dy}{dx}$
$$\frac{1}{1-n}\frac{dv}{dx} + P(x)v = Q(x)$$
Linear in $v$: $\frac{dv}{dx} + (1-n)P(x)v = (1-n)Q(x)$

---

## 2. Second-Order Linear Equations

### 2.1 Homogeneous with Constant Coefficients
**Form:** $ay'' + by' + cy = 0$

**Auxiliary (Characteristic) Equation:**
$$am^2 + bm + c = 0$$

**Cases for Roots:**

| Roots | Complementary Function $y_c$ |
|-------|------------------------------|
| Real, distinct $m_1, m_2$ | $y_c = Ae^{m_1 x} + Be^{m_2 x}$ |
| Real, repeated $m$ | $y_c = (Ax + B)e^{mx}$ |
| Complex $\alpha \pm i\beta$ | $y_c = e^{\alpha x}(A\cos\beta x + B\sin\beta x)$ |

**Derivation (Ansatz method):**
Assume $y = e^{mx}$. Then $y' = me^{mx}$, $y'' = m^2e^{mx}$.
Substitute: $am^2e^{mx} + bme^{mx} + ce^{mx} = 0 \Rightarrow (am^2 + bm + c)e^{mx} = 0$.
Since $e^{mx} \neq 0$, $am^2 + bm + c = 0$.

**Proof of Linear Independence (Wronskian):**
For $y_1 = e^{m_1x}, y_2 = e^{m_2x}$ ($m_1 \neq m_2$):
$$W = \begin{vmatrix} e^{m_1x} & e^{m_2x} \\ m_1e^{m_1x} & m_2e^{m_2x} \end{vmatrix} = (m_2 - m_1)e^{(m_1+m_2)x} \neq 0$$
For repeated root: $y_1 = e^{mx}, y_2 = xe^{mx}$:
$$W = \begin{vmatrix} e^{mx} & xe^{mx} \\ me^{mx} & e^{mx}(1+mx) \end{vmatrix} = e^{2mx} \neq 0$$
For complex: $y_1 = e^{\alpha x}\cos\beta x, y_2 = e^{\alpha x}\sin\beta x$:
$$W = \beta e^{2\alpha x} \neq 0$$

---

### 2.2 Non-Homogeneous Equations
**Form:** $ay'' + by' + cy = f(x)$
**General Solution:** $y = y_c + y_p$

#### Method of Undetermined Coefficients
Assume $y_p$ form based on $f(x)$:

| $f(x)$ | Trial $y_p$ |
|--------|-------------|
| $P_n(x)$ (polynomial deg $n$) | $Q_n(x)$ |
| $e^{kx}$ | $Ae^{kx}$ |
| $\sin kx$ or $\cos kx$ | $A\sin kx + B\cos kx$ |
| $P_n(x)e^{kx}$ | $Q_n(x)e^{kx}$ |
| $P_n(x)\sin kx$ or $\cos kx$ | $Q_n(x)\sin kx + R_n(x)\cos kx$ |

**Adjustment Rule:** If any term in trial $y_p$ appears in $y_c$, multiply by $x$ (or $x^2$ if repeated root).

**Derivation:** Substitute $y_p$ into ODE, equate coefficients.

---

### 2.3 Variation of Parameters (General Method)
**For:** $y'' + P(x)y' + Q(x)y = R(x)$ with known $y_1, y_2$ (solutions of homogeneous)

**Assume:** $y_p = u_1(x)y_1 + u_2(x)y_2$

**Conditions:**
$$u_1'y_1 + u_2'y_2 = 0$$
$$u_1'y_1' + u_2'y_2' = R(x)$$

**Solve for $u_1', u_2'$:**
$$W = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} = y_1y_2' - y_2y_1' \quad \text{(Wronskian)}$$
$$u_1' = -\frac{y_2 R}{W}, \quad u_2' = \frac{y_1 R}{W}$$
$$u_1 = -\int \frac{y_2 R}{W} dx, \quad u_2 = \int \frac{y_1 R}{W} dx$$

**Derivation of Conditions:**
$y_p' = u_1'y_1 + u_1y_1' + u_2'y_2 + u_2y_2'$
Set $u_1'y_1 + u_2'y_2 = 0$ (simplifies $y_p'$ to $u_1y_1' + u_2y_2'$)
Then $y_p'' = u_1'y_1' + u_1y_1'' + u_2'y_2' + u_2y_2''$
Substitute into ODE, use $y_1, y_2$ satisfy homogeneous, get $u_1'y_1' + u_2'y_2' = R$.

## 3. Higher-Order Linear Equations

### 3.1 $n$-th Order Constant Coefficient
$$a_n y^{(n)} + a_{n-1} y^{(n-1)} + \cdots + a_1 y' + a_0 y = 0$$

**Auxiliary Equation:**
$$a_n m^n + a_{n-1} m^{n-1} + \cdots + a_1 m + a_0 = 0$$

**General Solution:** Sum of terms corresponding to each root (real: $e^{mx}$, repeated: $x^k e^{mx}$, complex: $e^{\alpha x}\cos\beta x, e^{\alpha x}\sin\beta x$).

---

## 4. Existence and Uniqueness Theorems

### 4.1 First-Order IVP (Picard-Lindelöf)
**Theorem:** For $y' = f(x,y), y(x_0) = y_0$:
If $f$ and $\frac{\partial f}{\partial y}$ continuous on rectangle $R$ containing $(x_0, y_0)$, then $\exists$ unique solution on some interval $|x - x_0| \le h$.

**Proof Sketch (Picard Iteration):**
$$\phi_0(x) = y_0$$
$$\phi_{n+1}(x) = y_0 + \int_{x_0}^x f(t, \phi_n(t)) dt$$
Show $\phi_n$ converges uniformly to solution via contraction mapping (Lipschitz condition on $f$).

### 4.2 $n$-th Order Linear IVP
**Theorem:** For $y^{(n)} + a_{n-1}(x)y^{(n-1)} + \cdots + a_0(x)y = g(x)$ with continuous coefficients on $I$, and initial conditions at $x_0 \in I$:
Unique solution exists on entire interval $I$.

---

## 5. Wronskian and Linear Independence

### 5.1 Wronskian Definition
For $y_1, y_2, \dots, y_n$:
$$W(y_1, \dots, y_n)(x) = \det \begin{pmatrix}
y_1 & y_2 & \cdots & y_n \\
y_1' & y_2' & \cdots & y_n' \\
\vdots & \vdots & \ddots & \vdots \\
y_1^{(n-1)} & y_2^{(n-1)} & \cdots & y_n^{(n-1)}
\end{pmatrix}$$

### 5.2 Abel's Identity
For $y'' + P(x)y' + Q(x)y = 0$:
$$W(x) = W(x_0) \exp\left(-\int_{x_0}^x P(t) dt\right)$$

**Proof:** Let $W = y_1y_2' - y_2y_1'$.
$W' = y_1y_2'' - y_2y_1'' = y_1(-Py_2' - Qy_2) - y_2(-Py_1' - Qy_1) = -P(y_1y_2' - y_2y_1') = -PW$.
Solve: $W' + PW = 0 \Rightarrow W = Ce^{-\int P}$.

### 5.3 Linear Independence Criterion
For solutions of linear ODE:
- $W(x_0) \neq 0$ at some point $\iff$ linearly independent on $I$
- $W \equiv 0 \iff$ linearly dependent

## 6. Reduction of Order

**Given:** One solution $y_1(x)$ of $y'' + P(x)y' + Q(x)y = 0$

**Find:** Second solution $y_2 = v(x)y_1$

**Derivation:**
$y_2 = vy_1$, $y_2' = v'y_1 + vy_1'$, $y_2'' = v''y_1 + 2v'y_1' + vy_1''$
Substitute:
$$v''y_1 + 2v'y_1' + vy_1'' + P(v'y_1 + vy_1') + Qvy_1 = 0$$
Since $y_1$ is solution: $y_1'' + Py_1' + Qy_1 = 0$, terms with $v$ cancel.
$$y_1 v'' + (2y_1' + Py_1)v' = 0$$
Let $w = v'$:
$$w' + \left(2\frac{y_1'}{y_1} + P\right)w = 0$$
Solve: $w = \frac{C}{y_1^2} e^{-\int P}$
Then $v = \int w$, $y_2 = y_1 \int \frac{e^{-\int P}}{y_1^2} dx$

## 7. Cauchy-Euler (Equidimensional) Equation
**Form:** $ax^2y'' + bxy' + cy = 0$

**Substitution:** $x = e^t$ (or $y = x^m$)

**Using $y = x^m$:**
$y' = mx^{m-1}$, $y'' = m(m-1)x^{m-2}$
$$ax^2 m(m-1)x^{m-2} + bx mx^{m-1} + cx^m = 0$$
$$[am(m-1) + bm + c]x^m = 0$$
**Auxiliary Equation:** $am^2 + (b-a)m + c = 0$

**Roots $\to$ Solution:**
| Roots | General Solution |
|-------|------------------|
| $m_1 \neq m_2$ real | $y = Ax^{m_1} + Bx^{m_2}$ |
| $m$ repeated | $y = x^m(A + B\ln x)$ |
| $\alpha \pm i\beta$ | $y = x^\alpha [A\cos(\beta\ln x) + B\sin(\beta\ln x)]$ |

---

## 8. Laplace Transform Method (for IVPs)

### 8.1 Definition
$$\mathcal{L}\{f(t)\} = F(s) = \int_0^\infty e^{-st} f(t) dt$$

### 8.2 Key Properties
| $f(t)$ | $\mathcal{L}\{f(t)\}$ |
|--------|----------------------|
| $1$ | $\frac{1}{s}$ |
| $t^n$ | $\frac{n!}{s^{n+1}}$ |
| $e^{at}$ | $\frac{1}{s-a}$ |
| $\sin at$ | $\frac{a}{s^2+a^2}$ |
| $\cos at$ | $\frac{s}{s^2+a^2}$ |
| $f'(t)$ | $sF(s) - f(0)$ |
| $f''(t)$ | $s^2F(s) - sf(0) - f'(0)$ |

### 8.3 Solving IVP
1. Take Laplace transform of ODE
2. Use initial conditions
3. Solve for $Y(s)$
4. Inverse Laplace: $y(t) = \mathcal{L}^{-1}\{Y(s)\}$

---

## 9. Systems of Linear ODEs

### 9.1 Matrix Form
$$\mathbf{x}' = A\mathbf{x}$$
where $\mathbf{x} = \begin{pmatrix} x_1 \\ \vdots \\ x_n \end{pmatrix}$

### 9.2 Solution via Eigenvalues
Assume $\mathbf{x} = \mathbf{v}e^{\lambda t}$:
$$\lambda \mathbf{v} = A\mathbf{v} \Rightarrow (A - \lambda I)\mathbf{v} = 0$$
Eigenvalues $\lambda_i$, eigenvectors $\mathbf{v}_i$.
General solution: $\mathbf{x} = \sum c_i \mathbf{v}_i e^{\lambda_i t}$

## 10. Summary: Solution Methods Decision Tree

```
1st Order:
  ├── Separable? → ∫ 1/h(y) dy = ∫ g(x) dx
  ├── Linear? → μ = e^∫P, y = (1/μ)∫μQ
  ├── Homogeneous? → v = y/x
  ├── Exact? (M_y = N_x) → ψ(x,y) = C
  ├── Bernoulli? (y^n) → v = y^(1-n)
  └── Else: Check integrating factor

2nd Order Linear:
  ├── Constant coeff? → Auxiliary eq → CF
  │    └── Non-homog? → f(x) form → Undetermined coeffs
  ├── Cauchy-Euler? → x^m or x=e^t
  ├── One solution known? → Reduction of order
  ├── Variable coeff? → Series solution / Special functions
  └── System? → Matrix eigenvals
```
