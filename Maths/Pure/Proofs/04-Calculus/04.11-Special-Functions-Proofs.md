# Special Functions â€” Full Derivations

## 1. Gamma Function

### 1.1 Convergence
For $z > 0$:
- Near $0$: $t^{z-1}e^{-t} \sim t^{z-1}$, integrable if $z-1 > -1 \Rightarrow z > 0$
- Near $\infty$: $e^{-t}$ dominates, convergent for all $z$

### 1.2 Recurrence Relation
$$\Gamma(z+1) = \int_0^\infty t^z e^{-t} dt$$
Integration by parts: $u = t^z$, $dv = e^{-t}dt$
$$= \left[-t^z e^{-t}\right]_0^\infty + z \int_0^\infty t^{z-1} e^{-t} dt = z \Gamma(z)$$
Boundary term vanishes: $\lim_{t\to\infty} t^z e^{-t} = 0$, $\lim_{t\to 0} t^z = 0$ for $z > 0$.

### 1.3 Integer Values
$\Gamma(1) = \int_0^\infty e^{-t} dt = 1$
By recurrence: $\Gamma(n) = (n-1)\Gamma(n-1) = \cdots = (n-1)!$

### 1.4 $\Gamma(1/2) = \sqrt{\pi}$
$$\Gamma\left(\frac{1}{2}\right)^2 = \int_0^\infty \int_0^\infty x^{-1/2} y^{-1/2} e^{-(x+y)} dx\,dy$$
Substitute $x = r\cos^2\theta, y = r\sin^2\theta$ (or use polar):
$$\Gamma\left(\frac{1}{2}\right)^2 = 4 \int_0^\infty e^{-r^2} r dr \int_0^{\pi/2} d\theta = \pi$$
Thus $\Gamma(1/2) = \sqrt{\pi}$ (positive since $\Gamma > 0$ for $z>0$).

### 1.5 Half-Integer Values
$$\Gamma\left(n+\frac{1}{2}\right) = \frac{(2n)!}{4^n n!}\sqrt{\pi}$$
**Proof:** By induction using $\Gamma(z+1) = z\Gamma(z)$ and $\Gamma(1/2) = \sqrt{\pi}$.

## 2. Beta Function

### 2.1 Convergence
$\int_0^1 t^{x-1}(1-t)^{y-1} dt$ converges for $\text{Re}(x), \text{Re}(y) > 0$.

### 2.2 Symmetry
$$B(x,y) = \int_0^1 t^{x-1}(1-t)^{y-1} dt$$
Substitute $u = 1-t$: $= \int_0^1 (1-u)^{x-1} u^{y-1} du = B(y,x)$

### 2.3 Relation to Gamma
$$B(x,y) = \frac{\Gamma(x)\Gamma(y)}{\Gamma(x+y)}$$

**Proof:**
$$\Gamma(x)\Gamma(y) = \int_0^\infty \int_0^\infty u^{x-1} v^{y-1} e^{-(u+v)} du\,dv$$
Change variables: $u = st, v = s(1-t)$ where $s \in [0,\infty), t \in [0,1]$
Jacobian: $\left|\frac{\partial(u,v)}{\partial(s,t)}\right| = s$
$$\Gamma(x)\Gamma(y) = \int_0^1 t^{x-1}(1-t)^{y-1} dt \int_0^\infty s^{x+y-1} e^{-s} ds = B(x,y) \Gamma(x+y)$$

## 3. Legendre Duplication Formula

### 3.1 Statement
$$\Gamma(z)\Gamma\left(z+\frac{1}{2}\right) = 2^{1-2z}\sqrt{\pi}\,\Gamma(2z)$$

### 3.2 Proof
Start with Beta function:
$$B(z,z) = \frac{\Gamma(z)^2}{\Gamma(2z)}$$
But also:
$$B(z,z) = \int_0^1 t^{z-1}(1-t)^{z-1} dt = 2\int_0^{1/2} t^{z-1}(1-t)^{z-1} dt$$
Substitute $u = 4t(1-t)$, $t = \frac{1}{2}(1-\sqrt{1-u})$, $dt = \frac{du}{4\sqrt{1-u}}$
After algebra:
$$B(z,z) = 2^{1-2z} B\left(\frac{1}{2}, z\right) = 2^{1-2z} \frac{\Gamma(1/2)\Gamma(z)}{\Gamma(z+1/2)} = 2^{1-2z} \frac{\sqrt{\pi}\Gamma(z)}{\Gamma(z+1/2)}$$
Equate the two expressions for $B(z,z)$:
$$\frac{\Gamma(z)^2}{\Gamma(2z)} = 2^{1-2z} \frac{\sqrt{\pi}\Gamma(z)}{\Gamma(z+1/2)}$$
Result follows.

## 4. Euler's Reflection Formula

### 4.1 Statement
$$\Gamma(z)\Gamma(1-z) = \frac{\pi}{\sin(\pi z)}, \quad z \notin \mathbb{Z}$$

### 4.2 Proof (Using Beta Function)
$$B(z,1-z) = \frac{\Gamma(z)\Gamma(1-z)}{\Gamma(1)} = \Gamma(z)\Gamma(1-z)$$
But also:
$$B(z,1-z) = \int_0^1 t^{z-1}(1-t)^{-z} dt$$
Substitute $t = \frac{u}{1+u}$, $dt = \frac{du}{(1+u)^2}$:
$$= \int_0^\infty u^{z-1}(1+u)^{-1} du$$
This is a known integral: $\int_0^\infty \frac{u^{z-1}}{1+u} du = \frac{\pi}{\sin(\pi z)}$ for $0 < \text{Re}(z) < 1$.
**Proof of integral:** Use contour integration or Beta function with analytic continuation.

## 5. Error Function

### 5.1 Gaussian Integral
$$I = \int_{-\infty}^\infty e^{-x^2} dx$$
$I^2 = \int_{-\infty}^\infty \int_{-\infty}^\infty e^{-(x^2+y^2)} dx\,dy = \int_0^{2\pi} \int_0^\infty e^{-r^2} r dr d\theta = 2\pi \cdot \frac{1}{2} = \pi$
Thus $I = \sqrt{\pi}$.

### 5.2 Error Function Definition
$$\text{erf}(x) = \frac{2}{\sqrt{\pi}} \int_0^x e^{-t^2} dt$$

### 5.3 Properties
- $\text{erf}(-x) = -\text{erf}(x)$ (odd)
- $\text{erf}(0) = 0$
- $\lim_{x\to\infty} \text{erf}(x) = 1$
- Derivative: $\frac{d}{dx}\text{erf}(x) = \frac{2}{\sqrt{\pi}} e^{-x^2}$

### 5.4 Series Expansion
$$e^{-t^2} = \sum_{n=0}^\infty \frac{(-1)^n t^{2n}}{n!}$$
$$\text{erf}(x) = \frac{2}{\sqrt{\pi}} \sum_{n=0}^\infty \frac{(-1)^n x^{2n+1}}{n!(2n+1)}$$

## 6. Elliptic Integrals

### 6.1 Complete Elliptic Integral of First Kind
$$K(k) = \int_0^{\pi/2} \frac{d\theta}{\sqrt{1 - k^2 \sin^2 \theta}}$$

### 6.2 Complete Elliptic Integral of Second Kind
$$E(k) = \int_0^{\pi/2} \sqrt{1 - k^2 \sin^2 \theta} \, d\theta$$

### 6.3 Derivatives
$$\frac{dK}{dk} = \frac{E(k) - (1-k^2)K(k)}{k(1-k^2)}$$
$$\frac{dE}{dk} = \frac{E(k) - K(k)}{k}$$

**Proof:** Differentiate under integral sign, use integration by parts.

### 6.4 Relationship
$$E(k) = K(k) - \frac{1}{2}k^2 \frac{dK}{dk} \quad \text{(from above)}$$

### 6.5 Special Values
- $K(0) = E(0) = \pi/2$
- $K(1) = \infty$ (logarithmic divergence)
- $E(1) = 1$
- $K(k') = E(k)/\sqrt{1-k^2} + \cdots$ (complementary modulus $k' = \sqrt{1-k^2}$)

## 7. Applications in Integration

### 7.1 $\int_0^\infty x^{n-1} e^{-ax} dx$
Substitute $u = ax$: $dx = du/a$, $x = u/a$
$$= \int_0^\infty \left(\frac{u}{a}\right)^{n-1} e^{-u} \frac{du}{a} = \frac{1}{a^n} \int_0^\infty u^{n-1} e^{-u} du = \frac{\Gamma(n)}{a^n}$$

### 7.2 $\int_0^1 x^{p-1}(1-x)^{q-1} dx$
Directly $B(p,q) = \frac{\Gamma(p)\Gamma(q)}{\Gamma(p+q)}$

### 7.3 $\int_0^{\pi/2} \sin^{2m-1}\theta \cos^{2n-1}\theta d\theta$
Substitute $t = \sin^2\theta$, $dt = 2\sin\theta\cos\theta d\theta$
$$\int_0^1 t^{m-1}(1-t)^{n-1} \frac{dt}{2} = \frac{1}{2} B(m,n) = \frac{\Gamma(m)\Gamma(n)}{2\Gamma(m+n)}$$

### 7.4 $\int_0^\infty \frac{x^{p-1}}{1+x} dx$
Substitute $u = \frac{x}{1+x}$, $x = \frac{u}{1-u}$, $dx = \frac{du}{(1-u)^2}$
$$= \int_0^1 u^{p-1}(1-u)^{-p} du = B(p, 1-p) = \frac{\Gamma(p)\Gamma(1-p)}{\Gamma(1)} = \frac{\pi}{\sin(\pi p)}$$
using reflection formula.

### 7.5 Wallis' Integrals
$$I_n = \int_0^{\pi/2} \sin^n x dx = \int_0^{\pi/2} \cos^n x dx$$
**Reduction Formula:** $I_n = \frac{n-1}{n} I_{n-2}$ for $n \ge 2$
**Proof:** $I_n = \int \sin^{n-1}x \sin x dx = \left[-\sin^{n-1}x \cos x\right] + (n-1)\int \sin^{n-2}x \cos^2 x dx$
$= (n-1)\int \sin^{n-2}x (1-\sin^2 x) dx = (n-1)(I_{n-2} - I_n)$
Thus $n I_n = (n-1) I_{n-2}$.

**Explicit Form:**
- $I_{2n} = \frac{(2n-1)!!}{(2n)!!} \cdot \frac{\pi}{2} = \frac{(2n)!}{4^n (n!)^2} \cdot \frac{\pi}{2}$
- $I_{2n+1} = \frac{(2n)!!}{(2n+1)!!} = \frac{4^n (n!)^2}{(2n+1)!}$

## 8. Asymptotic Expansions

### 8.1 Stirling's Formula
$$\Gamma(z) \sim \sqrt{2\pi} z^{z-1/2} e^{-z} \left(1 + \frac{1}{12z} + \frac{1}{288z^2} - \cdots\right)$$

**Proof Sketch:**
$$\ln \Gamma(z) = \int_0^\infty \left( \frac{e^{-t} - e^{-zt}}{1-e^{-t}} \right) \frac{dt}{t}$$
Use Euler-Maclaurin summation on $\ln \Gamma(z) = \sum_{k=1}^{z-1} \ln k$ for integer $z$, then analytic continuation.

### 8.2 Error Function (Large $x$)
$$\text{erfc}(x) = \frac{2}{\sqrt{\pi}} \int_x^\infty e^{-t^2} dt \sim \frac{e^{-x^2}}{x\sqrt{\pi}} \left(1 - \frac{1}{2x^2} + \frac{3}{4x^4} - \cdots\right)$$
**Proof:** Integrate by parts repeatedly:
$$\int_x^\infty e^{-t^2} dt = \left[-\frac{1}{2t} e^{-t^2}\right]_x^\infty - \int_x^\infty \frac{1}{2t^2} e^{-t^2} dt = \frac{e^{-x^2}}{2x} - \frac{1}{2}\int_x^\infty \frac{e^{-t^2}}{t^2} dt$$
Continue iteratively.

## 9. Exponential Integral

### 9.1 Definition
$$E_1(x) = \int_x^\infty \frac{e^{-t}}{t} dt = -\text{Ei}(-x) \quad (x > 0)$$
$$E_n(x) = \int_1^\infty \frac{e^{-xt}}{t^n} dt$$

### 9.2 Recurrence
$$E_{n+1}(x) = \frac{1}{n}\left(e^{-x} - x E_n(x)\right)$$
**Proof:** Integration by parts on $\int_1^\infty e^{-xt} t^{-n-1} dt$.

### 9.3 Series
$$E_1(x) = -\gamma - \ln x - \sum_{n=1}^\infty \frac{(-x)^n}{n \cdot n!}$$
**Proof:** Expand $e^{-t}$, integrate term by term, handle $t^{-1}$ carefully.

## 10. Riemann Zeta Function

### 10.1 Integral Representation
$$\zeta(s) = \frac{1}{\Gamma(s)} \int_0^\infty \frac{t^{s-1}}{e^t - 1} dt$$
**Proof:** Use $\frac{1}{e^t-1} = \sum_{n=1}^\infty e^{-nt}$, integrate term by term:
$$\int_0^\infty t^{s-1} e^{-nt} dt = \frac{\Gamma(s)}{n^s}$$
Sum over $n$: $\Gamma(s) \sum_{n=1}^\infty \frac{1}{n^s} = \Gamma(s)\zeta(s)$.

### 10.2 Special Values
$$\zeta(2n) = \frac{(-1)^{n+1} B_{2n} (2\pi)^{2n}}{2(2n)!}$$
where $B_{2n}$ are Bernoulli numbers ($B_2 = 1/6, B_4 = -1/30, \dots$)
